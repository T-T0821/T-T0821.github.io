## 今日の動向

AIコーディングエージェントの運用が進み、その品質保証・可観測性・説明責任が主要な論点になっています。Google の AQuA や Netflix のナレッジグラフは本番エージェントの診断・運用に取り組む事例で、Antigravity のリモートエージェントはエージェントのクラウド実行を進めています。また、Compute Engine API の日付ベースバージョニングや AWS エミュレータなど、API 運用と開発環境の基盤整備に関する発表もありました。論文では、エージェントが生成した変更のレビュー、テスト、技術的負債、CI/CD 設計パターンといった実務寄りのテーマが目立ちます。

### Google が本番 AI エージェントの失敗を診断する AQuA をオープンソース化

[Google Open Sources Ambient Quality Agent (AQuA) to Diagnose Production AI Agent Failures](https://www.infoq.com/news/2026/11/google-ambient-agent-prod/?utm_campaign=infoq_content&utm_source=infoq&utm_medium=feed&utm_term=global) ・ InfoQ ・ 2026-11-13

Google は、本番の AI エージェントのセッションを分析し、繰り返し起きる失敗パターンを検証して、デプロイ済みソースのスナップショットに照らして根本原因を調べる参照実装 AQuA を公開しました。32 セッションのリプレイでは、プロンプト変更後に座席選択のバイパスが 15 セッションから 2 に、食事の好みの欠落が 7 から 0 に減ったと報告されています。

**影響・使いどころ:** 本番エージェントの品質改善を、ログ分析と原因調査に基づく反復作業として設計する際の参考になります。

### Google Cloud が Compute Engine API を不変の日付ベースバージョンへ

[Google Cloud Moves the Compute Engine API to Immutable Date-Based Versions](https://www.infoq.com/news/2026/11/compute-engine-api-versioning/?utm_campaign=infoq_content&utm_source=infoq&utm_medium=feed&utm_term=global) ・ InfoQ ・ 2026-11-14

Compute Engine API の日付ベースのバージョニングが一般提供となり、可変だった /v1 に加えて 2026-09-01 のような四半期ごとの不変スナップショットを、ヘッダーまたはクエリパラメータでリクエスト単位に選べるようになりました。新バージョンではデフォルト、エラー形式、IAM チェックが変わり得ますが、/v1 の利用者には影響しません。

**影響・使いどころ:** 自社 API のバージョニング方針を検討する際に、Azure Resource Manager や Stripe と並ぶ参考例になります。
