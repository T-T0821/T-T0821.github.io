# ICLR 2022

🤖 AI・機械学習全般 ・ [ICLR の年ごとの流れ](./) ・ [公式サイト ↗](https://iclr.cc/)

::: info この回のまとめ
3年連続でオンライン開催となり、投稿約3,400本・採択1,095本（約32%）でした。最優秀論文は7本で、グラフニューラルネットワークの表現力と近似性能の理論、差分プライバシー下でのハイパーパラメータ調整、拡散モデルの逆過程の分散を解析的に求める Analytic-DPM、ニューラルコラプス、ブートストラップ型メタ学習などが選ばれました。佳作には、長い系列を効率よく扱う構造化状態空間モデル S4 が入り、のちの Mamba などにつながる「Transformer 以外の系列モデル」研究の起点になりました。
:::

- **日程**: 2022年4月25日〜29日
- **開催地**: オンライン開催
- **規模**: 投稿 3,328 本 ／ 採択 1,095 本 ／ 採択率 32.9%（Wikipedia では投稿3,422本・採択率32.0%）
- **参加者**: 約5,200人（81か国）

**📝 注目論文（1 本）**

1. [S4：構造化状態空間による長い系列の効率的なモデリング](#paper-1)

## 🔭 この回の主なテーマ

- GNN の表現力: Weisfeiler-Lehman 検定との関係など、グラフ学習の理論が最優秀論文に
- 長系列モデリング: 状態空間モデル S4 が Long Range Arena で大幅な改善
- 拡散モデルの高速化: 逆過程の最適分散を解析的に求め、少ないステップで高品質な生成
- プライバシー: 差分プライバシーを保ったままハイパーパラメータを調整する方法

::: tip 💡 技術動向への示唆
- S4 に始まる状態空間モデルの系譜は、長い文脈を低コストで扱う LLM アーキテクチャ（Mamba やハイブリッド型）として実用化が進んでいる
- 拡散モデルの生成ステップ削減はこの頃から本格化し、画像生成のリアルタイム化につながった
:::

## 📝 注目論文

### 1. S4：構造化状態空間による長い系列の効率的なモデリング {#paper-1}

🏆 Honorable Mention ・ Albert Gu, Karan Goel, Christopher Ré ・ [論文を読む ↗](https://arxiv.org/abs/2111.00396)

<small>原題: Efficiently Modeling Long Sequences with Structured State Spaces</small>

制御工学の状態空間モデルを深層学習に取り入れ、行列の構造を工夫して高速に計算できるようにしました。数万ステップの長い系列で Transformer を大きく上回り、Mamba など後続の状態空間モデルの出発点になりました。

::: info 📝 落合フォーマット

**どんなもの？**

長距離依存（LRD）を持つ系列データを効率的に扱うため、状態空間モデル（SSM）を深層学習で実用的に計算できるようにした Structured State Space sequence model（S4）を提案した研究。HiPPO 行列で初期化した SSM の理論的な強みを保ちつつ、従来の計算・メモリ負荷を大幅に下げた。画像・音声・言語・時系列など幅広いタスクを単一モデルで扱える汎用系列モデルを目指している。

**先行研究と比べてどこがすごい？**

先行の LSSL は HiPPO 行列を使うことで LRD に強い一方、状態次元 N・系列長 L に対し O(N^2 L) の計算と O(NL) のメモリを要し、提案されていた高速アルゴリズムも数値的に不安定で実用的でなかった。S4 は HiPPO 行列が「正規行列＋低ランク（NPLR）」で表せることに着目し、安定に計算できる O~(N+L) の計算量と O(N+L) のメモリを実現した。LSSL と比べて最大 30 倍高速、メモリは 400 倍少ないと報告している。

**技術や手法のキモはどこ？**

状態行列 A を Λ − PQ* の対角＋低ランク（DPLR）形式に変換し、畳み込みカーネル K を直接求める代わりに、その切り詰め生成関数をルート・オブ・ユニティ上で評価して逆 FFT で復元する。生成関数は行列の冪ではなく逆行列（レゾルベント）を含む形になるため、低ランク部分は Woodbury の恒等式で補正でき、対角部分は数値的に安定な Cauchy カーネル計算に帰着する。学習時は畳み込み表現、推論時は 1 ステップ O(N) の再帰表現と使い分ける。各層は H 個の独立な SSM と位置ごとの線形層、非線形活性化で構成される。

**どうやって有効だと検証した？**

Long Range Arena の全タスクで SoTA を達成し、平均 80.48%（ベースラインはいずれも 60% 未満）、どのモデルも解けなかった長さ 16384 の Path-X で 88% を達成した。生音声分類（長さ 16000）では 98.3% で、MFCC を使うベースラインも上回り、0.5 倍の周波数でも再学習なしで 96.3% を維持した。さらに系列 CIFAR-10 で 91% 超、CIFAR-10 密度推定で 2.85 bpd、WikiText-103 で Transformer との差を perplexity 0.8 以内（20.95 vs 20.51）に縮め、生成速度は約 60 倍、時系列予測では Informer を 50 設定中 40 設定で上回った。アブレーションでは、性能向上の主因は NPLR 構造そのものではなく HiPPO 初期化であることを示した。

**議論はある？**

本文によれば、後続研究で A の固有値が右半平面にある場合に数値不安定が生じうることが分かり、Λ − PQ* を Λ − PP* に変える修正が提案されている。また現在の実装は理論上最良の Cauchy カーネル算法ではなく素朴な O(NL) 算法（pykeops 利用）であり、専用 CUDA 実装による高速化の余地がある。言語モデリングでは Transformer との差がなお残る。

**次に読むべき論文は？**

- HiPPO: Recurrent Memory with Optimal Polynomial Projections：S4 が初期化と NPLR 分解に使う HiPPO 行列の理論的な背景を理解するため。
- Combining Recurrent, Convolutional, and Continuous-time Models with the Structured Learnable Linear State Space Layer：S4 が計算上のボトルネックを解消した直接の先行研究である LSSL を把握するため。
- On the Parameterization and Initialization of Diagonal State Space Models：S4 を対角化へ簡略化した後続研究で、実装・理解がより容易になるため。

:::
