# ICLR

🤖 [AI・機械学習全般](../#ml) ・ International Conference on Learning Representations ・ 毎年4〜5月 ・ [公式サイト ↗](https://iclr.cc/)

::: info 2020年からの流れ
ICLR は表現学習（深層学習）に特化した会議で、OpenReview による公開査読が特徴です。2020〜2022年はオンライン開催で、スコアベース生成モデル（2021年）や状態空間モデル S4（2022年）など、その後の主流技術の基礎が評価されました。2023年にアフリカ初開催（キガリ）を実現し、2024年以降は ViT の改良、LLM の安全性・ファインチューニング・モデル編集（2025年）、複数ターン会話での LLM の脆さ（2026年）と、基盤モデルを理解し使いこなす研究が中心です。投稿は2020年の約2,600本から2026年の約2万本へ増えました。
:::

## 📅 各回のまとめ

- **ICLR 2027** — 開催前です<br><small>2027年4月26日〜30日 ・ 未発表</small>
- **[ICLR 2026](./2026)** — 投稿約2万本（リオデジャネイロ）。Transformer の簡潔さの理論と「LLM は複数ターンの会話で迷子になる」が最優秀論文に<br><small>2026年4月23日〜27日 ・ ブラジル・リオデジャネイロ</small>
- **[ICLR 2025](./2025)** — 参加者1.1万人（シンガポール）。安全性アラインメントの「浅さ」、LLM のファインチューニング動態、モデル編集が最優秀論文になった回<br><small>2025年4月24日〜28日 ・ シンガポール</small>
- **[ICLR 2024](./2024)** — ウィーン開催。ViT のレジスタトークン、実世界シミュレータ、拡散モデルの汎化理論が最優秀論文になった回<br><small>2024年5月7日〜11日 ・ オーストリア・ウィーン</small>
- **[ICLR 2023](./2023)** — アフリカ初の主要 ML 会議（キガリ）。テキストから3Dを作る DreamFusion が最優秀論文に選ばれた回<br><small>2023年5月1日〜5日 ・ ルワンダ・キガリ</small>
- **[ICLR 2022](./2022)** — 3年連続オンライン開催。長い系列を扱う状態空間モデル S4 や GNN の表現力など「Transformer の次」を探る研究が並んだ回<br><small>2022年4月25日〜29日 ・ オンライン開催</small>
- **[ICLR 2021](./2021)** — オンライン開催。スコアベース生成モデル（SDE）など、のちの拡散モデルブームの基礎が最優秀論文に選ばれた回<br><small>2021年5月3日〜7日 ・ オンライン開催</small>
- **[ICLR 2020](./2020)** — アフリカ初開催の予定がコロナ禍で主要 ML 会議初の完全オンライン開催に。最優秀論文賞は設けられなかった回<br><small>2020年4月26日〜30日 ・ オンライン開催（当初予定はアディスアベバ）</small>

## 🔭 年ごとのテーマの移り変わり

- 2020: 完全オンライン開催、最優秀論文賞なし
- 2021: スコアベース生成モデル（SDE）、グラフネットワークによる物理シミュレーション
- 2022: GNN の表現力、状態空間モデル S4、拡散モデルの高速化
- 2023: DreamFusion（テキストから3D）、汎用的な密な予測
- 2024: ViT のレジスタ、実世界シミュレータ、拡散モデルの汎化理論
- 2025: 浅い安全性アラインメント、ファインチューニングの学習動態、モデル編集
- 2026: Transformer の簡潔さの理論、複数ターン会話での LLM の性能低下、Muon 最適化

::: tip 💡 技術動向への示唆
- ICLR で評価された基礎技術（拡散モデル・状態空間モデル）は2〜3年後に実用化されており、ICLR の受賞論文は中期的な技術動向を読む先行指標になる
- 2025〜2026年は LLM の使い方そのもの（微調整・安全性・対話）の限界を示す研究が最高賞を得ており、実務での LLM 活用設計に直結する知見が増えている
:::
