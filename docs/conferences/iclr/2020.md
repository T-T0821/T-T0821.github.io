# ICLR 2020

🤖 AI・機械学習全般 ・ [ICLR の年ごとの流れ](./) ・ [公式サイト ↗](https://iclr.cc/)

::: info この回のまとめ
エチオピアのアディスアベバでアフリカ初の開催が予定されていましたが、COVID-19 のため3月に中止され、主要な機械学習会議として初めて完全オンラインで開催されました。投稿2,594本・採択687本（約26.5%）で、参加者は約5,600人と前年の現地参加（約2,700人）の倍以上に増えました。この年は最優秀論文賞が設けられていません。録画発表を時差に合わせて2回流す、論文推薦に機械学習を使うなど、オンライン学会の運営方法を確立した回として知られます。
:::

- **日程**: 2020年4月26日〜30日
- **開催地**: オンライン開催（当初予定はアディスアベバ）
- **規模**: 投稿 2,594 本 ／ 採択 687 本 ／ 採択率 26.5%
- **参加者**: 約5,600人（約90か国）

**📝 注目論文（3 本）**

1. [ALBERT: 言語表現の自己教師あり学習のための軽量版BERT](#paper-1)
2. [ELECTRA: 生成器ではなく識別器としてテキストエンコーダを事前学習する](#paper-2)
3. [BERTScore: BERTを用いたテキスト生成の評価](#paper-3)

## 🔭 この回の主なテーマ

- オンライン学会の設計: 録画発表・時差対応・バーチャル交流（ソーシャル29件）の仕組みを構築
- 運営への機械学習の活用: 査読スコアの補正、論文サムネイル生成、論文・参加者の推薦
- 表現学習の中心テーマ: 事前学習言語モデルの効率化（ALBERT・ELECTRA など）が多く発表された時期

::: tip 💡 技術動向への示唆
- 国際会議のオンライン化で、渡航が難しい地域の研究者も参加できるようになり、AI 研究のグローバル化が加速した
- 録画・論文の即時公開が当たり前になり、企業のエンジニアが最新研究に触れる障壁が下がった
:::

### 1. ALBERT: 言語表現の自己教師あり学習のための軽量版BERT {#paper-1}

📈 被引用数上位（Paper Digest の集計で同年1位） ・ Zhenzhong Lan, Mingda Chen, Sebastian Goodman, Kevin Gimpel ほか ・ [論文を読む ↗](https://arxiv.org/abs/1909.11942)

<small>原題: ALBERT: A Lite BERT for Self-supervised Learning of Language Representations</small>

BERTの大規模化で問題となるメモリ制約と学習時間の増大に対し、語彙埋め込みサイズと隠れ層サイズを切り離す因子分解と全層でのパラメータ共有でパラメータ数を削減し、さらに談話の一貫性に集中する文順序予測（SOP）損失を導入した研究です。約70%のパラメータ数のALBERT-xxlargeがBERT-largeをSQuAD、MNLI、SST-2、RACEなどで上回り、GLUE 89.4、SQuAD 2.0 test F1 92.2、RACE test 89.4%と当時の最高性能を達成した点が注目されます。ICLR 2020でPaper Digestの集計における同年被引用数1位に選ばれたことも、その影響の大きさを示しています。

::: info 📝 落合フォーマット

**どんなもの？**

BERTの事前学習モデルを大規模化する際に生じるGPU/TPUメモリ制約と学習時間の増大に対処するため、パラメータ数を大幅に削減した軽量アーキテクチャALBERT（A Lite BERT）を提案した研究。さらに文間の一貫性を学習する自己教師あり損失を導入し、GLUE・SQuAD・RACEで当時の最高性能を、BERT-largeより少ないパラメータ数で達成した。

**先行研究と比べてどこがすごい？**

BERTでは語彙埋め込みサイズEと隠れ層サイズHが等しい（E≡H）設計だったが、これを切り離す因子分解と、全層でのパラメータ共有という2つの削減手法を組み合わせた点が新しい。また、XLNetやRoBERTaが効果不安定として除外したNSP損失の代わりに、トピック予測を避けて談話の一貫性に集中する文順序予測（SOP）損失を提案した。

**技術や手法のキモはどこ？**

(1) 因子分解埋め込み：ワンホットベクトルをまず低次元E（128）に射影し、その後に隠れ空間Hへ射影することで、埋め込みパラメータをO(V×H)からO(V×E+E×H)に削減する。(2) 全層パラメータ共有：FFNとアテンションを含む全パラメータを層間で共有し、深さに伴うパラメータ増加を防ぐ。(3) SOP損失：同一文書内の連続する2セグメントを正例、その順序を入れ替えたものを負例として、MLM損失と併用する。最良モデルはALBERT-xxlarge構成（H=4096、12層）で、SOPを併用し、さらにドロップアウトを除去している。

**どうやって有効だと検証した？**

BookCorpus+Wikipediaで事前学習し、GLUE、SQuAD 1.1/2.0、RACEで評価した。約70%のパラメータ数のALBERT-xxlargeは、BERT-largeに対しdev setでSQuAD v1.1 +1.9%、v2.0 +3.1%、MNLI +1.4%、SST-2 +2.2%、RACE +8.4%の改善を示した。SOPはNSPに比べ下流タスクで平均約+1%改善し、最終的にGLUE 89.4、SQuAD 2.0 test F1 92.2、RACE test 89.4%を達成した。

**議論はある？**

ALBERT-xxlargeはパラメータ数こそ少ないが構造が大きく計算量が多いため、BERT-largeに比べ学習が約3倍遅く、sparse attentionやblock attentionなどによる学習・推論の高速化が今後の課題とされている。また、ドロップアウト除去が性能を損なうという現象は他のTransformer系モデルでも成り立つかは未検証で、現行の自己教師あり損失では捉えきれない表現力の要素がある可能性も指摘されている。

**次に読むべき論文は？**

- BERT: Pre-training of Deep Bidirectional Transformers for Language Understanding：ALBERTが改良対象とするベースラインであり、MLMとNSPを含む事前学習の基礎を理解するために必須であるため。
- RoBERTa: A Robustly Optimized BERT Pretraining Approach：NSP除去や学習設定の最適化を扱い、ALBERTが比較・参照する主要な先行研究であるため。
- Universal Transformers：層間パラメータ共有をTransformerで探究した先行研究であり、ALBERTの共有戦略との違いを理解できるため。

:::


### 2. ELECTRA: 生成器ではなく識別器としてテキストエンコーダを事前学習する {#paper-2}

📈 被引用数上位（Paper Digest の集計で同年2位） ・ Kevin Clark, Minh-Thang Luong, Quoc V. Le, Christopher D. Manning ・ [論文を読む ↗](https://arxiv.org/abs/2003.10555)

<small>原題: ELECTRA: Pre-training Text Encoders as Discriminators Rather Than Generators</small>

BERTなどのマスク言語モデルは入力トークンの約15%からしか学習できず計算コストが大きいという問題に対し、小さな生成器が差し替えたトークンを識別器が全トークンについて本物か置換かで判定する「置換トークン検出」という事前学習タスクを提案した研究です。全入力トークンに損失を定義できるため計算効率が高く、ELECTRA-SmallはGLUEで79.9と、同条件のBERT-Small（75.1）やより大きなGPT（78.8）を上回りました。大型モデルでもRoBERTaやXLNetと同等の性能を1/4未満の計算量で達成し、ELECTRA-1.75MはSQuAD 2.0で最高性能を示した点が注目されています。

::: info 📝 落合フォーマット

**どんなもの？**

BERTなどのマスク言語モデル（MLM）事前学習は入力トークンの約15%からしか学習できず計算コストが大きいという問題に対し、「置換トークン検出（replaced token detection）」という新しい事前学習タスクを提案した研究。小さな生成器が差し替えたトークンを、識別器が入力の全トークンについて本物か置換かで判定する。同じモデルサイズ・データ・計算量でBERTを大きく上回り、特に小型モデルで効果が大きい。

**先行研究と比べてどこがすごい？**

MLMが一部のマスク位置だけを予測するのに対し、ELECTRAは全入力トークンに対して損失を定義するため計算効率が高い。また、事前学習時に[MASK]を見せ、ファインチューニング時には見せないというBERTの不一致も解消する。GAN風の構成だが、生成器は敵対的ではなく最尤法で学習する点が特徴である。

**技術や手法のキモはどこ？**

Transformerエンコーダの生成器G（小型のMLM）と識別器Dを同時に学習する。入力の一部を[MASK]にし、Gのサンプルで置換した列を作り、Dが各トークンについて元のものか置換されたものかを二値分類する。損失はL_MLM + λL_Disc（λ=50）で、Dの損失は生成器へ逆伝播しない。工夫として、トークン埋め込みの共有と、識別器の1/4〜1/2程度の小さな生成器の採用がある。事前学習後は生成器を捨て、識別器のみをファインチューニングする。

**どうやって有効だと検証した？**

GLUEとSQuAD 1.1/2.0で、モデルサイズ・データ・計算量を揃えてBERTなどと比較した。ELECTRA-SmallはGLUEで79.9となり、同条件のBERT-Small（75.1）を約5ポイント上回り、より大きなGPT（78.8）も上回った。大型モデルのELECTRA-400KはRoBERTaやXLNetと同等の性能を1/4未満の計算量で達成し、ELECTRA-1.75Mは同程度の計算量でそれらを上回ってSQuAD 2.0で最高性能を示した。

**議論はある？**

ELECTRAがパラメータ効率で優れる理由は、各位置で語彙全体の分布をモデル化しなくてよいためだと推測されるが、完全な説明にはさらなる分析が必要だと著者は述べている。大型モデルの比較では、RoBERTaなどと学習データやテクニックが完全には揃っておらず、厳密な対等比較ではない。今後の方向性として、自己回帰型の生成器と「置換スパン検出」の組み合わせや多言語データへの適用が挙げられている。

**次に読むべき論文は？**

- BERT: Pre-training of Deep Bidirectional Transformers for Language Understanding：ELECTRAが改良対象とするMLM事前学習の基礎であり、比較の土台を理解できるため。
- RoBERTa: A Robustly Optimized BERT Pretraining Approach：大型モデルでの主要な比較対象であり、計算量を増やした学習の効果を把握できるため。
- XLNet: Generalized Autoregressive Pretraining for Language Understanding：BERTとは別系統の事前学習手法で、ELECTRAと同様にMLMの非効率性と事前学習・ファインチューニング間の不一致に関わる議論を比べられるため。

:::


### 3. BERTScore: BERTを用いたテキスト生成の評価 {#paper-3}

📈 被引用数上位（Paper Digest の集計で同年3位） ・ Tianyi Zhang, Varsha Kishore, Felix Wu, Kilian Q. Weinberger ほか ・ [論文を読む ↗](https://arxiv.org/abs/1904.09675)

<small>原題: BERTScore: Evaluating Text Generation with BERT</small>

機械翻訳や画像キャプション生成などの出力を、BLEUのような表層一致ではなく事前学習済みBERTの文脈埋め込みの類似度で比較する自動評価指標BERTScoreを提案した研究です。評価用の教師データや外部の言語ツールを必要とせず、WMT18の機械翻訳ではセグメントレベルでBLEUやRUSEを有意に上回り、敵対的パラフレーズ検出のPAWS_QQPでも他の指標より性能低下が小幅にとどまりました。ICLR 2020の論文で、Paper Digestの集計では同年の被引用数3位に入っており、広く参照されていることがうかがえます。

::: info 📝 落合フォーマット

**どんなもの？**

機械翻訳や画像キャプション生成などのテキスト生成を評価する自動評価指標 BERTScore を提案した研究。候補文と参照文の各トークンを、完全一致ではなく事前学習済み BERT の文脈埋め込みの類似度で比較し、人間の評価との相関を高めることを目指す。

**先行研究と比べてどこがすごい？**

BLEU や METEOR のような n-gram・表層一致やヒューリスティックな一致に頼らず、文脈埋め込みによって言い換えや遠距離依存・語順の変化を捉える。人間の判断で学習する RUSE や BEER などの学習型指標と違い、評価用の教師データを必要とせず、モデルは特定の評価タスクに最適化されていない。外部の言語ツールも不要で、BERT が対応する多言語に展開しやすい。

**技術や手法のキモはどこ？**

参照文と候補文の各トークンを BERT 等で文脈埋め込みに変換し、正規化済みベクトルの内積（コサイン類似度）を計算する。参照の各トークンを候補の最も類似するトークンに貪欲にマッチさせて再現率 R、候補側から適合率 P を求め、F1 にまとめる。さらに、テストコーパスの参照文から計算した idf によるトークン重み付けと、Common Crawl のランダム文対から求めた下限 b による線形リスケーリング（可読性向上のためで、順位や相関には影響しない）を任意で用いる。

**どうやって有効だと検証した？**

WMT18 の 149 システム・14 言語対（WMT17・WMT16 を含む全体では 363 システム）の機械翻訳で、システムレベルとセグメントレベルの人間評価との相関、および 10K のハイブリッドシステムを使ったモデル選択（Hits@1）を評価し、BERTScore は概ね上位で、セグメントレベルでは BLEU や RUSE を有意に上回った。COCO 2015 キャプションでは、タスク非依存の指標を大きく上回り、R_BERT(idf) は M1 で 0.917、M2 で 0.889 の相関を示した（タスク特化の Leic は 0.939/0.949 でさらに高い）。敵対的パラフレーズ検出 PAWS_QQP では、他の指標が偶然に近い性能まで落ちる中、BERTScore の低下は小幅にとどまった（F_BERT(idf) の AUC 0.693 に対し、BLEU は 0.527）。

**議論はある？**

すべての設定で最良となる単一の構成はなく、idf 重み付けの効果もタスクやデータで異なる（機械翻訳では小さな利点にとどまり、画像キャプションでは有意）ため、ドメインや言語に応じた構成選択が必要である。多言語 BERT は低資源言語で性能が不安定であり、トルコ語など一部の言語対では相関が低い。今後は、BERTScore を部品とするタスク特化の指標の設計や、微分可能性を生かした学習時の損失としての利用が展望されている。

**次に読むべき論文は？**

- BERT: Pre-training of Deep Bidirectional Transformers for Language Understanding：BERTScore が土台とする文脈埋め込みの事前学習手法を理解するために必要である。
- MoverScore / Zhao et al. (2019): Text Generation Evaluation with Contextualized Embeddings and Earth Mover Distance：本文で言及される同時期の関連手法で、貪欲マッチングの代わりに Earth Mover's Distance を用いる点を比較できる。なお、この題名は本文中の参考文献一覧には現れず、本文は Zhao et al. (2019) としか記していないため、正確な原題は確認が必要である。
- PAWS: Paraphrase Adversaries from Word Scrambling：BERTScore の頑健性評価に使われた敵対的パラフレーズデータセットの設計と狙いを理解できる。
