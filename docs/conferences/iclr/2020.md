# ICLR 2020

🤖 AI・機械学習全般 ・ [ICLR の年ごとの流れ](./) ・ [公式サイト ↗](https://iclr.cc/)

::: info この回のまとめ
エチオピアのアディスアベバでアフリカ初の開催が予定されていましたが、COVID-19 のため3月に中止され、主要な機械学習会議として初めて完全オンラインで開催されました。投稿2,594本・採択687本（約26.5%）で、参加者は約5,600人と前年の現地参加（約2,700人）の倍以上に増えました。この年は最優秀論文賞が設けられていません。録画発表を時差に合わせて2回流す、論文推薦に機械学習を使うなど、オンライン学会の運営方法を確立した回として知られます。
:::

- **日程**: 2020年4月26日〜30日
- **開催地**: オンライン開催（当初予定はアディスアベバ）
- **規模**: 投稿 2,594 本 ／ 採択 687 本 ／ 採択率 26.5%
- **参加者**: 約5,600人（約90か国）

## 🔭 この回の主なテーマ

- オンライン学会の設計: 録画発表・時差対応・バーチャル交流（ソーシャル29件）の仕組みを構築
- 運営への機械学習の活用: 査読スコアの補正、論文サムネイル生成、論文・参加者の推薦
- 表現学習の中心テーマ: 事前学習言語モデルの効率化（ALBERT・ELECTRA など）が多く発表された時期

::: tip 💡 技術動向への示唆
- 国際会議のオンライン化で、渡航が難しい地域の研究者も参加できるようになり、AI 研究のグローバル化が加速した
- 録画・論文の即時公開が当たり前になり、企業のエンジニアが最新研究に触れる障壁が下がった
:::
