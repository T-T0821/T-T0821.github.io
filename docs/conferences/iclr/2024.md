:::

### 1. Vision Transformer にはレジスタが必要 {#paper-1}

🏆 Outstanding Paper ・ Timothée Darcet, Maxime Oquab, Julien Mairal, Piotr Bojanowski ・ [論文を読む ↗](https://arxiv.org/abs/2309.16588)

<small>原題: Vision Transformers Need Registers</small>

大規模な ViT では、背景など情報の少ない領域のトークンが計算の「メモ用」に使われ、特徴マップにノイズが出ることを発見しました。入力に数個の追加トークン（レジスタ）を足すだけで解消し、物体発見などの性能も上がります。

::: info 📝 落合フォーマット

**どんなもの？**

教師あり・自己教師ありを問わず大規模なViTの特徴マップやアテンションマップに現れるアーティファクト（高ノルムの外れ値トークン）を特定・特徴づけ、その原因についての解釈を示した研究。さらに入力系列に学習可能な追加トークン（レジスタ）を加えるだけでこれを解消する簡潔な方法を提案した。

**先行研究と比べてどこがすごい？**

DINOでは見られなかったアーティファクトがDINOv2、DeiT-III、OpenCLIPなど多くの現代的ViTに共通して存在することを示し、高ノルムトークンが冗長なパッチを再利用して大域情報を保持するという解釈を与えた点が新しい。Memory Transformerなどの追加トークン手法とは異なり、新たな挙動を作るのではなくモデルが自然に行っている挙動をレジスタに分離するという位置づけで、出力が使われないトークンを事前学習時に加える。

**技術や手法のキモはどこ？**

パッチ埋め込み層の後に、[CLS]と同様に学習可能な値を持つN個の[reg]トークンを系列に追加し、ネットワーク最終出力では破棄して[CLS]とパッチトークンのみを使う。アーティファクトは出力ノルムが約150を超えるトークンとして検出し、近傍パッチとのコサイン類似度、位置予測・画素再構成・分類の線形プローブでその性質を分析した。この方法は構造変更のみなので、DeiT-III、OpenCLIP、DINOv2の各学習手順にそのまま適用できる。

**どうやって有効だと検証した？**

レジスタ導入で3モデルとも出力ノルムの外れ値が消え、ImageNet線形分類・ADE20kセグメンテーション・NYUd深度推定で性能は維持または向上した（例：DINOv2はADE20kで46.6→47.9 mIoU、NYUdのrmseで0.378→0.366）。LOSTによる物体発見ではDINOv2のVOC2007 corlocが35.3→55.4、DeiT-IIIが11.7→27.1に改善した一方、OpenCLIPはわずかに低下した（38.8→37.1）。レジスタ数の検討では1個でアーティファクトが消え、増やすと下流性能が上がる傾向があり、実験では4個を採用した。4個での計算量増加は2%未満である。

**議論はある？**

アーティファクトの発生要因（学習方式、モデルサイズ、学習長）を完全には特定できていない。レジスタごとのアテンションの多様性（スロットアテンションに似た挙動）や正則化の研究、レジスタのノルムが量子化されたように見える現象、OpenCLIPで外れ値がvalue射影の零空間に入るように見える現象は今後の課題とされている。ハイパーパラメータのカットオフ値（150）はモデルごとに調整が必要で、MAEには同様のアーティファクトが見られない点も議論の余地がある。

**次に読むべき論文は？**

- DINOv2: Learning Robust Visual Features without Supervision：本研究が主な分析対象とし、アーティファクトが観測されたモデルであり、下流評価の実験プロトコルも踏襲しているため。
- Emerging Properties in Self-Supervised Vision Transformers (DINO)：アーティファクトのないきれいなアテンションマップの基準として比較されており、本研究の動機を理解するうえで重要なため。
- Localizing Objects with Self-Supervised Transformers and No Labels (LOST)：レジスタ導入の効果を検証した物体発見手法であり、特徴マップの滑らかさへの依存を理解できるため。

:::


### 2. 対話型の実世界シミュレータの学習（UniSim） {#paper-2}

🏆 Outstanding Paper ・ Sherry Yang, Yilun Du, Kamyar Ghasemipour, Jonathan Tompson ほか ・ [論文を読む ↗](https://arxiv.org/abs/2310.06114)

<small>原題: Learning Interactive Real-World Simulators</small>

言語指示や低レベル制御といった多様な行動を入力に、その視覚的結果を動画として生成する対話型シミュレータ UniSim を、性質の異なる複数のデータセットを統合して学習した研究です。このシミュレータ上だけで学習した視覚言語ポリシーや強化学習ポリシー、動画キャプションモデルが実世界にゼロショットで展開でき、RL による VLA ポリシーの成功率は 0.58 から 0.81 に、生成動画のみでの PaLI-X 微調整では ActivityNet の CIDEr が 15.2 から 46.23 に向上しました。汎用的で現実的な映像を対象に、他のエージェントの学習にも使える点が注目されます。

::: info 📝 落合フォーマット

**どんなもの？**

UniSim は、言語指示（「引き出しを開ける」）や低レベル制御（Δx, Δy）といった多様な行動を入力に、その視覚的結果を動画として生成する「実世界の対話型シミュレータ」を学習する研究である。このシミュレータ上だけで学習した高レベルの視覚言語ポリシー、低レベルの強化学習ポリシー、動画キャプションモデルが、実世界にゼロショットで展開できることを示した。

**先行研究と比べてどこがすごい？**

物体が豊富な画像データ、行動が密なロボットデータ、動きが多様なナビゲーションデータなど、それぞれ異なる側面に強みを持つデータセットを統合し、「行動入力→動画出力」という統一インターフェースで扱う点が新しい。従来の世界モデルは系ごとに状態空間で学習するか、ゲームなど視覚的に単純な領域に限られていたが、本研究は汎用的で現実的な映像を対象とし、他のエージェントの学習にも使える点で異なる。

**技術や手法のキモはどこ？**

各データセットの行動を、T5 言語埋め込みと離散化した低レベル制御値を連結した連続表現に変換し、行動空間を統一する。シミュレータは観測予測モデル p(o_t | h_&#123;t-1}, a_&#123;t-1}) として定式化し、動画拡散モデル（video U-Net、5.6B パラメータ）で実装する。履歴フレームをノイズにチャネル方向で連結し、行動は classifier-free guidance で条件付けする。これを自己回帰的にロールアウトして長期の対話を実現する。低データ領域にはデータセット名を識別子として行動に付与して生成品質を改善する。

**どうやって有効だと検証した？**

Ego4D の検証分割での履歴フレーム数の比較では、直近4フレーム条件付けが1フレームより良好だった（FVD 315.69→211.3、FID 59.47→34.63）。Language Table では、シミュレータで生成した長期ハインドサイト軌跡で学習した VLM ポリシーが、元の短期データで学習したものより目標距離削減率（RDG）で 3〜4 倍高く（0.34 対 0.07〜0.11）、実ロボットでも動作した。RL による VLA ポリシー改善では成功率が 0.58 から 0.81 に、ポインティングタスクでは 0.12 から 0.71 に向上した。また、生成動画のみで PaLI-X を微調整すると ActivityNet の CIDEr が 15.2 から 46.23 に向上し、実データ微調整の 84% の性能に達した。

**議論はある？**

著者らは、非現実的な行動に対する幻覚、数フレームの履歴しか使わないことによる長期記憶の欠如、学習データにないロボット形態などへの汎化の限界、視覚以外（音や力など）を扱えない点を限界として挙げている。今後は、シミュレート不能な行動の検出、より長い記憶の扱い、さらなるデータのスケールアップが課題となる。

**次に読むべき論文は？**

- Learning Universal Policies via Text-Guided Video Generation：動画生成をポリシーとして使う関連研究で、UniSim がシミュレータとして埋める位置づけを理解できる。
- PaLM-E: An Embodied Multimodal Language Model：本論文のハインドサイト学習で使う視覚言語ポリシーのアーキテクチャを把握できる。
- RT-2: Vision-Language-Action Models Transfer Web Knowledge to Robotic Control：低レベル制御を出力する VLA ポリシーのベースラインとデータ源として本論文に関わる。

:::


### 3. 拡散モデルの汎化は幾何適応型調和表現から生まれる {#paper-3}

🏆 Outstanding Paper ・ Zahra Kadkhodaie, Florentin Guth, Eero P. Simoncelli, Stéphane Mallat ・ [論文を読む ↗](https://arxiv.org/abs/2310.02557)

<small>原題: Generalization in diffusion models arises from geometry-adaptive harmonic representations</small>

画像ノイズ除去用に学習したDNN（拡散モデルのスコア推定器）がなぜ次元の呪いを回避して汎化できるのかを調べた研究です。互いに素な2つの訓練集合で学習した2つのネットワークが、データが十分大きいとほぼ同一のスコア関数を学習すること（モデル分散の消失）を示し、従来の訓練/テスト誤差の比較より直接的な汎化の証拠を示しました。さらにデノイザのヤコビアン固有分解から、帰納バイアスが輪郭や一様領域に沿って振動する「幾何適応型調和基底（GAHB）」での縮小として現れることを明らかにした点が注目され、ICLR 2024 の Outstanding Paper に選ばれています。

::: info 📝 落合フォーマット

**どんなもの？**

画像ノイズ除去用に学習したDNN（拡散モデルのスコア推定器）が、なぜ次元の呪いを回避して汎化できるのかを調べた研究。訓練データが十分大きいと、互いに素な2つの訓練集合で学習した2つのネットワークがほぼ同一のスコア関数（密度）を学習することを示した。さらにデノイザのヤコビアン固有分解から、帰納バイアスが「幾何適応型調和基底（GAHB）」での縮小（シュリンケージ）として現れることを明らかにした。

**先行研究と比べてどこがすごい？**

従来の訓練/テスト誤差の比較より直接的な汎化の証拠として、非重複データで学習した2モデルのスコア（生成サンプル）の一致、すなわちモデル分散のゼロへの収束を示した点が新しい。また、デノイザの帰納バイアスを、輪郭や一様領域に沿って振動する適応的な調和基底という具体的な関数クラスとして特徴づけた。バンドレット基底が最適なCα画像でほぼ最適な性能を示し、基底が最適でない場合には劣る様子も確認して、この仮説を裏付けた。

**技術や手法のキモはどこ？**

デノイザ f(y) のヤコビアンを固有分解し、f(y)=Σλ_k(y)⟨y,e_k(y)⟩e_k(y) と、適応基底 e_k(y) 上でのシュリンケージとして解釈する。最適デノイザのヤコビアンが事後共分散に比例すること、MSEが固有値の和に等しいこと、およびSUREを用いて、デノイズ誤差とスパース表現の関係を理論的に整理した。実験ではバイアスなしのUNetとBF-CNNを、CelebAなどの部分集合（N=1〜10^5）で学習し、同一の初期ノイズから逆拡散サンプリングして2モデルの出力を比較した。

**どうやって有効だと検証した？**

CelebA（80×80）でN=1〜10^5の訓練集合を用いて、小Nでは記憶、N=10^5では訓練/テストPSNRがほぼ一致し、2モデルの生成画像もほぼ同一になる（モデル分散が消失する）ことを示した。Cα画像では、PSNR曲線の傾きが理論最適値 α/(α+1) に近いことを確認した。円盤画像（5次元多様体）では、最初の5個の固有ベクトルが接空間に一致する一方で、追加のGAHBが残ってPSNR傾きが最適値1.0を下回った。顔画像のピクセルをシャッフルしたデータでは性能が大きく悪化した。

**議論はある？**

GAHBの厳密な数学的定義は与えられておらず、畳み込み（正弦波的な固有ベクトル）とReLUの相互作用が幾何適応性を生むという点は推測にとどまる。汎化への遷移に必要なデータ量は画像サイズ、複雑さ、ネットワーク容量に依存し、その理論的説明は今後の課題である。また、他のタスクやモダリティでのGAHBの役割の解明も今後の課題として挙げられている。

**次に読むべき論文は？**

- Robust and interpretable blind image denoising via bias-free convolutional neural networks：本論文が使うバイアスなしデノイザと、ヤコビアン固有分解による解析の土台になっているため。
- Solving linear inverse problems using the prior implicit in a denoiser：本論文で用いられるデノイザ残差からのサンプリングアルゴリズムの原典であるため。
- Diffusion probabilistic models generalize when they fail to memorize：拡散モデルにおける記憶と汎化の関係を、別の観点から扱った関連研究であるため。

:::


### 4. 離散 Walk-Jump Sampling によるタンパク質探索 {#paper-4}

🏆 Outstanding Paper ・ Nathan C. Frey, Daniel Berenberg, Karina Zadorozhny, Joseph Kleinhenz ほか ・ [論文を読む ↗](https://arxiv.org/abs/2306.12360)

<small>原題: Protein Discovery with Discrete Walk-Jump Sampling</small>

抗体のアミノ酸配列のような離散データに対し、平滑化した分布上での Langevin MCMC と1ステップのデノイジングで生成する Smoothed Discrete Sampling (SDS) の枠組みと、その具体的手法 discrete Walk-Jump Sampling (dWJS) を提案した研究です。ノイズレベル σ が1つだけで済み、EBM 学習で一般的なリプレイバッファや ℓ2 ノルムペナルティも不要とされる点が特徴で、IgLM に対して43倍高速とされています。in vitro 実験では約277配列中270が発現・精製に成功（97.47%）し、trastuzumab の CDR H3 再設計では70%が HER2 に結合して LaMBO-2 の25%や AbDiffuser の22%を上回ったことから、ICLR 2024 の Outstanding Paper に選ばれました。

::: info 📝 落合フォーマット

**どんなもの？**

離散データ（抗体のアミノ酸配列）の生成モデルを、平滑化したデータ分布上での Langevin MCMC と1ステップのデノイジングで実現する Smoothed Discrete Sampling (SDS) の枠組みと、その具体的アルゴリズム discrete Walk-Jump Sampling (dWJS) を提案した研究。あわせて、生成タンパク質の品質を1つのスカラーで評価する指標 Distributional Conformity Score (DCS) を導入し、抗体の in silico 評価と in vitro 実験で有効性を示した。

**先行研究と比べてどこがすごい？**

Neural empirical Bayes を離散データへ初めて適用し、EBM（ウォーク）とデノイザー（ジャンプ）を分離して別々に学習する点が新しい。拡散モデルのような複数ノイズスケジュールが不要で、ノイズレベル σ の1つだけで済み、EBM 学習でよく使われるリプレイバッファや ℓ2 ノルムペナルティ等のトリックも不要とされる。ノイズ分布上の連鎖の全サンプルが有効なサンプルとなり、1本の MCMC チェーンで複数の抗体クラスを訪れる高速混合も示した。

**技術や手法のキモはどこ？**

one-hot 化した配列（AHo 番号付けで整列し、重鎖149・軽鎖148、ギャップを含む21トークン）にガウスノイズ y=x+ε を加え、平滑化分布に対して CNN ベースの離散 EBM を対照発散で学習する。別に 35 層 ByteNet のデノイザー g_φ を Eq.4 の最小二乗目的で学習する。サンプリングでは EBM の勾配による Langevin MCMC で y をウォークし、最後に x̂=y+σ²g_φ(y) でジャンプして argmax で one-hot に戻す。σ は距離行列 χ から求めた臨界ノイズレベル σ_c≈0.5 を目安にし（実験では σ≥0.5）、設計では保存したい位置を射影行列で固定する制約付きサンプリングを行う。

**どうやって有効だと検証した？**

OAS のペア抗体データで、抗体らしさ指標・Wasserstein 距離・編集距離・多様性・DCS を IgLM、SeqVDM、DEEN、ESM2、GPT 3.5 などと比較した。dWJS（エネルギーベース）は W_property が 0.056 で最良、score-based は DCS 0.49 を示し、IgLM に対して 43 倍高速とされる。in vitro では約277配列中270が発現・精製に成功（97.47%）で、通常の EBM は 42%。trastuzumab の CDR H3 再設計（HER2 結合）では 70% が結合し、LaMBO-2 の 25%、AbDiffuser の 22%（フィルタ後 57%）を上回った。

**議論はある？**

著者らは他の分子クラスや画像など他モダリティへの一般化と、結果に対する理論的な検討を今後の課題としている。拡散モデルが持つ構造生成（AbDiffuser）やガイド付きサンプリング（LaMBO-2）といった機能は本手法の主眼ではない。なお本文では、IgLM のほうが DCS は高く、dWJS は ab initio での発見に焦点を絞っている。また、結合実験は HER2 に対する trastuzumab の CDR H3 再設計という1つのタスクで示されている。

**次に読むべき論文は？**

- Neural empirical Bayes：dWJS の土台である平滑化分布・最小二乗推定量・Walk-Jump の理論的背景を理解できる。
- Protein design with guided discrete diffusion：同じ trastuzumab CDR H3 再設計タスクで比較された離散拡散（LaMBO-2）の手法と結果を確認できる。
- AbDiffuser: Full-atom generation of in-vitro functioning antibodies：配列・構造を同時に生成する拡散モデルとして、dWJS と対照的なアプローチおよび実験結果を比較できる。

:::


### 5. SDXL: 高解像度画像合成のための潜在拡散モデルの改良 {#paper-5}

📈 被引用数上位（Paper Digest の集計で同年1位） ・ Dustin Podell, Zion English, Kyle Lacey, Andreas Blattmann ほか ・ [論文を読む ↗](https://arxiv.org/abs/2307.01952)

<small>原題: SDXL: Improving Latent Diffusion Models for High-Resolution Image Synthesis</small>

約3倍大きいUNet（2.6B）と2つ目のテキストエンコーダを用い、約1024×1024画素の高解像度でテキストから画像を生成する潜在拡散モデルSDXLを提案し、コードとモデル重みも公開した研究です。学習画像の元サイズやクロップ座標を条件として与えるマイクロコンディショニングにより、小さい画像を捨てたりアップスケールしたりせずに済み、被写体の見切れも抑えています。ユーザー調査ではSDXLがSD1.5やSD2.1を大きく上回り、Midjourney v5.1との比較（PartiPrompts）でも54.9%でSDXLが選ばれたため、オープンモデルでブラックボックスの最先端モデルに匹敵する性能を示した点が注目されます。被引用数でも同年1位（Paper Digest集計）です。

::: info 📝 落合フォーマット

**どんなもの？**

テキストから画像を生成する潜在拡散モデルSDXLを提案した研究。従来のStable Diffusionより約3倍大きいUNet（2.6B）と2つ目のテキストエンコーダを採用し、複数アスペクト比で約1024×1024画素の高解像度生成を行う。さらにリファインメントモデルで画質を高め、コードとモデル重みを公開した。

**先行研究と比べてどこがすごい？**

学習画像の元サイズやクロップ座標を追加条件として与える「マイクロコンディショニング」により、小さい画像を捨てたりアップスケールしたりせず、ランダムクロップによる被写体の見切れも抑えた。また、トランスフォーマーブロックをUNetの低解像度側に偏らせる構成、より強力なテキストエンコーダの併用、改良オートエンコーダ、潜在空間でのリファイナ（SDEdit方式）を組み合わせた。ブラックボックスの最先端モデルに匹敵する性能をオープンモデルで示した点も特徴である。

**技術や手法のキモはどこ？**

UNetはトランスフォーマーブロックを [0, 2, 10] と配置し、最高解像度レベルのブロックと8倍ダウンサンプリング段を省いた。テキスト条件にはOpenCLIP ViT-bigGとCLIP ViT-Lの出力をチャネル方向に連結し、OpenCLIPのプーリング埋め込みも加える。元画像サイズ(h,w)、クロップ座標(top,left)、ターゲットサイズをFourier特徴で埋め込み、タイムステップ埋め込みに加算する。学習は256²で600k step、512²で200k step、その後オフセットノイズ0.05と複数アスペクト比バケットで約1024²の面積でファインチューニングする。リファイナは同じ潜在空間で最初の200ノイズスケールに特化し、ベース出力にノイズを加えて除去する。

**どうやって有効だと検証した？**

ImageNet 512²のクラス条件付き実験で、サイズ条件付きモデルはFID-5kが36.53、IS-5kが215.34となり、512未満の画像を除外したモデル（43.84 / 110.64）や条件なしモデル（39.76 / 211.50）を上回った。改良オートエンコーダはCOCO2017でPSNR 24.7、rFID 4.4と、SD-VAE 1.x（23.4、5.0）や2.x（24.5、4.7）より良かった。ユーザー調査での勝率はSDXLリファイナ付き48.44%、SDXL単体36.93%、SD1.5が7.91%、SD2.1が6.71%だった。Midjourney v5.1との比較（PartiPrompts）では54.9%でSDXLが選ばれた。一方、FIDとCLIPスコアでは改善が反映されなかった。

**議論はある？**

最良の結果には2モデルのロードが必要で、メモリ使用量とサンプリング速度に課題があるため、単一ステージ化や蒸留が今後の課題とされる。手の描写、複雑な空間配置、概念の混ざり合い（concept bleeding）、長い文字列の描画、データ由来の社会的バイアスといった限界も挙げられている。FIDやCLIPスコアが人間の評価と合わないため、基盤モデルに適した新たな定量指標が必要であると指摘している。

**次に読むべき論文は？**

- High-Resolution Image Synthesis with Latent Diffusion Models：SDXLの土台である潜在拡散モデル（Stable Diffusion）の基本設計を理解するために読む。
- SDEdit: Guided Image Synthesis and Editing with Stochastic Differential Equations：SDXLのリファインメント段階で使われるノイズ付加・除去の手法の原理を押さえるために読む。
- Pick-a-Pic: An Open Dataset of User Preferences for Text-to-Image Generation：COCOのFIDが人間の好みや美的品質と合わないという、SDXLの評価の議論の根拠を確認するために読む。

:::
