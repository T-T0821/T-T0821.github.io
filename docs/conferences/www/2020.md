# WWW 2020

🔎 データマイニング・Web ・ [WWW の年ごとの流れ](./) ・ [公式サイト ↗](https://www2026.thewebconf.org/)

::: info この回のまとめ
台北で予定されていた The Web Conference 2020 は、COVID-19 のため2020年4月20〜24日にオンラインで開催されました。投稿1,129本・採択219本（19.4%）です。最優秀論文は、事前に決めた意図のカテゴリに頼らず、ユーザーの発話から新しい意図を抽出する研究でした。最優秀学生論文は、人気アプリに似せた名前で利用者をだます「アプリスクワッティング」の実態調査です。開会挨拶には台湾のオードリー・タン氏が登壇しました。
:::

- **日程**: 2020年4月20日〜24日
- **開催地**: オンライン開催（当初予定は台湾・台北）
- **規模**: 投稿 1,129 本 ／ 採択 219 本 ／ 採択率 19.4%
- **招待講演**: Yolanda Gil、Sir Nigel Shadbolt、Wei-Ying Ma

**📝 注目論文（1 本）**

1. [自然言語の対話からのオープンな意図抽出](#paper-1)

## 🔭 この回の主なテーマ

- 対話システム: 事前定義なしにユーザーの意図を抽出する
- モバイルのセキュリティ: 人気アプリに似せた偽アプリの実態（最優秀学生論文）
- 意見マイニング: 製品レビューの意見抽出が Seoul Test of Time 賞

::: tip 💡 技術動向への示唆
- 対話から意図を自動で見つける研究は、のちの LLM による意図理解やチャットボットの設計の先行例となった
- Web の研究がセキュリティ・社会・言語にまたがる学際的な場であることを示す回だった
:::

## 📝 注目論文

### 1. 自然言語の対話からのオープンな意図抽出 {#paper-1}

🏆 Best Paper ・ Nikhita Vedula, Nedim Lipka, Pranav Maneriker, Srinivasan Parthasarathy

<small>原題: Open Intent Extraction from Natural Language Interactions</small>

対話システムの意図理解は、あらかじめ決めた意図のカテゴリに分類する方法が主流でした。カテゴリを決めずに発話から意図を抜き出す課題を設定し、未知の要望にも対応できる対話システムへの道を示しました。
