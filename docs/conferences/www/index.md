# WWW

🔎 [データマイニング・Web](../#dm) ・ The ACM Web Conference (WWW) ・ 毎年4〜5月 ・ [公式サイト ↗](https://www2026.thewebconf.org/)

::: info 2020年からの流れ
The Web Conference（WWW）は1994年から続く Web 研究の国際会議で、検索・推薦・グラフ・セキュリティ・Web と社会など幅広い分野を扱います。2020〜2022年はオンラインまたはハイブリッドで、最優秀論文は対話からの意図抽出（2020年）、共感的な返信の支援（2021年）、推薦による過激化の緩和（2022年）でした。2023年はボット検出ベンチマークの欠陥、2024年は LLM のためのメカニズムデザイン、2025年は逆強化学習による振る舞いの同類性、2026年は医療 QA での外部知識と LLM 内部知識の統合が選ばれています。投稿は2020年の約1,100本から2026年の3,370本へ増え、2027年はダブリンで開催予定です。
:::

## 📅 各回のまとめ

- **[WWW 2026](./2026)** — ドバイ開催・投稿3,370本。外部知識と LLM 内部の知識を統合する医療 QA の研究が最優秀論文に<br><small>2026年6月29日〜7月3日 ・ アラブ首長国連邦・ドバイ</small>
- **[WWW 2025](./2025)** — シドニー開催。逆強化学習で Reddit ユーザーの「振る舞いの似かより」を測る研究が最優秀論文に<br><small>2025年4月28日〜5月2日 ・ オーストラリア・シドニー</small>
- **[WWW 2024](./2024)** — シンガポール開催・投稿2,008本。LLM が生成する広告文への「入札」の仕組みを設計した研究が最優秀論文に<br><small>2024年5月13日〜17日 ・ シンガポール</small>
- **[WWW 2023](./2023)** — オースティン開催。Twitter のボット検出は「データセットの作り方」のせいで精度が高く見えていたと示した研究が最優秀論文に<br><small>2023年5月 ・ 米国・オースティン</small>
- **[WWW 2022](./2022)** — リヨン主催でハイブリッド開催。動画推薦が人を過激なコンテンツへ導く経路を減らす研究が最優秀論文に<br><small>2022年4月 ・ フランス・リヨン（ハイブリッド）</small>
- **[WWW 2021](./2021)** — リュブリャナ主催でオンライン開催。オンラインの心の相談で共感的な応答を強化学習で支援する研究が最優秀論文に<br><small>2021年4月19日〜23日 ・ オンライン開催（主催はスロベニア・リュブリャナ）</small>
- **[WWW 2020](./2020)** — 台北開催予定から初のオンライン開催へ。対話から「未知の意図」を抽出する研究が最優秀論文に<br><small>2020年4月20日〜24日 ・ オンライン開催（当初予定は台湾・台北）</small>

## 🔭 年ごとのテーマの移り変わり

- 2020: 初のオンライン開催、対話からの意図抽出
- 2021: オンラインのメンタルヘルス支援、12の研究トラック
- 2022: 推薦による過激化の経路の緩和
- 2023: ボット検出ベンチマークの欠陥、文脈つきバンディットが Test of Time 賞
- 2024: LLM のためのメカニズムデザイン（広告オークション）
- 2025: 逆強化学習による振る舞いの同類性
- 2026: RAG と LLM の知識統合、推薦が最大分野、Agentic Web

::: tip 💡 技術動向への示唆
- WWW の最高賞は Web が社会に与える影響（過激化・偽情報・分断・心の健康）を扱う研究に多く与えられており、プラットフォーム設計の社会的責任を考える手がかりになる
- LLM が検索・広告・推薦に入り込んだことで、生成コンテンツの経済的な仕組みや、エージェントが使う Web の設計が新しい研究課題になっている
:::
