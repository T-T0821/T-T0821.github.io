# WWW 2025

🔎 データマイニング・Web ・ [WWW の年ごとの流れ](./) ・ [公式サイト ↗](https://www2026.thewebconf.org/)

::: info この回のまとめ
The Web Conference 2025 は、2025年4月28日〜5月2日にオーストラリアのシドニーで、シドニー工科大学の主催により開催されました。最優秀論文は、交流のネットワークを作りにくいプラットフォームでも、逆強化学習でユーザーの行動方針を推定して「振る舞いの似かより（ホモフィリー）」を測る方法を示した研究（シドニー工科大学・EPFL）です。Reddit の6年分・590万件のやり取りを分析し、サッカーと e スポーツのように話題が違っても振る舞いがよく似たユーザーがいることを明らかにしました。
:::

- **日程**: 2025年4月28日〜5月2日
- **開催地**: オーストラリア・シドニー

**📝 注目論文（3 本）**

1. [逆強化学習によるソーシャルメディアの振る舞いの同類性: Reddit の事例研究](#paper-1)

## 🔭 この回の主なテーマ

- エコーチェンバーの分析: 話題や交流ではなく「振る舞い」の似かよりを測る
- 逆強化学習の社会への応用: ユーザーの行動方針を推定して比較する

::: tip 💡 技術動向への示唆
- 分断や偏りの分析が、投稿内容やつながりだけでなく行動パターンにも広がっており、プラットフォームの健全性を測る新しい指標につながる
:::

### 1. 逆強化学習によるソーシャルメディアの振る舞いの同類性: Reddit の事例研究 {#paper-1}

🏆 Best Paper ・ Lanqin Yuan, Philipp J. Schneider, Marian-Andrei Rizoiu ・ [論文を読む ↗](https://arxiv.org/abs/2502.02943)

<small>原題: Behavioral Homophily in Social Media via Inverse Reinforcement Learning: A Reddit Case Study</small>

同類の人同士がつながるホモフィリーはエコーチェンバーの形成に関わりますが、従来は交流ネットワークや話題の分析に頼っていました。逆強化学習で各ユーザーの行動方針を推定して比べる新しい方法で、交流が見えにくい場でも似かよりを測れるようにしました。

::: info 📝 落合フォーマット

**どんなもの？**

Redditのように明示的なフォロー関係がなく、トピック単位で構成されるプラットフォームでユーザー間のホモフィリーを測るため、逆強化学習（IRL）でユーザーの行動方策を推定し、方策の類似度を「行動的ホモフィリー」として定量化する手法を提案した研究。2015〜2022年のReddit全データから抽出した662ユーザーを対象にケーススタディを行い、トピック的ホモフィリーとの違いやユーザーの行動ペルソナを分析した。

**先行研究と比べてどこがすごい？**

従来のホモフィリー測定はフォローネットワークやハッシュタグ、トピック・コンテンツの類似性に依存しており、Redditのような構造では限界があった。本研究は階層的なスレッド構造に合わせた状態・行動空間（賛成・中立・反対の区別を含む）を設計したIRLを適用し、方策の類似度から行動に基づくホモフィリーを測る点が新しい。また、状態の訪問頻度で重み付けした対称KLダイバージェンス（SWKL）を導入している。

**技術や手法のキモはどこ？**

ユーザーをReddit全体を環境とするエージェントとみなし、最大エントロピー深層IRLで報酬関数を学習して価値反復により方策（12状態×6行動の行列）を得る。状態は初回スレッド作成・初回ルートコメント・返信（賛成/中立/反対）・返信受信などの12種、行動はスレッド作成・ルートコメント・返信（賛成/中立/反対）・返信待ちなどの6種で、賛否はDeBERTaV3をDEBAGREEMENTでファインチューニングして分類した。2ユーザー間の方策の差は状態訪問割合で重み付けしたSWKLで測り、比較基準としてBERTopic（484トピック）のトピックベクトルのコサイン距離によるトピック的ホモフィリーを用いた。

**どうやって有効だと検証した？**

15のホームサブレディット（最もコメント活動が多いサブレディット）から各45人、計662ユーザーを対象に、トピックと行動のホモフィリーをサブレディット間で比較した。トピック的ホモフィリーはサブレディット内で強い一方、行動的ホモフィリーは弱く重なりが大きかった。サブレディット対でのSpearman相関（Bonferroni補正、有意水準5%）では多くが正の相関だったが、r/soccerとr/leagueoflegendsは負の相関（トピックのコサイン距離0.944で重なりは小さいが行動は類似）を示した。k-meansで5つのペルソナ（Thread Creators 25人、Root Only 114人、Root Favored 263人、Balanced 136人、Disagreers 124人）が得られ、政治系サブレディットでDisagreersが多かった。

**議論はある？**

本文で確認できる範囲では、結論として行動的ホモフィリーは従来のトピック型と概ね整合しつつ、ユーザーの役割など別の側面も捉えるとされている。一方でサンプルは662ユーザーと小規模で、間接的活動は第一世代の子のみに限定され、各ペルソナの解釈には定性的な確認（100コメントや20スレッドの目視など）が含まれる。なお、本文は結論部以降が省略されており、限界や今後の展望についての詳細な記述は確認できなかった。

**次に読むべき論文は？**

- Maximum Entropy Inverse Reinforcement Learning：本研究の方策推定の基盤である最大エントロピーIRLの原理を理解するため。
- Maximum entropy deep inverse reinforcement learning：報酬関数をニューラルネットで表現する深層IRLの拡張で、本研究が実際に用いた手法の詳細がわかる。
- Detecting Troll Behavior via Inverse Reinforcement Learning: A Case Study of Russian Trolls in the 2016 US Election：ソーシャルメディアのユーザー行動分析にIRLを適用した代表的な先行研究で、本研究との比較に役立つ。

:::


### 2. MemoRAG: グローバルメモリ強化型の検索拡張により長文脈処理を高める {#paper-2}

📈 被引用数上位（Paper Digest の集計で同年1位） ・ Hongjin Qian, Zheng Liu, Peitian Zhang, Kelong Mao ほか ・ [論文を読む ↗](https://arxiv.org/abs/2409.05591)

<small>原題: MemoRAG: Boosting Long Context Processing with Global Memory-Enhanced Retrieval Augmentation</small>

入力全体から軽量なメモリモデルでグローバルメモリを作り、そこから生成した回答の下書きを手がかりに検索を導く RAG フレームワーク MemoRAG を提案した研究です。元のクエリで直接検索する従来 RAG と異なり、要約のようにクエリが曖昧なタスクや複雑な QA にも対応でき、KV 圧縮によるメモリ実現と、最終回答の質で手がかり生成を強化する RLGF も導入しています。LongBench、InfiniteBench、自作の UltraDomain で平均 40.2 と長文 LLM の Full（35.0）を上回り、128K 文脈を 60 GiB 未満の GPU メモリで処理できた点に加え、被引用数が同年1位（Paper Digest 集計）であることも注目の理由です。

::: info 📝 落合フォーマット

**どんなもの？**

長い文脈を扱うタスクのために、入力全体から「グローバルメモリ」を作り、そこから生成した回答の下書き（手がかり）で検索を導く RAG フレームワーク MemoRAG を提案した研究。明示的なクエリや整理された知識を前提とする従来 RAG の制約を緩和し、要約などクエリが曖昧なタスクや複雑な QA にも対応することを狙う。

**先行研究と比べてどこがすごい？**

従来 RAG が元のクエリで直接検索するのに対し、全文を把握した軽量メモリモデルが生成した下書き回答を検索クエリとして使う二重システム構成が新しい。さらにメモリを KV 圧縮で実現し、最終回答の質のフィードバックで手がかり生成を強化する RLGF を導入した。HyDE や RQ-RAG のようにモデル内部知識のみに頼らず、また GraphRAG のような静的なグラフ構築にも頼らない点が優れているとされる。

**技術や手法のキモはどこ？**

軽量で長文対応のメモリモデルが、各コンテキストウィンドウ後に k 個のメモリトークンを挿入し（k ≪ l）、専用の Q/K/V 重みで入力を KV 空間に圧縮して圧縮率 β=4〜64 のコンパクトなグローバルメモリを形成する。タスク提示時にメモリが下書き回答（手がかり）を生成し、それを検索クエリとして長文から根拠を取得、重い生成モデルが最終回答を作る。学習は、新規重みのみを更新する事前学習、手がかり生成の SFT、最終回答への貢献度に基づく選好ランキング損失による RLGF の3段階で行う。

**どうやって有効だと検証した？**

LongBench、InfiniteBench、および20ドメインで構成される自作の UltraDomain で、Full（長文 LLM）、MInference、SelfExtend、BGE-M3 等の標準 RAG、HyDE、RQ-RAG、GraphRAG と比較した。表1では MemoRAG の平均が 40.2 で、Full の 35.0 を上回り、多くのデータセットで全ベースラインを上回った。UltraDomain でも全データセットで一貫して上回り、圧縮率 β を上げると性能は低下するが β=32 付近で安定し、全 β で標準 RAG を上回った。効率面では標準 RAG より遅いが、高度な RAG や長文 LLM よりは時間・メモリ効率が良く、128K 文脈を 60 GiB 未満の GPU メモリで処理できた。

**議論はある？**

標準 RAG と比べると、メモリ形成と手がかり生成のため索引・検索のレイテンシが大きい。圧縮率を上げるほど意味情報が失われて性能が下がる点や、SFT データの構築に強力な LLM と人手の確認が必要な点も課題である。また評価に用いた UltraDomain は著者らが独自に作成したものであり、他の設定での汎化は今後の検証が必要である。

**次に読むべき論文は？**

- From Local to Global: A Graph RAG Approach to Query-Focused Summarization：MemoRAG が主要な比較対象とするグラフベース RAG で、クエリ指向要約への別アプローチを理解できる。
- Precise Zero-Shot Dense Retrieval without Relevance Labels：仮想文書で検索する HyDE であり、MemoRAG の「下書き回答で検索する」発想との違いを比較できる。
- MInference 1.0: Accelerating Pre-filling for Long-Context LLMs via Dynamic Sparse Attention：MemoRAG の軽量メモリのベースラインであり、長文の prefill 高速化手法として圧縮型メモリとの比較に役立つ。

:::


### 3. 適応的活性化ステアリング:多様なハルシネーションカテゴリに対応する、チューニング不要のLLM真実性向上手法 {#paper-3}

📈 被引用数上位（Paper Digest の集計で同年2位） ・ Tianlong Wang, Xianfeng Jiao, Yinghao Zhu, Zhongzhi Chen ほか ・ [論文を読む ↗](https://arxiv.org/abs/2406.00034)

<small>原題: Adaptive Activation Steering: A Tuning-Free LLM Truthfulness Improvement Method for Diverse Hallucinations Categories</small>

LLMが内部では真実性を「知っている」のに誤った内容を語ってしまうギャップに対し、推論時に活性化を truthful 方向へ動かすチューニング不要のACTを提案した研究です。単一ベクトル・固定強度の既存手法と異なり、教師なしクラスタリングによる複数のステアリングベクトルと、活性化の真実性に応じた適応的な強度を用います。TruthfulQAでLLaMA-7BのTrue*Infoを23.1から42.3へ高め、最良の比較手法Mean-Centringに対し34%改善し、推論時間の増加も2%未満で、WWW 2025で被引用数が同年2位(Paper Digest集計)という点でも注目されます。

::: info 📝 落合フォーマット

**どんなもの？**

LLMが内部では真実性を「知っている」のに誤った内容を「語ってしまう」ギャップを埋めるため、推論時に活性化を「truthful」方向へシフトするチューニング不要の手法ACT（Adaptive Activation Steering）を提案した研究。多様なハルシネーションカテゴリに対応するため、複数のステアリングベクトルと適応的な介入強度を用いる。

**先行研究と比べてどこがすごい？**

既存手法（ITI、RepE、Mean-Centring等）は単一のステアリングベクトルと固定強度を使うのに対し、ACTは活性化の真実性の度合いに応じて強度を調整し、教師なしクラスタリングで複数のベクトルを生成する。著者らは、ハルシネーションのカテゴリごとにステアリングベクトルが活性化空間で異なるクラスタを形成することを初めて観察したと主張している。TruthXのようなオートエンコーダの学習も不要である。

**技術や手法のキモはどこ？**

各質問について真実回答と非真実回答の最終トークン活性化の平均差を方向表現とし、K-meansでC個のクラスタに分け、クラスタごとに各層・各ヘッドの線形プローブ（ロジスティック回帰）を学習する。検証精度が高い上位Kヘッドを介入対象に選び、推論時にはプローブ出力（真実性との類似度、0〜1）をもとにステアリングベクトル（既定ではプローブのパラメータθ）を (1−類似度) に基づく強度α(1−p+β)でスケールして加算する。わずか40サンプル程度の学習データで済み、推論時の追加計算はO(CHD)の定数オーダーである。

**どうやって有効だと検証した？**

TruthfulQA（817問、38カテゴリ）で、True*Info・MC1/MC2などを用いて評価した。フルデータ設定のLLaMA-7BではTrue*Infoがベースライン23.1から42.3へ向上し、最良の比較手法Mean-Centringに対し34%の改善となった。LLaMA・LLaMA2・Alpaca・Vicuna・LLaMA2-Chat・LLaMA3でも改善し、LLaMAでは142%の相対向上である。さらに人手評価、Natural QuestionsとMMLUへの汎化（50.6→52.5、35.0→36.9）、推論時間の増加2%未満、Few-shot Prompting併用での7B〜65Bのスケーラビリティも示している。

**議論はある？**

マルチターン対話など実運用のチャット場面での有効性は未検証であり、真実性と有用性（文章の滑らかさなど）のトレードオフも今後の課題とされている。また、フルデータ設定ではモデルが大きくなると「I have no comments」のような回答が増えて情報量が下がるため、活性化ステアリング単独では7B超へのスケールが難しく、大規模モデルではFew-shot Promptingとの併用が必要である。

**次に読むべき論文は？**

- Inference-Time Intervention: Eliciting Truthful Answers from a Language Model：ACTが直接の土台・主要ベースラインとしている、単一ベクトル・固定強度の活性化介入手法であり、差分を理解するのに必須である。
- Improving activation steering in language models with mean-centring：フルデータ設定でACTの最良の比較手法となったステアリングベクトル生成手法である。
- TruthfulQA: Measuring how models mimic human falsehoods：ACTの評価に使われるベンチマークで、38カテゴリの構成やTrue*Infoなどの指標を把握するために読む価値がある。

:::
