# ACL 2020

💬 自然言語処理 ・ [ACL の年ごとの流れ](./) ・ [公式サイト ↗](https://www.aclweb.org/)

::: info この回のまとめ
シアトルで予定されていた第58回大会は、COVID-19 のため2020年7月5〜10日にオンラインで開催されました。投稿3,088本に対し採択は779本（長論文571・短論文208、採択率25.2%）です。最優秀論文は、ソフトウェアテストの考え方を持ち込み、NLP モデルの能力を項目ごとのテストで確かめる CheckList（Microsoft ほか）でした。佳作にはドメイン適応のための追加事前学習（Don't Stop Pretraining）と、機械翻訳の自動評価指標の見直しが選ばれ、「精度の数字だけでは分からない」ことを示す評価研究が評価された回です。
:::

## 🔭 この回の主なテーマ

- 評価方法の見直し: 正解率だけでなく、能力ごとの振る舞いテストでモデルの弱点を洗い出す（CheckList）
- ドメイン適応: 対象分野やタスクのテキストで事前学習を続けると性能が上がる
- 自動評価指標の信頼性: 機械翻訳の BLEU などと人手評価の関係を再検証

::: tip 💡 技術動向への示唆
- ベンチマークの高得点と実際の頑健さは別物であり、実務では用途に合わせたテストケースを自前で用意する必要がある、という考え方がここで広まった
- 汎用の事前学習モデルを自社ドメインのデータで追加学習する手法は、その後の LLM の継続事前学習やドメイン特化モデルの基本になった
:::

### 1. 正解率を超えて: CheckList による NLP モデルの振る舞いテスト {#paper-1}

🏆 Best Paper ・ Marco Tulio Ribeiro, Tongshuang Wu, Carlos Guestrin, Sameer Singh ・ [論文を読む ↗](https://arxiv.org/abs/2005.04118)

<small>原題: Beyond Accuracy: Behavioral Testing of NLP Models with CheckList</small>

否定の理解や固有名詞の置き換えへの頑健さなど、言語能力ごとにテストを作ってモデルを調べる枠組みです。高精度とされた商用モデルにも多くの失敗が見つかり、評価の仕方そのものを変えるきっかけになりました。

::: info 📝 落合フォーマット

**どんなもの？**

NLPモデルの汎化性能を、ホールドアウトデータの精度だけでなくソフトウェア工学の振る舞いテスト（ブラックボックステスト）の考え方で評価する、タスク非依存の方法論とツール「CheckList」を提案した研究。言語的な能力（Capabilities）とテスト種別を行列として整理し、網羅的なテスト設計と大量のテストケース生成を支援する。

**先行研究と比べてどこがすごい？**

従来の評価手法（ノイズ頑健性、敵対的摂動、公平性、診断用データセットなど）は個別タスクや特定の振る舞いに限られていたが、CheckListは Vocabulary、Negation、NER、Temporal、SRL、Logic などの汎用的な能力と3種のテスト型を組み合わせた包括的な指針を与える。また、テンプレート、マスク言語モデルによる埋め込み候補提案、汎用摂動などの抽象化により、テスト作成の労力を下げている点が新しい。

**技術や手法のキモはどこ？**

モデルをブラックボックスとして扱い、能力（行）×テスト種別（列）の行列のセルを埋める形でテストを作る。テスト種別は、単純な例で基本機能を確認する Minimum Functionality test (MFT)、ラベルを保つ摂動で予測が変わらないことを確認する Invariance test (INV)、期待される方向に予測が変わることを確認する Directional Expectation test (DIR) の3つ。テストケースは「I &#123;NEGATION} &#123;POS_VERB} the &#123;THING}.」のようなテンプレートとレキシコンの直積で生成し、RoBERTa のマスク予測や WordNet でフィルイン候補を拡張する。実装は OSS として公開され、テストの保存・共有や、文字入れ替え（タイポ）、固有名詞置換などの汎用摂動も備える。

**どうやって有効だと検証した？**

感情分析（商用3モデル、BERT-base、RoBERTa-base）、Quora Question Pair（BERT-base、RoBERTa-base）、機械読解（SQuAD で微調整した BERT-large）に適用した。ベンチマークでは高精度（例: QQP で 91.1%/91.3%、SQuAD で 93.2 F1）のモデルでも、否定、時制、SRL、共参照などで深刻な失敗が見つかり、たとえば感情分析では文末の否定で商用モデルの失敗率がほぼ100%となった。ユーザー調査では、商用感情分析チームが約5時間のセッションで多数の新規かつ対処可能なバグを発見した。また、18名による QQP の2時間テストでは、CheckList の能力一覧とテンプレートを使った条件が、補助なしの条件より多くのテストを作成し（13.5 対 5.8）、重大バグ（severity≥3）数も多かった（6.2 対 2.2）。

**議論はある？**

テストで失敗が見つからなくても、モデルが公平である、または問題がないことの証明にはならず（公平性テストはその一例）、あくまで簡単なテストを通過したにすぎない。提示された能力の一覧は網羅的ではなく、タスクやドメインに応じてユーザー自身が能力を追加する必要がある。また、データのバージョン管理問題、ラベル誤り、アノテータバイアス、最悪ケースのセキュリティ、解釈可能性といった非振る舞い的な問題には直接使えず、ベンチマークを置き換えるのではなく補完するものとされている。

**次に読むべき論文は？**

- Errudite: Scalable, reproducible, and testable error analysis：モデルの失敗箇所を特定する対話的な誤り分析手法で、CheckList とは異なる視点から集約精度の限界を補う関連研究として読む価値がある。
- Semantically equivalent adversarial rules for debugging NLP models：CheckList の INV テストの発想に近い、意味を保つ摂動によるモデルのデバッグ手法である。
- Perturbation sensitivity analysis to detect unintended model biases：名前などの置換でモデルの予測がどう変わるかを調べる手法で、CheckList の公平性・NER テストの背景として参考になる。

:::


### 2. 事前学習をやめるな：言語モデルをドメインとタスクに適応させる {#paper-2}

🏆 Best Paper Honorable Mention ・ Suchin Gururangan, Ana Marasović, Swabha Swayamdipta, Kyle Lo ほか ・ [論文を読む ↗](https://arxiv.org/abs/2004.10964)

<small>原題: Don't Stop Pretraining: Adapt Language Models to Domains and Tasks</small>

RoBERTaに対し、対象ドメインの未ラベルテキストでの追加事前学習(DAPT)とタスク自身の未ラベルデータでの追加事前学習(TAPT)を、4ドメイン・8つの分類タスクで体系的に比較した研究である。TAPTは全タスクでベースラインを上回り、DAPTとの併用が全タスクで最良となり、無関係なドメインへの適応は多くのタスクで性能を悪化させた。TAPTはDAPTより約60倍高速に学習でき、RCT-500ではCurated-TAPTがラベルデータの0.3%でフルラベルのDAPT+TAPTの95%の性能を達成した点も注目される。

::: info 📝 落合フォーマット

**どんなもの？**

大規模汎用コーパスで事前学習済みの言語モデル(RoBERTa)に対し、対象ドメインの未ラベルテキストや、タスク自身の未ラベルデータで追加の事前学習(継続事前学習)を行うことの有効性を調べた研究である。生物医学、計算機科学、ニュース、レビューの4ドメイン・8つの分類タスクで、高資源・低資源の両設定を検証している。

**先行研究と比べてどこがすごい？**

従来は単一ドメイン・小規模コーパスで事前学習したモデルでの継続事前学習の検証が中心だったが、本研究は最新の大規模LMであるRoBERTaで複数ドメインを横断的に分析した。ドメイン適応(DAPT)とタスク適応(TAPT)を体系的に比較・組み合わせ、さらにドメインコーパスから自動でタスク関連データを選ぶ簡便な手法も示した点が新しい。

**技術や手法のキモはどこ？**

DAPTは、RoBERTaをドメイン別の大規模未ラベルコーパス(12.5Kステップ、約1パス)でマスク言語モデル目的により追加学習する。TAPTは、タスクの未ラベル訓練データのみで100エポック追加学習し、エポックごとにマスク位置を変えてデータを疑似的に増やす。さらにVAMPIRE(軽量なbag-of-words LM)で文を埋め込み、タスク文ごとにドメインコーパスからk近傍(kNN-TAPT)で関連テキストを選び、TAPTのコーパスを拡張する。人手でキュレーションされた追加未ラベルデータを使うCurated-TAPTも比較している。

**どうやって有効だと検証した？**

RoBERTaベースラインに対し、DAPTはChemProtで81.9→84.2、ACL-ARCで63.0→75.4と改善し、無関係なドメインへの適応(¬DAPT)は多くのタスクでベースラインより悪化した。TAPTは全タスクでベースラインを上回り、DAPT+TAPTが全タスクで最良だった。RCT-500では、Curated-TAPTがフルラベルのDAPT+TAPTの95%の性能を、ラベルデータの0.3%で達成し、kNN-TAPTはkを増やすとDAPTに近づいた。TAPTはDAPTより約60倍高速に学習できる。

**議論はある？**

TAPTは他タスクへの転移で性能が下がる(例:HyperPartisanで7.7ポイント低下)ため、単一タスク向けの最適化である点に注意が必要である。ドメイン境界は曖昧で(ReviewsとNewsで40%の語彙共有)、より良いデータ選択手法、DAPTとTAPTのカリキュラム的な組み合わせ、遠いドメインへの効率的な適応は今後の課題として挙げられている。また、実験はRoBERTa-baseと分類タスクに限られている。

**次に読むべき論文は？**

- Universal Language Model Fine-tuning for Text Classification：タスク適応型の事前学習(TAPT)の先駆的な有効性を示した研究で、本論文の背景を理解できる。
- BioBERT: A pre-trained biomedical language representation model for biomedical text mining：ドメイン特化の継続事前学習の代表例で、DAPTの先行研究として比較できる。
- Unsupervised domain clusters in pretrained language models：埋め込み空間のクラスタによる「ドメイン」の定義とデータ選択を扱い、本論文の5章や「ドメインとは何か」の議論を発展させる。

:::


### 3. BLEUに絡め取られて：機械翻訳の自動評価指標に対する評価方法の再検証 {#paper-3}

🏆 Best Paper Honorable Mention ・ Nitika Mathur, Timothy Baldwin, Trevor Cohn ・ [論文を読む ↗](https://arxiv.org/abs/2006.06264)

<small>原題: Tangled up in BLEU: Reevaluating the Evaluation of Automatic Machine Translation Evaluation Metrics</small>

機械翻訳の自動評価指標を人手評価（Direct Assessment）との相関で測る現行のメタ評価を、WMT19のデータで再検証した研究です。外れ値システムが相関を大きく左右することを示し（例：英独で外れ値2システムを除くとBLEUの相関は0.97から0.81、YiSi-2は0.92から-0.01に低下）、システムペア単位でType I/II誤りも定量化しました。BLEU差が0〜3点で有意な場合の半分超は人手では差なしと判定されるなど、指標の差が何を意味するかを具体的な数字で示した点が注目されます。

::: info 📝 落合フォーマット

**どんなもの？**

機械翻訳（MT）の自動評価指標を人手評価（Direct Assessment）との相関で評価する現行のメタ評価手法を再検証した研究。WMT19のメトリクスタスクのデータを用い、外れ値システムやサンプル数の影響を分析し、さらにシステムペア比較での指標差が人手評価の差を何を意味するかを定量化した。

**先行研究と比べてどこがすごい？**

WMT19で指摘された「強いシステムのみで相関が下がる」現象を、システム数が変わるtop-N方式の人工的な結果である可能性として、サンプル数を固定したローリングウィンドウで再検討した。また、外れ値システムがピアソン相関を過大・過小評価させることを、MADに基づく頑健な外れ値除去で示した。さらにシステムペア単位でType I/II誤りを定量化し、BLEU差の閾値の意味を人手評価に対して示した点が新しい。

**技術や手法のキモはどこ？**

人手評価スコア（DA）の中央値とMAD（1.483×中央値絶対偏差）から頑健zスコアを計算し、絶対値が2.5を超えるシステムを外れ値として除いた上でピアソン相関を再計算する。システム数を一定にしたローリングウィンドウ（4または8システム）で相関の安定性を可視化する。システムペア比較では、人手評価はWilcoxon順位和検定、BLEUはブートストラップ、YiSi-1/ESIM/chrFは文単位スコアのpaired t検定で有意差を判定し、指標の差と人手評価の差の一致・不一致（Type I/II誤り）を集計する。

**どうやって有効だと検証した？**

WMT19の多数の言語対のDAスコアと、BLEU・TER・chrF・YiSi-1・ESIM・YiSi-2などの指標を用いて検証した。英独では外れ値2システムを除くとBLEUの相関が0.97から0.81、YiSi-2は0.92から-0.01に低下し、英カザフ語でもBLEUが0.85から0.58に低下した。1362件のシステムペア比較では、BLEU差が0〜3点でも有意な場合の半分超が人手では差なしと判定され、3〜5点でも約4分の1が同等品質であった。chrF・YiSi-1・ESIMはBLEUやTERより誤りが少ないが、全指標の誤りの半分超は共通していた。

**議論はある？**

人手評価のDAを正解とみなしており、その欠点は考慮されていない。また、システム数が少ない（言語対あたり約10〜15）ため、指標の信頼性が高品質MTで低下するかを検証する、より良い手法が必要である。著者らは、外れ値除去後の相関報告、BLEU・TERからchrF・YiSi-1・ESIMへの移行、小さな指標差のみに頼らず人手評価で裏付けることを推奨している。

**次に読むべき論文は？**

- Results of the WMT19 metrics shared task: Segment-level and strong MT systems pose big challenges：本論文が再検証の対象とした、強いシステムで相関が低下するという知見の出典であり、データと評価手順を把握できる。
- Re-evaluating the role of Bleu in machine translation research：BLEUの限界を分析した古典的研究で、本論文のBLEU批判の背景を理解できる。
- Taking MT evaluation metrics to extremes: Beyond correlation with human judgments：高品質と低品質の翻訳で指標の振る舞いが異なることをセンテンスレベルで分析しており、相関以外の評価観点を補える。

:::


### 4. BART: 自然言語の生成・翻訳・理解のためのデノイジング型系列変換事前学習 {#paper-4}

📈 被引用数上位（Paper Digest の集計で同年1位） ・ Mike Lewis, Yinhan Liu, Naman Goyal, Marjan Ghazvininejad ほか ・ [論文を読む ↗](https://arxiv.org/abs/1910.13461)

<small>原題: BART: Denoising Sequence-to-Sequence Pre-training for Natural Language Generation, Translation, and Comprehension</small>

任意のノイズで破損させたテキストを復元するよう学習するseq2seq型のデノイジング・オートエンコーダで、双方向エンコーダと自己回帰デコーダを持つTransformerによりBERTやGPTなどを一般化した枠組みを示した研究です。任意長のスパンを単一の[MASK]に置き換えるtext infillingと文順序のシャッフルの組み合わせが最良と示し、GLUEとSQuADではRoBERTaと同等、XSumではROUGE-1が45.14で従来の38.81を大きく上回るなど、生成と理解の両方で高い性能を達成しました。WMT16 RO-ENの機械翻訳でも逆翻訳を用いた強いベースラインをBLEUで1.1ポイント上回っており、ACL 2020で被引用数1位（Paper Digest集計）という点でも注目されます。

::: info 📝 落合フォーマット

**どんなもの？**

BARTは、任意のノイズ関数で破損させたテキストを元に復元するよう学習する、系列変換（seq2seq）型のデノイジング・オートエンコーダによる事前学習手法である。双方向エンコーダと左から右への自己回帰デコーダを持つ標準的なTransformerで、BERTやGPTなどを一般化した枠組みとして位置づけられる。生成タスクで特に有効で、理解タスクでもRoBERTa並みの性能を示す。

**先行研究と比べてどこがすごい？**

従来の事前学習手法は特定の下流タスク（スパン予測や生成など）に偏りがちだったが、BARTは生成と理解の両方に適用できる点が特徴である。ノイズの与え方に自由度があり（長さを変える変換も可能）、任意長のスパンを単一の[MASK]に置換する新しいtext infillingと文順序のシャッフルの組み合わせが最良であると示した。さらに、BART全体を事前学習済みデコーダとして機械翻訳に使う新しい微調整方式も提案した。

**技術や手法のキモはどこ？**

事前学習では、トークンマスキング、トークン削除、text infilling（スパン長はPoisson分布λ=3、各スパンを単一の[MASK]に置換）、文の並べ替え、文書回転といったノイズを単独または組み合わせて入力に適用し、元文書に対するデコーダ出力のクロスエントロピーを最小化する。アーキテクチャは標準のseq2seq Transformerで、活性化関数をGeLUにし、baseは6層、largeは12層である。分類タスクでは同じ入力をエンコーダとデコーダの両方に与え、デコーダ最終トークンの隠れ状態を分類器に入力する。翻訳ではBARTのエンコーダ埋め込み層を新しいエンコーダに置き換え、まずそれを中心に学習し、次に全パラメータを少数反復で学習する。

**どうやって有効だと検証した？**

base規模でマスク言語モデル、置換言語モデル、MASS風モデルなどを同条件で再実装して比較し、text infillingを用いたBARTがELI5を除きほぼ全タスクで安定して高い性能を示した。large規模（RoBERTaと同規模の160GBデータ、バッチサイズ8000、50万ステップ）では、GLUEとSQuADでRoBERTaと同等であり、XSumではROUGE-1が45.14で従来の38.81を約6ポイント上回り、CNN/DMでも44.16で全指標で先行手法を超えた。ConvAI2とELI5でも最良の結果を得て、WMT16 RO-ENでは逆翻訳を用いた強いベースライン（36.80）に対しBLEU 37.96と1.1ポイントの改善を示した。

**議論はある？**

ELI5のように出力が入力で弱くしか制約されないタスクでは、純粋な言語モデルの方がperplexityで優れ、BARTは相対的に効果が小さい。翻訳では逆翻訳データがない場合に効果が弱く過学習しやすいと述べられており、追加の正則化が今後の課題である。また、要約例には原文に根拠のない記述（Science誌掲載という主張）も見られ、今後はタスクに合わせたノイズ手法の探索が課題として挙げられている。

**次に読むべき論文は？**

- RoBERTa: A Robustly Optimized BERT Pretraining Approach：BARTが判別タスクの主な比較対象とし、事前学習の規模や設定を揃えた基準でもあるため。
- MASS: Masked Sequence to Sequence Pre-training for Language Generation：BARTに最も近いseq2seq事前学習手法であり、両者の違いを理解できるため。
- Unified Language Model Pre-training for Natural Language Understanding and Generation：UniLMは生成と判別の両方を扱う点でBARTと目的が共通し、比較に適しているため。

:::


### 5. 大規模な教師なし言語横断表現学習 {#paper-5}

📈 被引用数上位（Paper Digest の集計で同年2位） ・ Alexis Conneau, Kartikay Khandelwal, Naman Goyal, Vishrav Chaudhary ほか ・ [論文を読む ↗](https://arxiv.org/abs/1911.02116)

<small>原題: Unsupervised Cross-lingual Representation Learning at Scale</small>

100言語・2.5TBのフィルタ済みCommonCrawlデータ（CC-100）でTransformerベースの多言語マスク言語モデルXLM-R（XLM-RoBERTa）を事前学習し、XNLIではmBERTを14.6%、XLM-100を10.2%上回るなど、言語横断ベンチマークで大幅な性能向上を示した研究です。低資源言語でも改善が見られ、言語数増加による性能劣化「curse of multilinguality」や語彙サイズの影響を大規模に分析したうえで、単一の多言語モデルが単言語モデルに匹敵し得ることを初めて示した点が注目されます。ACL 2020で被引用数が同年2位（Paper Digest集計）という影響力の大きさも際立っています。

::: info 📝 落合フォーマット

**どんなもの？**

100言語・2.5TBのフィルタ済みCommonCrawlデータでTransformerベースの多言語マスク言語モデルXLM-R（XLM-RoBERTa）を事前学習し、言語横断転移の性能を大幅に向上させた研究。mBERTやXLMを、XNLI・NER・MLQAなどの言語横断ベンチマークで上回り、低資源言語でも大きな改善を示した。さらに多言語モデルが単言語モデルと同等の性能を保てることも示した。

**先行研究と比べてどこがすごい？**

従来の多言語MLMがWikipediaで学習していたのに対し、CC-100を用いて低資源言語のデータ量を平均で2桁増やし、RoBERTaに倣って学習の不十分さ（undertuned）を解消した。また、言語数の増加で全体性能が劣化する「curse of multilinguality」や、高資源・低資源言語のトレードオフ、語彙サイズの影響を大規模に分析した。単一モデルで全言語を扱いつつ単言語モデルに匹敵する性能が得られることを初めて示した。

**技術や手法のキモはどこ？**

XLMに近い多言語MLM目的関数を、単言語データのみで学習する。言語埋め込みは使わず、SentencePiece（unigram）を生テキストに直接適用し、語彙サイズは250Kとした。言語サンプリングは指数平滑化パラメータα=0.3とし、XLM-R Base（12層、270M）とXLM-R（24層、550M）を学習した。検証パープレキシティが頭打ちになっても学習を続け、大バッチで長く訓練している。

**どうやって有効だと検証した？**

XNLIの言語横断転移でXLM-Rは平均80.9%となり、XLM-100に10.2%、mBERTに14.6%の差をつけた。translate-train-allでは83.6%で新たなSOTAとなった。MLQAではF1/EMが70.7/52.7（従来SOTAは61.6/43.5）、NERでも各言語で転移平均F1がmBERTを2.42上回った。GLUEではRoBERTaに平均で1.0%差まで迫り、7言語の比較ではtranslate-train-allで多言語XLM-7（CC）が80.0%と単言語BERT（77.5%）を上回った。

**議論はある？**

固定容量のモデルでは言語数が増えるほど性能が劣化するcurse of multilingualityが残り、モデルを大きくすれば緩和できるが計算資源の制約があるため重要な課題とされる。RoBERTaとのGLUEでの差（1.0%）は、この問題や語彙の希薄化の軽減で縮められる余地があると述べられている。また、モデルごとの比較は容量の違い以外の要因も含むため、解釈には注意が必要である。

**次に読むべき論文は？**

- Cross-lingual Language Model Pretraining：XLM-RのベースとなったXLM（MLM・TLM）の手法とXNLIでの先行結果を理解するため。
- RoBERTa: A Robustly Optimized BERT Pretraining Approach：XLM-Rが踏襲した、より多くのデータで長く・大バッチで学習するという方針の根拠を確認するため。
- CCNet: Extracting High Quality Monolingual Datasets from Web Crawl Data：XLM-Rの学習データCC-100の構築・フィルタリング手法の詳細を知るため。

:::
