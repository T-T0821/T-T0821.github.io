# ACL 2021

💬 自然言語処理 ・ [ACL の年ごとの流れ](./) ・ [公式サイト ↗](https://www.aclweb.org/)

::: info この回のまとめ
IJCNLP と合同の ACL-IJCNLP 2021 として、2021年8月1〜6日に再びオンラインで開催されました。完全な論文の投稿は3,350本で、本会議に710本（長論文571・短論文139、採択率21.2%）、前年に始まった Findings に457本が掲載されています。最優秀論文は、機械翻訳で使う語彙（サブワード）の大きさと中身を、最適輸送の問題として自動で決める VOLT（ByteDance AI Lab・UCSB ほか）でした。基調講演は Christopher Potts、Helen Meng、Alejandrina Cristia の3氏です。
:::

- **日程**: 2021年8月1日〜6日
- **開催地**: オンライン開催（ACL-IJCNLP 2021）
- **規模**: 投稿 3,350 本 ／ 採択 710 本 ／ 採択率 21.2%（要旨の投稿は4,266本。Findings には457本を掲載）
- **招待講演**: Christopher Potts（スタンフォード大学）、Helen Meng（香港中文大学）、Alejandrina Cristia（高等師範学校）

**📝 注目論文（1 本）**

1. [最適輸送による機械翻訳の語彙学習](#paper-1)

## 🔭 この回の主なテーマ

- トークン化と語彙設計: 試行錯誤に頼っていた語彙サイズの選択を、情報理論と最適輸送で自動化（VOLT）
- 発表の場の拡大: 本会議に届かなかった質の高い論文を Findings として掲載する仕組みが定着
- オンライン開催の継続: 2年続けての完全オンライン

::: tip 💡 技術動向への示唆
- トークン化（語彙）の設計がモデル性能と計算量の両方を左右することが示され、多言語 LLM の語彙設計でも重要な論点であり続けている
- Findings の定着で採択論文数が実質的に増え、NLP 研究の量的な拡大が加速した
:::

## 📝 注目論文

### 1. 最適輸送による機械翻訳の語彙学習 {#paper-1}

🏆 Best Paper ・ Jingjing Xu, Hao Zhou, Chun Gan, Zaixiang Zheng ほか ・ [論文を読む ↗](https://arxiv.org/abs/2012.15671)

<small>原題: Vocabulary Learning via Optimal Transport for Neural Machine Translation</small>

語彙を大きくすると情報は増えるが学習が難しくなる、というトレードオフを「限界効用」として定式化し、最適輸送で最適な語彙を求めます。何通りも学習して比べる手間を省きつつ、少ない語彙で同等以上の翻訳品質を得ました。

::: info 📝 落合フォーマット

**どんなもの？**

機械翻訳における語彙（トークン辞書）の選び方を情報理論の観点から捉え直し、試行学習なしで適切な語彙とそのサイズを自動的に求める手法VOLTを提案した研究。語彙構築を最適輸送（OT）問題として定式化し、多項式時間で解けるようにした。

**先行研究と比べてどこがすごい？**

BPEなど既存のサブワード手法は頻度（エントロピー）しか考慮せず、語彙サイズの影響は試行学習で探す必要があった。本研究は経済学の限界効用に着想を得たMUV（Marginal Utility of Vocabularization）でエントロピーとサイズを同時に扱い、それを最大化する語彙を最適輸送で学習する点が新しい。

**技術や手法のキモはどこ？**

MUVを語彙サイズに対するエントロピーの負の微分と定義し、サイズ列S（bilingualは1K〜10K、multilingualは40K〜160K）の各時点で最大エントロピーの語彙を求め、隣接時点間のエントロピー差が最大となる語彙を選ぶ（式3の上界を最適化）。各時点の語彙探索は、文字分布からトークン分布への輸送行列を求める不均衡エントロピー正則化OTとして緩和し、一般化Sinkhornアルゴリズムで解く。候補トークンにはBPE-100K（multilingualはBPE-300K）を用い、輸送量の少ないトークンを除いて語彙を得る。符号化はBPE同様の貪欲なマージで行う。

**どうやって有効だと検証した？**

WMT-14英独、TEDの二言語翻訳（X→En / En→X、12言語対）、TEDの多言語翻訳（52方向）で評価した。英独ではBPE-30K比で語彙サイズを約70%削減（33.6K→11.6K）しつつ0.5 BLEU向上（29.3→29.8）し、探索コストはBPE-Searchの384 GPU時間に対し0.5 CPU時間＋30 GPU時間（Table 4）だった。多言語ではBPE-60Kに対し多くの言語対で高いBLEUを示し、SentencePiece・WordPieceを1 BLEU超上回った。低資源のTEDではBPE-1Kと同等で、MUVとBLEUの相関は45言語対の約2/3で正（Spearman中央値0.4）だった。

**議論はある？**

MUVとBLEUの正の相関は約2/3のタスクにとどまり、MUVが万能な指標とは言えない。VOLTの語彙はBPEの同サイズ語彙（BPE-9K）と大きく重なり、同等の性能を示したため、BPEをVOLT推定サイズで使うだけでも有効という側面がある。また、標準サイズのアーキテクチャでの検証が中心であり、小さなモデルではより大きな語彙を推奨すると述べられている。Convolutional Seq2SeqではBLEUは同等（26.4 vs 26.3）で、向上ではなく小型化が主な利点だった。

**次に読むべき論文は？**

- Neural Machine Translation of Rare Words with Subword Units：VOLTが比較・初期化に用いるBPEの原典で、頻度ベース語彙構築の基礎を理解できる。
- A Call for Prudent Choice of Subword Merge Operations in Neural Machine Translation：語彙サイズが性能に与える影響と、低資源でBPE-1Kが適する根拠を示しており、本論文の動機と比較対象に直結する。
- Sinkhorn Distances: Lightspeed Computation of Optimal Transport：VOLTが語彙探索に用いるSinkhornアルゴリズムとエントロピー正則化OTの基礎を学べる。

:::
