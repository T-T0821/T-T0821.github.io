# ACL 2024

💬 自然言語処理 ・ [ACL の年ごとの流れ](./) ・ [公式サイト ↗](https://www.aclweb.org/)

::: info この回のまとめ
2024年8月11日からタイのバンコクで6日間開催されました。ARR の2月サイクルで4,835本の投稿があり、本会議に940本（21.3%）、Findings に975本（22.1%）が採択されています。最優秀論文は7本と多く、人間の言語にありえない規則を持つ「不可能な言語」を LLM が学べるかを調べた研究、拡散モデルによる甲骨文字の解読、101言語に対応したオープンな多言語 LLM の Aya、Transformer が入力の小さな変化に敏感な関数を苦手とする理由の理論などが選ばれました。特別テーマ「オープンサイエンス・オープンなデータとモデル」の賞は OLMo、10年前の論文に贈る Test of Time 賞は GloVe でした。
:::

## 🔭 この回の主なテーマ

- LLM と人間の言語: 「不可能な言語」の学習しにくさから、LLM が人間の言語の性質をどこまで反映するかを検証
- LLM の理論: 感度の高い関数が Transformer で学習しにくい理由、記憶の因果的な推定
- オープンな LLM: 多言語の Aya、学習の全過程を公開した OLMo
- 文化・歴史資料への応用: 拡散モデルによる甲骨文字の解読

::: tip 💡 技術動向への示唆
- オープンなモデルとデータ（OLMo・Aya）が特別テーマとして表彰され、研究の再現性と検証可能性が LLM 時代の重要な価値として明示された
- LLM の挙動を理論・言語学の両面から説明しようとする研究が最高賞を占め、「なぜ動くか」を理解する方向に研究の重心が広がっている
:::

### 1. ミッション: インポッシブル言語モデル {#paper-1}

🏆 Best Paper ・ Julie Kallini, Isabel Papadimitriou, Richard Futrell, Kyle Mahowald ほか ・ [論文を読む ↗](https://arxiv.org/abs/2401.06416)

<small>原題: Mission: Impossible Language Models</small>

「LLM は人間に可能な言語も不可能な言語も同じように学べる」という主張を、語順を逆転・ランダム化するなどした人工言語で実験的に検証しました。GPT-2 は不可能な言語ほど学習に苦労することを示し、言語学と LLM 研究をつなげました。

::: info 📝 落合フォーマット

**どんなもの？**

「LLMは人間にとって可能な言語も不可能な言語も同等に学習できる」というChomskyらの主張を実験的に検証した研究。英語を体系的に改変して、ランダムシャッフルや語順の位置カウントに基づく規則などを持つ合成の「不可能言語」群を作り、GPT-2 smallでの学習しやすさを英語と比較した。結果として、GPT-2は不可能言語を英語ほど効率よく学習できないことを示した。

**先行研究と比べてどこがすごい？**

Chomskyらの強い主張に対し、これまで十分な実験的裏付けがなかった（引用されていたのは主にMitchell and Bowers 2020のみ）点に対して、不可能性の連続体上に複数の言語を設計して体系的に検証した。最終的な性能だけでなく、学習の途中の複数チェックポイントで評価して学習過程を比較し、さらにperplexity、surprisal、因果抽象化（interchange intervention）という複数の観点から分析した点が新しい。

**技術や手法のキモはどこ？**

英語文に摂動関数を適用して、*Shuffle（非決定的・決定的・局所・偶奇シャッフル）、*Reverse（部分・完全反転）、*Hop（動詞の数・時制マーカーを動詞の4トークンまたは4語後に置くカウント規則）の3系統の不可能言語を、それぞれ英語に近い対照言語とともにBabyLMデータから作る。各言語でGPT-2 smallをゼロから学習し（乱数シード5通り）、perplexity、マーカートークンのsurprisalによる最小対比較、subject-verb agreementでのinterchange interventionによる内部機構分析を、学習ステップごとに行う。位置エンコーディングを除いたモデルでも追加実験をしている。

**どうやって有効だと検証した？**

実験1では、BabyLMのテスト文1万文のperplexityを比較した。NoShuffleが常に最も低く、NondeterministicShuffleが最も高い。次いで決定的シャッフル、局所シャッフルの順で、窓サイズが小さいほど低かった。*Reverseと*Hopは対照との差が小さかった。実験2の*Hopでは、NoHopがマーカーのsurprisalを最も低く、最小対のsurprisal差を最も大きく示し、TokenHopがWordHopより良好だった。実験3では、全*Hopモデルが主語位置から最終トークン位置へ情報が移る同様のモジュール的な解を獲得したが、NoHopは約1,500ステップでほぼ100%のIIAに到達し、他より早かった。

**議論はある？**

GPT-2 smallという単一アーキテクチャと英語由来の合成言語に限られており、他のアーキテクチャや英語以外の基底言語、より多様な形態操作への拡張が今後の課題である。また、可能・不可能言語の明確な定義がないこと、LLMがトークンをカウントできるなど人間と本質的に異なる点があることから、結果を人間の言語学習に直接結びつけることには注意が必要である。著者らは、GPT系モデルの帰納バイアスが情報の局所性と関係している可能性を示唆している。

**次に読むべき論文は？**

- Priorless recurrent networks learn curiously：Chomskyらが唯一引用する先行実験研究であり、本論文が何に対する反論・拡張なのかを把握できる。
- Findings alignments between interpretable causal variables and distributed neural representations：実験3で用いたinterchange intervention・因果抽象化の手法的背景を理解できる。
- Information-theoretic locality properties of natural language：著者らが自然言語とGPTの帰納バイアスの対応として挙げる情報の局所性の理論的基盤を学べる。

:::


### 2. Aya: 指示チューニングされたオープンな多言語言語モデル {#paper-2}

🏆 Best Paper ・ Ahmet Üstün, Viraat Aryabumi, Zheng-Xin Yong, Wei-Yin Ko ・ [論文を読む ↗](https://arxiv.org/abs/2402.07827)

<small>原題: Aya Model: An Instruction Finetuned Open-Access Multilingual Language Model</small>

半数以上が低資源言語を含む101言語で指示に従うモデルを、重みとデータを公開して開発しました。英語中心になりがちな LLM の恩恵を多言語に広げる取り組みとして評価されました。

::: info 📝 落合フォーマット

**どんなもの？**

101言語（うち50%超が低リソース言語）で指示に従うことができる、大規模多言語の生成言語モデル「Aya」を提案した研究。13Bパラメータのmt5を指示ファインチューニングしたモデルで、データセットとモデルをApache 2.0ライセンスで公開している。英語中心だった指示追従モデルの言語的な不平等を縮小することを目指している。

**先行研究と比べてどこがすごい？**

既存のオープンな多言語指示追従モデル（mT0/BLOOMZが46言語、Bactrian-Xが52言語、Okapiが25言語）の約2倍の101言語に対応した。学習データはxP3の2.5倍にあたる203Mサンプルで、英語の比率はxP3の39%に対し21.5%に抑えている。評価も99言語に拡張し、判別・生成タスク、人手評価、GPT-4による模擬勝率、安全性評価を組み合わせた。

**技術や手法のキモはどこ？**

mT5の13Bモデルを、人手でプルーニングしたxP3x、Data Provenance Collection、Aya Collection（テンプレート・翻訳）、Ayaデータセット（母語話者による人手アノテーション）、ShareGPT-Command（合成データの機械翻訳）の混合データでファインチューニングした。xP3xは人手の監査で、短い出力や重複的なテンプレートなどを除去し、英語テンプレートの50.2%・多言語テンプレートの35.9%を削除した。ソース別の重み付け（人手注釈重視・翻訳重視・テンプレート重視）をアブレーションし、学習予算は25Mサンプル、Adafactor、学習率3×10^-4で行った。安全性対策として、多言語の安全性コンテキスト蒸留を適用した「Aya Safe」も作成した。

**どうやって有効だと検証した？**

未知タスクの判別タスク（XWinograd、XNLI、XCOPA、XStoryCloze）、多言語MMLU、生成タスク（FLORES-200、XLSum、TydiQA）、人手評価とGPT-4による勝率評価で、mT0・BLOOMZ・mT0x・Bactrian-X・Okapiなどと比較した。本文の記載では、mT0xに対する相対的な性能向上は判別タスクで13.1%、生成タスクで11.7%で、7言語の人手評価ではmT0xに対する勝率が75%だった。また、安全性コンテキスト蒸留により敵対的プロンプトでの有害な生成が人手評価で78〜89%減少し、18言語で毒性・社会的バイアス・性別バイアスも分析している。なお、与えられた本文は途中で切れているため、各設定ごとの詳細な結果やアブレーションの結論は確認できていない。

**議論はある？**

ベースモデルのmT5は2019年の古いモデルで、最新のLLMほど強力ではなく、多言語の事前学習済みベースモデルが少ないことが性能の制約になっている。評価タスクの多くは10〜15言語程度にとどまり高・中リソース言語に偏っており、翻訳データには翻訳調（translationese）が混入する点や、言語のリソース量による分類が不完全である点も限界として挙げられている。また、比較対象のモデルはいずれも選好学習（preference training）を行っていない。

**次に読むべき論文は？**

- Aya Dataset: An Open-Access Collection for Multilingual Instruction Tuning：Ayaの学習・評価に使われた母語話者による人手アノテーションデータ、翻訳データ、テンプレートデータの詳細が分かる。
- Crosslingual Generalization through Multitask Finetuning：主要なベースラインであるmT0とBLOOMZ、およびxP3データセットを提案した論文で、Ayaの改善点を比較して理解できる。
- The Data Provenance Initiative: A Large Scale Audit of Dataset Licensing & Attribution in AI：Ayaが寛容なライセンスのデータを選ぶ際に用いたデータ来歴の調査で、指示チューニングデータの英語偏重（73%）の根拠も示されている。

:::


### 3. 拡散モデルによる甲骨文の解読 {#paper-3}

🏆 Best Paper ・ Haisu Guan, Huanxin Yang, Xinyu Wang, Shengwei Han ほか ・ [論文を読む ↗](https://arxiv.org/abs/2406.00684)

<small>原題: Deciphering Oracle Bone Language with Diffusion Models</small>

未解読の甲骨文字に対し、条件付き拡散モデルで対応する現代漢字の画像を生成し、解読の手がかりを与える OBSD を提案した研究です。解読を画像生成タスクとして定式化し、局所的な部首構造を学ぶ Localized Structural Sampling とゼロショット補正を組み合わせることで、素の拡散モデルの Top-1 0.5% を 41.0%（OBS-OCR）まで引き上げ、10回試行では 80.0% に達しました。標準的な符号化も完全なコーパスもない甲骨文という、大規模テキスト前提の NLP が使いにくい対象で、解読済み文字の認識ではなく未解読文字の解読支援に取り組んだ点が注目され、ACL 2024 の Best Paper に選ばれています。

::: info 📝 落合フォーマット

**どんなもの？**

甲骨文字（OBS）の未解読文字に対し、画像生成（条件付き拡散モデル）で対応する現代漢字の画像を生成し、解読の手がかりを与える手法 OBSD を提案した研究。甲骨文には標準的な符号化や完全なコーパスがなく、BERT や GPT のような大規模テキスト前提の NLP 手法が使いにくいという問題に対処する。

**先行研究と比べてどこがすごい？**

解読を画像生成タスクとして定式化し、既存の甲骨研究が主だった解読済み文字の認識・理解ではなく、未解読文字の解読支援に取り組んだ点が新しい。単純な条件付き拡散では意味のない筆画断片しか出ないが、局所的な部首構造を学習させる Localized Structural Sampling（LSS）と、フォント変換で学んだ構造知識を使うゼロショット補正を組み合わせて解決した。事例ベース推論や Cascade GAN など、既解読文字や完全な字形進化経路に依存する先行手法の制約も避けている。

**技術や手法のキモはどこ？**

初期解読では、甲骨文画像を条件、現代漢字画像を目標とする条件付き拡散モデル（U-Net）を、64×64 のパッチ単位で学習する。推論時はスライディングウィンドウで重なるパッチを抽出し、各タイムステップで重複部分を平均化して継ぎ目のアーティファクトを防ぐ（LSS）。その後、FontDiffuser に基づく補正モジュール（MCA・RSI ブロック、クロスアテンションと DCN による変形オフセット）を、20種の現代フォント間の one-to-one 変換で学習し、初期結果の構造の崩れをゼロショットで補正する。

**どうやって有効だと検証した？**

HUST-OBS と EVOBC（1,590字種・71,698画像）を用い、学習:テスト=9:1で、テストの字種は学習に含まれないよう分離した。評価には自作 OBS-OCR（ResNet-101、88,899字種で認識精度99.87%）と PaddleOCR を使用した。単回の Top-1 は OBS-OCR で 41.0%、PaddleOCR で 30.0% と、Pix2Pix・CycleGAN・DRIT++・Palette の 0% や、BBDM（19.5%、OBS-OCR）、CDE（31.0%、OBS-OCR）を上回った。10回試行では OBS-OCR で 80.0%、PaddleOCR で 58.5% に達した。アブレーションでは素の拡散 0.5% が LSS で 37.5%、補正でさらに 41.0% に向上した（OBS-OCR Top-1）。

**議論はある？**

評価は解読済み文字を OCR で照合する疑似的なもので、真に未解読の文字に対する出力の妥当性には専門家による検証が必要であり、著者らも専門家との協力を今後の課題としている。方法は漢字やマヤ文字のような表意・表語文字を想定しており、他の文字体系への適用可能性は今後の検討事項とされている。

**次に読むべき論文は？**

- FontDiffuser: One-shot font generation via denoising diffusion with multi-scale content aggregation and style contrastive learning：OBSD のゼロショット補正モジュールの基盤となっているフォント変換フレームワークを理解できる。
- An open dataset for oracle bone script recognition and decipherment (HUST-OBS)：本研究の学習・評価に使われた甲骨文データセットの内容と構成を確認できる。
- Sundial-GAN: A cascade generative adversarial networks framework for deciphering oracle bone inscriptions：字形進化の経路を使った GAN による甲骨文解読という代表的な先行手法で、本手法との違いを把握できる。

:::


### 4. 記憶プロファイルの因果推定 {#paper-4}

🏆 Best Paper ・ Pietro Lesci, Clara Meister, Thomas Hofmann, Andreas Vlachos ほか ・ [論文を読む ↗](https://arxiv.org/abs/2406.04327)

<small>原題: Causal Estimation of Memorisation Profiles</small>

言語モデルの記憶を、ある事例で学習したことがその事例の予測能力に与える因果効果として定式化し、再学習なしに反事実を推定する手法を提案した研究である。計量経済学の差分の差分(DiD)デザインを取り入れ、学習の各ステップにおける記憶の推移を、特定のモデルインスタンスについて効率的に得られる点が注目される。Pythiaモデル群への適用では、記憶が大きいモデルほど強く持続的であること、データ順序や学習率に左右されること、小さなモデルから大きなモデルの記憶を予測できることが示されており、ACL 2024のBest Paperに選ばれている。

::: info 📝 落合フォーマット

**どんなもの？**

言語モデルの「記憶(memorisation)」を、ある事例で学習したことがその事例の予測能力に与える因果効果として定式化し、反事実を再学習なしに推定する手法を提案した研究。学習全体を通した記憶の推移を表す「記憶プロファイル」を、学習データと検証データの小さなサブセットの挙動観測だけで得られるようにした。Pythiaモデル群に適用し、記憶の性質を分析している。

**先行研究と比べてどこがすごい？**

従来は、データ部分集合を変えて複数回再学習する方法(アーキテクチャ単位の記憶しか測れず高コスト)や、反事実を無視できると仮定する方法(抽出可能性の記憶など)が主流だった。本研究はこれらを潜在的結果の枠組みで統一的に記述し、特定のモデルインスタンスについて、学習の各ステップごとの記憶を効率的に推定できる点が新しい。計量経済学の差分の差分(DiD)デザインを導入し、i.i.d.仮定より弱い平行トレンド仮定で、差分推定量より低分散な推定を可能にした。

**技術や手法のキモはどこ？**

反事実的記憶を、バッチgで学習した場合と学習しなかった場合のチェックポイントcでの性能(対数尤度)の差として定義し、その期待値τ_&#123;g,c}を行列(記憶プロファイル)として表す。反事実項は直接観測できないため、検証セットの性能を用いて推定する。差分推定量は学習バッチと検証セットの平均性能の差で求める。DiD推定量は、学習バッチのg−1からcまでの性能変化から、検証セットの同期間の性能変化を引くことで求め、平行トレンドと無予期の2仮定の下で不偏となる。実際には複数チェックポイントでの性能をパネルとして構築して計算する。

**どうやって有効だと検証した？**

Pythiaモデル群(70Mから12B、重複排除済みPile、約143kステップ、バッチサイズ1,024、第1エポックのステップ約95kまで)に手法を適用し、記憶プロファイルを分析した。その結果、記憶は大きいモデルほど強く持続的であること、データ順序と学習率に左右されること、モデルサイズを超えて傾向が安定しており小さなモデルから大きなモデルの記憶を予測できることを示した。提供された本文には実験の詳細な数値や指標の結果は含まれていない。

**議論はある？**

DiDの妥当性は平行トレンドと無予期の仮定に依存し、また推定はインスタンス単位ではなくバッチ(同一ステップで学習した事例群)単位の平均効果に限られる。本文の範囲では、実験はPythiaと主に対数尤度の性能指標に基づいており、他のモデルや指標への一般化は追加の検証が必要である。

**次に読むべき論文は？**

- Difference-in-Differences with multiple time periods：本手法の推定量の基盤となる、複数時点でのDiDと異質な処置効果の識別を扱った論文であるため。
- Pythia: A suite for analyzing large language models across training and scaling：実験で使われたモデル群とチェックポイント・データ順序の詳細を理解するために必要であるため。
- Quantifying memorization across neural language models：比較対象である抽出可能性に基づく記憶の定義と、その暗黙の仮定を確認するため。

:::


### 5. Video-ChatGPT: 大規模視覚・言語モデルによる詳細な動画理解に向けて {#paper-5}

📈 被引用数上位（Paper Digest の集計で同年1位） ・ Muhammad Maaz, Hanoona Rasheed, Salman Khan, Fahad Shahbaz Khan ・ [論文を読む ↗](https://arxiv.org/abs/2306.05424)

<small>原題: Video-ChatGPT: Towards Detailed Video Understanding via Large Vision and Language Models</small>

動画について詳細な会話ができる動画対話モデル Video-ChatGPT を提案し、動画向けに適応した視覚エンコーダと LLM を統合しました。あわせて10万件の動画-指示ペアのデータセットと、動画対話モデルを定量評価する最初のフレームワークを構築した点が特徴です。ActivityNet-200 に基づく評価やゼロショット動画QA（MSVD-QA 64.9% など）で比較モデルを上回ったと報告されており、同年の被引用数1位（Paper Digest 集計）という点でも注目されます。

::: info 📝 落合フォーマット

**どんなもの？**

動画について詳細な会話ができる動画対話モデル Video-ChatGPT を提案した研究。動画向けに適応した視覚エンコーダと LLM を統合し、動画の内容を理解して対話を生成できる。あわせて10万件の動画-指示ペアのデータセットと、動画対話モデル向けの定量評価フレームワークを構築した。

**先行研究と比べてどこがすごい？**

画像ベースの対話モデルは多かったが動画対話は未開拓であり、本研究は人手支援と半自動の注釈パイプラインでラベルノイズに頑健かつスケーラブルな動画指示データを作る点が新しい。先行の VideoChat と異なり、高品質な指示データ生成の枠組みと、動画対話を定量評価する最初のフレームワークを提案したと主張している。アーキテクチャは事前学習済み CLIP を用いた単純でスケーラブルな設計である。

**技術や手法のキモはどこ？**

LLaVA（CLIP ViT-L/14 と Vicuna-v1.1 7B）を出発点とし、T フレームを独立に CLIP で符号化したのち、空間方向の平均プーリングで時間特徴（T×D）、時間方向の平均プーリングで空間特徴（N×D）を得て連結する。これを学習可能な線形層で LLM の入力空間に射影し、テキストクエリと連結して入力する。学習では動画エンコーダと LLM を凍結し線形層のみを更新する。データは、ActivityNet-200 のキャプションを人手で詳細化する方法と、BLIP-2・GRiT・Tag2Text を用いて Tag2Text のタグと合わない記述を除去してノイズを抑えつつ、GPT-3.5 で動画レベルのキャプションと質問応答を生成する半自動方法で作る。

**どうやって有効だと検証した？**

ActivityNet-200 に基づくテストセットで、GPT-3.5 を使った1〜5点評価（正確性、詳細性、文脈理解、時間理解、一貫性）を行い、Video Chat、LLaMA Adapter、Video-LLaMA と比較した。Video-ChatGPT は正確性 2.40、詳細性 2.52、文脈理解 2.62、一貫性 2.37 などで最高スコアを示し、時間理解は 1.98 で LLaMA Adapter と同値で最高だった。ゼロショット動画QAでは MSVD-QA 64.9%、MSRVTT-QA 49.3%、TGIF-QA 51.4%、ActivityNet-QA 35.2% を達成し、比較モデルを上回ったと報告している。アブレーションでは人手注釈のみ・半自動のみより両者の併用が全体として良く（平均 2.38）、評価者を Vicuna-1.5 (13B) に替えても同様の傾向を確認した。

**議論はある？**

約2分を超える長い動画での微妙な時間的関係の理解や、小さな物体の細部の認識が苦手であるとされている。また、時間理解のスコアは比較モデルと同程度にとどまり、評価が GPT-3.5 等の LLM に依存する点や、データ作成過程に残りうるバイアスにも注意が必要である。

**次に読むべき論文は？**

- Visual Instruction Tuning (LLaVA)：Video-ChatGPT の基盤モデルであり、視覚指示チューニングの考え方とアーキテクチャを理解するために必要である。
- VideoChat: Chat-centric Video Understanding：同時期の最も近い動画対話モデルであり、本論文の主要な比較対象として設計やデータ構築の違いを把握できる。
- Video-LLaMA: An Instruction-tuned Audio-Visual Language Model for Video Understanding：比較対象の一つである動画向け LLM で、音声も含めた別アプローチとの違いを確認できる。

:::
