# ACL

💬 [自然言語処理](../#nlp) ・ Annual Meeting of the Association for Computational Linguistics ・ 毎年7〜8月 ・ [公式サイト ↗](https://www.aclweb.org/)

::: info 2020年からの流れ
ACL は計算言語学会の年次大会で、NLP で最も歴史と権威のある会議です。2020〜2021年はオンライン開催で、CheckList（2020年）と機械翻訳の語彙を最適輸送で決める VOLT（2021年）が最優秀論文でした。2022年から ACL Rolling Review による査読に移り、2023年に「大規模言語モデル」が主要分野に加わると、最高賞も LLM のユーモア理解や政治的偏り（2023年）、「不可能な言語」や Aya（2024年）、DeepSeek の Native Sparse Attention（2025年）と LLM 関連が中心になりました。2026年は投稿12,148本と過去最多で、2027年は京都で開催予定です。
:::

## 📅 各回のまとめ

- **ACL 2027** — 開催前です<br><small>2027年8月17日〜22日 ・ 日本・京都</small>
- **[ACL 2026](./2026)** — サンディエゴ開催・投稿1.2万本。LLM 全盛の中、最優秀論文3本は言語学・形式理論寄りの研究に<br><small>2026年7月2日〜7日 ・ 米国・サンディエゴ</small>
- **[ACL 2025](./2025)** — ウィーン開催・投稿8,360本で過去最多。DeepSeek の Native Sparse Attention など4本が最優秀論文に<br><small>2025年7月27日〜8月1日 ・ オーストリア・ウィーン</small>
- **[ACL 2024](./2024)** — バンコク開催。「不可能な言語」を学べるかを問う研究や甲骨文字の解読、多言語 LLM の Aya など7本が最優秀論文に<br><small>2024年8月11日〜16日 ・ タイ・バンコク</small>
- **[ACL 2023](./2023)** — トロント開催。LLM が主要分野に加わり、ユーモア理解のベンチマークや政治的偏りの追跡が最優秀論文に<br><small>2023年7月9日〜14日 ・ カナダ・トロント（ハイブリッド）</small>
- **[ACL 2022](./2022)** — ダブリンでハイブリッド開催。構文解析の学習済み表現を扱う研究が最優秀論文、プロンプトの並び順の研究も受賞<br><small>2022年5月22日〜27日 ・ アイルランド・ダブリン（ハイブリッド）</small>
- **[ACL 2021](./2021)** — ACL-IJCNLP としてオンライン開催。機械翻訳の語彙を最適輸送で決める VOLT（ByteDance ほか）が最優秀論文に<br><small>2021年8月1日〜6日 ・ オンライン開催（ACL-IJCNLP 2021）</small>
- **[ACL 2020](./2020)** — シアトル開催予定からオンラインへ。モデルを「振る舞いのテスト」で評価する CheckList が最優秀論文に<br><small>2020年7月5日〜10日 ・ オンライン開催（当初予定は米国・シアトル）</small>

## 🔭 年ごとのテーマの移り変わり

- 2020: 振る舞いテストによる評価（CheckList）、ドメイン適応の追加事前学習
- 2021: 語彙設計の自動化（VOLT）、Findings の定着
- 2022: ARR の導入、プロンプトの並び順への過敏さ、言語の多様性
- 2023: LLM が主要分野に、ユーモア理解の限界、政治的偏りの追跡
- 2024: 「不可能な言語」、オープンな LLM（Aya・OLMo）、Transformer の理論
- 2025: 疎なアテンション（NSA）、アラインメントの戻りやすさ、第一著者の過半数が中国
- 2026: 投稿1.2万本、エージェントや安全性のトラック新設、言語学・形式理論寄りの最優秀論文

::: tip 💡 技術動向への示唆
- 投稿は6年で約4倍に増え、ほぼすべてのトラックが LLM 中心になった一方、最高賞は LLM の限界や原理を問う研究に多く与えられており、性能競争と理解の研究が並走している
- 2025年に第一著者の過半数が中国となるなど研究の担い手が大きく変わっており、中国発の効率化技術（DeepSeek など）の動向を追うことが欠かせない
:::
