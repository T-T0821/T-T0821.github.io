# 🎓 主要AI国際会議

AI 分野の主要国際会議について、2020年以降の各回の概要・受賞論文・技術動向への示唆を日本語でまとめています。特に注目された論文は落合フォーマットで要約しています。新しい回が開催されると自動で追加します。

**🆕 最近の回**

1. [EMNLP 2026](./emnlp/2026) — ブダペスト開催・採択5,252本。人間と LLM の答え方の違いを比べる DiscoTrace と線形アテンションの改良が最優秀論文に
2. [ECCV 2026](./eccv/2026) — マルメ開催・投稿1万本超。UV 展開を不要にする熱核テクスチャ（インペリアル・カレッジ）が最優秀論文に
3. [IJCAI 2026](./ijcai/2026) — ブレーメンで ECAI と合同開催。エージェント型 AI が主題となり、予算配分の投票や長文脈時系列の推論効率化が最優秀論文に
4. [KDD 2026](./kdd/2026) — 済州島開催。行列演算で超高速に近傍探索の索引を作る PiPNN と、Web 規模のマルチキャリブレーション MCGrad が最優秀論文に
5. [ICML 2026](./icml/2026) — 投稿約2.4万本・ソウル開催。拡散 LM の「自由な生成順序」の罠と、拡散モデルの高精度サンプリング理論が受賞した回

**🗓️ 開催予定**

- NeurIPS 2026 — 2026年12月6日〜13日 ・ オーストラリア・シドニー（アトランタ・パリにサテライト会場）
- AAAI 2027 — 2027年2月16日〜23日 ・ カナダ・モントリオール
- ICLR 2027 — 2027年4月26日〜30日 ・ 未発表
- CVPR 2027 — 2027年6月 ・ 米国・シアトル（日程は公式ページ内で記載が食い違っている）
- ICML 2027 — 2027年7月31日〜8月6日 ・ ブラジル・リオデジャネイロ
- KDD 2027 — 2027年8月1日〜5日 ・ 米国・サンノゼ
- IJCAI 2027 — 2027年8月7日〜13日 ・ 日本・京都（中国・横琴でも8月15〜17日に開催）
- ACL 2027 — 2027年8月17日〜22日 ・ 日本・京都
- ICCV 2027 — 2027年10月2日〜8日 ・ 中国・香港

## 🤖 AI・機械学習全般 {#ml}

「機械学習の3大トップ会議」と呼ばれ、深層学習や基盤モデルの最重要論文が集中します。

::: info 分野の流れ
2020年の GPT-3 受賞から始まり、2022年に Chinchilla（計算最適なスケーリング）と拡散モデル、2023年に DPO と LLM 評価、2024〜2025年に世界モデル・推論と強化学習へと、3会議の最高賞の対象は「大きくする」から「どう学習し、どう検証し、どう安全に使うか」へ移ってきました。投稿数は NeurIPS が約9,500本（2020年）から約2.2万本（2025年）、ICML が約5,000本から約2.4万本（2026年）、ICLR が約2,600本から約2万本（2026年）へ急増しています。
:::

- **[ICML](./icml/)** — International Conference on Machine Learning<br><small>[2026](./icml/2026) ・ [2025](./icml/2025) ・ [2024](./icml/2024) ・ [2023](./icml/2023) ・ [2022](./icml/2022) ・ [2021](./icml/2021) ・ [2020](./icml/2020)</small>
- **[ICLR](./iclr/)** — International Conference on Learning Representations<br><small>[2026](./iclr/2026) ・ [2025](./iclr/2025) ・ [2024](./iclr/2024) ・ [2023](./iclr/2023) ・ [2022](./iclr/2022) ・ [2021](./iclr/2021) ・ [2020](./iclr/2020)</small>

::: tip 💡 分野横断の示唆
- 最先端の研究テーマは「モデル規模」から「データの質・学習後の調整（アラインメントや強化学習）・評価方法」へ移っており、実務でも自社データと評価設計が差別化の源泉になる
- 拡散モデル・状態空間モデル・拡散言語モデルなど、Transformer の自己回帰以外の選択肢が毎年最高賞に入っており、アーキテクチャの多様化は今後も続く
- 安全性・プライバシー・透かし・攻撃耐性が毎年受賞しており、生成 AI を製品に組み込む際の非機能要件として定着した
- 投稿数の急増で査読の信頼性が課題になっており、論文の主張は再現実験やコード公開の有無とあわせて評価する必要がある
:::

## 🏛️ AI全般（老舗・総合） {#ai}

AI分野で最も歴史と権威のある総合国際会議で、理論から応用まで幅広いテーマを扱います。

::: info 分野の流れ
AAAI と IJCAI は機械学習だけでなく、計画・論理・知識表現・マルチエージェント・計算社会選択などを含む総合 AI 会議です。最高賞は2020〜2023年に常識推論ベンチマーク、時系列 Transformer、推薦の公平性、逆強化学習の頑健性など幅広いテーマから選ばれ、2024年以降は創薬、ニューロシンボリック推論、ロボットの VLA モデル、規範に従う強化学習、エージェント型 AI へと広がりました。AAAI の投稿は約7,700本（2020年）から約2.4万本（2026年）に増えた一方、IJCAI は採択率12〜15%前後の狭き門を保っています。
:::

- **[AAAI](./aaai/)** — AAAI Conference on Artificial Intelligence<br><small>[2026](./aaai/2026) ・ [2025](./aaai/2025) ・ [2024](./aaai/2024) ・ [2023](./aaai/2023) ・ [2022](./aaai/2022) ・ [2021](./aaai/2021) ・ [2020](./aaai/2020)</small>
- **[IJCAI](./ijcai/)** — International Joint Conference on Artificial Intelligence<br><small>[2026](./ijcai/2026) ・ [2025](./ijcai/2025) ・ [2024](./ijcai/2024) ・ [2023](./ijcai/2023) ・ [2022](./ijcai/2022) ・ [2021](./ijcai/2021) ・ [2020](./ijcai/2020)</small>

::: tip 💡 分野横断の示唆
- LLM 全盛の中でも、論理・計画・社会選択といった記号的な AI が毎年最高賞に選ばれており、LLM の弱点（推論の一貫性・規則遵守）を補う技術として再評価が進んでいる
- 安全性・公平性・規範遵守を扱う専用トラックが両会議で増えており、AI ガバナンスや規制対応を見据えた研究が主流の一角になった
- エージェント型 AI とマルチエージェントの協調が2026年の中心テーマで、IJCAI がもともと強い分野と LLM エージェントの研究が合流しつつある
- IJCAI-27 は京都で開催予定で、日本の企業・研究者が総合 AI 会議の動向に直接触れる好機になる
:::

## 👁️ 画像認識・CV {#cv}

コンピュータビジョン分野の最高峰会議です。特にCVPRは全科学分野でもトップクラスの影響力を持ちます。

::: info 分野の流れ
CV の3会議の最高賞は、2020〜2022年に教師なし3D復元・光学フロー（RAFT）・NeRF 系の生成モデル・Swin Transformer など「画像をどう表現し、3Dをどう復元するか」の研究が中心でした。2023年に UniAD（自動運転）・Visual Programming（LLM による視覚推論）・Segment Anything と基盤モデルや LLM との結合が評価され、2025〜2026年は VGGT・D4RT のように最適化を1回の推論で置き換えるフィードフォワード3D/4D復元が主役になっています。投稿は CVPR が約6,700本（2020年）から約1.6万本（2026年）、ICCV が約6,200本（2021年）から約1.1万本（2025年）、ECCV が約5,000本（2020年）から1万本超（2026年）に増えました。
:::

- **[CVPR](./cvpr/)** — IEEE/CVF Conference on Computer Vision and Pattern Recognition<br><small>[2026](./cvpr/2026) ・ [2025](./cvpr/2025) ・ [2024](./cvpr/2024) ・ [2023](./cvpr/2023) ・ [2022](./cvpr/2022) ・ [2021](./cvpr/2021) ・ [2020](./cvpr/2020)</small>
- **[ICCV](./iccv/)** — IEEE/CVF International Conference on Computer Vision<br><small>[2025](./iccv/2025) ・ [2023](./iccv/2023) ・ [2021](./iccv/2021)</small>
- **[ECCV](./eccv/)** — European Conference on Computer Vision<br><small>[2026](./eccv/2026) ・ [2024](./eccv/2024) ・ [2022](./eccv/2022) ・ [2020](./eccv/2020)</small>

::: tip 💡 分野横断の示唆
- 3D・4D復元が「シーンごとの最適化」から「大規模学習済みモデルによる1回の推論」へ移っており、測量・ロボット・AR などで3D取得のコストが大きく下がる
- Segment Anything や VLM のように、CV でも汎用の基盤モデルを使い分野ごとに調整する流れが定着した
- 画像生成は画質競争から、編集のしやすさ・人間の評価との一致・物理的な実現可能性（BrickGPT）へと評価軸が移っている
- 単一光子カメラや自由形状の画素など、センサーと AI を一体で設計する計算イメージングが毎回のように受賞しており、ハードウェアの工夫が差別化要因になりうる
:::

## 💬 自然言語処理 {#nlp}

言語モデルやテキスト解析など、NLP分野における世界最高峰の国際会議です。

::: info 分野の流れ
NLP の2会議の最高賞は、2020〜2021年に CheckList（振る舞いテスト）や VOLT（語彙設計）、無発声音声の合成など評価や基盤技術の研究から選ばれました。ChatGPT 後の2023年からは、LLM のユーモア理解の限界、政治的偏り、文脈内学習の仕組み（2023年）、「不可能な言語」やオープンな多言語 LLM（2024年）、DeepSeek の疎なアテンションやアラインメントの戻りやすさ、学習データの検索（2025年）と、LLM を測り・理解し・効率化する研究が中心になりました。2026年は投稿の大半が LLM とエージェントでありながら、最高賞は言語学・形式理論寄りの研究にも与えられています。ACL の投稿は約3,100本（2020年）から約1.2万本（2026年）に、EMNLP の採択は約750本（2020年）から本会議と Findings を合わせ5,000本超（2026年）に増えました。
:::

- **[ACL](./acl/)** — Annual Meeting of the Association for Computational Linguistics<br><small>[2026](./acl/2026) ・ [2025](./acl/2025) ・ [2024](./acl/2024) ・ [2023](./acl/2023) ・ [2022](./acl/2022) ・ [2021](./acl/2021) ・ [2020](./acl/2020)</small>
- **[EMNLP](./emnlp/)** — Conference on Empirical Methods in Natural Language Processing<br><small>[2026](./emnlp/2026) ・ [2025](./emnlp/2025) ・ [2024](./emnlp/2024) ・ [2023](./emnlp/2023) ・ [2022](./emnlp/2022) ・ [2021](./emnlp/2021) ・ [2020](./emnlp/2020)</small>

::: tip 💡 分野横断の示唆
- LLM の評価・解釈・学習データの検証（偏り、汚染、文脈内学習の仕組み）が毎年最高賞を得ており、LLM を製品に使う際の品質保証の方法論がこの分野から生まれている
- 多言語・多文化への対応が繰り返し表彰されており、英語以外の言語や文化圏での性能差は依然として大きな課題である
- 疎なアテンションや線形アテンションなど推論の効率化が最高賞に入るようになり、長文脈を安く扱う技術が研究と実用の両面で重要になっている
- ACL-27 は京都で開催予定で、IJCAI-27 とあわせて2027年は日本で主要 AI 会議が続く
:::

## 🔎 データマイニング・Web {#dm}

検索技術、推薦システム、ビッグデータ解析など、ITサービスの実装に直結する研究が集まります。

::: info 分野の流れ
KDD と WWW の最高賞は、推薦システムの評価（2020年）、移動データによる COVID-19 対策（2021年）、推薦が過激化を招く経路の緩和（2022年）、ボット検出ベンチマークの欠陥（2023年）など、実データに基づく分析と社会への影響を扱う研究が多いのが特徴です。2023年以降はグラフのプロンプト学習や LinkedIn の GNN 基盤、LLM のためのメカニズムデザイン（2024年）、A/B テストの判断ルール（2025年）、ベクトル検索の索引構築や医療 RAG（2026年）と、LLM 時代のデータ基盤と意思決定に重心が移っています。WWW の投稿は約1,100本（2020年）から3,370本（2026年）に増え、KDD は2025年にデータセット・ベンチマークトラックを新設しました。
:::

- **[KDD](./kdd/)** — ACM SIGKDD Conference on Knowledge Discovery and Data Mining<br><small>[2026](./kdd/2026) ・ [2025](./kdd/2025) ・ [2024](./kdd/2024) ・ [2023](./kdd/2023) ・ [2022](./kdd/2022) ・ [2021](./kdd/2021) ・ [2020](./kdd/2020)</small>
- **[WWW](./www/)** — The ACM Web Conference (WWW)<br><small>[2026](./www/2026) ・ [2025](./www/2025) ・ [2024](./www/2024) ・ [2023](./www/2023) ・ [2022](./www/2022) ・ [2021](./www/2021) ・ [2020](./www/2020)</small>

::: tip 💡 分野横断の示唆
- 推薦・広告・A/B テストなど企業の実データを使う研究が毎年最高賞を得ており、両会議の受賞論文は Web サービスの設計や運用にそのまま応用しやすい
- 推薦による過激化、ボット検出の信頼性、エコーチェンバーなど、Web の社会的な副作用を測り、緩和する研究が繰り返し評価されている
- ベクトル検索・RAG・エージェントが使う Web（Agentic Web）など、LLM を支えるデータ基盤が新しい中心テーマになりつつある
:::
