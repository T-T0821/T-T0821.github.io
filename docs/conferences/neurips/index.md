# NeurIPS

🤖 [AI・機械学習全般](../#ml) ・ Conference on Neural Information Processing Systems ・ 毎年12月 ・ [公式サイト ↗](https://neurips.cc/)

::: info 2020年からの流れ
NeurIPS は機械学習で最大規模の会議で、2020年の GPT-3、2022年の Chinchilla と Imagen、2023年の DPO、2024年の VAR、2025年の Gated Attention と、その年の基盤モデル研究の到達点を最高賞が映してきました。2021年に Datasets and Benchmarks トラックが新設され、評価とデータそのものが研究成果として扱われるようになったのも大きな変化です。参加者は2025年に2.6万人を超え、2025年は2都市、2026年はシドニーを中心に3都市での開催となっています。
:::

## 📅 各回のまとめ

- **NeurIPS 2026** — 開催前です<br><small>2026年12月6日〜13日 ・ オーストラリア・シドニー（アトランタ・パリにサテライト会場）</small>
- **[NeurIPS 2025](./2025)** — 投稿2万本超・2都市開催。アテンションのゲート化、拡散モデルの記憶、RL は推論力を伸ばすのかが問われた回<br><small>2025年12月 ・ 米国・サンディエゴ／メキシコ・メキシコシティ</small>
- **[NeurIPS 2024](./2024)** — 登録者約2万人。画像生成の次トークン予測化（VAR）と、事前学習データのトークン選別が受賞した回<br><small>2024年12月10日〜15日 ・ カナダ・バンクーバー</small>
- **[NeurIPS 2023](./2023)** — ChatGPT 後最初の NeurIPS。DPO・「創発は幻か」・LLM の信頼性評価など、LLM を検証し使いこなす研究が受賞した回<br><small>2023年12月10日〜16日 ・ 米国・ニューオーリンズ</small>
- **[NeurIPS 2022](./2022)** — 3年ぶりの現地開催。Chinchilla・Imagen・LAION-5B など、基盤モデルの「作り方」を決めた研究が受賞した回<br><small>2022年11月28日〜12月9日 ・ 米国・ニューオーリンズ（第2週はオンライン）</small>
- **[NeurIPS 2021](./2021)** — 2年連続のオンライン開催。データセット・ベンチマーク専用トラックが新設され「評価の質」に光が当たった回<br><small>2021年12月6日〜14日 ・ オンライン開催</small>
- **[NeurIPS 2020](./2020)** — コロナ禍で初の完全オンライン開催。GPT-3 が最優秀論文に選ばれ、大規模言語モデル時代の幕開けを告げた回<br><small>2020年12月6日〜12日 ・ オンライン開催（当初予定はバンクーバー）</small>

## 🔭 年ごとのテーマの移り変わり

- 2020: GPT-3 が最優秀論文。大規模事前学習と少数例学習の時代へ
- 2021: ロバスト性の理論、評価の統計的な厳密さ、データセット研究の制度化
- 2022: Chinchilla（計算最適なスケーリング）、拡散モデル（Imagen・EDM）、LAION-5B
- 2023: DPO、創発的能力への疑問、LLM の信頼性評価（DecodingTrust）
- 2024: 自己回帰による画像生成（VAR）、事前学習データのトークン選別
- 2025: アテンションの改良、強化学習は推論力を本当に伸ばすのか、出力の均質化

::: tip 💡 技術動向への示唆
- 最高賞が「性能を上げる手法」だけでなく「主張を検証する研究」（創発の幻、RL の効果検証）にも与えられており、LLM の能力評価は今後も中心テーマであり続ける
- データセット・ベンチマークが正式な研究成果として扱われるようになり、良い評価データを作ること自体が競争力になった
:::
