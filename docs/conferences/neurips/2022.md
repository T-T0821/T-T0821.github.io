# NeurIPS 2022

🤖 AI・機械学習全般 ・ [NeurIPS の年ごとの流れ](./) ・ [公式サイト ↗](https://neurips.cc/)

::: info この回のまとめ
ニューオーリンズで3年ぶりに現地開催され、第2週はオンラインのハイブリッド形式でした。投稿は約10,400本です。最優秀論文は13本と多く、計算資源に対して最適なモデル規模とデータ量の比を示した Chinchilla、テキストから画像を生成する Imagen、拡散モデルの設計空間を整理した EDM などが選ばれました。データセット部門では LAION-5B と MineDojo が受賞し、Test of Time 賞には AlexNet（2012年）が満場一致で選ばれました。ChatGPT 公開（2022年11月30日）とほぼ同時期の開催です。
:::

- **日程**: 2022年11月28日〜12月9日
- **開催地**: 米国・ニューオーリンズ（第2週はオンライン）
- **規模**: 投稿 10,411 本 ／ 採択率 25.6%（採択数は出典で未記載）

**📝 注目論文（1 本）**

1. [Chinchilla：計算量に対して最適な LLM の学習](#paper-1)

## 🔭 この回の主なテーマ

- スケーリング則の精緻化: Chinchilla が「パラメータを増やすより学習トークンを増やせ」と示し、以降の LLM 設計を変えた
- 拡散モデルの成熟: Imagen（テキスト→画像）、EDM（設計空間の整理）、リーマン多様体上のスコアモデルが同時受賞
- オープンな大規模データ: LAION-5B（50億の画像・テキスト対）がオープンな画像生成モデル開発を支える基盤に
- 身体性 AI・エージェント: MineDojo（Minecraft）や ProcTHOR（手続き生成の3D環境）でインターネット規模の知識と行動学習を結ぶ

::: tip 💡 技術動向への示唆
- 最適な「モデル規模：データ量」の比が示されたことで、データの確保と品質が LLM 開発の主戦場になった
- 画像生成は研究段階から実用段階へ移り、オープンデータとオープンモデルが商用サービスと競う構図ができた
- エージェント研究の土台（環境・データ）がこの年に整い、数年後の LLM エージェントブームにつながっている
:::

## 📝 注目論文

### 1. Chinchilla：計算量に対して最適な LLM の学習 {#paper-1}

🏆 Outstanding Paper（受賞時の題名は "An empirical analysis of compute-optimal large language model training"） ・ Jordan Hoffmann, Sebastian Borgeaud, Arthur Mensch, Elena Buchatskaya ほか ・ [論文を読む ↗](https://arxiv.org/abs/2203.15556)

<small>原題: Training Compute-Optimal Large Language Models</small>

同じ計算予算なら、モデルを小さくしてその分多くのデータで学習した方が強いことを400以上のモデルで示しました。700億パラメータの Chinchilla が2,800億の Gopher を上回り、以降の LLM の学習レシピの基準になりました。

::: info 📝 落合フォーマット

**どんなもの？**

固定の計算予算（FLOPs）のもとで、Transformer言語モデルのモデルサイズと学習トークン数をどう配分すべきかを実証的に調べた研究。現行の大規模LLMは学習データ量が足りず「学習不足」であると指摘し、その予測を検証するためにGopherと同じ計算量で70Bパラメータ・1.4兆トークン学習のChinchillaを訓練した。

**先行研究と比べてどこがすごい？**

Kaplan et al. (2020) は計算予算が10倍になるとモデルサイズを5.5倍、学習トークンを1.8倍にすべきとしたが、本研究は両者をほぼ同じ比率で増やすべきと結論づけた。差が生じる理由として、Kaplanらは全モデルで学習トークン数と学習率スケジュールを固定していた点を挙げ、本研究は学習率スケジュールを学習トークン数に合わせ、より大きなモデル（最大16B）を含めた点を指摘している。

**技術や手法のキモはどこ？**

70M〜16B超のパラメータ、5B〜400B超トークンで400以上のモデルを学習し、3つの手法で最適配分を推定した。(1) 固定サイズのモデルでトークン数を変えた学習曲線の下側包絡線を取る、(2) 9種類の固定FLOPs（6e18〜3e21）でモデルサイズを変えたIsoFLOPプロファイルに放物線をフィットする、(3) L(N,D)=E+A/N^α+B/D^β というパラメトリック損失をHuber損失とL-BFGSで当てはめ、FLOPs≈6NDの制約下で最適点を求める。いずれもN_opt∝C^a、D_opt∝C^bのべき乗則で表す。

**どうやって有効だと検証した？**

3手法のスケーリング指数はa=0.50/0.49/0.46、b=0.50/0.51/0.54とほぼ一致し、Kaplanらの0.73/0.27と明確に異なった。Chinchilla（70B）はGopher（280B）、GPT-3、Jurassic-1、MT-NLG 530Bを幅広い下流タスクで上回り、MMLUの5-shot平均精度は67.6%（Gopherより7.6ポイント向上）、BIG-benchは65.1%（Gopherは54.4%）だった。毒性は両モデルでほぼ差がなく、性別バイアス（Winogender）は正答率が全体で改善したものの、グループ間で改善幅に差が残った。

**議論はある？**

大規模での比較はChinchillaとGopherの2本のみで、中間スケールでの検証がない。また、べき乗則の仮定に対して高計算量域で対数N_optに凹性が見られ、最適モデルサイズをなお過大評価している可能性がある。さらに、学習はすべて1エポック未満であり、複数エポックの領域は未検討で、高品質な大規模データの収集とデータ汚染・倫理面への配慮が今後の課題である。

**次に読むべき論文は？**

- Scaling Laws for Neural Language Models：本論文が直接の比較・反論対象としている先行研究で、スケーリング則の前提と結論の違いを理解できる。
- Scaling language models: Methods, analysis & insights from training Gopher：ChinchillaがFLOPsを揃えて比較したベースライン（Gopher）の詳細と評価設定が書かれている。
- Improving language models by retrieving from trillions of tokens：検索機構で実質的な学習データ量を増やす手法で、性能が学習データ量に強く依存するという本論文の示唆と関連する。

:::
