# NeurIPS 2024

🤖 AI・機械学習全般 ・ [NeurIPS の年ごとの流れ](./) ・ [公式サイト ↗](https://neurips.cc/)

::: info この回のまとめ
バンクーバーで開催され、登録者は19,756人に増えました。本会議は投稿15,671本・採択4,037本（25.8%）です。最優秀論文は、画像を粗い解像度から細かい解像度へ「次のスケール」を予測して生成する VAR と、高階微分を効率よく推定する確率的テイラー推定器（STDE）の2本でした。次点は「すべてのトークンが学習に必要なわけではない」と示した事前学習データ選別の研究と、拡散モデルを自分の劣化版で誘導する Autoguidance。Test of Time 賞は GAN と Seq2Seq の2本で、深層生成モデルと系列変換という現在の LLM・生成 AI の源流が同時に表彰されました。
:::

## 🔭 この回の主なテーマ

- 自己回帰モデルによる画像生成: VAR が拡散モデルに迫る品質と、LLM と同様のスケーリング則を示した
- 事前学習データの質: トークン単位で学習に使うデータを選ぶ Rho-1 が次点に。量から質への転換
- 拡散モデルの誘導手法: CFG（分類器なし誘導）に代わる Autoguidance で品質と多様性を両立
- アラインメント用データ: 多文化・多様な人間のフィードバックを集めた PRISM がデータセット部門で受賞

::: tip 💡 技術動向への示唆
- 画像と言語を同じ「次トークン予測」の枠組みで扱う流れが強まり、マルチモーダル統合モデルの設計に影響している
- 「データをさらに集める」から「どのデータで学習するか選ぶ」へ重心が移り、データキュレーションが競争力の源泉になった
- 誰の価値観に合わせるのかというアラインメントの多様性が、技術課題として扱われ始めた
:::

### 1. VAR：次のスケールを予測する画像生成 {#paper-1}

🏆 Best Paper ・ Keyu Tian, Yi Jiang, Zehuan Yuan, Bingyue Peng ほか ・ [論文を読む ↗](https://arxiv.org/abs/2404.02905)

<small>原題: Visual Autoregressive Modeling: Scalable Image Generation via Next-Scale Prediction</small>

画像を左上から1トークンずつではなく、低解像度から高解像度へ段階的に予測する自己回帰モデルで、拡散モデルを上回る品質と速度、LLM と同様のスケーリング則を示しました。

::: info 📝 落合フォーマット

**どんなもの？**

画像の自己回帰生成を、ラスタースキャン順の「次トークン予測」ではなく、粗い解像度から細かい解像度へトークンマップ単位で予測する「次スケール予測」として再定義したVisual AutoRegressive modeling (VAR)を提案した研究。GPT型の自己回帰モデルとして初めて、ImageNet 256×256でDiffusion Transformerを上回る画質と高速な推論を実現し、LLMに見られるスケーリング則とゼロショット汎化も確認した。

**先行研究と比べてどこがすごい？**

従来の画像ARはトークンを1次元に平坦化するため、VQVAE特徴の双方向依存と単方向仮定の矛盾、空間的局所性の劣化、O(n^6)の計算量といった問題があった。VARは自己回帰の単位をトークンマップにしてこれらを回避し、計算量をO(n^4)、反復回数をO(log n)に削減した。GPT型ARがDiTを上回った初の例であり、スケーリング則も実証した。

**技術や手法のキモはどこ？**

二段階構成で、第1段階では共有コードブック(V=4096)を使う多スケールVQVAEが画像をK個のトークンマップ(1×1から最終解像度まで)に残差方式で量子化する。第2段階ではGPT-2型のデコーダ専用Transformerにブロック単位の因果マスクを適用し、先行する全スケールを条件に次のスケールの全トークンを並列に予測する。モデルはAdaLN、クラス埋め込みを開始トークンとする条件付け、attention前のqueryとkeyの単位ベクトル正規化により構成され、幅・ヘッド数・ドロップ率を深さdに比例させて拡大する。

**どうやって有効だと検証した？**

ImageNet 256×256のクラス条件付き生成で、VAR-d30(2B)はFID 1.73、IS 350.2(棄却サンプリング使用)を達成し、VQGANベースのAR(FID 18.65、IS 80.4)を大きく上回った。DiT-XL/2に対しては約45倍高速で、学習エポックは350対1400と少なく、512×512でもVAR-d36-sがFID 2.63でDiT-XL/2(3.04)を上回った。12種類のモデル(18.5Mから2B)ではテスト損失とモデルサイズ・計算量の間にべき乗則が成り立ち、相関係数は約-0.998であった。さらにゼロショットでインペインティング、アウトペインティング、クラス条件付き編集が可能であることも示した。

**議論はある？**

VQVAEの構造や学習はベースラインのまま据え置かれており、より優れたトークナイザやサンプリング手法による改善余地が残る。テキスト条件付き生成と動画生成(3Dの次スケール予測)は未実装で今後の課題とされ、LLMとの統合や長い時間依存の扱いに優位性があると主張されているが、本論文では検証されていない。

**次に読むべき論文は？**

- Taming Transformers for High-Resolution Image Synthesis (VQGAN)：VARが直接のベースラインとし、トークナイザの構造も踏襲しているラスタースキャン型ARの基礎となる論文であるため。
- Scalable Diffusion Models with Transformers (DiT)：VARが画質・速度・スケーラビリティの面で比較・上回ったと主張する拡散Transformerの代表的手法を理解するため。
- Autoregressive Image Generation using Residual Quantization (RQ-Transformer)：VARの多スケール量子化の残差設計の着想元であり、スタック型コードを用いた類似の手法として比較できるため。

:::


### 2. Stochastic Taylor Derivative Estimator:任意の微分作用素に対する効率的な償却 {#paper-2}

🏆 Best Paper ・ Zekun Shi, Zheyuan Hu, Min Lin, Kenji Kawaguchi ・ [論文を読む ↗](https://arxiv.org/abs/2412.00088)

<small>原題: Stochastic Taylor Derivative Estimator: Efficient amortization for arbitrary differential operators</small>

高次元かつ高階の微分作用素を含む損失(PINNなど)に対し、次元への多項式スケーリングと階数への指数スケーリングを同時に解決するSTDEを提案した研究です。従来ラプラシアン中心だったランダム化手法を任意の微分作用素へ一般化し、SDGDとHTEを特殊例として包含する点も特徴です。100万次元では他の全手法がOOMとなる中、STDEは13.61 it/sで動作し、PINNで100万次元のPDEを単一のA100 GPUで8分で解けるとされ、NeurIPS 2024のBest Paperに選ばれました。

::: info 📝 落合フォーマット

**どんなもの？**

高次元（d）かつ高階（k）の微分作用素を含む損失（例：PINN）を効率的に最適化するため、Stochastic Taylor Derivative Estimator (STDE) を提案した研究。任意階数の微分テンソルの任意の縮約を、1変数のTaylorモードAD（高階AD）への入力タンジェントを適切に構成することで確率的に推定できる。PINNに適用すると、100万次元のPDEを単一のA100 GPUで8分で解けるとされている。

**先行研究と比べてどこがすごい？**

従来、次元dに対する多項式スケーリングは確率的償却（SDGD、HTEなど）で、階数kに対する指数スケーリングはd=1の1変数高階ADで別々に扱われていたが、本研究は両方を同時に解決する。従来のランダム化手法が主にラプラシアンに限られていたのに対し、任意の微分作用素をランダム化する一般的な手順を与え、SDGDとHTEを特殊例として包含する。またHTE型の密なジェットによる推定量は4階以上の作用素には一般化できないことを反例で証明している。

**技術や手法のキモはどこ？**

1変数Taylorモードを、入力のk-ジェット（g(t)の各階タンジェント）を押し出す操作として捉え、その出力が多変量の微分テンソルと入力タンジェントの縮約になっていることを利用する。作用素の係数テンソルC(L)に対し、E[v_&#123;d1}^&#123;(v1)}…v_&#123;dk}^&#123;(vk)}]=C_&#123;d1,…,dk}となる不偏性条件を満たすジェット分布からランダムジェットを引き、押し出し結果の標本平均でLuを推定する。標準基底とゼロベクトルのみからなるスパースジェットは任意の作用素に使え、ラプラシアンでは2-ジェット(e_j, 0)をサンプルする。混合偏微分を含む場合（例：2D KdV方程式）は、適切な高階ジェット（13-ジェット）を構成して必要な項を取り出す。1回の押し出しのメモリはO(kd)、計算量はO(k²dL)で、評価トレースの保持は不要であり並列化しやすい。

**どうやって有効だと検証した？**

STDEで償却したPINNを、2体厳密解を持つ非分離型Allen-Cahn方程式などで評価し、100D〜1M次元で速度とメモリをSDGD各種実装、Forward Laplacianと比較するアブレーションを行った。速度は100万次元でSTDEが13.61 it/sであるのに対し、他の全手法はOOMとなった。メモリも100K次元でSTDEが1073MBであり、並列化SDGDの4931MBより少ない。また、JAXでの再実装によりPyTorch版SDGDに対して約15倍の高速化と最大約4倍のメモリ削減、並列化でさらに約15倍の高速化が得られた。L2誤差は手法間で同程度とされる。

**議論はある？**

密なジェットによるSTDEは2階を超えると構成できない作用素があり、スパース版が普遍的に使えるが、分散の発生源が異なるため分散が過大になる場合がある。混合偏微分を含む高階PDEでは必要なジェット階数lが大きくなる（最大非対角では(1+k)k/2）ことが課題であり、これらのPDEの実験結果は「後ほど提供」と本文で述べられている（提供された本文は途中で省略されており、これ以外の詳細は確認できていない）。

**次に読むべき論文は？**

- Tackling the curse of dimensionality with physics-informed neural networks (SDGD)：STDEが比較対象とし、特殊例として包含するベースライン手法であり、確率的次元勾配降下の原理を理解できる。
- Taylor-mode automatic differentiation for higher-order derivatives in JAX：STDEの計算基盤となるTaylorモードAD（jet）のJAX実装の背景を押さえられる。
- Hutchinson Trace Estimation for High-Dimensional and High-Order Physics-Informed Neural Networks：STDEが一般化する密なランダムジェット（HTE）によるPINN償却の先行研究である。

:::


### 3. 拡散モデルを自身の劣化版でガイドする {#paper-3}

🏆 Best Paper Runner-up ・ Tero Karras, Miika Aittala, Tuomas Kynkäänniemi, Jaakko Lehtinen ほか ・ [論文を読む ↗](https://arxiv.org/abs/2406.02507)

<small>原題: Guiding a Diffusion Model with a Bad Version of Itself</small>

拡散モデルの画像品質・多様性・条件への整合性が絡み合う問題に対し、同じ条件付けで学習した小型かつ学習不足の劣化版自身で本体を誘導する「オートガイダンス」を提案した研究である。従来のCFGと違い品質向上の効果だけを分離して制御でき、無条件モデルにも適用可能で、ImageNet-512でFID 1.25、ImageNet-64でFID 1.01を記録した。NeurIPS 2024でBest Paper Runner-upに選ばれた点も注目される。

::: info 📝 落合フォーマット

**どんなもの？**

拡散モデルの画像品質・多様性・条件への整合性が絡み合う問題に対し、品質向上の効果だけを分離して制御する「オートガイダンス」を提案した研究。条件付きの本体モデルを、同じ条件付けで学習した小型かつ学習不足の劣化版モデル自身で誘導する。ImageNet-512でFID 1.25、ImageNet-64でFID 1.01という記録を達成し、無条件モデルにも適用できる。

**先行研究と比べてどこがすごい？**

従来のCFGは無条件モデルとの差分でガイドするため、条件付き生成にしか使えず、タスクの不一致により軌道が行き過ぎて多様性が下がり、画像構成が単純化していた。本手法は条件付けを変えず、同じタスクを解く劣化版の自分自身を誘導役にすることで、品質向上の効果を整合性向上から切り離し、多様性を損なわずに制御できる。無条件生成のガイダンスも可能にした点が新しい。

**技術や手法のキモはどこ？**

高品質モデルD1を、同じタスク・条件・データで学習した低品質モデルD0（容量の縮小や学習時間の短縮）でガイドし、D_w = wD1 + (1-w)D0 として外挿する。弱いモデルは強いモデルと似た誤差をより強く出すという仮定に基づき、両者の予測が食い違う領域で、より良いサンプルの方向へ押し出す。2Dの玩具例で、スコアマッチングが外れ値を生む仕組みと、CFGが実質的に品質差を使って多様体の中心に引き寄せていることを分析した。実際の設定ではEDM2-Sに対しXSサイズで学習量1/16のガイドモデルを使い、ガイド重みとEMA長はグリッドサーチで決める。

**どうやって有効だと検証した？**

ImageNet-512（EDM2-S）でFIDを2.56から1.34に改善し、CFG+ガイダンス区間の1.68を上回った。EDM2-XXLではFID 1.25、FD DINOv2 24.18、ImageNet-64ではFID 1.01、FD DINOv2 31.85を記録した。無条件のEDM2-SではFIDが11.67から3.86に改善した。アブレーションでは、学習削減のみでFID 1.51、容量削減のみで2.13と、どちらもCFGより良く、改善の大半は学習削減によるものだった。ドロップアウトや入力ノイズによる人工的な劣化では、両モデルの劣化が同種のときだけ効果があり、種類が食い違うと改善しなかった。

**議論はある？**

別途ガイド用モデルを学習する必要があるが、追加コストはEDM2-S/XSで+3.6%、XXL/Mで約+11%と小さい。一方、大規模な既存の画像生成モデルでは初期スナップショットや小型版が公開されていないことが多く、段階的学習でデータ分布が変わると前提が崩れうる。最適なガイドモデルの選び方や有効条件の理論的証明、他のガイダンス手法や精度・再現率、人間の選好指標との併用が今後の課題である。

**次に読むべき論文は？**

- Classifier-free diffusion guidance：本手法が分離・拡張の対象とするCFGの原典で、比較の基準を理解するために必要。
- Applying guidance in a limited interval improves sample and distribution quality in diffusion models：本論文が主要な比較対象とし、組み合わせの検討も述べているガイダンス区間手法を知るため。
- Analyzing and improving the training dynamics of diffusion models：実験のベースラインであるEDM2と、本手法で重要な事後EMAの技術を理解するため。

:::


### 4. PRISMアライメントデータセット：参加型・代表性・個別化された人間フィードバックが明らかにする、大規模言語モデルの主観的・多文化的アライメント {#paper-4}

🏆 Datasets and Benchmarks Best Paper ・ Hannah Rose Kirk, Alexander Whitefield, Paul Röttger, Andrew Bean ほか ・ [論文を読む ↗](https://arxiv.org/abs/2404.16019)

<small>原題: The PRISM Alignment Dataset: What Participatory, Representative and Individualised Human Feedback Reveals About the Subjective and Multicultural Alignment of Large Language Models</small>

75か国・1,500人の参加者の社会属性や選好を、21種のLLMとの8,011件のライブ対話における文脈的な評価・細かなフィードバックに紐づけた人間フィードバックデータセットPRISMを提案した研究です。二値のA/B比較中心で属性情報に乏しかった従来データと異なり、サーベイ回答と対話評価を結びつけた初の選好データセットだとされています。3つのケーススタディでは、モデル順位が話題や地域で変動し、標本が小さいほど悪いモデルを選ぶ確率が上がることなどが示され、誰がアライメントデータを提供するかが結果に影響することを裏付けた点が注目されます。

::: info 📝 落合フォーマット

**どんなもの？**

75か国・1,500人の多様な参加者の社会属性や明示的な選好を、8,011件の21種のLLMとのライブ対話における文脈的選好・細かなフィードバックに紐づけた人間フィードバックデータセットPRISMを提案した。主観的・価値観が絡む・論争的な話題や多文化的な視点に焦点を当て、誰がどんなアライメントデータを提供するかが結果に影響することを示した。

**先行研究と比べてどこがすごい？**

従来の多くのデータセットは二値のA/B比較中心で、サンプルが狭く、アノテータIDや属性情報も乏しかった。PRISMは参加型の広い地理・属性、英国・米国の国勢調査代表サンプル、個人プロファイルに紐づく個別評価を備え、サーベイ回答と対話評価を結びつけた初の選好データセットである（本文の主張）。

**技術や手法のキモはどこ？**

二段階の設計で、第1段階のサーベイでは属性、LLM利用経験、自由記述の「憲法」（システム文字列）と価値観、行動属性の重要度（VAS）を取得する。第2段階では参加者が非誘導・価値観誘導・論争誘導のいずれかの対話タイプを選んで自由に最初のプロンプトを入力し、最大4モデルの応答を1〜100のVASで評価する。最高評価モデルが以降のターンに固定され、2応答を再評価し、終了後に性能・選択理由の属性評価と自由記述フィードバックを集める。応答は50語以内に制限された。

**どうやって有効だと検証した？**

3つのケーススタディで検証した。(1)プロンプトのクラスタリング(22トピック)では、対話タイプの誘導が有意に効き、属性による有意な係数は11%であった。局所的なプロンプト近傍の84%が交差属性の多様性を満たした。(2)Pairwise Rank Centralityによるモデル順位は、100人のサンプルでノイズが大きく、話題や地域で変動し(例: palm-2は米国で4位下落、mistral-7bはアフリカで7位上昇)、ChatbotArenaとも異なる結果となった。(3)福祉分析では、標本が小さいほど悪いモデルを選ぶ確率が上がり、特定集団のみからの標本は外集団の福祉を下げた。どのモデルも過半数の選好を得られず、米国で最大45%(meanChoice)であった。

**議論はある？**

参加者は英語話者のクラウドワーカーに偏り、WEIRD的な偏りや米英の過剰代表が残る。自由な対話選択や基数評価はモデル間・個人間の比較や統計的検出力を難しくし、プライバシーや有害内容のリスクも残る。選好に基づく功利主義的アライメントの正当性や、個人・集団のどちらを整合の単位とするかについての議論が必要である。

**次に読むべき論文は？**

- Social Choice for AI Alignment: Dealing with Diverse Human Feedback：PRISMの多様な選好を集約する際の社会的選択理論の枠組みを理解できるため。
- The benefits, risks and bounds of personalizing the alignment of large language models to individuals：個人プロファイルに紐づく評価を使ったパーソナライズ・アライメントの意義とリスクを整理しているため。
- Collective Constitutional AI: Aligning a Language Model with Public Input：PRISMのサーベイで得た「憲法」的な明示選好を、公衆参加でモデルに反映する先行事例であるため。

:::


### 5. YOLOv10: リアルタイムのエンドツーエンド物体検出 {#paper-5}

📈 被引用数上位（Paper Digest の集計で同年1位） ・ Ao Wang, Hui Chen, Lihao Liu, Kai Chen ほか ・ [論文を読む ↗](https://arxiv.org/abs/2405.14458)

<small>原題: YOLOv10: Real-Time End-to-End Object Detection</small>

リアルタイム物体検出モデルYOLOの精度と速度のトレードオフを、後処理(NMS)とモデル構造の両面から改善した研究です。一対多と一対一の二重ヘッドを一貫したマッチング指標で整合させるconsistent dual assignmentsにより、推論コストを増やさずNMSフリー化し、さらに各構成要素を見直す設計で冗長性の削減と精度向上を両立しました。COCOでYOLOv8に対しAPを改善しつつ、パラメータ数を28〜57%、レイテンシを37〜70%削減しており、NeurIPS 2024で被引用数が同年1位(Paper Digest集計)という点でも注目されます。

::: info 📝 落合フォーマット

**どんなもの？**

リアルタイム物体検出モデルYOLOの精度と速度のトレードオフを、後処理(NMS)とモデル構造の両面から改善した、エンドツーエンド物体検出器YOLOv10を提案した研究。NMSなしで推論できる学習方式と、効率・精度の両面から各部品を見直した設計により、N/S/M/B/L/Xの各スケールのモデル群を構築した。

**先行研究と比べてどこがすごい？**

従来のYOLOは一対多ラベル割り当てのためNMSが必須で、遅延増加とNMSハイパーパラメータへの感度が課題だった。本研究は一対多と一対一の二重ヘッドを、一貫したマッチング指標で整合させるconsistent dual assignmentsを導入し、推論コストを増やさずNMSフリー化した。加えて、YOLOの各構成要素を網羅的に点検するholistic設計で、計算冗長性の削減と精度向上を同時に実現した点が新しい。

**技術や手法のキモはどこ？**

学習時は一対多ヘッドと同一構造の一対一ヘッドを併用し、推論時は一対一ヘッドのみを使う。両ヘッドの教師信号のずれを1-Wasserstein距離で解析し、α_o2o=r·α_o2m、β_o2o=r·β_o2m(既定r=1)とする一貫マッチング指標で最小化した。効率面では、軽量分類ヘッド(depthwise separable conv)、空間・チャネル分離ダウンサンプリング(pointwiseでチャネル変更後にdepthwiseで空間縮小)、固有ランクに基づくrank-guided block design(コンパクトなCIBを冗長なステージに適用)を導入した。精度面では、深いステージのCIB内の7×7大カーネルdepthwise畳み込み(再パラメータ化付き、小モデルのみ)と、最低解像度のStage 4後に置く部分自己注意(PSA)を採用した。

**どうやって有効だと検証した？**

YOLOv8をベースラインとし、COCOでスクラッチ学習し、T4 GPU・TensorRT FP16でレイテンシを測定して比較した。YOLOv8のN/S/M/L/Xに対しAPを1.2/1.4/0.5/0.3/0.5ポイント改善し、パラメータ数は28〜57%減、レイテンシは37〜70%減となった。YOLOv10-SはRT-DETR-R18と同程度のAPで1.8倍高速かつパラメータ・FLOPsが2.8倍小さく、YOLOv10-BはYOLOv9-Cと同等性能でレイテンシ46%減、パラメータ25%減となった。アブレーションでは各要素の寄与が確認された(例:YOLOv10-SでNMSフリー化によりレイテンシが4.63ms短縮、精度駆動設計でAP +1.8)。

**議論はある？**

NMSフリー学習は従来の一対多学習+NMSに比べ性能差が残り、特にYOLOv10-Nでは1.0 AP差があった。この差はモデル容量不足により特徴の識別性が不足するためと著者らは考えており、モデルが大きいほど差は縮小する(Xでは差なし)。この差を縮めてさらにエンドツーエンド性能を高めることが今後の課題とされている。

**次に読むべき論文は？**

- End-to-End Object Detection with Transformers (DETR)：一対一マッチング(ハンガリアン損失)によるNMSフリー検出の原点であり、YOLOv10の動機と比較対象を理解できる。
- DATE: Dual Assignment for End-to-End Fully Convolutional Object Detection：CNN検出器に二重割り当てを導入した先行研究で、YOLOv10の一貫マッチング指標との違いを把握できる。
- DETRs Beat YOLOs on Real-time Object Detection (RT-DETR)：YOLOv10が主な比較対象とするリアルタイムのエンドツーエンド検出器で、設計思想の違いを理解できる。

:::
