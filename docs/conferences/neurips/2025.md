# NeurIPS 2025

🤖 AI・機械学習全般 ・ [NeurIPS の年ごとの流れ](./) ・ [公式サイト ↗](https://neurips.cc/)

::: info この回のまとめ
サンディエゴとメキシコシティの2会場で開催され、参加者は約26,000人、投稿は21,575本、採択は5,290本（約24.5%）と過去最大規模になりました。最優秀論文は、アテンション出力にゲートを入れて学習の安定性と「アテンション・シンク」問題を改善する Gated Attention（Qwen チーム）、拡散モデルが学習データを丸暗記しにくい理由の理論、1,000層の深いネットワークで自己教師あり強化学習が新しい能力を得ることを示した研究、そして LLM の出力が均質化する問題を扱った Artificial Hivemind（データセット部門）の4本。次点には「強化学習は LLM の推論能力をベースモデル以上に本当に伸ばしているのか」を問う論文が入りました。
:::

## 🔭 この回の主なテーマ

- LLM アーキテクチャの改良: ゲート付きアテンションで非線形性・スパース性を加え、長文での安定性を改善
- 推論と強化学習の検証: RLVR（検証可能な報酬による RL）が新しい推論能力を生むのか、既存能力の引き出しに過ぎないのかを議論
- 生成モデルの理論: 拡散モデルが暗記より汎化する仕組みを学習ダイナミクスから説明
- 強化学習のスケーリング: ネットワークを1,000層まで深くすると目標到達タスクで質的に新しい能力が出現
- LLM 出力の多様性: 多数のモデルが似た回答に収束する「人工ハイブマインド」問題を大規模データで示した

::: tip 💡 技術動向への示唆
- 推論モデルの強化学習は「何が本当に伸びているか」の検証段階に入り、評価設計（pass@k など）の重要性が増した
- LLM の基本構造（アテンション）にもまだ改良の余地があり、オープンモデル開発元の研究が最高賞を得る時代になった
- モデル間の出力の均質化は、多様なアイデアを求める用途（創作・研究支援）で複数モデルや工夫が必要になることを示唆する
- 投稿2万本超で査読体制が限界に近づき、複数都市開催など学会運営そのものの変化が始まった
:::

### 1. LLM のためのゲート付きアテンション {#paper-1}

🏆 Best Paper ・ Zihan Qiu, Zekun Wang, Bo Zheng, Zeyu Huang ほか ・ [論文を読む ↗](https://arxiv.org/abs/2505.06708)

<small>原題: Gated Attention for Large Language Models: Non-linearity, Sparsity, and Attention-Sink-Free</small>

アテンションの出力にヘッドごとのシグモイドゲートを1つ足すだけで、学習が安定し、長文性能が上がり、先頭トークンに注意が集中する「アテンション・シンク」が消えることを、最大 15B 規模の MoE を含む大規模実験で示しました。

::: info 📝 落合フォーマット

**どんなもの？**

標準的なソフトマックスアテンションにゲーティング機構を加える多数のバリアント（位置・粒度・活性化関数など）を、15B MoEと1.7B denseモデルで体系的に比較した研究。SDPA出力の後に頭ごとのシグモイドゲートを置く単純な変更が、性能・学習安定性・スケーリングを一貫して改善することを示した。

**先行研究と比べてどこがすごい？**

ゲーティングは多くの先行モデルで使われてきたが、その効果自体を他の設計要素から切り離して検証した例は少なかった。本研究は約30の変種を最大3.5Tトークンの学習で比較し、効果の要因を非線形性とクエリ依存のスパース性に整理した。さらに、スパースなゲートがattention sinkを解消し、長文脈への外挿にも寄与することを示した。

**技術や手法のキモはどこ？**

ゲートは Y' = Y ⊙ σ(XW_θ) の形で、Xはプレノーム後の隠れ状態、Yは変調対象である。ゲートはQ/K/V射影後（G4/G3/G2）、SDPA出力後（G1）、最終dense層後（G5）に挿入し、要素ごと/ヘッドごと、ヘッド固有/共有、乗算/加算、シグモイド/SiLUを比較した。既定はヘッド固有・乗算・シグモイドである。分析では、W_VとW_Oが低ランクの線形写像にまとまる点に着目し、間に非線形性を入れる効果と、ゲートスコアのスパース性・クエリ依存性の効果を、入力非依存ゲートや値域を[0.5,1]にしたNS-sigmoidなどの対照実験で切り分けた。

**どうやって有効だと検証した？**

15A2B MoEを400Bトークンで学習した比較では、ベースラインの平均PPL 6.026に対しSDPA要素ごとゲート(G1)は5.761、MMLUは58.79から60.82、GSM8kは52.92から55.27に改善し、KVヘッド増・クエリヘッド増・エキスパート追加といったパラメータ拡張より良い結果だった。denseモデルでも各設定で改善が見られ、ゲートなしでは最大学習率8e-3で発散するケースがあったが、ゲートありでは学習できた。また、先頭トークンへのアテンション割合は46.7%から4.8%に低下した。32kに拡張後YaRNで128kに延ばしたRULER評価では、128kでベースライン31.65に対しゲート付きは58.82だった。

**議論はある？**

著者らは、非線形性がアテンションの学習ダイナミクス全体に与える影響が十分に調べられていないこと、attention sinkの解消が長文脈汎化を助ける理由について厳密な理論的説明がないことを限界として挙げている。また、32k以内ではゲートの利得は小さく、長文脈での優位性は主にYaRN拡張時に現れる点も留意が必要である。

**次に読むべき論文は？**

- Efficient Streaming Language Models with Attention Sinks：attention sinkを最初に定式化した論文で、本研究が解消対象とする現象の基礎を押さえられる。
- Forgetting Transformer: Softmax Attention with a Forget Gate：ソフトマックスアテンションの出力にゲートを導入した最も近い先行研究で、本研究との違いを比較できる。
- Quantizable Transformers: Removing Outliers by Helping Attention Heads Do Nothing：アテンションへのゲート導入で極端な注意集中や外れ値が緩和されることを先に示した関連研究である。

:::


### 2. 1,000層ネットワークによる自己教師あり強化学習 {#paper-2}

🏆 Best Paper ・ Kevin Wang, Ishaan Javali, Michał Bortkiewicz, Tomasz Trzciński ほか ・ [論文を読む ↗](https://arxiv.org/abs/2503.14858)

<small>原題: 1000 Layer Networks for Self-Supervised RL: Scaling Depth Can Enable New Goal-Reaching Capabilities</small>

強化学習では浅いネットワークが常識でしたが、報酬なしの目標条件付き RL でネットワークを1,000層まで深くすると性能が大きく伸び、新しい行動が出現することを示しました。

::: info 📝 落合フォーマット

**どんなもの？**

教師なしのゴール条件付き強化学習（報酬もデモもなし）において、自己教師ありのコントラスティブRL（CRL）のネットワーク深度を最大1024層まで拡大する手法を示した研究。従来のRLで一般的な2〜5層を大きく超える深さで、移動・ナビゲーション・操作タスクの性能を大幅に高めた。

**先行研究と比べてどこがすごい？**

従来のRLのスケーリング研究（SimBa、BROなど）は主に幅の拡大に注目し、深さの拡大では利得が小さいか負になると報告していた。本研究は自己教師ありCRL、GPU高速化による大量データ、残差接続・LayerNorm・Swishの組み合わせにより深さ方向のスケーリングを可能にし、幅だけの拡大より効果が大きいことを示した。また、特定の臨界深度で性能が跳ね上がり、質的に異なる行動が現れる点も新しい。

**技術や手法のキモはどこ？**

JaxGCRLを用いたオンラインのゴール条件付きRLで、CRLのアクターとクリティック（状態行動エンコーダとゴールエンコーダ）に残差ネットワークを導入する。残差ブロックは「Dense→LayerNorm→Swish」を4回繰り返す構成で、残差接続は最後の活性化の直後に加える。深さはDense層の総数（4N）と定義し、アクターと両クリティックのエンコーダを共同でスケールする。クリティックはInfoNCE目的で学習し、方策はクリティックを最大化するよう学習する。

**どうやって有効だと検証した？**

Brax/MJXの移動・ナビゲーション・操作の10環境で深さ4と8〜64（一部は256、1024）を比較した。深さ4と比べ、操作タスクで2〜5倍、Ant U4/U5-Mazeなどの長期迷路で20倍超、Humanoid系で50倍超の向上が得られ、10タスク中8タスクでSAC、SAC+HER、TD3+HER、GCBC、GCSLを上回った。Humanoid U-Mazeでは深さ256と1024でも性能が伸びた。アブレーションでは、深さ8（幅256）が幅2048（深さ4）を上回ること、深いネットワークでバッチサイズ拡大が効くようになることを示した。また、探索と表現力が相乗的に効くことも確認した。

**議論はある？**

深さの拡大は計算コストを増やすことが限界として挙げられており、分散学習や枝刈り・蒸留による軽量化が今後の課題である。OGBenchでのオフライン設定では深さ拡大の効果がほとんど見られず、オフラインへの適用は未解決である。また、1024層ではアクターの損失が発散したため、アクターは512層に抑えている。計算資源の制約で1024層より先は試せていない。

**次に読むべき論文は？**

- Contrastive Learning as Goal-Conditioned Reinforcement Learning：本研究が土台とするCRLアルゴリズムとInfoNCEによるクリティック学習の原典である。
- Accelerating Goal-Conditioned RL Algorithms and Research：実験基盤のJaxGCRLとGPU高速化されたGCRLベンチマークの詳細が分かる。
- SimBa: Simplicity Bias for Scaling Up Parameters in Deep Reinforcement Learning：残差構造で幅方向のスケーリングを扱った先行研究で、本研究の深さスケーリングとの比較に役立つ。

:::


### 3. 拡散モデルはなぜ記憶しないのか：訓練における暗黙的な動的正則化の役割 {#paper-3}

🏆 Best Paper ・ Tony Bonnaire, Raphaël Urfin, Giulio Biroli, Marc Mézard ・ [論文を読む ↗](https://arxiv.org/abs/2505.17638)

<small>原題: Why Diffusion Models Don't Memorize: The Role of Implicit Dynamical Regularization in Training</small>

過剰パラメータ化された拡散モデルが訓練データを記憶せず汎化できる理由を、訓練ダイナミクスの観点から説明した研究である。高品質な生成が始まる時間 τ_gen は n に依存せず、記憶が現れ始める時間 τ_mem は n にほぼ比例するため、その間の早期停止区間で汎化することを、U-Net 実験とランダム特徴量モデルの理論の両面で示した。従来の正則化やアーキテクチャの帰納バイアスといった説明に対し、訓練時間そのものが「暗黙的な動的正則化」として働くことを示した点が評価され、NeurIPS 2025 の Best Paper に選ばれた。

::: info 📝 落合フォーマット

**どんなもの？**

拡散モデルが過剰パラメータ化された状況でも訓練データを記憶せず汎化できる理由を、訓練ダイナミクスの観点から説明した研究。高品質な生成が始まる時間 τ_gen と、記憶が現れ始める時間 τ_mem という2つの時間スケールを特定し、その間の早期停止区間で汎化することを示した。実験（U-Net）と理論（ランダム特徴量モデル）の両面から裏付けている。

**先行研究と比べてどこがすごい？**

従来は正則化、アーキテクチャの帰納バイアス、有限学習率などが記憶回避の説明に挙げられていたが、本研究は「暗黙的な動的正則化」という訓練時間そのものの役割を示した。τ_gen は n に依存せず一定で、τ_mem は n にほぼ線形に比例するため、汎化の窓が n とともに広がることを明らかにした。先行研究のランダム特徴量解析（τ→∞ の漸近損失）を、訓練ダイナミクスと早期停止へ拡張した点も新しい。

**技術や手法のキモはどこ？**

CelebA（32×32のグレースケール）で、時間条件付きのU-Netスコアモデルを SGD で訓練し、訓練セットサイズ n とU-Netの基底幅 W（パラメータ数 p）を変えた。生成品質は FID、記憶は生成サンプルの最近傍距離と第2近傍距離の比（閾値 k=1/3）で測り、τ_gen と τ_mem を同定している。理論面では、第1層を固定して第2層のみを学習するランダム特徴量ネットワークの勾配流を解き、時間スケールを行列 U の固有値の逆数に対応させた。レプリカ法で U のスペクトル密度を導出し、過剰パラメータ領域で分離した2つのバルク ρ1 と ρ2 が τ_mem と τ_gen に対応することを示した。

**どうやって有効だと検証した？**

U-Net実験では、FID が最小になる τ_gen は約100K ステップで n に依存せず、記憶割合を τ/n で再スケールすると曲線が collapse して τ/n ≈ 300 付近で立ち上がり、τ_mem ∝ n が確認された。またバッチ全体の更新でも τ_mem ∝ n が成り立ち、データの反復回数が原因ではないことも示された。幅 W に対しては τ_gen ∝ W⁻¹、τ_mem ∝ nW⁻¹ のスケーリングが得られ、n=32768 では約1100万ステップ後も訓練損失とテスト損失の差が小さいままだった。ランダム特徴量モデルでも、同様の時間スケール分離と、n > p での過学習の低減が再現された。

**議論はある？**

理論解析は固定の拡散時刻 t を扱う簡略化されたランダム特徴量モデルに基づくもので、実用的な単一の時間条件付きモデルとは差がある。実験は主に SGD で行われ、Adam でも同様の時間スケールが現れるものの、最適化手法の違いの影響は今後の課題である。また、フローマッチングなど他のスコアベース手法への一般化は予想にとどまり、検証されていない。

**次に読むべき論文は？**

- Denoising score matching with random features: Insights on diffusion models from precise learning curves：本研究の理論部分が拡張しているランダム特徴量モデルの先行研究で、τ→∞ での訓練損失・テスト損失の漸近解析が書かれている。
- Bigger isn't always memorizing: Early stopping overparameterized diffusion models：過剰パラメータ化した拡散モデルでの早期停止による記憶回避を扱っており、本研究の主張と直接関係する。
- Dynamical regimes of diffusion models：経験的スコアによる記憶と汎化の遷移を高次元理論で整理した論文で、本研究の問題設定の背景を理解できる。

:::


### 4. Artificial Hivemind：言語モデルのオープンエンドな出力における均質性（とその先） {#paper-4}

🏆 Best Paper（Datasets & Benchmarks） ・ Liwei Jiang, Yuanjun Chai, Margaret Li, Mickel Liu ほか ・ [論文を読む ↗](https://arxiv.org/abs/2510.22954)

<small>原題: Artificial Hivemind: The Open-Ended Homogeneity of Language Models (and Beyond)</small>

実世界のオープンエンドなクエリ26K件からなる Infinity-Chat とその分類体系を作り、70以上の言語モデルの出力を調べて、モデル内の反復とモデル間の均質性からなる「Artificial Hivemind」効果を示した研究です。top-p=0.9・温度1.0では79%のクエリで同一モデル内の平均ペア類似度が0.8を超え、モデル間の平均類似度も71〜82%に達し、逐語的に同一の応答も見られました。さらに1項目あたり25名による密な人手評価（計31,250件）を備え、LM・報酬モデル・LMジャッジが、品質の近い応答や評価者間で意見が割れる応答で人間との相関が大きく下がることも示した点が注目されます。

::: info 📝 落合フォーマット

**どんなもの？**

実世界のオープンエンドなユーザークエリ26K件からなるデータセット Infinity-Chat と、そのクエリの分類体系（6大カテゴリ・17サブカテゴリ）を提案した研究。これを用いて70以上のLMの出力を調べ、単一モデル内の反復（intra-model repetition）とモデル間の均質性（inter-model homogeneity）からなる「Artificial Hivemind」効果を示した。あわせて、25名による密な人手評価（計31,250件）を収集し、LM・報酬モデル・LMジャッジが人間の評価とどの程度整合するかを分析した。

**先行研究と比べてどこがすごい？**

従来の多様性評価は乱数・名前生成、詩や比喩など限定的なタスクか、単一モデルの繰り返しサンプリングに限られていた。本研究はWildChat由来の実利用クエリで、70以上のモデルを横断した大規模なモデル内・モデル間の均質性分析を行った点が新しい。また、同一クエリへの代替応答に対して1項目あたり25名という密な人手ラベル（絶対評価と対比較）を備えた初の大規模リソースだと主張している（先行データセットは例として1項目3名程度）。

**技術や手法のキモはどこ？**

WildChatの単一ターンGPT-4クエリ37,426件（英語・非有害・15〜200文字）をGPT-4oで分類・曖昧なものは修正し、オープンエンドなクエリ26,070件を得た。分類体系は約100件の手動ラベル付けから階層化し、GPT-4oで全件にラベル付けして新規カテゴリ314件も検出した。均質性は、Infinity-Chat100（人手で確認した100クエリ）について各モデルから50応答をサンプリングし、OpenAI text-embedding-3-smallによる文埋め込みの平均ペア類似度で測定した。人間との整合性は、LM（パープレキシティ）、報酬モデル、LMジャッジのスコアと人間の平均評価との相関を、全体、類似品質サブセット（Tukey's fencesなど）、高不一致サブセット（Shannonエントロピーなど）で比較した。

**どうやって有効だと検証した？**

top-p=0.9・温度1.0では、同一モデル内の平均ペア類似度が0.8を超えるクエリが79%あった。min-p（温度2.0）でも、応答ペアの81%が類似度0.7超、61.2%が0.8超だった。モデル間の平均類似度は71〜82%で、DeepSeek-V3とqwen-max-2025-01-25は0.82、DeepSeek-V3とgpt-4o-2024-11-20は0.81だった。上位50類似応答には平均約8モデルが含まれ、一部の指示では逐語的に同一の応答もあった。人手評価（絶対18,750件・対比較12,500件）では、LM（56モデル）・報酬モデル（6）・LMジャッジ（4）のいずれも、品質が近い応答や評価者間の不一致が大きい応答で人間との相関が大きく低下した。

**議論はある？**

著者らは、均質性の原因（事前学習データ、アライメント、記憶、汚染、合成データなど）の因果分析は本研究の範囲外とし、今後の課題としている。分析は100クエリのサブセットと文埋め込み類似度に基づく点、1.0〜2.0の限られたサンプリング設定である点に留意が必要である。人間評価の不一致を考慮した報酬モデルや学習時の多様性維持手法の開発が今後の方向性として示されている。

**次に読むべき論文は？**

- Min-p Sampling: Balancing Creativity and Coherence at High Temperature (Nguyen et al., 2025)：本論文で多様性志向のデコーディングとして評価されたmin-pの原論文で、それでも残る反復の背景を理解できる。
- WildChat: 1M ChatGPT Interaction Logs in the Wild (Zhao et al., 2024)：Infinity-Chatのクエリの元データであり、収集方法や特性を知ることでデータセットの前提を把握できる。
- Modifying Large Language Model Post-Training for Diverse Creative Writing (Chung et al., 2025)：学習時の介入で出力多様性を維持する手法を扱っており、本論文が提起した課題への対処策を読める。

### 5. DAPO: 大規模なオープンソースLLM強化学習システム {#paper-5}

📈 被引用数上位（Paper Digest の集計で同年1位） ・ Qiying Yu, Zheng Zhang, Ruofei Zhu, Yufeng Yuan ほか ・ [論文を読む ↗](https://arxiv.org/abs/2503.14476)

<small>原題: DAPO: An Open-Source LLM Reinforcement Learning System at Scale</small>

長いChain-of-Thoughtを用いるLLM強化学習では、実績ある推論モデルの訓練詳細が非公開で再現が難しいという課題があり、本研究はアルゴリズム DAPO、学習コード(verlベース)、データセット DAPO-Math-17K をすべて公開した。素朴な GRPO で30点だった AIME 2024 の精度(avg@32)を、4つの技術と Dynamic Sampling により Qwen2.5-32B ベースで50点まで引き上げ、DeepSeek-R1-Zero-Qwen-32B(47点)を学習ステップ数50%で上回ったと報告している。各技術の寄与を段階的に示し、再現性を重視した点に加え、同年の被引用数1位(Paper Digest集計)という点でも注目される。

::: info 📝 落合フォーマット

**どんなもの？**

長いChain-of-Thought（long-CoT）を伴う大規模LLM強化学習で、実績のある推論モデルの訓練詳細が非公開で再現が難しい問題に対し、アルゴリズム DAPO（Decoupled Clip and Dynamic sAmpling Policy Optimization）と学習コード、データセットを完全公開した研究。Qwen2.5-32Bベースモデルから AIME 2024 で 50 点（avg@32）を達成した。

**先行研究と比べてどこがすごい？**

素朴な GRPO ではエントロピー崩壊・報酬ノイズ・学習不安定が生じ AIME で 30 点にとどまったが、4つの技術でこれを解消した。DeepSeek-R1-Zero-Qwen-32B（47 点）を、学習ステップ数 50% で上回ったと報告している。アルゴリズム・コード（verl ベース）・データ（DAPO-Math-17K）をすべて公開し、再現性を高めた点も特徴である。

**技術や手法のキモはどこ？**

(1) Clip-Higher：クリップ範囲を ε_low=0.2 と ε_high=0.28 に分離し、低確率の探索トークンの確率上昇余地を広げてエントロピー崩壊を防ぐ。(2) Dynamic Sampling：正答率が 0 または 1 のプロンプトを除外し、勾配が有効なプロンプトでバッチを埋めるまでサンプリングを続ける。(3) Token-Level Policy Gradient Loss：サンプル単位の平均ではなく全トークンで正規化し、長い応答のトークンにも十分な重みを与える。(4) Overlong Reward Shaping：切り捨てられた応答の損失をマスクする Overlong Filtering と、長さに応じた段階的ペナルティを与える Soft Overlong Punishment を用いる。KL項は除去し、ルールベース報酬（正解 +1、不正解 −1）を使う。答えを整数に変換した問題を用いて報酬判定を簡素化している。

**どうやって有効だと検証した？**

AIME 2024 で avg@32 を評価し、Naive GRPO 30 → +Overlong Filtering 36 → +Clip-Higher 38 → +Soft Overlong Punishment 41 → +Token-level Loss 42 → +Dynamic Sampling（DAPO）50 と、各技術が段階的に精度を押し上げることを示した。Dynamic Sampling はサンプル数が増えても必要な学習ステップ数が減り、収束時間は短縮されたと報告している。学習中の応答長・報酬・エントロピー・生成確率の推移も監視し、学習の健全性の指標として分析している。

**議論はある？**

評価は数学タスク（AIME 2024）と Qwen2.5-32B に限られ、他タスクへの転用は「容易に移せる」と述べるにとどまり、本文中では検証していない。学習データ上の最終報酬と検証精度の相関が低く、過学習の兆候が見られること、また RL 中に出現する反省・バックトラッキングといった推論行動の仕組みの解明は今後の課題とされている。

**次に読むべき論文は？**

- DeepSeek-R1: Incentivizing reasoning capability in LLMs via reinforcement learning：DAPO が比較・改善の対象とした DeepSeek-R1-Zero-Qwen-32B の手法と結果の出典であり、背景理解に不可欠。
- DeepSeekMath: Pushing the limits of mathematical reasoning in open language models：DAPO のベースラインである GRPO の原典で、DAPO の改良点を理解する前提となる。
- HybridFlow: A flexible and efficient RLHF framework：DAPO の実装基盤である verl の設計を説明しており、学習インフラを再現する際に役立つ。

:::
