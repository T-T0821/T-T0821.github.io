# ECCV 2022

👁️ 画像認識・CV ・ [ECCV の年ごとの流れ](./) ・ [公式サイト ↗](https://eccv.ecva.net/)

::: info この回のまとめ
イスラエルのテルアビブで開催され、投稿5,804本・採択1,645本（約28.3%）でした。最優秀論文は、統計学の部分距離相関という手法を深層学習に持ち込み、異なるネットワークが学んだ表現の似ている部分・違う部分を比較したり、多様なモデルを学習させたり、敵対的な頑健性を高めたりできることを示した研究（ウィスコンシン大学）です。ViT と CNN の比較などモデルの理解が注目された時期を反映しています。
:::

- **日程**: 2022年10月
- **開催地**: イスラエル・テルアビブ
- **規模**: 投稿 5,804 本 ／ 採択 1,645 本 ／ 採択率 28.3%

**📝 注目論文（3 本）**

1. [深層学習における部分距離相関の多様な使い道](#paper-1)

- ネットワークの比較と理解: 部分距離相関による表現の比較
- ViT と CNN の比較: アーキテクチャ間で学習内容の違いを分析

:::

### 1. 深層学習における部分距離相関の多様な使い道 {#paper-1}

🏆 Best Paper ・ Xingjian Zhen, Zihang Meng, Rudrasis Chakraborty, Vikas Singh ・ [論文を読む ↗](https://arxiv.org/abs/2207.09684)

<small>原題: On the Versatile Uses of Partial Distance Correlation in Deep Learning</small>

次元の異なる特徴同士でも依存関係を測れる距離相関と、その「ほかの要因を除いた」版である部分距離相関を深層学習に応用し、ネットワーク間の比較、多様なモデルの学習、敵対的頑健性の向上、生成モデルの属性の分離に使えることを示しました。

::: info 📝 落合フォーマット

**どんなもの？**

異なる次元の特徴空間間の相関を測れる統計量である距離相関（distance correlation）と偏距離相関（partial distance correlation）を、大規模な深層学習モデルで使えるように整備した研究。これにより、あるモデルを別のモデルで条件付ける、独立な特徴を持つ複数モデルを学習する、もつれを解いた表現（disentanglement）を学習する、といった幅広い用途に使える汎用的な正則化項・制約として提案している。

**先行研究と比べてどこがすごい？**

従来のCCAは浅い設定では使えるが、深層学習向けには専用アルゴリズムが必要で、偏CCAの深層版は報告されていなかった。距離相関は特徴間の距離が計算できれば深層でもほぼそのまま適用でき、その偏版により「一方のモデルの影響を除いた上での他方の情報」を測ったり損失に組み込んだりできる点が新しい。著者らは、ネットワーク間の条件付けを行うこの機能は従来示されていなかったと述べている。

**技術や手法のキモはどこ？**

ミニバッチ（サイズm）ごとに距離行列を計算してO(m^2)で距離相関を確率的に推定し、微分可能な損失として使う。2つのネットワークのパラメータが分離可能であることを利用し、ブロック確率的勾配法（Alg.1）を示すが、実験では通常のSGDで十分だったとしている。偏距離相関はU中心化行列とその内積、および射影により定義され、Z の影響を除いた残差間の相関として計算する。用途ごとに、独立性のためにCE損失に α·距離相関を加える（式11）、偏距離相関を最大化する（式12）、属性と残差表現の距離相関を最小化する（式13）といった損失を設計している。

**どうやって有効だと検証した？**

敵対的攻撃の転移実験では、CIFAR10（ResNet18）とImageNet（MobileNet-v3-small、EfficientNet-B0、ResNet34、ResNet152）で、f1で作った敵対例によるf2の精度を評価した（FGM/PGD、α=0.05）。ベースラインより敵対的精度が向上し、ResNet18とMobileNet-v3-smallのPGDでは10%以上の絶対改善があり、クリーン精度はおおむね同程度だった（ResNet18は89.14→87.61）。ネットワーク比較では、BERTによるクラス名埋め込みとの距離相関で ViT・ResNet 各層の類似度を可視化し、偏距離相関で「Yを除いたXが持つ情報」を定量化した。また Grad-CAM による可視化と、FFHQ上のStyleGAN2ベース半教師あり disentanglement で属性操作の有効性を定性的に示した。

**議論はある？**

本文の範囲では、評価の多くが定性的な可視化や少数の設定に基づいており、ミニバッチ推定の近似精度やバッチサイズ依存性、計算コストの詳細な検証は示されていない。また偏距離相関の最大化による効果は Grad-CAM などの定性的な確認が中心で、精度向上など定量的な利得は示されていない。なお本文には、content-style disentanglement で距離相関を用いた先行研究[43]の存在が後から追記されている。

**次に読むべき論文は？**

- Do Vision Transformers See Like Convolutional Neural Networks?：本論文のネットワーク間類似度比較の直接のベースラインであり、CKAによる ViT と CNN の層ごとの比較が参照できる。
- Similarity of Neural Network Representations Revisited：距離相関の代替・比較対象となるCKAの理論的性質（不変性）を理解するために有用である。
- An Online Riemannian PCA for Stochastic Canonical Correlation Analysis：深層学習向けの確率的CCAであり、本論文が対比している深層CCA手法の中心的な先行研究である。

:::


### 2. Visual Prompt Tuning（視覚プロンプトチューニング） {#paper-2}

📈 被引用数上位（Paper Digest の集計で同年1位） ・ Menglin Jia, Luming Tang, Bor-Chun Chen, Claire Cardie ほか ・ [論文を読む ↗](https://arxiv.org/abs/2203.12119)

<small>原題: Visual Prompt Tuning</small>

大規模な事前学習済みVision Transformerを下流タスクに適応する際、バックボーンを凍結したまま入力空間に少量の学習可能なプロンプトだけを追加するVPTを提案した研究です。モデル全体の1%未満のパラメータで適応でき、FGVCとVTAB-1kの24タスク中20タスクでフルファインチューニングを上回り、タスクごとの保存コストも大幅に削減しました。NLPで発展したプロンプトチューニングを画像エンコーダに体系的に適用した取り組みで、ECCV 2022で被引用数が同年1位（Paper Digest集計）となった点でも注目されます。

::: info 📝 落合フォーマット

**どんなもの？**

大規模な事前学習済みVision Transformerを下流タスクへ適応する際、バックボーン全体を更新するフルファインチューニングの代わりに、入力空間に少量の学習可能パラメータ（プロンプト）だけを追加するVisual Prompt Tuning（VPT）を提案した研究。バックボーンは凍結したまま、モデル全体の1%未満のパラメータでタスク適応を行い、タスクごとの保存コストを大幅に削減する。

**先行研究と比べてどこがすごい？**

NLPで発展したプロンプトチューニングを画像エンコーダ（Vision Transformer）に適用し、その有効性と汎用性を複数ドメイン・複数バックボーンで体系的に検証した点が新しい（著者らは最初の取り組みと主張）。NLPではプロンプトチューニングがフルファインチューニングに並ぶ程度であるのに対し、視覚ではVPTが多くのケースでフルファインチューニングを上回ると報告している。

**技術や手法のキモはどこ？**

事前学習済みViTの埋め込み層の後ろに、p個のd次元の学習可能ベクトル（プロンプト）を系列に連結（prepend）し、プロンプトと線形分類ヘッドのみを更新してTransformer本体は凍結する。最初の層のみに挿入するVPT-shallowと、全Transformer層の入力に挿入するVPT-deepの2種類がある。プロンプト長pが唯一のVPT固有ハイパーパラメータで、検証セットで選択する。ViT-Base（50プロンプト）ではshallowで全パラメータの0.04%、deepで0.53%の追加となる。

**どうやって有効だと検証した？**

ImageNet-21k事前学習のViT-B/16で、FGVC（5タスク）とVTAB-1k（19タスク）の計24の分類タスクで評価した。VPT-deepは24タスク中20タスクでフルファインチューニングを上回り、他のパラメータ効率的手法（Linear、Adapter、Biasなど）も全タスクグループで上回った（総パラメータは1.18倍 vs Fullの24.02倍）。またデータ規模（10〜80%）やモデル規模（ViT-B/L/H）を変えてもFullに対する優位性が維持され、プロンプトの位置・長さ・深さなどのアブレーションも行っている。

**議論はある？**

Swin-Bではフルファインチューニングが総合的に最高精度となり、MAEやMoCo v3の自己教師あり事前学習ViTではVPTの優位が明確でなく、理由は未解明の課題として残る。セマンティックセグメンテーション（ADE20K）ではFullに及ばずBiasと同程度、ConvNetでも小さいResNet-50では優位性が薄れる。最適なプロンプト長がタスクごとに異なり、より広い認識タスクへの効率的転移が今後の課題である。

**次に読むべき論文は？**

- The Power of Scale for Parameter-Efficient Prompt Tuning：VPTが直接の着想源とするNLPのプロンプトチューニング手法で、視覚への適用との違いを理解するのに役立つ。
- Prefix-Tuning: Optimizing Continuous Prompts for Generation：各層に連続的なプロンプトを挿入するVPT-deepの考え方に近い手法で、背景を把握できる。
- Parameter-Efficient Transfer Learning for NLP：本論文の主要ベースラインであるAdapterの原典で、比較対象の仕組みを理解できる。

:::


### 3. ByteTrack: すべての検出ボックスを関連付ける多目的追跡 {#paper-3}

📈 被引用数上位（Paper Digest の集計で同年2位） ・ Yifu Zhang, Peize Sun, Yi Jiang, Dongdong Yu ほか ・ [論文を読む ↗](https://arxiv.org/abs/2110.06864)

<small>原題: ByteTrack: Multi-Object Tracking by Associating Every Detection Box</small>

多目的追跡（MOT）で、従来は捨てられていた低スコアの検出ボックスもトラックレットとの類似度で関連付け、真の物体を回復しつつ背景を除去するデータ関連付け手法BYTEを提案し、YOLOXと組み合わせたByteTrackを構築した研究です。Re-IDや注意機構を使わずKalman filterとIoUのみでも高精度で、既存9種のトラッカーにも適用でき、MOT17検証セットではSORTに対しMOTAを74.6から76.6、IDF1を76.9から79.3へ改善しました。MOT17テストで80.3 MOTA・77.3 IDF1・63.1 HOTAを単一V100で30 FPSで達成し、MOT20、HiEve、BDD100Kでも1位となった点が注目されます。

::: info 📝 落合フォーマット

**どんなもの？**

多目的追跡（MOT）において、閾値で捨てられがちな低スコア検出ボックスも含めてほぼ全ての検出ボックスを関連付ける汎用的なデータ関連付け手法BYTEを提案した研究。さらにYOLOXとBYTEを組み合わせたシンプルで高性能なトラッカーByteTrackを構築し、MOT17・MOT20・HiEve・BDD100Kで最先端性能を示した。

**先行研究と比べてどこがすごい？**

従来は高スコア検出ボックスのみを関連付け、遮蔽された物体などの低スコア検出を捨てていたため、真の物体の見逃しや軌跡の分断が生じていた。本手法は低スコア検出とトラックレットの類似度を使って真の物体を回復しつつ背景を除去する点が新しい。Re-IDや注意機構を使わずKalman filterとIoUのみでも高精度を実現し、既存9種のトラッカーにも適用できる汎用性を持つ。

**技術や手法のキモはどこ？**

検出ボックスをスコア閾値τ（既定0.6）で高スコア群と低スコア群に分ける。まずKalman filterで予測したトラック位置と高スコア検出をIoU（またはRe-ID特徴距離）で類似度計算し、ハンガリアン法で1回目の関連付けを行う。次に未マッチのトラックと低スコア検出をIoUのみで2回目の関連付けし（低スコア検出ではRe-ID特徴が信頼できないため）、未マッチの低スコア検出は背景として削除する。1回目で未マッチの高スコア検出から新規トラックを初期化し、見失ったトラックは30フレーム保持する。

**どうやって有効だと検証した？**

MOT17検証セットでBYTEはSORTからMOTAを74.6から76.6、IDF1を76.9から79.3、IDsを291から159に改善し、9種のトラッカーへの適用でもIDF1が1〜10ポイント程度改善した（例：CenterTrackでIDF1 64.2→74.0）。ByteTrackはMOT17テストで80.3 MOTA・77.3 IDF1・63.1 HOTAを単一V100で30 FPSで達成し、MOT20（77.8 MOTA）、HiEve、BDD100Kでも1位となった。

**議論はある？**

BDD100Kのように大きなカメラ運動や低フレームレートの場面ではKalman filterが機能せず、別途Re-ID特徴の利用が必要になる。低スコア検出の2回目の関連付けはIoUのみに依存するため、類似度の設計や完全に遮蔽された物体の扱い（本論文ではトラックレット補間による後処理で対応）に改善の余地がある。また性能は検出器（YOLOX）の精度に左右される。

**次に読むべき論文は？**

- Simple Online and Realtime Tracking (SORT)：BYTEのベースラインであり、Kalman filterとIoUによる関連付けの基礎を理解できる。
- YOLOX: Exceeding YOLO Series in 2021：ByteTrackが検出器として採用しており、高精度な検出が追跡性能を支える点を理解できる。
- FairMOT: On the Fairness of Detection and Re-Identification in Multiple Object Tracking：検出とRe-IDを統合した代表的トラッカーで、BYTEと組み合わせた際の効果を比較して読める。
