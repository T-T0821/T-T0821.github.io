# ECCV 2024

👁️ 画像認識・CV ・ [ECCV の年ごとの流れ](./) ・ [公式サイト ↗](https://eccv.ecva.net/)

::: info この回のまとめ
イタリアのミラノで開催され、投稿8,585本・採択2,395本（約27.9%）でした。最優秀論文は、四角い画素を大量に並べる通常のカメラではなく、課題に合わせて形を学習した少数の「自由形状の画素」で必要な情報だけを取る最小限の視覚システム（コロンビア大学・Shree Nayar 氏ら）です。カメラのハードウェアをニューラルネットの第1層として学習する発想で、室内監視をわずか8画素で行うなど、省電力・プライバシー保護の両面で注目されました。
:::

- **日程**: 2024年9月
- **開催地**: イタリア・ミラノ
- **規模**: 投稿 8,585 本 ／ 採択 2,395 本 ／ 採択率 27.9%

## 🔭 この回の主なテーマ

- センサーと AI の共同設計: カメラの画素形状をネットワークの一部として学習
- プライバシー保護型センシング: 画像を復元できないほど少ない画素で必要な情報だけを取得
- 省電力の視覚システム: 太陽電池で自律動作するカメラ

::: tip 💡 技術動向への示唆
- 「高画質の画像を撮ってから AI で解析する」のではなく「課題に必要な情報だけを撮る」設計は、工場や店舗での人の計測など、プライバシーと電力に制約がある現場で有望である
- センサーのハードウェアまで含めて最適化する考え方は、エッジ AI の設計の幅を広げる
:::

### 1. 自由形状の画素による最小限の視覚 {#paper-1}

🏆 Best Paper ・ Jeremy Klotz, Shree K. Nayar ・ [論文を読む ↗](https://arxiv.org/abs/2501.00142)

<small>原題: Minimalist Vision with Freeform Pixels</small>

カメラの各画素を「光検出器＋光学マスク」で任意の形にし、その形をニューラルネットの第1層として課題ごとに学習します。室内の監視や照明の計測、交通量の推定を8〜数十画素で行い、画像を残さないためプライバシーにも配慮できることを示しました。

::: info 📝 落合フォーマット

**どんなもの？**

必要最小限の画素数で視覚タスクを解く「ミニマリストカメラ」を提案した研究。通常の正方形画素ではなく任意形状の「フリーフォームピクセル」（フォトディテクタ＋光学マスクで実装）を用い、室内空間の監視（8画素）、室内照明の計測（8画素）、交通量の推定（8画素）の各カメラを設計した。プライバシー保護性と、バッテリー・外部電源なしで動作する自己給電性を利点として挙げている。

**先行研究と比べてどこがすごい？**

カメラのハードウェアをニューラルネットワークの第1層としてモデル化し、タスクに対する学習でフリーフォームピクセルの形状そのものを得る点が新しい。本文の参考文献には、類似概念のThe Minimalist Camera、単一画素イメージング、Deep Opticsやプライバシー保護光学などがあり、それらに対し、極少数画素で従来の多画素カメラと同等の性能を示した点が特徴である。画素数が極めて少ないため、視覚的な詳細が取得できず、プライバシーを自然に保てる点と、測定数が少ないため自己給電が可能な点も優れている。

**技術や手法のキモはどこ？**

カメラの光学マスクとフォトディテクタによる計測を、ネットワークの第1層（各画素の形状＝学習可能な重み）として表現し、後続の層で推論を行う構成にする。タスクごとにネットワーク全体を学習することで、最適なフリーフォームピクセルの形状が得られる。得られた形状を光学マスクとして実装し、フォトディテクタと組み合わせて物理的なカメラとする。（提供された本文は参考文献中心のため、学習の詳細や損失関数などは確認できない。）

**どうやって有効だと検証した？**

アブストラクトによれば、室内空間の監視、室内照明の計測、交通量の推定の3タスクでそれぞれ8画素のカメラを設計し、桁違いに多い画素数を持つ従来カメラと同等の性能を示したとされる。また、測定数が少ないため完全自己給電（外部電源・バッテリー不要）で動作することも示したとされる。ただし、提供された本文には具体的な精度指標や数値結果が含まれておらず、詳細は確認できない。

**議論はある？**

提供された本文には限界や今後の展望の記述がなく、詳細は確認できない。一般的には、タスクごとに専用のカメラを設計・学習する必要がある点、アブストラクトで挙げられた3タスク以外への汎用性が論点になり得るが、これは本文からの確認ではない。プライバシー保護の程度についても、定量的な評価は原論文で確認する必要がある。

**次に読むべき論文は？**

- The Minimalist Camera：本研究の概念的な先行研究であり、ミニマリストカメラの考え方の出発点を把握できるため。
- Towards Self-Powered Cameras：同じ著者グループによる自己給電カメラの研究で、本研究の自己給電の主張の背景を理解できるため。
- Single-Pixel Imaging via Compressive Sampling：少数の測定から情報を取得する単一画素イメージングの代表的研究で、比較対象として有用なため。

:::


### 2. Grounding DINO: DINOとグラウンデッド事前学習を結びつけたオープンセット物体検出 {#paper-2}

📈 被引用数上位（Paper Digest の集計で同年1位） ・ Shilong Liu, Zhaoyang Zeng, Tianhe Ren, Feng Li ほか ・ [論文を読む ↗](https://arxiv.org/abs/2303.05499)

<small>原題: Grounding DINO: Marrying DINO with Grounded Pre-Training for Open-Set Object Detection</small>

Transformer系検出器DINOに言語を密に統合し、カテゴリ名や属性を含む参照表現で指定した任意の物体を検出できるオープンセット検出器を提案した研究である。neck・クエリ初期化・headの3フェーズすべてで言語を融合し、無関係なカテゴリ名同士の注意を遮断するsub-sentenceレベルのテキスト表現も導入した点が新しい。COCOを学習に使わないゼロショットでAP 52.5（Swin-L）を達成し、ODinWゼロショットでも平均AP 26.1と新記録を示したことに加え、ECCV 2024で被引用数が同年1位（Paper Digest集計）である点も注目される。

::: info 📝 落合フォーマット

**どんなもの？**

Transformer系検出器DINOに言語を密に統合し、カテゴリ名や参照表現（属性を含む記述）で指定した任意の物体を検出できるオープンセット物体検出器Grounding DINOを提案した研究。大規模なグラウンデッド事前学習により、COCOを一切学習に使わないゼロショット設定でも高い性能を示す。

**先行研究と比べてどこがすごい？**

従来のオープンセット検出器（GLIPはneckのみ、OV-DETRはクエリ初期化のみ）が言語融合を一部のフェーズに限っていたのに対し、neck・クエリ初期化・headの3フェーズすべてで融合する「密な融合」を採用した。また無関係なカテゴリ名同士の注意を遮断するsub-sentenceレベルのテキスト表現を導入した。さらに評価を新規カテゴリだけでなく、属性付き物体を指す参照表現理解（REC）にも広げた点も特徴である。

**技術や手法のキモはどこ？**

画像バックボーン（Swin）とテキストバックボーン（BERT）の特徴を、変形可能自己注意・通常の自己注意と、画像→テキスト／テキスト→画像のクロスアテンションを積んだfeature enhancerで融合する。言語誘導クエリ選択では、画像特徴とテキスト特徴の内積の最大値が上位となる900個のトークンをデコーダのクエリ位置として選ぶ。クロスモダリティデコーダは各層に画像クロスアテンションに加えテキストクロスアテンションを持つ。sub-sentenceレベル表現ではアテンションマスクで無関係なカテゴリ名間の相互作用を排除し、単語単位の特徴を保つ。損失はL1・GIoUによる箱回帰と、クエリとテキストトークン間のコントラスト（focal）損失を用いる。

**どうやって有効だと検証した？**

COCO、LVIS、ODinW、RefCOCO/+/gで評価した。COCOゼロショットではSwin-LでAP 52.5を達成し、同条件でDINOより+0.5 AP、GLIPより+1.8 AP高く、ODinWゼロショットでは平均AP 26.1と新記録を示した。アブレーションでは、エンコーダ融合、言語誘導クエリ選択、テキストクロスアテンション、sub-sentenceプロンプトがいずれもLVISゼロショット性能に寄与した（クエリ選択+3.0 AP、テキストクロスアテンション+1.8 AP、sub-sentence+0.5 AP）。RECではGLIPを上回るが、REC用データなしでは精度が低く、RefCOCO系データで学習すると大きく向上した。

**議論はある？**

LVISではDetCLIPv2に劣り、特に希少カテゴリのAPが低く、DETR系アーキテクチャの特性の可能性が論じられている。セグメンテーションには対応せず、学習データがGLIPの最大モデルより少なく、誤検出（ハルシネーション）も見られるとされる。RECのゼロショット性能は低く、今後の重点課題として挙げられている。

**次に読むべき論文は？**

- Grounded Language-Image Pre-training (GLIP)：Grounding DINOが拡張・比較する主要な基盤であり、物体検出をフレーズグラウンディングとして定式化する手法を理解できる。
- DINO: DETR with Improved DeNoising Anchor Boxes for End-to-End Object Detection：Grounding DINOのベースとなる検出器で、クエリ選択やデコーダの構造を理解するために必要である。
- MDETR - Modulated Detection for End-to-End Multi-Modal Understanding：DETR系で言語とグラウンディングを統合した先行研究で、REC評価での比較対象でもある。

:::


### 3. YOLOv9: Programmable Gradient Information を用いて学習したいことを学習する {#paper-3}

📈 被引用数上位（Paper Digest の集計で同年2位） ・ Chien-Yao Wang, I-Hau Yeh, Hong-Yuan Mark Liao ・ [論文を読む ↗](https://arxiv.org/abs/2402.13616)

<small>原題: YOLOv9: Learning What You Want to Learn Using Programmable Gradient Information</small>

深層ネットワークで層を重ねるほど入力情報が失われ、損失関数が信頼できる勾配を生成できなくなる情報ボトルネックの問題に対し、推論時の追加コストなしに補助可逆ブランチなどで対処する学習概念 PGI と、通常の畳み込みのみで構成される軽量な GELAN を提案し、両者を組み合わせた物体検出器 YOLOv9 を構築した研究です。MS COCO 2017 で事前学習なしの train-from-scratch 条件でも、YOLOv9-E が AP 55.6% を達成して YOLOv8-X よりパラメータ16%減、計算量27%減、AP +1.7% となり、ImageNet 事前学習済みの RT DETR-X と同等の精度をパラメータ66%で実現しました。PGI は深層監督が浅いモデルで精度を下げる場合があるのに対し GELAN-S/M/C/E の全サイズで AP を改善しており、軽量モデルから大型モデルまで効く点が注目され、Paper Digest の集計で ECCV 2024 の被引用数2位となっています。

::: info 📝 落合フォーマット

**どんなもの？**

深層ネットワークでは層を重ねるほど入力情報が失われる情報ボトルネックにより、損失関数が信頼できる勾配を生成できないという問題に取り組んだ研究である。これを解決する学習概念 PGI（Programmable Gradient Information）と、軽量で効率的なアーキテクチャ GELAN を提案し、両者を組み合わせた物体検出器 YOLOv9 を構築した。

**先行研究と比べてどこがすごい？**

従来の可逆アーキテクチャは推論コストが増え、マスクモデリングは再構成損失がターゲット損失と衝突し、深層監督は浅いモデルで性能が落ちるという欠点があった。PGI は補助可逆ブランチと multi-level auxiliary information により、推論時の追加コストなしにこれらを回避し、軽量モデルから大型モデルまで適用できる。GELAN は通常の畳み込みのみで、depth-wise 畳み込みベースの YOLO-MS よりパラメータ効率が高いとされる。

**技術や手法のキモはどこ？**

PGI は、推論に使う main branch、学習時のみ使う auxiliary reversible branch、multi-level auxiliary information の3要素から成る。補助可逆ブランチが信頼できる勾配を main branch に供給し、推論時には取り除ける。multi-level auxiliary information は、特徴ピラミッドの各階層と main branch の間に統合ネットワークを挿入し、全ターゲット物体の勾配情報を集約して、特定サイズの物体情報に偏らないようにする。GELAN は CSPNet と ELAN を組み合わせ、ELAN を任意の計算ブロックを使える形に一般化したもので、YOLOv9 では RepConv を用いた CSP ブロックを採用している。

**どうやって有効だと検証した？**

MS COCO 2017 で、全モデルを事前学習なしの train-from-scratch、500 エポックで学習して比較した。YOLOv9-E は AP 55.6% で、YOLOv8-X に対しパラメータ16%減、計算量27%減、AP +1.7%、YOLOv9-C は YOLOv7 AF と同じ AP 53% をパラメータ42%減、計算量22%減で達成した。アブレーションでは、深層監督が浅いモデルで精度を下げる場合があるのに対し、PGI は GELAN-S/M/C/E の全サイズで AP を改善した（例: GELAN-E で +0.6）。また ImageNet 事前学習済みの RT DETR-X と同等の精度を、パラメータ66%で達成した。

**議論はある？**

GELAN は深さに対して感度が低く、特別な設計なしに安定した性能を得られるとされるが、評価は MS COCO の物体検出に限られており、他タスクや他ドメインでの有効性は本文では示されていない。補助可逆ブランチは学習時に追加の計算・メモリを要する点も考慮が必要である（本文では学習コストの定量評価は確認できない）。

**次に読むべき論文は？**

- YOLOv7: Trainable bag-of-freebies sets new state-of-the-art for real-time object detectors：YOLOv9 のベースモデルであり、補助ヘッドや lead-head guided assignment、RepConv の理解に必要である。
- Reversible Column Networks：可逆アーキテクチャを多階層に一般化した手法で、PGI が対比・参照する可逆ブランチの考え方を理解できる。
- DETRs beat YOLOs on real-time object detection：RT DETR は YOLOv9 の主な比較対象であり、Transformer 系リアルタイム検出器との違いを把握できる。

:::


### 4. MMBench: あなたのマルチモーダルモデルは万能選手か? {#paper-4}

📈 被引用数上位（Paper Digest の集計で同年3位） ・ Yuan Liu, Haodong Duan, Yuanhan Zhang, Bo Li ほか ・ [論文を読む ↗](https://arxiv.org/abs/2307.06281)

<small>原題: MMBench: Is Your Multi-modal Model an All-around Player?</small>

大規模視覚言語モデル(VLM)を客観的かつ頑健に評価するため、3,217問の選択式問題からなる英語・中国語の二言語ベンチマーク MMBench を提案した研究です。厳格な CircularEval や GPT-4 による選択肢抽出(人手抽出と91.5%一致)などを組み合わせ、従来の完全一致評価や人手評価の課題を解消し、知覚と推論にわたる20の細粒度能力でモデルの得意・不得意を分析できます。ECCV 2024 で被引用数が上位(Paper Digest 集計で同年3位)であり、InternLM-XComposer2 が78.1%、Qwen-VL-Max が75.4%、GPT-4v が74.3%という比較結果も示されています。

::: info 📝 落合フォーマット

**どんなもの？**

大規模視覚言語モデル（VLM）の能力を客観的かつ頑健に評価するため、3,217問の選択式問題からなる二言語（英語・中国語）ベンチマーク MMBench を提案した研究。知覚と推論を軸とする階層的な分類（L-1〜L-3、計20の細粒度能力）で、モデルの得意・不得意を詳細に分析できる。

**先行研究と比べてどこがすごい？**

従来の VQAv2 や COCO Caption は完全一致による偽陰性が多く細粒度の分析ができず、OwlEval など人手評価は再現性・拡張性に課題があった。本研究は、客観的な選択式問題、厳格な CircularEval、LLM による選択肢抽出、英中の対応比較を組み合わせ、これらの課題をまとめて解消した。また、テキストのみで解ける問題や誤問題を LLM/VLM で自動検出して人手確認する品質管理手法も提示している。

**技術や手法のキモはどこ？**

各問題を（質問、2〜4個の選択肢、画像、正解）の組とし、ボランティアが主にインターネット（80%超）から収集した。CircularEval では選択肢を循環シフトして N 回（N は選択肢数）問い、全パスで正解したときのみ正答とする。自由形式の出力は、まずヒューリスティックなマッチングで選択肢ラベルを抽出し、失敗した場合は GPT-4（gpt-4-0125）で選択肢に対応づける。中国語版は GPT-4 で翻訳し、人手で検証した。

**どうやって有効だと検証した？**

GPT-4 による選択肢抽出は、人手による抽出結果と91.5%一致した。CircularEval により多くのVLMで精度が大きく低下し（GPT-4v で約10%減、OpenFlamingo v2 は36.7%から2.6%）、モデル間の差が明確になった。MMBench-test では、オープンソースの InternLM-XComposer2 が78.1%で最高となり、プロプライエタリでは Qwen-VL-Max 75.4%、GPT-4v 74.3% だった。LLM の性能が VLM の性能に大きく影響すること、プロプライエタリモデルは構造化された画像テキスト理解や外部知識を要するタスクで優位なことも示された。

**議論はある？**

全VLMが、画像の低レベル特徴の認識、表・図・レイアウトなど構造化された視覚入力の理解、物体間の空間関係の認識・推論に弱いことが示され、今後の改善課題となっている。プロプライエタリモデルのコンテンツ制限による回答拒否は、精度に最大2.4%の影響を与える。選択式形式の評価であるため、自由記述の生成能力までは直接測れない点が限界として考えられる（この点は本文中で明示的には論じられていない）。

**次に読むべき論文は？**

- MME: A Comprehensive Evaluation Benchmark for Multimodal Large Language Models：同時期の代表的なVLM評価ベンチマークであり、MMBench との設計や評価方法の違いを比較できる。
- Visual Instruction Tuning (LLaVA)：MMBench で高い性能を示したLLaVA系モデルの基盤となる手法で、VLM の学習パラダイムを理解できる。
- LVLM-eHub: A Comprehensive Evaluation Benchmark for Large Vision-Language Models：MMBench が課題として挙げた人手による主観評価アプローチの代表例で、客観評価との違いを理解できる。
