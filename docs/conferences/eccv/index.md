# ECCV

👁️ [画像認識・CV](../#cv) ・ European Conference on Computer Vision ・ 偶数年の秋 ・ [公式サイト ↗](https://eccv.ecva.net/)

::: info 2020年からの流れ
ECCV は偶数年に欧州で開かれる CV の国際会議です。2020年（グラスゴー予定からオンライン）は光学フロー推定の決定版となった RAFT、2022年（テルアビブ）はニューラルネット同士の表現を比べる部分距離相関、2024年（ミラノ）は最小限の画素で課題を解く自由形状の画素を持つカメラ、2026年（マルメ）は UV 展開を不要にする熱核テクスチャが最優秀論文でした。CVPR に比べ、手法の流行よりも幾何学やセンサー設計など基礎的な発想の転換が評価される傾向があります。投稿は2020年の約5,000本から2026年の1万本超に増えました。
:::

## 📅 各回のまとめ

- **[ECCV 2026](./2026)** — マルメ開催・投稿1万本超。UV 展開を不要にする熱核テクスチャ（インペリアル・カレッジ）が最優秀論文に<br><small>2026年9月8日〜12日 ・ スウェーデン・マルメ</small>
- **[ECCV 2024](./2024)** — ミラノ開催。最小限の画素数で課題を解く「自由形状の画素」を持つカメラ（コロンビア大学）が最優秀論文に<br><small>2024年9月 ・ イタリア・ミラノ</small>
- **[ECCV 2022](./2022)** — テルアビブ開催。ニューラルネット同士の「機能」を比べる部分距離相関の研究が最優秀論文に選ばれた回<br><small>2022年10月 ・ イスラエル・テルアビブ</small>
- **[ECCV 2020](./2020)** — グラスゴー開催予定からオンラインへ。光学フロー推定の決定版となった RAFT（プリンストン大学）が最優秀論文に<br><small>2020年8月 ・ オンライン開催（当初予定は英国・グラスゴー）</small>

## 🔭 年ごとのテーマの移り変わり

- 2020: 光学フローの RAFT、初のオンライン開催
- 2022: 部分距離相関によるネットワークの比較、ViT と CNN の分析
- 2024: センサーと AI の共同設計（自由形状の画素）、プライバシー保護型センシング
- 2026: Gaussian Splatting の発想をテクスチャへ応用、離散リーマン幾何による表現

::: tip 💡 技術動向への示唆
- ECCV の最高賞は大規模モデルではなく、表現やセンサーの設計を見直す研究に多く与えられており、計算資源が限られる組織でも勝負できるテーマを探す参考になる
- 画素数を極限まで減らす省電力・プライバシー保護型のカメラは、エッジ機器や見守り用途での実用につながる
:::
