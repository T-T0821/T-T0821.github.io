# ECCV 2020

👁️ 画像認識・CV ・ [ECCV の年ごとの流れ](./) ・ [公式サイト ↗](https://eccv.ecva.net/)

::: info この回のまとめ
グラスゴーで予定されていましたが、COVID-19 のためオンラインで開催されました。投稿5,025本・採択1,360本（約27.1%）です。最優秀論文は、動画のフレーム間で各画素がどう動いたかを推定する光学フローで、全画素の組み合わせの相関を作り、再帰的に推定を更新する RAFT（プリンストン大学）でした。精度・汎化・効率のすべてで従来手法を大きく上回り、その後の光学フローや動きの推定の標準的な設計になりました。
:::

### 1. RAFT：光学フローのための再帰的な全ペア場変換 {#paper-1}

🏆 Best Paper ・ Zachary Teed, Jia Deng ・ [論文を読む ↗](https://arxiv.org/abs/2003.12039)

<small>原題: RAFT: Recurrent All-Pairs Field Transforms for Optical Flow</small>

2枚の画像の全画素の組み合わせについて特徴の相関を4次元の表として作り、そこから情報を引きながら1つの高解像度のフロー場を GRU で反復的に更新します。粗い解像度から段階的に推定する従来の方式をやめ、精度と汎化性能を大きく上げました。

::: info 📝 落合フォーマット

**どんなもの？**

RAFT（Recurrent All-Pairs Field Transforms）は、2枚の連続フレーム間のピクセルごとの動き（オプティカルフロー）を推定する新しいエンドツーエンド学習型のネットワーク構造である。単一の高解像度（1/8解像度）のフロー場を、軽量な再帰ユニットで繰り返し更新する設計をとる。KITTIでF1-all 5.10%、Sintel（final）でEPE 2.855 pixelsを達成し、汎化性能と効率も高いとされる。

**先行研究と比べてどこがすごい？**

従来主流のcoarse-to-fine（ピラミッド）設計ではなく、単一の固定解像度のフロー場を保持・更新するため、粗い解像度での誤りから回復しにくい点や小さく速い物体を見逃す点を避けられると主張している。また、重みを共有した軽量な更新演算子（2.7Mパラメータ）を使い、推論時に100回以上反復しても発散しない。さらに、全ピクセル対の4D相関ボリュームに対してルックアップを行うConvGRUという新しい更新器の設計が特徴である。

**技術や手法のキモはどこ？**

特徴エンコーダで1/8解像度の特徴を抽出し、全ピクセル対の内積から4D相関ボリュームを一度だけ計算して、最後の2次元を平均プーリング（カーネル1,2,4,8）した4段のピラミッドを作る。各反復では、現在のフロー推定が指す位置の周囲（半径r）を相関ピラミッドから双線形サンプリングで取り出し、フロー特徴・コンテキスト特徴と連結してConvGRUに入力し、フロー更新量Δfを予測する。初期値は0で、出力は学習したconvex upsampling（近傍3x3の凸結合）で解像度を戻す。損失は全反復の予測に対し、指数的に増える重み（γ=0.8）を付けたl1距離である。

**どうやって有効だと検証した？**

FlyingChairs・FlyingThingsで事前学習後、SintelとKITTIで評価した。C+T学習のみでもSintel(train)のcleanでEPE 1.43（FlowNet2比29%減）、KITTI-15(train)でEPE 5.04（従来の最良8.36から約40%減）と高い汎化を示した。テストではSintelのclean・finalで1位、KITTIでF1-all 5.10%（先行の最良6.10%）を達成した。アブレーションでは、ConvGRU、重み共有、コンテキスト、相関プーリング、all-pairs、相関（ワーピングとの比較）、convex upsamplingの各要素が有効であることを確認した。また1080Ti上で10 fps程度、小型版は約1Mパラメータで動作し、1080p動画も12反復で550 msで処理した。

**議論はある？**

本文では限界についてほとんど述べられていないが、all-pairs相関の計算量・メモリはO(N²)で、高解像度では代替のO(NM)実装に切り替える必要がある。1080pでは相関計算が推論時間の17%を占めると報告されている。また、評価の多くは1/8解像度の出力と学習済みupsamplingに依存しており、細部の扱いや、warm-startなど動画向け初期化の活用は今後の検討余地として残されている。

**次に読むべき論文は？**

- PWC-Net: CNNs for Optical Flow Using Pyramid, Warping, and Cost Volume：RAFTが対比しているcoarse-to-fine型の代表的手法であり、設計の違いを理解するための基準になる。
- Iterative Residual Refinement for Joint Optical Flow and Occlusion Estimation (IRR)：重みを共有した反復的な精緻化という、RAFTに最も近い先行の深層学習手法である。
- Deep Equilibrium Models：重み共有ユニットを多数回適用して固定点に収束させるというRAFTの考え方の背景を理解できる。

:::


### 2. Transformerによるend-to-end物体検出 {#paper-2}

📈 被引用数上位（Paper Digest の集計で同年1位） ・ Nicolas Carion, Francisco Massa, Gabriel Synnaeve, Nicolas Usunier ほか ・ [論文を読む ↗](https://arxiv.org/abs/2005.12872)

<small>原題: End-to-End Object Detection with Transformers</small>

物体検出を集合の直接予測問題として定式化し、NMSやアンカー生成といった手設計の構成要素を不要にしたTransformerベースの検出器DETRを提案した研究です。二部マッチングによる集合損失と並列デコードのTransformerを組み合わせ、COCOでFaster R-CNNと同等の42.0 AP（ResNet-50）を達成し、パノプティックセグメンテーションにも拡張できることを示しました。ECCV 2020でPaper Digest集計の被引用数が同年1位で、推論コードがPyTorchで50行未満という簡潔さも注目される点です。

::: info 📝 落合フォーマット

**どんなもの？**

物体検出を「集合の直接予測問題」として定式化し、NMSやアンカー生成といった手設計の構成要素を不要にした、Transformerベースのend-to-end検出器DETR（DEtection TRansformer）を提案した研究。固定数の学習済みオブジェクトクエリから最終的な検出集合を並列に出力する。同じ枠組みでパノプティックセグメンテーションにも拡張できることを示した。

**先行研究と比べてどこがすごい？**

二部マッチングによる集合損失と、非自己回帰（並列デコード）のTransformerを組み合わせた点が新しい。従来の集合予測系の手法はRNNによる自己回帰が中心で小規模データでしか評価されていなかったが、DETRはCOCOで強力なFaster R-CNNと比較可能な性能を示した。特殊なライブラリ不要で、推論コードはPyTorchで50行未満で書ける簡潔さも特徴である。

**技術や手法のキモはどこ？**

CNNバックボーンの特徴マップを1x1畳み込みで次元圧縮・平坦化し、位置エンコーディングを加えてTransformerエンコーダに入力する。デコーダはN個の学習済みオブジェクトクエリをエンコーダ出力にアテンションさせ、各出力をFFNでクラスと正規化ボックス座標（または「no object」）に変換する。学習ではハンガリアンアルゴリズムで予測とGTを1対1に最適マッチングし、クラスのNLLとL1＋GIoUのボックス損失で最適化する。各デコーダ層に補助損失を付与し、パノプティックでは出力にマスクヘッドを追加する。

**どうやって有効だと検証した？**

COCO 2017（学習118k枚、検証5k枚）でFaster R-CNNと比較し、DETR（ResNet-50）は42.0 AP（41Mパラメータ、28 FPS）でFaster R-CNN-FPN+と同等、DETR-DC5-R101は44.9 APを達成した。大物体のAP_Lは61.1とFaster R-CNN-FPN+（53.4）より大きく上回る一方、AP_Sは20.5と劣る。アブレーションではエンコーダ層なしでAP 3.9低下、GIoU損失単独でも-0.7 AP程度と示した。パノプティックではDETR-R101が45.1 PQで、PanopticFPN++（R101で44.1）等を上回った。

**議論はある？**

小物体の性能が低いことに加え、学習に500エポックなど非常に長いスケジュールを要し、最適化面の課題が残ると著者自身が述べている。FPNがFaster R-CNNの小物体性能を改善したように、今後の研究でこれらの改善が期待されるとしている。また損失の組み合わせは単純な重み付けしか検証されておらず、他の組み合わせの余地がある。

**次に読むべき論文は？**

- Attention Is All You Need：DETRのエンコーダ・デコーダの基盤であるTransformerの原典で、アテンション機構を理解するために必要。
- Generalized Intersection over Union：DETRのボックス損失に用いられるGIoU損失の定義と、スケール不変性の根拠を確認できる。
- Panoptic Segmentation：DETRの拡張実験で用いられるパノプティックセグメンテーションのタスク定義と評価指標PQを理解できる。

:::


### 3. Contrastive Multiview Coding（対照的マルチビュー符号化） {#paper-3}

📈 被引用数上位（Paper Digest の集計で同年3位） ・ Yonglong Tian, Dilip Krishnan, Phillip Isola ・ [論文を読む ↗](https://arxiv.org/abs/1906.05849)

<small>原題: Contrastive Multiview Coding</small>

輝度・色差・深度・法線・オプティカルフローなど複数のビュー間で共有される情報を、同一シーンのビューを近づけ別シーンのビューを遠ざける対照学習で捉える教師なし表現学習の枠組み CMC を提案した研究です。対照学習の目的関数を2ビューから任意の M 個のビューへ一般化し、ビュー数が増えるほど表現が向上すること、および対照学習が cross-view prediction より強い表現を学習することを示した点が注目されます。ImageNet の線形評価で Top-1 68.3%（RandAugment 併用で 70.6%）を達成し、ECCV 2020 の被引用数上位（Paper Digest 集計で同年3位）に選ばれています。

::: info 📝 落合フォーマット

**どんなもの？**

複数のセンサ的ビュー（輝度・色差・深度・法線・オプティカルフローなど）間で共有される情報を捉える教師なし表現学習の枠組み Contrastive Multiview Coding (CMC) を提案した。同一シーンの異なるビューを埋め込み空間で近づけ、異なるシーンのビューを遠ざけることで、相互情報量の最大化を目指す。任意のビュー数に拡張でき、ビューの種類にも依存しない。

**先行研究と比べてどこがすごい？**

CPC や Instance Discrimination と同様の対照学習の目的関数を、2ビューから任意のM個のビューへ一般化した点が新しい。ビュー数が増えるほど表現の質が向上することを明示的に示した初めての研究だと主張している。また、対照学習が cross-view prediction（予測型学習）より強い表現を学習することを直接比較で示した。

**技術や手法のキモはどこ？**

各ビューに個別のエンコーダを用意し、コサイン類似度を温度τでスケーリングした指数関数をクリティックとして、正例1つをk個の負例から選ぶ softmax 型の対照損失を、アンカーを入れ替えて対称に足し合わせる。3ビュー以上では、1つのコアビューと他の全ビューを対にする「core view」と、全ビュー対を使う「full graph」の2方式がある。計算量削減のため、メモリバンクから m 個の負例をランダムサンプリングして (m+1)-way softmax 分類を行う（ImageNetでは τ=0.07、負例16384個）。

**どうやって有効だと検証した？**

ImageNetの線形評価では、&#123;L,ab} の ResNet50x2 で Top-1 68.3%、&#123;Y,DbDr} で約0.7%向上、RandAugment 併用で 70.6%（Top-5 89.7%）を達成した。UCF-101 では2ストリーム(V+D)の3ビューで 59.1%となり、単一ストリームより高精度であった。NYU-Depth-V2 ではビューを1から4に増やすと mIoU と画素精度が単調に向上し、STL-10 の比較でも対照学習が予測型学習を上回った（例: L,Depth で 58.3 対 55.5）。

**議論はある？**

相互情報量と表現品質の関係は単純ではなく、共有情報が多すぎても少なすぎても性能が下がる「Goldilocks」的な最適点が存在する。相互情報量の下界は弱い可能性があり、より良い推定器の開発が未解決課題とされている。関連情報だけを共有する最適なビューの選択が今後の研究方向として挙げられている。

**次に読むべき論文は？**

- Representation Learning with Contrastive Predictive Coding：CMC の対照損失と相互情報量下界の基礎となる手法であり、直接の出発点だから。
- Unsupervised Feature Learning via Non-Parametric Instance Discrimination：CMC が採用するメモリバンクと温度設定の元になっており、実装の詳細を理解できるから。
- Momentum Contrast for Unsupervised Visual Representation Learning：メモリバンクを発展させ、負例を効率的に扱う後続の代表的手法だから。
