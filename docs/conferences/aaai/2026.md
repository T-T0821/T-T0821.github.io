# AAAI 2026

🏛️ AI全般（老舗・総合） ・ [AAAI の年ごとの流れ](./) ・ [公式サイト ↗](https://aaai.org/conference/aaai/)

::: info この回のまとめ
第40回の節目となる回で、シンガポールで開催されました。投稿は23,680本と前年の約1.8倍に急増し、採択は4,167本（17.6%）と狭き門になりました。最優秀論文は5本で、視覚・言語・行動をつなぐロボット制御モデル（VLA）に注視領域の再構成を組み合わせた ReconVLA、LLM の知識で CLIP の画像・テキスト表現を強化する LLM2CLIP（Microsoft ほか）、記述論理の概念の変更、動的システムの因果構造学習、ハイパーグラフニューラルネットの高周波成分の理論が選ばれました。新設の AI アラインメントトラックでは、LLM の意見が世界の人々の意見とどれだけ合っているかを分析した研究が最優秀論文になっています。
:::

## 📝 注目論文

### 1. ReconVLA：再構成によってロボットの知覚を強化する VLA モデル {#paper-1}

🏆 Outstanding Paper ・ Wenxuan Song, Ziyang Zhou, Han Zhao, ほか ・ [論文を読む ↗](https://arxiv.org/abs/2508.10333)

<small>原題: ReconVLA: Reconstructive Vision-Language-Action Model as Effective Robot Perceiver</small>

画像と言語指示からロボットの動作を出力する VLA モデルが、操作すべき物体に注意を向けられない問題に対し、注視すべき領域の画像を再構成させる補助タスクで視覚的な注意を鍛え、実機と模擬環境で操作の成功率を上げました。

::: info 📝 落合フォーマット

**どんなもの？**

従来のVLAは行動予測時に視覚的注意が目標物に集中せず分散してしまうという問題を指摘し、それを解決するReconVLAを提案した研究である。VLAの視覚出力（reconstructive tokens）を条件に拡散Transformerで操作対象の注視領域（gaze region）を再構成させる「暗黙的グラウンディング」により、精密な操作を目指す。あわせて10万超の軌道・200万サンプルの事前学習データセットを構築した。

**先行研究と比べてどこがすごい？**

従来のグラウンディングは、外部の検出器・セグメンタへの依存（明示的グラウンディング）やバウンディングボックスのCoT出力に頼っていたが、これらは注意配分そのものを改善しない。本手法は追加の入出力を必要とせず、視覚出力を直接再構成で監督することでモデル自身の注意配分と細粒度表現を改善する点が新しい。また、未来フレーム予測型の生成手法と異なり、現在観測の注視領域を再構成する。

**技術や手法のキモはどこ？**

LLaVA-7b（Qwen2-7B + SigLIP）をベースに、行動トークンの自己回帰予測（クロスエントロピー）と、再構成損失を併用する。注視領域の画像をVAEトークナイザでscene tokens z0に変換し、軽量な拡散Transformerがノイズ付きトークンztからLLM出力のreconstructive tokensを条件にノイズを予測する。画像トークンが指示に注目できるよう指示トークンを画像トークンの前に置く。事前学習データはBridgeData V2、LIBERO、CALVINからGrounding DINOで注視領域を切り出して作成し、事前学習後にタスクごとにファインチューニングする。

**どうやって有効だと検証した？**

CALVINで評価し、ABC→Dで平均タスク長3.95（ベースライン3.36、明示的グラウンディング3.61、CoTグラウンディング0.63、UniVLA 3.80）、ABCD→Dで4.23を達成した。アブレーションでは、再構成・注視領域・事前学習の各要素が性能向上に寄与し、「stack block」タスクではベースライン59.3%から79.5%に向上した。実世界の6自由度アームによる4タスク（各20試行）でもOpenVLAやPD-VLAを上回り、未知物体ではそれらがほぼ0%となる中で成功を示した。

**議論はある？**

本文には限界を扱う独立した節がなく、注視領域の注釈をGrounding DINOなど外部検出器に頼る点や、拡散再構成による学習コストが課題として考えられるが、これらは本文で検証されていない。実世界実験は4タスク・各20試行と規模が限られ、未知物体への汎化の範囲の検証も今後の課題といえる。

**次に読むべき論文は？**

- Reconstructive Visual Instruction Tuning：ReconVLAの着想元であり、視覚出力を再構成で監督する基本アイデアを理解できる。
- Robotic control via embodied chain-of-thought reasoning：本論文で比較対象とされたCoTグラウンディング（ECoT）の仕組みと限界を把握できる。
- UniVLA: Learning to Act Anywhere with Task-centric Latent Actions：CALVIN ABC→Dで最も近い性能の大規模VLAであり、比較の文脈を理解できる。

:::


### 2. LLM2CLIP：強力な言語モデルでより豊かなクロスモーダル表現を引き出す {#paper-2}

🏆 Outstanding Paper ・ Weiquan Huang, Aoqi Wu, Yifan Yang, ほか ・ [論文を読む ↗](https://arxiv.org/abs/2411.04997)

<small>原題: LLM2CLIP: Powerful Language Model Unlocks Richer Cross-Modality Representation</small>

画像とテキストを結びつける CLIP のテキスト側を LLM に置き換えるため、まず LLM のキャプション識別能力を対照学習で高めてから CLIP の学習に使う方法を示し、長文や複雑な説明文での検索性能を大きく改善しました。

::: info 📝 落合フォーマット

**どんなもの？**

事前学習済みCLIPのテキストエンコーダをLLM（Llama 3.1 8Bなど）で置き換え、少量（数百万〜6,000万ペア）の画像キャプション対で軽量に追加学習するフレームワークLLM2CLIPを提案した研究。LLMの言語理解力と世界知識により、特に長く複雑なキャプションの扱いを強化し、通常のCLIPファインチューニングとほぼ同等の学習コストで性能を向上させる。

**先行研究と比べてどこがすごい？**

従来のLLM-as-embedding手法（LLM2Vec、NV-Embed-v2など）は純テキストタスク向けであり、CLIPに使うにはキャプション特徴の分離性が不足する点に着目し、CLIP向けのキャプション対照学習（Stage 1）という段階を設けた点が新しい。さらにLLMを凍結して出力特徴を事前計算し、小さなアダプタとCLIP視覚エンコーダのみを学習することで、LLMの大規模な再学習なしにEVA02やSigLIP-2といった最先端CLIPを改善できる。著者らはLLMのCLIPへの統合に関する初の包括的研究だと主張している。

**技術や手法のキモはどこ？**

Stage 1ではLLMをLoRAで微調整し、平均プーリングによる文表現、双方向注意（マスク除去）、教師ありSimCSE損失で学習する。同一画像の異なる2つのキャプション（DreamLIP由来）を正例とし、純テキスト対1.5Mも混ぜて汎用性を保つ。Stage 2ではCLIPの元のテキストエンコーダを破棄し、LLMを凍結したまま出力に4層の線形アダプタ（逆ボトルネックMLP）を付け、ViTの勾配を有効にしてクロスモーダル対照学習を行う。LLM特徴はオフラインで事前計算でき、学習時にLLMをGPUに載せずに済む。学習データは実キャプションとMLLM生成の詳細キャプションを50%ずつ混合する。

**どうやって有効だと検証した？**

Flickr・COCO（短文）とShareGPT4V・Urban1K・DOCCI（長文）のゼロショット画像テキスト検索で評価し、例えばSigLIP2に適用すると短文検索で+1.0/+1.9、長文検索で+14.8/+15.8、多言語検索で+11.9/+15.2の改善を報告している（本文の概要記述による）。EVA02 ViT-L/14ではLLM2CLIP-60Mが5データセット平均でI2T/T2Iとも大幅向上（224解像度でEVA02の78.4/71.5に対し90.4/86.3）。また英語のみで学習したにもかかわらずEVA02の多言語検索能力が大幅に向上し、線形プローブ（ImageNet）、ゼロショット/教師ありセグメンテーション、検出、LLaVA-1.5の視覚エンコーダ置換でも改善が見られた。アブレーションでは、CC微調整なしのLlama3.1-8Bは元のCLIPより悪化し、キャプション対照学習の必要性が示された。

**議論はある？**

ImageNetのゼロショット分類は微調整後に僅かに低下しており（例: L/14-336で76.6→75.8）、細粒度・ロングテールのクラス間の識別力が弱まる可能性がある。著者らは追加データで緩和できると仮説を立てているが、未検証である。また、CLIPとLLMの特徴を連結する方式(d)は有望な向上を示したが、簡潔さのため採用されず今後の課題とされている。LLaVA-1.5の一部ベンチマーク（本文では2タスクで微減）では性能が下がるなど、効果が一様でない点にも留意が必要である。

**次に読むべき論文は？**

- LLM2Vec: Large Language Models Are Secretly Powerful Text Encoders：LLMをテキスト埋め込みモデルに変換する手法で、LLM2CLIPのStage 1（双方向注意・MNTP・SimCSE）の土台となっているため。
- SigLIP 2: Multilingual Vision-Language Encoders with Improved Semantic Understanding, Localization, and Dense Features：LLM2CLIPが改善対象とした最先端ベースラインであり、比較対象の性能や設計を理解するのに役立つため。
- VLM2Vec: Training Vision-Language Models for Massive Multimodal Embedding Tasks：MLLMを直接マルチモーダル埋め込みに用いる対照的アプローチで、CLIPの二塔構成との比較の観点で重要であるため。

:::
