# AAAI 2020

🏛️ AI全般（老舗・総合） ・ [AAAI の年ごとの流れ](./) ・ [公式サイト ↗](https://aaai.org/conference/aaai/)

::: info この回のまとめ
コロナ禍直前の2020年2月にニューヨークで開催されました。投稿7,737本・採択1,591本（約20.6%）です。最優秀論文は、常識推論の古典的テスト Winograd Schema を4万4千問規模に拡張し、言語モデルが統計的な手がかりで「ずる」をできないよう偏りを取り除いた WinoGrande でした。AI の社会貢献トラックでは、多数のセンサーを使った機械学習による地震早期警報が受賞しています。BERT 系モデルが既存ベンチマークで人間並みの点を出し始めた時期で、「本当に理解しているのか」を問う評価の作り方が注目されました。
:::

- **開催地**: 米国・ニューヨーク
- **規模**: 投稿 7,737 本 ／ 採択 1,591 本 ／ 採択率 20.6%

## 🔭 この回の主なテーマ

- 常識推論とベンチマークの偏り: 敵対的フィルタリング（AFLite）でデータの統計的な手がかりを除去
- AI の社会貢献: 地震早期警報など、防災・社会インフラへの応用を独立トラックで評価
- 事前学習言語モデルの台頭: BERT 系の成功を受け、NLP 系の発表が増えた

::: tip 💡 技術動向への示唆
- ベンチマークの高得点がそのまま実力を意味しないという問題提起は、その後の LLM 評価（データ汚染・ショートカット学習）の議論に直結している
- 社会課題への応用を正式なトラックで評価する流れは、以降の AAAI の特色として定着した
:::

### 1. WinoGrande：大規模な敵対的 Winograd スキーマ課題 {#paper-1}

🏆 Outstanding Paper ・ Keisuke Sakaguchi, Ronan Le Bras, Chandra Bhagavatula, Yejin Choi ・ [論文を読む ↗](https://arxiv.org/abs/1907.10641)

<small>原題: WinoGrande: An Adversarial Winograd Schema Challenge at Scale</small>

代名詞が何を指すかを常識で判断させる課題を4万4千問に拡張し、モデルが単語の共起などの手がかりで正解できる問題をアルゴリズムで取り除きました。人間は94%正解する一方、当時の最先端モデルは大きく下回り、評価データ作りの考え方を変えました。

::: info 📝 落合フォーマット

**どんなもの？**

Winograd Schema Challenge（WSC）に着想を得た、4.4万問規模の常識推論ベンチマーク WinoGrande を提案した研究。クラウドソーシングで問題を大量に作成し、アルゴリズムでバイアスを除去して、人間には易しい（94.0%）が機械には難しいデータセットにしている。さらに、転移学習の資源としても有効であることを示した。

**先行研究と比べてどこがすごい？**

WSCは273問と小規模で、単語連想などのデータセット固有バイアスの影響を受けやすいという課題があった。本研究は、クラウドソーシングによる大規模化と、単語共起で検出できるバイアスを埋め込み表現上の機械検出可能なバイアスへ一般化した軽量な敵対的フィルタリング AfLite を組み合わせた。AfLite は過剰生成も各反復でのモデル再学習も不要という点で従来の AF より広く適用でき、計算コストも小さい。

**技術や手法のキモはどこ？**

作業者には WikiHow 記事からランダムに選んだアンカー語を含めるという制約を課し、ツイン文（15〜30語、70%以上の単語重複）を作成させた。計7.7万問を収集し、3人の検証者による検証で68%（5.3万問）を有効とした。AfLite では、少量データ（6k件）で微調整した RoBERTa の埋め込みを用い、ランダム分割で学習した線形分類器（ロジスティック回帰）のアンサンブル（n=64、m=10,000）が正解を高い割合（閾値τ=0.75以上）で当てられる事例を、反復ごとに上位k=500件ずつ除去する。その結果、12,282問の debiased 版が得られ、除去された31k問は追加の訓練データとして公開された（all 版は43,972問）。

**どうやって有効だと検証した？**

WinoGrande debiased のテストで、RoBERTa は 79.1%（訓練データ41k件時）、2%の訓練データ（約800件）では約59%にとどまり、人間の 94.0% を15〜35ポイント下回った。局所文脈のみのベースラインや DPR で微調整したモデルはほぼ偶然水準から60%未満だった。WinoGrande での転移学習により、WSC 90.1%、DPR 93.1%、COPA 90.6%、KnowRef 85.6%、Winogender 97.1% を達成した。KL ダイバージェンスは AfLite により 2.53 から 0.12 へ大幅に低下した（ランダム削減では 2.51、PMI フィルタでは 2.42）。

**議論はある？**

著者らは、既存ベンチマークでの高精度は、真の常識推論能力ではなくデータセット固有のバイアスによって過大評価されている可能性があると指摘している。転移学習による改善のうち、既存データのバイアス利用によるものと真の常識推論の進歩によるものがどの程度かは、今後の課題として残されている。また、人間が作る静的なベンチマークではなく、最先端モデルの進歩に合わせて進化する動的なデータセットの設計が必要だと主張している。

**次に読むべき論文は？**

- RoBERTa: A Robustly Optimized BERT Pretraining Approach：本論文の主要なベースラインかつ AfLite の埋め込み抽出にも使われているモデルの詳細を理解するため。
- SWAG: A Large-Scale Adversarial Dataset for Grounded Commonsense Inference：AfLite の元になった敵対的フィルタリング（AF）の考え方を把握するため。
- Annotation artifacts in natural language inference data：データセットのアノテーションアーティファクトという問題設定の背景を理解するため。

:::


### 2. Random Erasing によるデータ拡張 {#paper-2}

📈 被引用数上位（Paper Digest の集計で同年1位） ・ Zhun Zhong, Liang Zheng, Guoliang Kang, Shaozi Li ほか ・ [論文を読む ↗](https://arxiv.org/abs/1708.04896)

<small>原題: Random Erasing Data Augmentation</small>

CNNの学習時に画像のランダムな矩形領域をランダム値で塗りつぶし、様々な程度の遮蔽を持つ画像を生成するデータ拡張手法「Random Erasing」を提案した研究です。パラメータ学習やメモリ追加が不要で実装が容易なうえ、ランダムフリップやランダムクロップとも併用でき、画像分類・物体検出・人物再識別の幅広いタスクとモデルで一貫して精度が改善しました。AAAI 2020の論文のうち、Paper Digestの集計で同年の被引用数1位という点でも注目されます。

::: info 📝 落合フォーマット

**どんなもの？**

CNNの学習時に、画像中のランダムな矩形領域をランダム値で塗りつぶして様々な程度の遮蔽を持つ画像を生成するデータ拡張手法「Random Erasing」を提案した研究。過学習の抑制と遮蔽に対する頑健性の向上を狙い、画像分類・物体検出・人物再識別で有効性を示している。

**先行研究と比べてどこがすごい？**

パラメータ学習やメモリ追加が不要で実装が容易なため、既存のCNNモデルを学習方針の変更なしに利用できる。ランダムフリップやランダムクロップと相補的に使える点が特徴。A-Fast-RCNNのような敵対的ネットワークによる遮蔽生成と比べて、学習不要でありながら物体検出で同等以上の精度を得ている。

**技術や手法のキモはどこ？**

ミニバッチ内の各画像に対し、確率pでRandom Erasingを適用し、確率1-pでそのまま使う。適用時は、面積比が[s_l, s_h]、アスペクト比が[r1, r2]の範囲でランダムに矩形サイズを決め、画像内に収まる位置が得られるまで繰り返し、領域内の各画素を[0,255]のランダム値で置き換える。分類と人物再識別では画像全体を対象とし、物体検出では画像全体(IRE)、物体のバウンディングボックス内(ORE)、その両方(I+ORE)の3方式を用いる。

**どうやって有効だと検証した？**

CIFAR-10/100とFashion-MNISTでResNet、Pre-act ResNet、ResNeXt、WRNなど複数のアーキテクチャを比較し、一貫して誤差が改善した。WRN-28-10ではCIFAR-10の誤差が3.80%から3.08%、CIFAR-100が18.49%から17.73%になった。PASCAL VOC2007のFast-RCNNではI+OREで71.5% mAP（07のみ、A-Fast-RCNNより0.5%高い）、07+12では76.2% mAPとなった。Market-1501、DukeMTMC-reID、CUHK03でもIDE、TriNet、SVDNetの全てで改善し、例えばTriNet (ResNet-50)のCUHK03(labeled)でrank-1が49.86%から58.14%に向上した。テスト時に遮蔽を加えた実験では、遮蔽面積が画像の半分のときの誤差がベースラインの75.04%に対し56.36%に抑えられた。

**議論はある？**

本文では、今後の課題として画像検索や顔認識など他のCNN認識タスクへの適用を挙げている。本文中の検証は主に畳み込みネットワークとの組み合わせに限られ、ハイパーパラメータ(p、s_h、アスペクト比)はタスクごとに設定しており、物体検出と人物再識別ではs_hを0.2に変えている。

**次に読むべき論文は？**

- A-Fast-RCNN: Hard Positive Generation via Adversary for Object Detection：敵対的ネットワークで遮蔽例を生成する比較対象の手法であり、Random Erasingの学習不要という利点を対比して理解できる。
- Dropout: A Simple Way to Prevent Neural Networks from Overfitting：Random Erasingを画像レベルのDropoutに近いものとして位置づけているため、正則化の基礎を確認できる。
- Wide Residual Networks：CIFARで最良の結果を出したWRN-28-10の構造と学習設定を理解するのに役立つ。

:::


### 3. Distance-IoU損失：バウンディングボックス回帰をより速く、より良く学習する {#paper-3}

📈 被引用数上位（Paper Digest の集計で同年2位） ・ Zhaohui Zheng, Ping Wang, Wei Liu, Jinze Li ほか ・ [論文を読む ↗](https://arxiv.org/abs/1911.08287)

<small>原題: Distance-IoU Loss: Faster and Better Learning for Bounding Box Regression</small>

物体検出のバウンディングボックス回帰で、IoU損失やGIoU損失の収束の遅さと精度不足を改善するため、中心点間の正規化距離を直接最小化するDIoU損失と、重なり面積・中心点距離・アスペクト比を併せて考慮するCIoU損失を提案した研究です。DIoUをNMSの基準に用いるDIoU-NMSも示しており、YOLOv3（PASCAL VOC 2007）ではAPがIoU損失の46.57からCIoUで49.21に向上し、SSDやFaster R-CNNでも一貫した改善が確認されています。被引用数が多く、Paper Digestの集計でAAAI 2020の2位に入った点でも注目されます。

::: info 📝 落合フォーマット

**どんなもの？**

物体検出のバウンディングボックス回帰において、IoU損失やGIoU損失の収束の遅さと回帰精度の不足を改善するため、DIoU損失とCIoU損失を提案した研究。あわせて、DIoUをNMSの基準に用いるDIoU-NMSも提案している。

**先行研究と比べてどこがすごい？**

GIoUは包含関係や水平・垂直配置の場面でIoU損失とほぼ同じになり収束が遅いが、DIoUは中心点間の正規化距離を直接最小化するため速く収束し、これらの場面でも区別できる。さらに重なり面積・中心点距離・アスペクト比という3つの幾何学的要素を併せて考慮するCIoUを導入した点が新しい。

**技術や手法のキモはどこ？**

DIoU損失は L = 1 − IoU + ρ²(b, b^gt)/c² で、ρは2つのボックスの中心点間のユークリッド距離、cは両者を囲む最小ボックスの対角線長である。CIoU損失はこれにアスペクト比の整合性を表す項 αv を加え、v は arctan(w/h) の差に基づき、α = v/((1−IoU)+v) として重なりを優先させる。vの勾配の分母 w²+h² は勾配爆発を招くため実装では除去している。DIoU-NMSは IoU − R_DIoU が閾値以上のボックスのみ抑制し、中心が離れたボックスは別物体として残す。

**どうやって有効だと検証した？**

1,715,000ケースのシミュレーション実験で収束と回帰誤差を比較し、DIoUはGIoUより速く、全域で誤差が小さいことを示した。YOLOv3（PASCAL VOC 2007）ではIoU損失のAP 46.57に対しCIoUが49.21（相対+5.67%）、AP75は49.82に対し54.28（+8.95%）で、DIoU-NMS併用でAP 49.32、AP75 54.74となった。SSD（VOC）とFaster R-CNN（MS COCO 2017）でも一貫した改善があり、後者ではCIoUがAP 37.93から38.65に向上した。

**議論はある？**

Faster R-CNNのようにアンカーの初期IoUが高い手法ではGIoUとの差は小さく、改善幅は限定的である。また、COCOのAPsmallではCIoUがIoU損失よりわずかに劣り、小物体ではアスペクト比項が中心点距離の効果を弱める可能性があると著者らは述べている。この影響はDIoU-NMSで緩和できるとされるが、検証は限られた検出器とデータセットに留まる。

**次に読むべき論文は？**

- Generalized Intersection over Union: A Metric and a Loss for Bounding Box Regression：本論文が直接の改良対象とするGIoU損失の定義と動機を理解するために必要である。
- UnitBox: An Advanced Object Detection Network：IoU損失を物体検出の回帰に初めて導入した研究で、スケール不変性の背景を押さえられる。
- Soft-NMS – Improving Object Detection with One Line of Code：NMSの基準を改良する代表的手法であり、DIoU-NMSとの比較・位置づけを理解できる。

:::
