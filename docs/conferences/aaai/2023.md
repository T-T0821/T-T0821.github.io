# AAAI 2023

🏛️ AI全般（老舗・総合） ・ [AAAI の年ごとの流れ](./) ・ [公式サイト ↗](https://aaai.org/conference/aaai/)

::: info この回のまとめ
ワシントン D.C. で3年ぶりに現地開催されました。投稿8,777本・採択1,721本（約19.6%）です。最優秀論文は、人間の行動から目的（報酬）を推定する逆強化学習が、人間の行動モデルの仮定が少しずれただけでどれほど誤った結論を出しうるかを理論的に分析した研究でした。ChatGPT 公開直後の開催で、人間の好みから報酬を学ぶ RLHF の基礎にも関わる「人間の意図をどう正しく推定するか」が評価された形です。
:::

- **日程**: 2023年2月
- **開催地**: 米国・ワシントン D.C.
- **規模**: 投稿 8,777 本 ／ 採択 1,721 本 ／ 採択率 19.6%

## 🔭 この回の主なテーマ

- 逆強化学習と価値の推定: 行動モデルの誤った仮定（最適性・ボルツマン合理性など）への頑健性を分析
- アラインメントの理論的基礎: 人間のデータから目的を推定する手法の限界の明確化
- 現地開催への回帰: オンライン開催の2年を経て対面に戻った

::: tip 💡 技術動向への示唆
- 人のフィードバックから報酬を学ぶ RLHF や DPO も、人間の行動モデルの仮定に依存しており、その仮定が外れたときの挙動を理解することが安全な AI 開発の前提になる
- デモや操作ログから「熟練者の意図」を学ぶ模倣学習・逆強化学習を製造現場などに使う場合、仮定のずれへの感度を確認する必要があることを示唆する
:::

## 📝 注目論文

### 1. 逆強化学習におけるモデルの誤指定 {#paper-1}

🏆 Outstanding Paper ・ Joar Skalse, Alessandro Abate ・ [論文を読む ↗](https://arxiv.org/abs/2212.03201)

<small>原題: Misspecification in Inverse Reinforcement Learning</small>

逆強化学習でよく使われる「人間は最適に行動する」「確率的に良い行動を選ぶ」などの行動モデルについて、真の行動とどの程度ずれると推定された報酬が誤った方向を指すのかを数学的に整理し、多くの標準的なモデルが小さなずれにも弱いことを示しました。

::: info 📝 落合フォーマット

**どんなもの？**

逆強化学習（IRL）で標準的に使われる行動モデル（最適性、ボルツマン合理性、最大因果エントロピー）が、実際の人間行動との乖離（誤指定）にどこまで頑健かを数学的に解析した研究。デモンストレータの方策が各モデルからどの程度ずれても報酬関数について誤った推論に至らないかを、必要十分条件として厳密に特徴づけている。あわせて、新しいIRLモデルの頑健性を導出するための枠組みと形式的ツールも提示している。

**先行研究と比べてどこがすごい？**

先行研究は選択集合の誤指定など特定の誤指定の影響を扱うか、行動モデルをデータから学習・精緻化する方向が中心だった。本研究は誤指定の種類を限定せず、各行動モデルが頑健となる誤指定を必要十分条件で完全に特徴づける点で範囲が広い。また方策の順序を保存する報酬変換の特徴づけ（定理2.6）を新たに与え、解析がアルゴリズムではなく行動モデルに対して行われるため、そのモデルに基づく任意のアルゴリズムに結果が適用できる。

**技術や手法のキモはどこ？**

報酬関数から計算できる任意の量を「報酬オブジェクト」f: R→X とみなし、その曖昧性 Am(f) と、報酬空間の分割 P（学習した報酬が真の報酬と十分近いかを表す同値関係）に対する P-許容性・P-頑健性を定義する。中核は補題2.2で、f が P-許容的なとき、f が g に対して P-頑健であることは g = f∘t（t は P を保存する報酬変換）と同値であるとする。P には同じ最適方策を持つ同値類（OPT）と同じ方策順序を持つ同値類（ORD）を用い、これらを保存する変換（ポテンシャルシェーピング、S'-再分配、正のスケーリング、最適性保存変換）を使って各モデルの頑健な誤指定を導出する。補題2.1は、誤指定への感度が計算過程で派生する量にも継承されることを示す。

**どうやって有効だと検証した？**

実験は行わず、定理と証明（付録）による理論的検証が中心である。結果として、ボルツマン合理性モデルは、全行動に正の確率を与え最適行動に最大確率を与える任意の方策（定理3.1）に対してOPT頑健であり、ORD頑健なのは温度パラメータの誤指定のみ（定理3.2）。最大因果エントロピーモデルもORD頑健なのは重みαの誤指定のみ（定理3.4）で、最適性モデルはいかなる誤指定にも頑健でない（定理3.3）。さらに、S'-再分配やポテンシャルシェーピングに不変な行動モデルは、遷移関数τや割引率γの誤指定に頑健でないこと（定理3.7）も示された。

**議論はある？**

頑健性の基準が最適方策や方策順序の完全一致という厳しい条件であり、γ≈γ'、τ≈τ' のような近似的な誤指定の場合の解析は今後の課題として残されている。報酬関数を部分集合に制限しても結果はおおむね保たれるが、制限によって負の結果（τやγの誤指定への非頑健性）が成り立たなくなる場合がある。事前分布や学習アルゴリズムの帰納バイアスが既知の場合や、転移学習を保証するより強い同値類については、さらなる解析が望まれる。

**次に読むべき論文は？**

- Invariance in Policy Optimisation and Partial Identifiability in Reward Learning：本研究が技術的基盤とし拡張している、報酬学習の部分識別性と最適性保存変換（OP）の特徴づけを与える先行研究である。
- Choice Set Misspecification in Reward Inference：IRLにおける誤指定（選択集合の誤指定）を扱う数少ない関連研究で、本研究の一般的な解析と比較できる。
- Reward-rational (implicit) choice: A unifying formalism for reward learning：報酬推論を統一的に捉える形式化であり、Freedmanらの誤指定研究や本論文の枠組みの背景理解に役立つ。

:::
