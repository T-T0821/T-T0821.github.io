# AAAI

🏛️ [AI全般（老舗・総合）](../#ai) ・ AAAI Conference on Artificial Intelligence ・ 毎年1〜3月 ・ [公式サイト ↗](https://aaai.org/conference/aaai/)

::: info 2020年からの流れ
AAAI は北米を中心に毎年1〜3月に開かれてきた総合 AI 会議で、2026年はシンガポールで開催されました。最高賞は WinoGrande（2020年、評価データの偏り）、Informer（2021年、時系列予測）、推薦の公平性監査（2022年）、逆強化学習の誤指定（2023年）、創薬の GxVAEs など3本（2024年）、ニューロシンボリック推論の矛盾修正など3本（2025年）、ReconVLA・LLM2CLIP など5本（2026年）と、毎年テーマが大きく異なるのが特徴です。社会貢献（AI for Social Impact）やアラインメントの専用トラックも設けられています。投稿は2020年の約7,700本から2026年の約2.4万本に増え、2026年の採択率は17.6%でした。
:::

## 📅 各回のまとめ

- **AAAI 2027** — 開催前です<br><small>2027年2月16日〜23日 ・ カナダ・モントリオール</small>
- **[AAAI 2026](./2026)** — シンガポール開催・投稿2.4万本で採択率17.6%。ロボットの VLA モデルや LLM2CLIP が最優秀論文に選ばれた回<br><small>2026年1月20日〜27日 ・ シンガポール</small>
- **[AAAI 2025](./2025)** — フィラデルフィア開催・投稿1.3万本。ニューロシンボリック推論の矛盾修正（周志華氏ら）などが最優秀論文に選ばれた回<br><small>2025年2月25日〜3月4日 ・ 米国・フィラデルフィア</small>
- **[AAAI 2024](./2024)** — バンクーバー開催。遺伝子発現から薬の候補分子を生成する GxVAEs など3本が最優秀論文に選ばれた回<br><small>2024年2月20日〜27日 ・ カナダ・バンクーバー</small>
- **[AAAI 2023](./2023)** — ワシントン D.C. で現地開催再開。逆強化学習の「仮定の誤り」への頑健性が最優秀論文になった回<br><small>2023年2月 ・ 米国・ワシントン D.C.</small>
- **[AAAI 2022](./2022)** — 2年連続のオンライン開催・採択率15%。推薦システムの公平性を運用中に監査する手法が最優秀論文に選ばれた回<br><small>2022年2月 ・ オンライン開催</small>
- **[AAAI 2021](./2021)** — 初のオンライン開催。長期時系列予測の Informer が最優秀論文に選ばれ、Transformer の応用先が広がった回<br><small>2021年2月 ・ オンライン開催</small>
- **[AAAI 2020](./2020)** — ニューヨーク開催。常識推論ベンチマーク WinoGrande が最優秀論文に選ばれ、「ベンチマークの抜け穴」問題に光が当たった回<br><small>2020年2月 ・ 米国・ニューヨーク</small>

## 🔭 年ごとのテーマの移り変わり

- 2020: 常識推論ベンチマークの偏り除去（WinoGrande）
- 2021: 長期時系列予測の Transformer（Informer）
- 2022: 推薦システムの公平性のオンライン監査
- 2023: 逆強化学習のモデル誤指定への頑健性
- 2024: 遺伝子発現からの分子生成、矛盾するマルチビュー学習、逐次的な意思決定の比例性
- 2025: ニューロシンボリック推論、少数の問い合わせによる投票、POMDP の判定可能性
- 2026: ロボットの VLA モデル、LLM による CLIP の強化、アラインメントトラックの新設

::: tip 💡 技術動向への示唆
- 実務に近いテーマ（時系列予測・推薦・創薬・ロボット）と基礎理論が同時に最高賞を得ており、AAAI の受賞論文は応用先の広がりを把握するのに向いている
- 2026年に投稿が約1.8倍に増え採択率が下がったことは、機械学習系の投稿が総合会議にも大量に流れ込んでいることを示す
:::
