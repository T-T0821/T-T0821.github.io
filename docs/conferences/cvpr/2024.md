# CVPR 2024

👁️ 画像認識・CV ・ [CVPR の年ごとの流れ](./) ・ [公式サイト ↗](https://cvpr.thecvf.com/)

::: info この回のまとめ
シアトルで開催され、投稿は11,500本を超え、採択は2,719本（約23.6%）でした。最優秀論文は2本で、1枚の写真から木々や布の自然な揺れの動きを生成する Generative Image Dynamics と、生成画像のどこがおかしいか・どの語が反映されていないかを人が細かく注釈したデータで画像生成を評価・改善する研究（いずれも Google）です。最優秀学生論文は、3D Gaussian Splatting のちらつきを抑える Mip-Splatting と、生物の画像の基盤モデル BioCLIP。賞の数は前年の倍の10本になり、3D Gaussian Splatting 関連の受賞が目立ちました。Longuet-Higgins 賞は R-CNN（2014年）です。
:::

## 🔭 この回の主なテーマ

- 画像から動画へ: 静止画のスペクトル的な動きの事前分布で自然な揺れを生成
- 画像生成の評価と改善: 人間の詳細なフィードバック（不自然な部位・不一致の単語）
- 3D Gaussian Splatting: エイリアシング対策（Mip-Splatting）、2枚の画像からの汎化的な再構成（pixelSplat）
- 分野特化の基盤モデル: 生物の「生命の樹」全体を対象にした BioCLIP
- 世界モデル: 移動ロボット用の Navigation World Models（佳作）

::: tip 💡 技術動向への示唆
- 3D Gaussian Splatting が NeRF に代わる主流の3D表現になり、デジタルツインや設備の3D記録などに実用的な速度で使えるようになった
- 画像生成の品質改善が「人の細かいフィードバックを集めて学習する」段階に入り、LLM の RLHF と同じ流れが画像にも広がった
:::

### 1. 画像の生成的ダイナミクス {#paper-1}

🏆 Best Paper ・ Zhengqi Li, Richard Tucker, Noah Snavely, Aleksander Holynski ・ [論文を読む ↗](https://arxiv.org/abs/2309.07906)

<small>原題: Generative Image Dynamics</small>

1枚の画像から、各画素の長期的な振動を周波数領域の表現（スペクトルボリューム）として拡散モデルで予測し、木や花、ろうそくの炎などが自然に揺れるループ動画を作ります。画像をタップして引っ張ると反応するインタラクティブな動きも生成できます。

::: info 📝 落合フォーマット

**どんなもの？**

単一画像から、木・花・ろうそく・衣服などの風による振動的な自然運動を予測し、リアルな動画を生成する手法を提案した研究。運動を周波数領域の「スペクトルボリューム」として拡散モデルで予測し、モーションテクスチャに変換して画像ベースレンダリングでアニメーション化する。シームレスなループ動画や、ユーザー操作に反応するインタラクティブな画像動力学にも応用できる。

**先行研究と比べてどこがすごい？**

実動画から抽出した長期・高密度な画素軌跡を、Davisらのスペクトルボリューム（時間方向フーリエ変換）として表現し、拡散モデルの出力に適した運動事前分布として学習した点が新しい。RGBフレームを直接生成する従来の動画拡散モデルと異なり、動画全体にわたる運動を一括で予測するため、長時間でも時間的一貫性が保たれ劣化しにくい。また単一画像だけからインタラクティブな動力学を得られる点も、従来が動画入力を必要としたのに対する利点である。

**技術や手法のキモはどこ？**

潜在拡散モデル（LDM）で、K=16の低周波成分（4K チャネル）からなるスペクトルボリュームを入力画像条件付きで予測する。周波数ごとに振幅が大きく異なるため、周波数ごとに95パーセンタイルでスケーリングし平方根変換を施す周波数適応正規化を導入した。さらに、まず1周波数スライス用のLDMを学習して固定し、周波数軸方向のアテンション層を挿入して微調整する周波数協調デノイジングで、周波数間の整合性を確保する。予測結果は逆FFTで時間領域の運動場に変換し、運動の平均大きさを深度の代理とした重みでマルチスケール特徴をsoftmax splattingするレンダリングモジュールで各フレームを合成する。ループ動画は、開始・終了フレームの位置と速度を一致させる運動セルフガイダンスで実現し、インタラクティブ動力学はスペクトル係数を画像空間モーダル基底として質量・バネ・ダンパ系をシミュレートする。

**どうやって有効だと検証した？**

約3,015本の自然な振動運動の動画から15万組以上の画像・運動ペアを作り、10%をテストに用いた。TATS、Stochastic I2V、MCVD、LFDM、DMVFN、Endoら、Holynskiらと比較し、FIDは4.03（次点は10.4）、FVDは47.1（同166.0）、DTFVDは2.53（同5.35）と大幅に上回り、スライディングウィンドウ評価でも時間経過による劣化が見られなかった。AnimateDiff、ModelScope、Gen-2との比較ユーザースタディでは80.9%が本手法をより現実的と評価した。アブレーションでは、周波数数Kは16を超えると改善が小さいこと、適応正規化・周波数協調・提案レンダリングがいずれも有効であることが示された。

**議論はある？**

低周波成分のみを予測するため、非振動的な運動や高周波の振動はモデル化できない（学習ベースの運動基底で改善できる可能性がある）。また、細い物体や大きな変位を含む場面では運動軌跡の品質が劣化し、大量の未観測コンテンツを補完する必要がある場合にもレンダリングにアーティファクトが出る。

**次に読むべき論文は？**

- Image-space modal bases for plausible manipulation of objects in video：本論文のスペクトルボリュームと画像空間モーダル基底によるインタラクティブ動力学の理論的基礎となる論文である。
- Animating pictures with Eulerian motion fields：単一画像を運動場でアニメーション化・ループ化する直接の先行手法であり、本論文の主要な比較対象である。
- Align your latents: High-resolution video synthesis with latent diffusion models：本論文の周波数協調デノイジングが着想を得た、LDMを時間方向アテンションで動画に拡張する手法である。

:::


### 2. 画像生成のための豊かな人間のフィードバック {#paper-2}

🏆 Best Paper ・ Youwei Liang, Junfeng He, Gang Li, ほか ・ [論文を読む ↗](https://arxiv.org/abs/2312.10240)

<small>原題: Rich Human Feedback for Text-to-Image Generation</small>

生成画像1万8千枚に、不自然な領域や指示と合わない単語を人が注釈したデータセット RichHF-18K を作り、それを予測するモデルで生成画像の評価・フィルタリング・修復を行い、画像生成の品質を改善しました。

::: info 📝 落合フォーマット

**どんなもの？**

text-to-image生成画像に対し、問題領域の点注釈、プロンプト中の不整合単語、4種の細粒度スコアからなるリッチな人間フィードバックデータセットRichHF-18Kを構築した研究です。さらにそれを自動予測するマルチモーダルTransformer(RAHF)を提案し、予測フィードバックで画像生成の改善も示しています。

**先行研究と比べてどこがすごい？**

既存の報酬モデル（ImageReward、PickScore、HPSなど）は画像1枚を単一スカラーで評価するのに対し、本研究は不自然・不整合領域のヒートマップ、不整合キーワード、複数の細粒度スコアを同時に与える点が新しいです。著者らによると、T2I生成に対する異種のリッチな人間フィードバックのデータセットとモデルとしては初めてです。

**技術や手法のキモはどこ？**

Pick-a-Pic由来の18K画像（学習16K・検証1K・テスト1K）に対し、各画像を3人が注釈しました。スコアは平均、キーワードは多数決、点注釈は円領域のヒートマップ化と平均で統合しています。モデルはViTとT5Xベースで、画像トークンとテキストトークンをself-attentionで融合し、ヒートマップ予測（畳み込み・逆畳み込み）、スコア予測、不整合語を示す接尾辞付きプロンプトの系列生成の3種のヘッドを持ちます。マルチヘッド版と、出力種別をプロンプトに付加するaugmented prompt版を比較しています。損失はヒートマップとスコアにMSE、系列にteacher-forcingのクロスエントロピーを重み付けして用います。

**どうやって有効だと検証した？**

テストセットでスコア予測のPLCC/SRCCをResNet-50、PickScore、CLIPと比較し、例えば plausibility ではaugmented prompt版がPLCC 0.693、ResNet-50は0.495でした。implausibilityヒートマップではaugmented prompt版がResNet-50を上回り（CC 0.556 対 0.506）、multi-head版は下回りました。不整合キーワード予測のF1は43.3〜43.9です。応用では、予測plausibilityスコアで選別したデータでMuseを微調整し、6人による100プロンプトの比較評価でfinetuned Museが「大幅に良い」21.5%、「やや良い」30.33%、「やや悪い」12.67%、「大幅に悪い」4.17%でした。ヒートマップをマスクにしたMuseのinpaintingでも改善例を示しています。

**議論はある？**

不整合ヒートマップは不自然さヒートマップより性能が低く、これは不整合の定義が曖昧でノイズの多い注釈になりやすいためと著者らは推測しています。また、データがPick-a-Pic（Stable Diffusion系）に限られており、他の生成モデルのデータ収集や、強化学習の報酬、ヒートマップの重みマップ利用、不整合系列の活用などは今後の課題とされています。

**次に読むべき論文は？**

- ImageReward: Learning and Evaluating Human Preferences for Text-to-Image Generation：人間の選好に基づく報酬モデルとReFLによる拡散モデル調整を扱っており、本研究が拡張したスカラー報酬の基準となる先行研究です。
- Pick-a-Pic: An Open Dataset of User Preferences for Text-to-Image Generation：RichHF-18Kの元データであり、比較ベースラインのPickScoreも提案しているため、データの性質を理解するのに必要です。
- Muse: Text-to-Image Generation via Masked Generative Transformers：本研究で微調整とinpaintingによる改善の対象となった生成モデルであり、手法の汎化性を検討する前提になります。

:::


### 3. Mip-Splatting: エイリアスのない3D Gaussian Splatting {#paper-3}

🏆 Best Student Paper ・ Zehao Yu, Anpei Chen, Binbin Huang, Torsten Sattler ほか ・ [論文を読む ↗](https://arxiv.org/abs/2311.16493)

<small>原題: Mip-Splatting: Alias-free 3D Gaussian Splatting</small>

3D Gaussian Splatting（3DGS）が焦点距離やカメラ距離の変化で生じるアーティファクトに対し、3Dスムージングフィルタと2D Mipフィルタの2つの修正で、任意スケールでエイリアスのないレンダリングを可能にした研究です。Mip-NeRF系の手法と違いマルチスケール画像での学習が不要で、単一スケール学習のみで異なるスケールでも忠実に描画できます。Blenderのマルチスケールテストでは平均PSNRが31.97（3DGSは24.84）、Mip-NeRF 360のzoom-inでも27.37（3DGSは23.25）と大きく上回り、同一スケールでも同等の性能を保ちました。CVPR 2024のBest Student Paperに選ばれています。

::: info 📝 落合フォーマット

**どんなもの？**

3D Gaussian Splatting（3DGS）が、焦点距離やカメラ距離の変更（サンプリングレートの変化）でアーティファクトを生じる問題を解決する研究。3Dスムージングフィルタと2D Mipフィルタの2つの修正により、任意スケールでエイリアスのないレンダリングを可能にした。

**先行研究と比べてどこがすごい？**

3DGSの失敗原因を、3D周波数制約の欠如と2Dダイレーションフィルタの使用に帰着させた。Mip-NeRF系の手法はマルチスケール画像での学習が必要だが、本手法は単一スケール学習のみで異なるスケールでも忠実にレンダリングできる。EWA splattingとは異なり、3D空間でのフィルタ適用と、1画素に対応するよう決めたMipフィルタにより再構成問題を扱う点が違う。

**技術や手法のキモはどこ？**

学習画像の焦点距離と深度から各ガウシアンの最大サンプリングレートν̂_kを求め（定数m=100イテレーションごとに再計算）、ナイキスト限界に合わせて3Dガウシアンにサイズs/ν̂_kのガウシアン低域通過フィルタを畳み込む。このフィルタは学習後は表現の一部として固定され、レンダリング時のオーバーヘッドはない。さらに2Dダイレーションを、物理的な撮像過程の2Dボックスフィルタをガウシアンで近似した2D Mipフィルタ（式10）に置き換え、1画素を覆うように設定する。分散は2D Mipが0.1、3Dスムージングが0.2で、合計0.3が3DGS/EWAと同等になる。

**どうやって有効だと検証した？**

BlenderとMip-NeRF 360で評価した。Blenderの単一スケール学習・マルチスケールテストでは、平均PSNRが3DGSの24.84、3DGS+EWAの29.40に対し31.97、平均SSIMも0.974と全手法で最高だった。Mip-NeRF 360の単一スケール学習・拡大テスト（zoom-in）では平均PSNRが27.37で、3DGS（23.25）や3DGS+EWA（25.43）を上回った。同一スケール学習・テストでも、PSNR 27.79と3DGSなどと同等の性能を保った。

**議論はある？**

ボックスフィルタのガウシアン近似は、ガウシアンが画面上で小さいときに誤差を生み、縮小が進むほど誤差が増える。サンプリングレートの計算（現状PyTorch実装）により学習時間がわずかに増えるため、CUDA実装や事前計算用データ構造の設計が今後の課題とされている。

**次に読むべき論文は？**

- 3D Gaussian Splatting for Real-Time Radiance Field Rendering：Mip-Splattingが改良するベース手法であり、ダイレーションを含むレンダリングと最適化の詳細を理解するために必要。
- Mip-NeRF: A Multiscale Representation for Anti-aliasing Neural Radiance Fields：コーントレーシングとIPEによるNeRFのアンチエイリアシングの代表例で、本手法との違いを比較できる。
- EWA Volume Splatting：本手法が比較・差別化するEWAフィルタの原理を理解するための基礎文献。

:::


### 4. BioCLIP: 生命の樹のための視覚基盤モデル {#paper-4}

🏆 Best Student Paper ・ Samuel Stevens, Jiaman Wu, Matthew J Thompson, Elizabeth G Campolongo ほか ・ [論文を読む ↗](https://arxiv.org/abs/2311.18803)

<small>原題: BioCLIP: A Vision Foundation Model for the Tree of Life</small>

1,040万枚超・約45.4万分類群のデータセットTreeOfLife-10Mを構築し、CLIPのマルチモーダル対照学習を界から種までの分類階層の活用に転用してBioCLIPを学習した研究である。動物・植物・菌類などの10種類の細粒度分類タスクで、CLIPやOpenCLIPに対しzero-shotで平均+17.5ポイント、5-shotで+17.3ポイント上回り、通常のクロスエントロピーや階層分類よりも優れた結果を示した点が注目される。CVPR 2024でBest Student Paperを受賞している。

::: info 📝 落合フォーマット

**どんなもの？**

生物の画像を扱う汎用の視覚基盤モデルとして、大規模データセットTreeOfLife-10M（1,040万枚超、約45.4万分類群）と、それで学習したBioCLIPを提案した。生命の樹全体に汎化し、細粒度の分類ができ、少数データ（zero-shot/few-shot）でも強いモデルを目指している。

**先行研究と比べてどこがすごい？**

従来の教師あり分類は各クラスを独立した記号として扱うが、本研究はCLIPのマルチモーダル対照学習を分類階層（界から種）の活用に転用した。これは新規かつ自明でない貢献だと著者は述べている。また、既存のML-readyな生物画像データセットiNat21（270万枚・1万種）を大きく上回る多様性をEOLの画像追加で実現した。さらに複数のテキスト型を混ぜる学習戦略を提案した。

**技術や手法のキモはどこ？**

界から種までの分類階層を連結した文字列（taxonomic name）を作り、画像とのペアでCLIPの対照学習目的を使って学習する。自己回帰型テキストエンコーダにより、下位ランクの表現が上位ランクに条件付けられて階層構造が埋め込まれる。さらに、学習時に各画像へ分類名・学名・通称などのテキスト型をランダムに割り当てるmixed text type学習を行い、推論時にどの名称しかなくても使えるようにした。初期値はOpenAIのCLIP（ViT-B/16）で、TreeOfLife-10Mで100エポック継続事前学習した。

**どうやって有効だと検証した？**

動物・植物・菌類などの10種類の細粒度分類タスク（Meta-Albumの8タスク、Birds 525、新規のRare Species）で評価した。BioCLIPはCLIPやOpenCLIPに対し、zero-shotで平均+17.5ポイント、5-shotで+17.3ポイント（1-shotは+16.7ポイント）上回った。Rare Speciesの未見種ではtaxonomic+common名の組合せが最良で、CLIP目的は通常のクロスエントロピーや階層分類より大きく優れ（1-shot平均44.7 対 16.5/19.3）、t-SNEでも階層に沿った表現が確認された。

**議論はある？**

BioCLIPは本質的に分類目的で学習されており、形質（トレイト）レベルの細かい表現の抽出は今後の課題である。Bioscan-1Mの属・種ラベルは少ない（それぞれ22.5%、7.5%）など、ラベル粒度の不足は避けがたい課題として本文でも指摘されている。今後はiNaturalistの1億枚超の研究グレード画像の取り込みによるデータ拡大と、種の外見に関するより豊かなテキスト記述の収集を計画している。

**次に読むべき論文は？**

- Learning Transferable Visual Models From Natural Language Supervision：BioCLIPが土台とし、その対照学習目的を転用しているCLIPの原論文であり、手法の前提理解に必須である。
- Making better mistakes: Leveraging class hierarchies with deep networks：クラス階層を深層分類器に組み込む代表的な先行研究で、BioCLIPの階層活用との違いを理解できる。
- A step towards worldwide biodiversity assessment: The BIOSCAN-1M insect dataset：TreeOfLife-10Mに統合された昆虫の実験室画像データセットで、データの構成と限界（ラベル粒度）を理解できる。

:::


### 5. 視覚指示チューニングによるベースラインの改良 {#paper-5}

📈 被引用数上位（Paper Digest の集計で同年1位） ・ Haotian Liu, Chunyuan Li, Yuheng Li, Yong Jae Lee ・ [論文を読む ↗](https://arxiv.org/abs/2310.03744)

<small>原題: Improved Baselines with Visual Instruction Tuning</small>

LLaVAの枠組みでLMMの入力解像度・モデル・データの設計選択を統制して調べ、MLPコネクタ、学術系VQAデータ、応答形式プロンプトという単純な改良でLLaVA-1.5を構築し、11〜12個のベンチマークでSoTAを達成した研究です。大規模な画像テキスト事前学習や専用リサンプラーに頼らず、公開データ約1.2Mのみで13Bモデルを8×A100・約1日で学習でき、再現しやすい強力なベースラインとして示した点が注目され、CVPR 2024の被引用数でPaper Digest集計の同年1位となっています。

::: info 📝 落合フォーマット

**どんなもの？**

LLaVAの枠組みの下で、LMMの設計選択（入力解像度・モデル・データ）を統制された条件で体系的に調べ、より強力で再現しやすいベースラインLLaVA-1.5を構築した研究。MLPコネクタ、学術系VQAデータ、応答形式プロンプトという単純な改良により、11〜12個のベンチマークでSoTAを達成した。最終13Bモデルは公開データ約1.2Mのみを用い、8×A100で約1日で学習できる。

**先行研究と比べてどこがすごい？**

InstructBLIPやQwen-VLのような大規模な画像テキスト事前学習（129M〜1.4B）や専用リサンプラーに頼らず、単純な全結合コネクタと558Kの事前学習データ、665Kの指示データだけで上回る性能を示した。短文回答と長文会話の両立の難しさを、曖昧なプロンプト形式とLLMを微調整しないことに起因すると整理し、単一の応答形式プロンプトで解決した。また、画像をグリッド分割して独立にエンコードするLLaVA-1.5-HDにより、追加の事前学習なしで任意解像度へ拡張できる。

**技術や手法のキモはどこ？**

線形射影を2層MLPに置き換え、CLIP-ViT-L-336pxを採用した。VQAv2、GQA、OKVQA、OCRVQA、A-OKVQA、TextCaps、Visual Genome、RefCOCO、ShareGPTなどを混合し、VQA質問の末尾に「Answer the question using a single word or phrase.」などの応答形式プロンプトを付けてLLMごと微調整する。LLaVA-1.5-HDでは、画像をCLIPの本来の解像度の小パッチに分割して個別に符号化し、特徴を結合する。そこに縮小画像の特徴をグローバルコンテキストとして連結し、行末トークンも追加する。LLMはVicuna v1.5（7B/13B）を用いる。

**どうやって有効だと検証した？**

VQAv2、GQA、VizWiz、ScienceQA-IMG、TextVQA、POPE、MME、MMBench、SEED-Bench、LLaVA-Bench-in-the-Wild、MM-Vetなどで評価した。学術系ベンチマーク5つのうち4つで最良、残る1つで2位だった。MMBenchは13Bで67.7、MMBench-CNは63.6でQwen-VL-Chatの56.7を上回り、7BモデルでもIDEFICS-80Bを上回った。アブレーションでは、VQA-v2の追加と形式プロンプトでMME 809.6→1323.8となった。HDではグローバルコンテキストの追加でMMEが+71、MM-Vetが+3.2向上した。学習データを50%に間引いても全体性能の98%以上を維持した。

**議論はある？**

著者らは限界として、高解像度での学習時間の増加、複数画像理解の欠如、特定分野での問題解決能力の限界、ハッカーションが残る点を挙げており、医療などの重要用途では注意が必要としている。データ圧縮戦略、合成能力（compositional capabilities）の仕組みの理解、韓国語など一部言語での会話能力の低さは今後の課題である。また、GQAなど一部の評価では学習時に当該データセットの画像を観測しているため、比較には注意が必要である。

**次に読むべき論文は？**

- Visual Instruction Tuning：LLaVAの原論文であり、本論文の出発点となるアーキテクチャと指示データ生成手法を理解できる。
- InstructBLIP: Towards General-Purpose Vision-Language Models with Instruction Tuning：Q-Formerと大規模事前学習を用いる主要な比較対象で、設計思想の違いを把握できる。
- Visual Instruction Tuning with Polite Flamingo：VQA型データ混合による会話能力の低下という、本論文が解決を図る問題を指摘した研究である。
