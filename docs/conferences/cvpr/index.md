# CVPR

👁️ [画像認識・CV](../#cv) ・ IEEE/CVF Conference on Computer Vision and Pattern Recognition ・ 毎年6月 ・ [公式サイト ↗](https://cvpr.thecvf.com/)

::: info 2020年からの流れ
CVPR は CV 分野で最大の会議で、毎年6月に北米で開かれます。2020〜2021年はオンライン開催で、教師なし3D復元（2020年）や NeRF を物体ごとに分解した GIRAFFE（2021年）が最優秀論文でした。2023年に自動運転の UniAD と LLM が画像処理プログラムを書く Visual Programming、2024年に静止画を動かす Generative Image Dynamics と画像生成への人間のフィードバック、2025年に VGGT、2026年に動的シーン復元の D4RT が選ばれ、3D復元と生成が二大テーマです。投稿は2020年の約6,700本から2026年の約1.6万本へ増えました。
:::

## 📅 各回のまとめ

- **CVPR 2027** — 開催前です<br><small>2027年6月 ・ 米国・シアトル（日程は公式ページ内で記載が食い違っている）</small>
- **[CVPR 2026](./2026)** — 投稿1.6万本・参加者1.2万人（デンバー）。動画から動的シーンを効率よく復元する D4RT（Google DeepMind）が最優秀論文に<br><small>2026年6月3日〜7日 ・ 米国・デンバー</small>
- **[CVPR 2025](./2025)** — ナッシュビル開催。数百枚の画像から3D情報を一度に推定する VGGT（Meta・オックスフォード大）が最優秀論文に<br><small>2025年6月11日〜15日 ・ 米国・ナッシュビル</small>
- **[CVPR 2024](./2024)** — シアトル開催・投稿1.15万本。静止画を揺らす Generative Image Dynamics と画像生成への人間の詳細フィードバックが最優秀論文に<br><small>2024年6月 ・ 米国・シアトル</small>
- **[CVPR 2023](./2023)** — バンクーバー開催。自動運転を「計画」中心に統合した UniAD と、LLM が画像処理プログラムを書く Visual Programming が最優秀論文に<br><small>2023年6月 ・ カナダ・バンクーバー</small>
- **[CVPR 2022](./2022)** — ニューオーリンズで現地開催再開。幾何計算の難しい最小問題を学習で解く研究が最優秀論文、Ref-NeRF などが佳作に<br><small>2022年6月 ・ 米国・ニューオーリンズ</small>
- **[CVPR 2021](./2021)** — 2年連続のオンライン開催。シーンを物体ごとに分けて生成・編集できる GIRAFFE が最優秀論文に選ばれた回<br><small>2021年6月 ・ オンライン開催</small>
- **[CVPR 2020](./2020)** — シアトル開催予定から初のオンライン開催へ。画像だけから左右対称な物体の3D形状を教師なしで学ぶ研究が最優秀論文に<br><small>2020年6月 ・ オンライン開催（当初予定は米国・シアトル）</small>

## 🔭 年ごとのテーマの移り変わり

- 2020: 教師なしの3D復元、初のオンライン開催
- 2021: NeRF と生成モデルの融合（GIRAFFE）、負例なしの自己教師あり学習
- 2022: 学習と幾何計算の融合、反射を扱う Ref-NeRF
- 2023: 計画中心の自動運転（UniAD）、LLM による視覚推論、DreamBooth
- 2024: 画像から動画、人間のフィードバックによる画像生成の改善、3D Gaussian Splatting
- 2025: フィードフォワード3D復元（VGGT）、オープンな VLM
- 2026: 動的シーンの4D復元（D4RT）、画像からの3D生成（SAM 3D）、身体性 AI

::: tip 💡 技術動向への示唆
- VGGT・D4RT と2年続けてフィードフォワード3D復元が最高賞を得ており、3D 取得は専門的な最適化から汎用モデルの推論へと移りつつある
- 自動運転・ロボット・ゲームエージェントなど身体性 AI の研究が増えており、CV の成果が実世界で動くシステムに直結するようになった
:::
