# CVPR 2021

👁️ 画像認識・CV ・ [CVPR の年ごとの流れ](./) ・ [公式サイト ↗](https://cvpr.thecvf.com/)

::: info この回のまとめ
2年連続でオンライン開催となり、投稿7,015本・採択1,661本（約23.7%）でした。最優秀論文は、生成モデルの中で3D シーンを物体ごとのニューラル特徴場として表し、物体の位置や向き、カメラ視点を個別に操作しながら画像を生成できる GIRAFFE（テュービンゲン大学）です。佳作には、負例なしで画像表現を学ぶ SimSiam（Kaiming He 氏ら）、動画と言語を効率よく学ぶ ClipBERT、リアルタイムの高解像度背景除去などが並びました。
:::

- **日程**: 2021年6月
- **開催地**: オンライン開催
- **規模**: 投稿 7,015 本 ／ 採択 1,661 本 ／ 採択率 23.7%

## 🔭 この回の主なテーマ

- NeRF と生成モデルの融合: 物体ごとに分解された3D表現で制御可能な画像生成（GIRAFFE）
- 自己教師あり学習: 負例を使わないシンプルな表現学習（SimSiam）
- 動画と言語: 疎なフレームサンプリングで効率よく学ぶ ClipBERT
- 実用的な画像処理: 高解像度の背景除去のリアルタイム化

::: tip 💡 技術動向への示唆
- 「3D を意識した生成モデル」の流れがここで本格化し、のちの3D 生成・動画生成でカメラや物体を制御する技術の基礎になった
- 負例なしの自己教師あり学習の成功は、ラベルの少ない産業画像（検査・医療）で事前学習を活用する道を広げた
:::

### 1. GIRAFFE：シーンを合成可能な生成的ニューラル特徴場として表現する {#paper-1}

🏆 Best Paper ・ Michael Niemeyer, Andreas Geiger ・ [論文を読む ↗](https://arxiv.org/abs/2011.12100)

<small>原題: GIRAFFE: Representing Scenes as Compositional Generative Neural Feature Fields</small>

GAN の中に物体ごとのニューラル特徴場を持たせ、それらを合成してから2D画像にレンダリングすることで、2D画像だけから学習しながら、物体の移動・回転・追加やカメラ視点の変更を個別に制御できる画像生成を実現しました。

::: info 📝 落合フォーマット

**どんなもの？**

GIRAFFEは、シーンを「合成可能な生成的ニューラル特徴場（compositional generative neural feature fields）」として表現し、ラベルやカメラポーズのない生画像集合から学習する3D対応の画像生成モデルである。個々の物体と背景、さらに各物体の形状・外観を教師なしで分離でき、物体の平行移動・回転、カメラポーズの変更、テスト時の物体追加などの制御が可能になる。

**先行研究と比べてどこがすごい？**

従来の2D GANは構成的なシーン構造を扱わず、ボクセル系や GRAF などの3D対応手法は主に単一物体シーンに限られ、複雑な実画像では結果が不安定になっていた。GIRAFFEは、物体ごとの特徴場を足し合わせる合成3Dシーン表現を生成モデルに組み込み、さらに低解像度の体積レンダリングと2Dニューラルレンダリングを組み合わせることで、複数物体・散らかった背景を持つ画像でも高速かつ高品質な生成を実現した点が新しい。

**技術や手法のキモはどこ？**

各物体（背景も1エンティティとして扱う）を、形状コードと外観コードで条件付けた MLP による特徴場 h_θ（密度σとM_f次元特徴f）で表し、アフィン変換 T=&#123;s,t,R} によりシーン空間に配置する。複数エンティティは、密度の総和と密度加重平均の特徴を取る合成演算子で統合し、全エンティティに勾配が流れるようにする。合成した特徴場を16²解像度の特徴画像として体積レンダリングし、スキップ接続付きの2D CNN（最近傍アップサンプリングと3×3畳み込み、各解像度でRGBへ写像して加算）で64²や256²のRGB画像に変換する。学習は非飽和GAN損失とR1勾配ペナルティによる敵対的学習で行い、カメラポーズと物体変換は一様分布からサンプリングする。

**どうやって有効だと検証した？**

Chairs・Cats・CelebA・CelebA-HQ・CompCars・LSUN Churches・FFHQ・Clevr-N（2〜5個のプリミティブ）で評価し、FIDをPlatonicGAN、BlockGAN、HoloGAN、GRAFおよびResNet系2D GANと比較した。64²ではCats 8、CelebA 6、Cars 16、Chairs 20、Churchesで17と同等以上のFIDを示し、256²でもCelebA-HQ 21、FFHQ 32、Cars 26、Churches 30、Clevr-2 31と3D対応ベースラインを上回った。生成器パラメータは0.41Mと2D GANの1.69Mより少なく、GRAF比で描画時間は64²で110.1msから4.8ms、256²で1595.0msから5.9msに短縮された。アブレーションでは、スキップ接続・最終活性化・アップサンプリング方式の選択がFIDを改善することも確認された。

**議論はある？**

データセット固有のバイアス（例：CelebA-HQで目や髪が常にカメラ方向を向く）があると要因の分離に失敗し、また実際の分布と一様分布で仮定した カメラポーズ・物体変換分布のずれにより、Churchesや CompCars で前景・背景の分離失敗が起こる。今後は、これらの分布をデータから学習することや、物体マスクのような容易に得られる教師情報を使って、より複雑な複数物体シーンへ拡張することが挙げられている。

**次に読むべき論文は？**

- GRAF: Generative Radiance Fields for 3D-Aware Image Synthesis：GIRAFFEが直接拡張した生成的NeRFのベースラインであり、単一物体シーンの限界と差分を理解できる。
- NeRF: Representing Scenes as Neural Radiance Fields for View Synthesis：GIRAFFEの物体表現・体積レンダリング・位置エンコーディングの基礎となる手法である。
- BlockGAN: Learning 3D Object-aware Scene Representations from Unlabelled Images：ボクセル特徴を用いた物体単位の3D対応生成手法で、GIRAFFEとの合成シーン表現の違いを比較できる。

:::


### 2. タスクプログラミング：データ効率の高い行動表現の学習 {#paper-2}

🏆 Best Student Paper ・ Jennifer J. Sun, Ann Kennedy, Eric Zhan, David J. Anderson ほか ・ [論文を読む ↗](https://arxiv.org/abs/2011.13917)

<small>原題: Task Programming: Learning Data Efficient Behavior Representations</small>

動物などの軌跡（キーポイント）データから行動を分類する際の専門家のアノテーション負担を減らすため、専門家が軌跡の属性を計算するプログラムを書く「タスクプログラミング」を用いた軌跡埋め込み手法TREBAを提案した研究です。自己教師あり表現学習と専門家のプログラムによる構造化知識の埋め込みを統合し、MARSでは専門家設計特徴に対して完全な訓練データでのベースライン性能を約5〜10%のデータで達成（10〜20倍の効率化）しました。アノテーション時間とプログラム作成の間の専門家労力のトレードオフを定量的に評価した点も特徴で、CVPR 2021のBest Student Paperに選ばれています。

::: info 📝 落合フォーマット

**どんなもの？**

動物などの軌跡（キーポイント）データから行動を分類する際、専門家のアノテーション負担を減らすための軌跡埋め込み手法TREBAを提案した研究。専門家が軌跡の属性を計算するプログラムを書く「タスクプログラミング」により、少数のプログラム化タスクで大量のアノテーションを代替できることを示した。

**先行研究と比べてどこがすごい？**

自己教師あり表現学習（軌跡生成）と、専門家が書いたプログラムによる構造化知識の明示的な埋め込みを統合した点が新しい。画像・動画向けの自己教師ありタスクは軌跡データに直接適用しにくいが、専門家定義の属性をデコーダタスクとして使うことでこれを補う。アノテーション時間とプログラム作成の間の専門家労力のトレードオフを定量的に評価した点も特徴。

**技術や手法のキモはどこ？**

軌跡VAE（TVAE：RNNエンコーダ・デコーダ）で軌跡の自己復元（次状態予測）を学習し、これに専門家プログラムに基づくデコーダタスクを加えたマルチタスク自己教師あり学習を行う。プログラムタスクには、生成軌跡で属性が保たれるようにする属性一貫性損失、属性の直接デコード、プログラム出力のクラスを正例とするコントラスティブ損失がある。実験では一貫性損失とコントラスティブ損失の組み合わせを使い、反射・回転・平行移動などの属性保存的データ拡張も併用する。学習済みエンコーダは凍結し、前後10フレームを含むT=21フレームの特徴として浅い全結合分類器に入力する。

**どうやって有効だと検証した？**

マウス2データセット（MARS、CRIM13）とハエ1データセット（Fly vs. Fly）で、訓練データ割合を変えながらMAPに基づく分類誤差を、生のキーポイントおよび専門家設計特徴と比較した。MARSでは専門家設計特徴に対し、完全な訓練データでのベースライン性能を約5〜10%のデータで達成し（10〜20倍の効率化）、CRIM13とFlyの特徴ありの設定では50%のデータで同等性能（2倍）であった。ハイパーパラメータ的な検証として、プログラム数を3個（マウス）や7個（ハエ）に増やすと全プログラム使用時と同程度の誤差削減になり、単一プログラムでは性能のばらつきが大きく、悪いものは誤差を増やす場合もあった。

**議論はある？**

タスクプログラミングとアノテーションのどちらが有効かは、アノテーションのコストと専門家が行動属性を特定できる理解度に依存する。単一プログラムの選択による性能のばらつきが大きく、良いプログラムの選び方が課題である。プログラム作成やアノテーションを支援するツールの整備や、スポーツ分析など他領域への応用が今後の方向として挙げられている。

**次に読むべき論文は？**

- Learning Calibratable Policies using Programmatic Style-Consistency：TREBAの基盤であるTVAEと、プログラムによる属性一貫性損失・微分可能近似の詳細が理解できる。
- The Mouse Action Recognition System (MARS): a software pipeline for automated analysis of social behaviors in mice：本研究のマウス実験で使われたデータセット、トラッカー、ベースライン特徴の出典であるため。
- Data Programming: Creating Large Training Sets, Quickly：タスクプログラミングの着想元であり、プログラムによる弱教師あり学習の考え方を把握できる。

:::


### 3. 単純なSiamese表現学習の探究 {#paper-3}

🏆 Best Paper Honorable Mention ・ Xinlei Chen, Kaiming He ・ [論文を読む ↗](https://arxiv.org/abs/2011.10566)

<small>原題: Exploring Simple Siamese Representation Learning</small>

負例ペア・大きなバッチ・モーメンタムエンコーダのいずれも使わず、単純なSiameseネットワークだけで教師なし視覚表現学習が成り立つことを示した研究です。提案手法SimSiamでは、崩壊回避の鍵がstop-gradientであることを実験で示し、ImageNetでの100エポックの学習では比較手法中最高精度（67.7%）を達成しました。一方で800エポックでは71.3%とBYOLの74.3%を下回るものの、SimCLR・SwAV・BYOLに共通する基盤がSiamese構造にあることを示唆した点が注目されます。

::: info 📝 落合フォーマット

**どんなもの？**

教師なし視覚表現学習において、負例ペア・大きなバッチ・モーメンタムエンコーダのいずれも使わず、単純なSiameseネットワークだけで有意な表現を学習できることを示した研究。提案手法「SimSiam」は同一画像の2つの拡張ビューの類似度を最大化するだけで、ImageNetや下流タスクで競合する性能を達成する。

**先行研究と比べてどこがすごい？**

SimCLR（負例・大バッチ）、SwAV（オンラインクラスタリング）、BYOL（モーメンタムエンコーダ）がそれぞれ崩壊回避に頼っていた要素をすべて取り除いても崩壊しないことを実証した。崩壊回避の鍵は stop-gradient であると実験で示し、それをEM的な交互最適化として解釈する仮説を提示して、これらの手法の共通基盤がSiamese構造にあることを示唆した。

**技術や手法のキモはどこ？**

共有重みのエンコーダf（バックボーン＋射影MLP）に2つのビューを通し、片側に予測MLP h を適用、もう片側に stop-gradient をかけて負のコサイン類似度を最小化し、対称化した損失で学習する（バッチ512、通常のSGD、LARS不要）。仮説では、θ（エンコーダ）とη（各画像の表現）の2組の変数をk-meansのように交互最適化していると見なし、stop-gradientはθ更新時にηを定数扱いする自然な帰結、予測器hは拡張に関する期待値 E_T[F(T(x))] の近似を補うものと位置づける。

**どうやって有効だと検証した？**

ImageNetでResNet-50を事前学習し線形評価を実施した。stop-gradientありで67.7%（100エポック）、なしでは0.1%となり崩壊が確認された。バッチサイズ64〜2048で概ね良好に動作し（256で68.1%、4096では64.0%）、100エポックでは比較手法中最高精度で、SimCLRを全エポック設定で上回った。一方、学習を長くした際の伸びは小さく、800エポックでは71.3%でBYOLの74.3%を下回った。VOC・COCOの物体検出・インスタンスセグメンテーションへの転移でも他手法と同等水準を示した。

**議論はある？**

著者らも認める通り、仮説は何を最適化しているかを説明するにとどまり、なぜ崩壊が起きないのかは経験的観察のままで未解決である。また長期学習ではBYOLなどモーメンタムエンコーダ系に及ばず、η のサブ問題を他のオプティマイザで解く可能性などが今後の課題として挙げられている。

**次に読むべき論文は？**

- Bootstrap your own latent: A new approach to self-supervised learning (BYOL)：SimSiamが「モーメンタムエンコーダを除いたBYOL」と位置づけられており、予測器とstop-gradientの出自を理解するのに必須であるため。
- A simple framework for contrastive learning of visual representations (SimCLR)：負例と大バッチに依存する対照学習の代表手法で、SimSiamとの方法論的な比較の基準になるため。
- Unsupervised learning of visual features by contrasting cluster assignments (SwAV)：オンラインクラスタリングで崩壊を防ぐ手法であり、SimSiamとの関係（交互最適化・クロスエントロピー類似度）を理解するのに役立つため。

:::


### 4. Less is More: 疎サンプリングによる動画・言語学習のための ClipBERT {#paper-4}

🏆 Best Paper Honorable Mention ・ Jie Lei, Linjie Li, Luowei Zhou, Zhe Gan ほか ・ [論文を読む ↗](https://arxiv.org/abs/2102.06183)

<small>原題: Less is More: ClipBERT for Video-and-Language Learning via Sparse Sampling</small>

ClipBERT は、動画から疎にサンプリングした短いクリップだけを使い、生のフレーム画素とテキストトークンから End-to-End で動画・言語タスク（テキスト→動画検索、動画質問応答）を学習する枠組みで、計算・メモリコストを抑えている。凍結した密な特徴量に頼る従来手法に対し、少数クリップのほうが精度が高いことが多いという「less is more」を示し、画像テキスト事前学習（COCO/Visual Genome Captions）が動画テキストタスクに有効であることも明らかにした点が注目される。MSRVTT 検索では HowTo100M で事前学習した HERO を R@1 で上回り、TGIF-QA でも QueST を上回るなど、6 つのデータセットで有効性が確認されている。

::: info 📝 落合フォーマット

**どんなもの？**

ClipBERT は、動画と言語のタスク（テキスト→動画検索、動画質問応答）を、オフライン抽出した密な特徴量ではなく、生のフレーム画素と生のテキストトークンから End-to-End で学習するための汎用フレームワークである。各学習ステップで動画から疎にサンプリングした 1 本または数本の短いクリップだけを使うことで、計算・メモリコストを抑えている。3 秒の GIF から 180 秒の YouTube 動画まで、6 つのデータセットで評価している。

**先行研究と比べてどこがすごい？**

従来は凍結した視覚・言語特徴量を使う（stop gradient）のが主流で、タスクやドメイン、モダリティ間のズレが問題だった。本研究は疎サンプリングで End-to-End 学習を現実的なコストにし、「少ないクリップのほうが全長動画の密な特徴量より精度が高いことが多い」という less-is-more を示した。また、2D CNN を使うことで、動画テキスト事前学習ではなく画像テキスト事前学習（COCO/Visual Genome Captions）が動画テキストタスクに有効であることを示した。

**技術や手法のキモはどこ？**

動画から Ntrain 個のクリップをランダムに疎サンプリングし、各クリップから T フレームを取り出す。各フレームを ResNet-50（2D CNN）で符号化し、平均プーリングでクリップ特徴にまとめ、2D 位置埋め込みを加える。これをテキスト埋め込みと連結して 12 層 Transformer（BERT-base 初期化）に入力し、[CLS] 表現から予測する。クリップごとの予測は平均、最大、LogSumExp などで集約して動画レベルの損失を計算する（LogSumExp が最良）。推論時は Ntest 個のクリップを一様に密サンプリングして予測を集約する（sparse training, dense inference）。重みは COCO/VG Captions での MLM と画像テキストマッチングによる事前学習で初期化する。

**どうやって有効だと検証した？**

MSRVTT、DiDeMo、ActivityNet Captions のテキスト→動画検索と、TGIF-QA、MSRVTT-QA、MSRVTT 多肢選択 QA で評価した。MSRVTT 検索では ClipBERT 4×1 が HowTo100M で事前学習した HERO より R@1 で 3.0% 高く、8×2 では 5.2% 高かった（22.0）。TGIF-QA では 1 フレーム学習の ClipBERT が QueST を Action で 6.9%、Transition で 6.8% 上回った。アブレーションでは、ランダム 4 クリップが一様 16 クリップを全指標で上回り、画像テキスト事前学習と End-to-End 学習の効果も確認された。

**議論はある？**

TGIF-QA の Count のように全長動画のモデリングが必要なタスクは対象外としており、長尺動画では少数クリップでは情報が足りない可能性がある（ActivityNet では音声を使う MMT などに及ばない結果もある）。著者らは、クリップ数を増やすこと、音声などの追加入力を組み込むこと、より高解像度の動画を使うことを今後の方向として挙げている。計算コストの制約から、動画テキストの大規模事前学習は行っていない。

**次に読むべき論文は？**

- HERO: Hierarchical Encoder for Video+Language Omni-representation Pre-training：HowTo100M で事前学習した密な特徴量ベースの主要比較対象であり、ClipBERT との設計差を理解できる。
- Pixel-BERT: Aligning Image Pixels with Text by Deep Multi-Modal Transformers：ClipBERT の視覚エンコーダ構成と画像テキスト事前学習の設計の元になっている。
- In Defense of Grid Features for Visual Question Answering：ClipBERT の ResNet-50 の初期化に使われた grid-feat の背景と、グリッド特徴の有効性を理解できる。

:::


### 5. Transformerによる系列対系列の視点からのセマンティックセグメンテーションの再考 {#paper-5}

📈 被引用数上位（Paper Digest の集計で同年2位） ・ Sixiao Zheng, Jiachen Lu, Hengshuang Zhao, Xiatian Zhu ほか ・ [論文を読む ↗](https://arxiv.org/abs/2012.15840)

<small>原題: Rethinking Semantic Segmentation from a Sequence-to-Sequence Perspective with Transformers</small>

セマンティックセグメンテーションを、エンコーダ・デコーダ型FCNではなく画像パッチ列から出力列を予測するsequence-to-sequence問題として捉え直し、解像度を下げず全層で大域的な文脈をモデル化する純Transformerエンコーダ採用のSETRを提案した研究です。ADE20KとPascal Contextで当時の最高性能を達成し、ADE20Kのテストサーバのリーダーボードでも1位となりました。ImageNet-21kで事前学習したFCNとの比較でも優位を示し、被引用数でもCVPR 2021の上位（Paper Digest集計で同年2位）に入ることから注目されています。

::: info 📝 落合フォーマット

**どんなもの？**

セマンティックセグメンテーションを、エンコーダ・デコーダ型FCNではなく「画像パッチ列から出力列を予測するsequence-to-sequence問題」として捉え直し、純粋なTransformerエンコーダを用いたSETR（SEgmentation TRansformer）を提案した研究。ADE20KとPascal Contextで当時の最高性能を達成した。

**先行研究と比べてどこがすごい？**

従来はdilated convolutionやアテンションモジュールの追加で受容野を広げるだけで、FCNのエンコーダ・デコーダ構造自体は不変だった。SETRは解像度を下げず、全層で大域的な文脈をモデル化する純Transformerエンコーダに置き換え、アーキテクチャレベルで受容野の制約を解消した点が新しい。解像度を段階的に落とすAxial-DeepLabとも異なり、標準的なself-attentionを使う。

**技術や手法のキモはどこ？**

画像をH/16×W/16の固定サイズパッチに分割し、線形埋め込みと学習可能な位置埋め込みを加えて長さHW/256の系列としてTransformerエンコーダ（T-Base 12層／T-Large 24層）に入力する。出力系列をH/16×W/16×Cの特徴マップに戻し、3種のデコーダで画素単位の分類を行う。デコーダは、一括でバイリニア補間するNaive、2倍ずつ段階的にアップサンプリングするPUP、複数層の特徴を集約するMLAである。ViTまたはDeiTの事前学習重みで初期化し、中間層に補助損失も加える。

**どうやって有効だと検証した？**

ADE20K、Pascal Context、Cityscapesで、mIoUを指標にFCN・Semantic FPN・各種アテンション系手法と比較した。SETR-MLAはマルチスケール推論でADE20Kにて50.28%、Pascal Contextにて55.83%を達成し、ADE20Kのテストサーバのリーダーボードで1位となった。Cityscapes検証セットではSETR-PUPが82.15%（80k、MS）で、テストセットでは81.08%（fineのみ、100k）となり競争力のある結果だった。ImageNet-21kで事前学習したFCNとの比較でも優位で、利点は事前学習データの多さだけによらないと示された。

**議論はある？**

事前学習への依存が大きく、ランダム初期化のSETR-PUPはCityscapesで42.27% mIoUにとどまる。GPUメモリの制約により出力ストライドは16としており、dilated FCNの8とは条件が異なる。T-Largeは約300M以上のパラメータを持ち、計算コストも大きい。

**次に読むべき論文は？**

- An Image is Worth 16x16 Words: Transformers for Image Recognition at Scale：SETRのエンコーダと事前学習重みの元になった純Transformerによる画像認識手法（ViT）で、パッチ系列化の基礎を理解できる。
- Axial-DeepLab: Stand-alone Axial-Attention for Panoptic Segmentation：アテンションのみのセグメンテーションモデルとしてSETRと最も近く、解像度を段階的に落とす設計との違いを比較できる。
- Training data-efficient image transformers & distillation through attention：SETRで事前学習に用いられるDeiTの学習法を理解でき、ImageNet-1kのみで得られる性能の根拠が分かる。

:::
