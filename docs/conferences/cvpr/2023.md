# CVPR 2023

👁️ 画像認識・CV ・ [CVPR の年ごとの流れ](./) ・ [公式サイト ↗](https://cvpr.thecvf.com/)

::: info この回のまとめ
バンクーバーで開催され、投稿9,155本・採択2,360本（約25.8%）でした。最優秀論文は2本で、認識・予測・計画を1つのネットワークにまとめ、最終目的である走行計画に向けて全体を最適化する自動運転モデル UniAD（上海 AI Lab ほか）と、自然言語の指示から LLM が視覚処理のプログラムを生成して実行し、追加学習なしで複雑な視覚推論を行う Visual Programming（Allen AI）が選ばれました。佳作には DreamBooth（被写体を指定した画像生成）や動的シーンのレンダリング DynIBaR が入っています。
:::

- **開催地**: カナダ・バンクーバー

- エンドツーエンド自動運転: 認識から計画までを計画中心に統合（UniAD）

### 1. UniAD：計画を目的とした自動運転 {#paper-1}

🏆 Best Paper ・ Yihan Hu, Jiazhi Yang, Li Chen, Keyu Li ほか ・ [論文を読む ↗](https://arxiv.org/abs/2212.10156)

<small>原題: Planning-oriented Autonomous Driving</small>

物体検出・追跡・地図・動き予測・占有予測・計画を別々に最適化するのではなく、すべてを走行計画に役立つよう1つのネットワークで結合しました。nuScenes で各タスクと計画の性能を同時に改善しています。

::: info 📝 落合フォーマット

**どんなもの？**

自動運転の最終目標である自車の経路計画（planning）に向けて、検出・追跡・地図生成・動き予測・占有予測を1つのネットワークに統合したエンドツーエンドの枠組み UniAD を提案した研究。各タスクを個別モデルや単純なマルチタスク学習で扱うのではなく、計画に貢献するよう設計・優先付けする「planning-oriented」な思想を掲げている。

**先行研究と比べてどこがすごい？**

知覚・予測・計画にわたる5つの主要タスク（検出/追跡、地図、動き予測、占有予測、計画）を包括的に連携させた初の取り組みとされ、従来のエンドツーエンド手法（Table 1の(c.2)）が欠いていた構成要素を補っている。全ノードを統一的なクエリインターフェースで接続することで、バウンディングボックス表現より広い受容野で上流の誤差の累積を和らげ、エージェント間相互作用なども柔軟に表現できる点が新しい。

**技術や手法のキモはどこ？**

マルチカメラ画像からBEVFormerでBEV特徴を得て、TrackFormer（検出・追跡クエリ＋自車クエリ）、MapFormer（パノプティックセグメンテーションによる地図クエリ）、MotionFormer（エージェント間・エージェント–地図・ゴール点の3種の相互作用で全エージェントの軌道をシーン中心で予測）、OccFormer（BEV特徴をクエリ、エージェント特徴をキー/バリューとし、アテンションマスクで画素とエージェントを対応付けてインスタンス単位の占有を予測）、Plannerの順にTransformerデコーダで接続する。Plannerは自車クエリにコマンド埋め込みを加えた「plan query」からウェイポイントを出力し、推論時にOccFormerの占有予測を用いたニュートン法で衝突を避けるよう最適化する。MotionFormerの学習ではKinematic制約付きの非線形平滑化でGT軌道を補正し、学習は知覚部の事前学習（6エポック）の後に全体を20エポックでエンドツーエンド学習する2段階で行う。

**どうやって有効だと検証した？**

nuScenesデータセットで、各タスクの有無を変えたアブレーションと既存手法との比較を実施した。MTLベースライン（ID-0）に対し、UniADはminADEで-15.2%、minFDEで-17.0%、平均L2で-0.15m、平均衝突率で-0.51%と改善し、計画ではST-P3に対しL2誤差を51.2%、衝突率を56.3%削減した（Table 7でL2平均1.03m、衝突率平均0.31%）。追跡ではMUTR3D比でAMOTA+6.5ポイント、モーション予測ではminADE 0.71でViP3DやPnPNetを上回った一方、Immortal Trackerや一部の地図クラスでは専用手法に劣る。

**議論はある？**

複数タスクを統合した系は学習に大きな計算資源を要し（特に時系列履歴を用いる場合）、軽量なデプロイ向けの設計が今後の課題とされている。深度推定や行動予測などの追加タスクをどう組み込むかも将来の方向として挙げられている。また失敗例は大型トラックやトレーラーなどのロングテールなシーンに偏っており、評価もnuScenesのオープンループ設定が中心である点に留意が必要。

**次に読むべき論文は？**

- BEVFormer: Learning Bird's-Eye-View Representation from Multi-Camera Images via Spatiotemporal Transformers：UniADのBEV特徴抽出器として採用されており、入力表現の理解に必須だから。
- ST-P3: End-to-End Vision-Based Autonomous Driving via Spatial-Temporal Feature Learning：計画性能の主要な比較対象であり、同じくビジョンベースのエンドツーエンド手法の先行例だから。
- ViP3D: End-to-End Visual Trajectory Prediction via 3D Agent Queries：クエリベースでエージェントを接続するエンドツーエンドの知覚・予測手法で、UniADの追跡・予測部との比較に役立つから。

:::


### 2. Visual Programming：学習なしの合成的な視覚推論 {#paper-2}

🏆 Best Paper ・ Tanmay Gupta, Aniruddha Kembhavi ・ [論文を読む ↗](https://arxiv.org/abs/2211.11559)

<small>原題: Visual Programming: Compositional visual reasoning without training</small>

GPT-3 に数例のプログラム例を見せて、自然言語の指示から物体検出・切り抜き・画像編集などを組み合わせる Python 風のプログラムを生成させ、それを実行して答えを出します。追加学習なしで画像の質問応答や編集ができ、処理過程も読めるのが特徴です。

::: info 📝 落合フォーマット

**どんなもの？**

自然言語の指示から、GPT-3 のインコンテキスト学習で Python 風のモジュール型プログラムを生成し、それを実行して解と解釈可能な根拠を得るニューロシンボリック手法 VisProg を提案した研究。タスク固有の学習を一切行わず、既存の視覚モデルや画像処理関数、Python 関数を組み合わせて、複雑で組み合わせ的な視覚タスクを解く。

**先行研究と比べてどこがすごい？**

従来の Neural Module Networks はレイアウト生成器の学習やエンドツーエンドの微分可能なネットワークを要したが、VisProg は少数の例示だけで高水準のプログラムを生成し、学習済み SOTA モデルや非微分の Python モジュールも呼び出せる。Socratic Models のようにタスクごとに固定された構成ではなく、インスタンスごとにモデルの組み合わせをプログラムとして決定できる。さらに各ステップの入出力を HTML で可視化した視覚的根拠を出力し、誤り分析や指示の修正に使える。

**技術や手法のキモはどこ？**

プロンプトには「指示とそれに対応する高水準プログラム」のペアを手書きで用意し、新しい指示を与えると GPT-3 が画像を見ずにプログラムを生成する。各行はモジュール名、引数、出力変数で構成され、20 種のモジュール（OWL-ViT、DSFD、MaskFormer、CLIP、ViLT、Stable Diffusion、OpenCV 系処理、算術・論理演算など）を呼び出す。各モジュールは parse・execute・html の3メソッドを持つ Python クラスで、インタプリタがプログラム状態（変数名と値の辞書）を更新しながら1行ずつ実行し、各ステップの HTML を連結して視覚的根拠を作る。

**どうやって有効だと検証した？**

4タスクで評価した。GQA（質問タイプごとにサンプルした部分集合）では ViLT-vqa の 47.8 に対し、5回の投票で 50.5（+2.7 点）、手作業で選んだプロンプトで 50.0 だった。NLVRv2 では画像ペアで学習せずに 62.4%（投票）を達成し、ファインチューニング済み ViLT-nlvr の 76.3 を上限として比較した。知識タグ付けでは元の指示で F1 63.7（局在のみ 80.6）、視覚的根拠を見て修正した指示で 75.7（局在のみ 84.9）に向上し、画像編集の正解率も 59.8 から 66.4 に向上した。

**議論はある？**

GQA では不正なプログラムが誤りの最大要因（16% のサンプル）であり、プロンプト例の追加やモジュールの高性能モデルへの置き換えが改善の方向とされる。NLVR では VQA モデルの性能が律速で、より良いモデルに替えれば最大 24% の改善余地があると分析されている。また GPT-3 の API コストのため評価は部分集合で行われており、プロンプト戦略の改善やユーザーのフィードバックを取り込む方法が今後の課題とされる。

**次に読むべき論文は？**

- Neural Module Networks：VisProg が比較・改良対象とするモジュール型視覚推論の原点であり、アプローチの違いを理解できる。
- Socratic Models: Composing Zero-Shot Multimodal Reasoning with Language：複数の事前学習モデルを言語で合成する関連手法で、タスクごとに固定された構成と VisProg のインスタンスごとのプログラム生成を比較できる。
- Chain of Thought Prompting Elicits Reasoning in Large Language Models：中間推論ステップをプロンプトに含める考え方の基礎であり、VisProg のプログラム生成と多数決による性能向上の背景を理解できる。

:::


### 3. 極大クリークを用いた3D位置合わせ {#paper-3}

🏆 Best Student Paper ・ Xiyu Zhang, Jiaqi Yang, Shikun Zhang, Yanning Zhang ・ [論文を読む ↗](https://arxiv.org/abs/2305.10854)

<small>原題: 3D Registration with Maximal Cliques</small>

3D点群位置合わせにおいて、対応点の互換性グラフ上の極大クリークから姿勢仮説を生成する、学習不要の幾何手法MACを提案した研究である。従来の最大クリーク制約より緩い極大クリークで局所的な合意情報も活用し、ノードごとに重み最大のクリークだけを残して計算量を抑えつつ、RANSACより多くの正しい仮説を得られる。3DMatchやKITTIなどで幾何手法・深層学習手法を上回り、GeoTransformerと組み合わせると3DMatch/3DLoMatchでRR 95.7%/78.9%を達成するなど他の深層手法も改善した点が注目される。

::: info 📝 落合フォーマット

**どんなもの？**

3D点群位置合わせ（PCR）において、初期対応点から構築した互換性グラフ上の極大クリーク（maximal clique）を用いて高精度な姿勢仮説を生成する幾何のみの手法MACを提案した研究。学習データを必要とせず、深層学習手法に差し込むモジュールとしても使える。

**先行研究と比べてどこがすごい？**

従来の最大クリーク（maximum clique）制約は大域的な合意情報しか使わず厳しすぎるのに対し、極大クリークに緩めて局所的な合意情報も活用する点が新しい。ノード誘導型のクリーク選択により、ノードごとに重み最大のクリークだけを残して計算量を抑えつつ、RANSACより多くの正しい仮説を生成できる。

**技術や手法のキモはどこ？**

初期対応点をノード、幾何的に整合する対応点間をエッジとする互換性グラフ（一次グラフFOG、または共通隣接を考慮する二次グラフSOG）を構築する。igraphの改良Bron-Kerbosch法で極大クリークを列挙し、各ノードについて辺重み和が最大のクリークを選び重複を除去する（必要に応じて法線整合やTop-Kランキングで絞り込む）。選ばれた各クリークにSVDで剛体変換仮説を計算し、MAE・MSE・インライア数といったRANSAC系の評価指標（MAEが最良）で最良の仮説を採用する。

**どうやって有効だと検証した？**

U3M、3DMatch、3DLoMatch、KITTIで評価し、3DMatchではFPFH/FCGF設定でRR 84.10% / 93.72%、3DLoMatchでは40.88% / 59.85%と、比較した幾何手法および深層学習手法を上回った（KITTIはFPFHで最良、FCGFでは同率最良）。GeoTransformerと組み合わせると3DMatch / 3DLoMatchでRR 95.7% / 78.9%を達成し、他の深層手法にも一貫して改善をもたらした。アブレーションでは極大クリークが最大クリークをFPFH+3DMatchで9.8%上回り、仮説の質を理想的に判定した場合の上限（MAC-1）は98.46% / 91.24%だった。

**議論はある？**

MACは正しい仮説を生成できるものの、それを最良として選び出す評価指標が不十分で、上限（MAC-1）と実際のRRに差が残るのが限界である。著者らは今後、意味情報を用いたより信頼できる仮説評価手法を開発する予定としている。また対応点数が5000に達すると極大クリーク探索のため計算時間が大きく増える（約3.3秒）が、MACは入力数に鈍感なので疎な入力で効率化できると述べている。

**次に読むべき論文は？**

- SC2-PCR: A Second Order Spatial Compatibility for Efficient and Robust Point Cloud Registration：MACが採用する二次互換性グラフの元となる手法で、最も直接的な比較対象の幾何手法でもあるため。
- Geometric Transformer for Fast and Robust Point Cloud Registration：MACと組み合わせて3DMatch/3DLoMatchで最高性能を達成したベース手法であり、深層側の背景を理解できる。
- TEASER: Fast and Certifiable Point Cloud Registration：最大クリークに基づく頑健な位置合わせの代表的手法で、MACが緩めた制約の出発点を把握できる。

:::


### 4. DynIBaR: ニューラル動的イメージベースレンダリング {#paper-4}

🏆 Best Paper Honorable Mention ・ Zhengqi Li, Qianqian Wang, Forrester Cole, Richard Tucker ほか ・ [論文を読む ↗](https://arxiv.org/abs/2211.11082)

<small>原題: DynIBaR: Neural Dynamic Image-Based Rendering</small>

単眼動画から、長時間で物体の動きが複雑、かつカメラ軌跡に制約のない動的シーンの新規視点（空間・時間）を合成する手法です。シーン全体をMLPの重みに符号化せず、静的シーン向けIBRのエピポーラ線上の特徴集約を、シーンの動きで補正した光線空間での集約へ拡張し、近傍フレームの特徴を集約して描画します。Nvidia Dynamic Scene DatasetとUCSD Dynamic Scenes Datasetで、全体のPSNRを2番目に良い手法より2dBおよび4dB改善し、LPIPSを50%以上低減した点が注目され、CVPR 2023のBest Paper Honorable Mentionに選ばれました。

::: info 📝 落合フォーマット

**どんなもの？**

モノクロ（単眼）動画から、長時間・複雑な物体運動・制約のないカメラ軌跡を持つ動的シーンの新規視点（空間・時間）を合成する手法 DynIBaR を提案した研究。シーン全体をMLPの重みに符号化する代わりに、ボリュームベースのイメージベースレンダリング（IBR）の枠組みで近傍フレームの特徴を集約して描画する。

**先行研究と比べてどこがすごい？**

従来の動的NeRF（NSFFは短い前向き動画向け、HyperNeRFなどの正準空間型は物体中心で動きが小さいシーン向け）が苦手とする長尺・複雑なシーンに対応できる点が新しい。静的シーン向けIBR（IBRNetなど）のエピポーラ線上の特徴集約を、シーンの動きで補正した光線空間での集約に拡張した。

**技術や手法のキモはどこ？**

各3D点の動きを、MLPが出力する係数と学習可能な大域基底（DCT基底で初期化し微調整）の組合せによる運動軌跡場で表現し、1回のMLP問い合わせで近傍時刻の対応点を得て、ソースビューの特徴を集約する。集約特徴は光線トランスフォーマで色と密度に変換し、ボリュームレンダリングする。時間的整合性のため、近傍時刻jを経由して描画するcross-time renderingと、遮蔽変化を考慮した光度損失を用いる。さらに、静的モデル（時間不変）と動的モデル（時間変化）に分解し、Cauchy分布に基づくベイズ的な動き領域分割モジュールで得たマスクで学習を教師する。加えて、単眼深度・オプティカルフローの事前情報や軌跡の正則化、実世界動画向けの仮想ビューなども導入している。

**どうやって有効だと検証した？**

Nvidia Dynamic Scene DatasetとUCSD Dynamic Scenes Datasetで、Nerfies、HyperNeRF、DVS、NSFFと比較した。全体のPSNRは2番目に良い手法より2dBおよび4dB改善し、LPIPSは50%以上低減した（例：Nvidiaで全体LPIPS 0.027、NSFFは0.062）。アブラレーションで、時間的整合性、運動軌跡表現、静的モデル、マスク損失、正則化の各要素の有効性を確認し、実世界の10秒動画でも先行手法より高品質な描画を示した。

**議論はある？**

視点変化は静的向け手法に比べ比較的小さい範囲に限られ、初期の深度・フロー推定が誤る小さく速い物体（細いリードなど）や、遠い時刻にしか現れない動的内容は扱えない。また、描画が厳密にはマルチビュー整合でなく、静的部分の品質が選ばれるソースビューに依存し、カメラと物体の動きがほぼ同一直線上にある場合は不安定になる。計算コストも大きく、10秒動画の最適化に8台のA100で約2日かかる。

**次に読むべき論文は？**

- Neural Scene Flow Fields for Space-Time View Synthesis of Dynamic Scenes：本論文が直接の比較対象かつ設計の土台とする、シーンフローベースの動的NeRFで、静的・動的分解や遮蔽重みの考え方を理解できる。
- IBRNet: Learning Multi-View Image-Based Rendering：本論文の基盤となる、ボリュームレンダリングとIBRを組み合わせた特徴集約・光線トランスフォーマの枠組みを把握できる。
- HyperNeRF: A Higher-Dimensional Representation for Topologically Varying Neural Radiance Fields：正準空間に基づく動的シーン表現の代表的手法で、本論文が指摘する限界との対比を理解するのに役立つ。

### 5. YOLOv7: 学習可能なbag-of-freebiesがリアルタイム物体検出器の新たな最高性能を打ち立てる {#paper-5}

📈 被引用数上位（Paper Digest の集計で同年1位） ・ Chien-Yao Wang, Alexey Bochkovskiy, Hong-Yuan Mark Liao ・ [論文を読む ↗](https://arxiv.org/abs/2207.02696)

<small>原題: YOLOv7: Trainable bag-of-freebies sets new state-of-the-art for real-time object detectors</small>

推論コストを増やさず学習過程の最適化（trainable bag-of-freebies）で精度を高めたリアルタイム物体検出器 YOLOv7 を提案した研究で、MS COCO のみのスクラッチ学習により V100 で30 FPS以上の検出器として最高の56.8% APを達成した。再パラメータ化モジュールの置き換えや複数出力層での動的ラベル割り当てという新たな課題を見出して解決策を示し、concatenation 型モデル向けの複合スケーリング法も設計した点が特徴である。YOLOv7 は 161 FPS で 51.4% AP を出し、同APの PPYOLOE-L（78 FPS）より高速で、被引用数でも CVPR 2023 の同年1位（Paper Digest 集計）として注目されている。

::: info 📝 落合フォーマット

**どんなもの？**

リアルタイム物体検出器 YOLOv7 を提案した研究。推論コストを増やさず学習過程の最適化（trainable bag-of-freebies）で精度を高め、5〜160 FPS の範囲で既存の検出器より速度・精度のバランスで上回ると主張している。MS COCO のみでスクラッチ学習し、V100 で30 FPS以上のリアルタイム検出器として最高の56.8% APを達成した。

**先行研究と比べてどこがすごい？**

アーキテクチャ最適化だけでなく学習プロセスの最適化に注力した点が特徴。再パラメータ化モジュールを異なる構造にどう置き換えるか、複数出力層を持つモデルで動的ラベル割り当てをどう行うか、という2つの新たな課題を見出し、それぞれに解決策を示した。また concatenation 型モデル向けの複合スケーリング法も新たに設計した。

**技術や手法のキモはどこ？**

(1) E-ELAN：グループ畳み込みで計算ブロックの channel と cardinality を拡張し、shuffle と merge cardinality により元の勾配経路を壊さず学習能力を高める。(2) 計画的再パラメータ化畳み込み：残差・concatenation を持つ層では RepConv の identity 接続を除いた RepConvN を用いる。(3) coarse-to-fine lead head guided label assignment：lead head の予測と正解から soft label を生成し、補助ヘッドには正例を緩めた粗いラベル、lead head には精細なラベルを割り当てる。(4) concatenation 型モデルでは、ブロックの深さをスケールした分だけ transition 層の幅も同量スケールする複合スケーリングを行う。

**どうやって有効だと検証した？**

MS COCO（train2017で学習、val2017で検証、test2017で比較）で評価。YOLOv7 は YOLOR-CSP に対しパラメータ43%減・計算量15%減で AP 0.4ポイント向上し、YOLOv7 は 161 FPS で 51.4% AP を達成（同APの PPYOLOE-L は 78 FPS）。YOLOv7-E6 は 56 FPS・55.9% APで、YOLOv7-E6E は 56.8% AP を記録した。アブレーションでも複合スケーリング、計画的再パラメータ化、coarse-to-fine ラベル割り当て、partial auxiliary head の有効性を示している。

**議論はある？**

比較は主に COCO 上で、V100 や A100 など特定の GPU・設定での速度に基づくため、他のデバイスや用途への一般化は本文からは確認できない。計画的再パラメータ化のアブレーション（Table 4）では AP 差が小さく、設定によっては改善が限定的な点にも留意が必要。補助ヘッドの設計や粗いラベルの制約の詳細は付録に依存している。

**次に読むべき論文は？**

- YOLOR: You Only Learn One Representation: Unified Network for Multiple Tasks：YOLOv7 の主要ベースラインであり、implicit knowledge の仕組みを理解するために必要なため。
- RepVGG: Making VGG-style convnets great again：YOLOv7 の計画的再パラメータ化畳み込みの土台となる RepConv の元論文であるため。
- OTA: Optimal transport assignment for object detection：YOLOv7 のラベル割り当てが前提とする動的ラベル割り当ての代表的手法であるため。
