# KDD 2021

🔎 データマイニング・Web ・ [KDD の年ごとの流れ](./) ・ [公式サイト ↗](https://kdd.org/)

::: info この回のまとめ
2021年8月14〜18日にオンラインで開催されました。研究トラックは投稿1,541本・採択238本（15.4%）、全体では投稿2,200本超・採択394本です。研究トラックの最優秀論文は、時間範囲を指定した問い合わせに高速・省メモリで答えるタッカー分解 Zoom-Tucker（ソウル大学）で、既存手法より最大171.9倍速く、最大230分の1の容量で動きます。ADS トラックでは、携帯電話の移動データから感染拡大を予測し、店舗の営業制限などの政策判断を支援するモデル（スタンフォード大学ほか）が選ばれました。
:::

- **日程**: 2021年8月14日〜18日
- **開催地**: オンライン開催
- **規模**: 投稿 1,541 本 ／ 採択 238 本 ／ 採択率 15.4%（研究トラックの数値。全体では投稿2,200本超・採択394本）

**📝 注目論文（1 本）**

1. [大規模な移動データに基づくモデルによる COVID-19 政策対応の支援](#paper-1)

## 🔭 この回の主なテーマ

- テンソル分解の効率化: 時間範囲の問い合わせに答える高速なタッカー分解（Zoom-Tucker）
- 公衆衛生への応用: 移動データによる COVID-19 の感染モデルと政策支援
- グラフのクラスタリング: 属性つき多関係グラフのスペクトラルクラスタリング（最優秀学生論文）
- 災害対応: 分散型深層強化学習による車両クラウドソーシング（ADS 次点）

::: tip 💡 技術動向への示唆
- 移動データのような大規模な行動データが政策判断に直接使われた例として、データマイニングの社会的な役割と、プライバシーへの配慮の両方を示した
:::

## 📝 注目論文

### 1. 大規模な移動データに基づくモデルによる COVID-19 政策対応の支援 {#paper-1}

🏆 Best Paper（ADS トラック） ・ Serina Chang, Mandy Wilson, Bryan Leroy Lewis, Zakaria Mehrab ほか

<small>原題: Supporting COVID-19 Policy Response with Large-Scale Mobility-Based Modeling</small>

携帯電話の位置情報から得た人の移動データで感染拡大をモデル化し、どの業種の営業を制限するとどの程度感染を抑えられるかを推定できるようにしました。実際の行政の政策判断に使われた点が評価されました。
