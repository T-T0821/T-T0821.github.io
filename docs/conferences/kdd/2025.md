# KDD 2025

🔎 データマイニング・Web ・ [KDD の年ごとの流れ](./) ・ [公式サイト ↗](https://kdd.org/)

::: info この回のまとめ
KDD 2025 は2025年8月3〜7日にカナダのトロントで開催されました。研究トラックの最優秀論文は、モデルが背景などの「見せかけの相関」に頼る問題を、グループのラベルなしで不確実性の推定を使って和らげる Evidential Alignment（バージニア大学）です。ADS トラックでは、何千もの A/B テストの結果からどの施策を採用するかを決める「判断ルール」を、事業指標への累積的な効果で評価する研究が選ばれ、新設のデータセット・ベンチマークトラックでは異質なグラフの大規模ベンチマークが受賞しました。最優秀学生論文には、東京科学大学のチームによる推薦の人気バイアスの研究が選ばれています。
:::

### 1. エビデンシャル・アラインメントによる見せかけの相関に対するグループ頑健性の向上 {#paper-1}

🏆 Best Paper（研究トラック） ・ Wenqian Ye, Guangtao Zheng, Aidong Zhang ・ [論文を読む ↗](https://arxiv.org/abs/2506.11347)

<small>原題: Improving Group Robustness on Spurious Correlation via Evidential Alignment</small>

「砂漠の背景でラクダと判定する」ような見せかけの相関への依存は、少数派のグループで性能を落とします。費用のかかるグループのラベルを使わず、不確実性の推定で偏ったサンプルを見つけて補正する方法を示しました。

::: info 📝 落合フォーマット

**どんなもの？**

深層ニューラルネットが非因果的特徴（背景など）に依存する「スプリアス相関」に対し、グループアノテーションなしでグループ頑健性（最悪グループ精度）を改善する枠組み Evidential Alignment を提案した研究。バイアスを持つモデルの認識論的不確実性を利用して、少数グループのサンプルを特定・補正する。

**先行研究と比べてどこがすごい？**

既存手法は外部のグループ注釈や、決定論的な補助モデル（JTT、LfF など）によるバイアス推定に頼っていたが、本手法は不確実性定量化（エビデンシャル深層学習）をグループ頑健性に適用し、注釈なしで単一モデルかつ単一パスでバイアスの振る舞いを捉える。補助モデルを一から再学習する必要がなく、最終層のみの操作で済むため計算・メモリ効率も高い。

**技術や手法のキモはどこ？**

2段階構成。第1段階の「2次リスク最小化」では、モデル出力をエビデンスとしてディリクレ分布のパラメータ α=e+1 を定め、負の対数尤度と、一様ディリクレ事前分布へのKLによるエビデンス正則化（アニーリング係数 λ_t=min(t/η,1)）で最終層を学習する。第2段階の「エビデンシャル較正」では、不確実性 u(x)=K/S(x) を計算し、誤分類サンプルを u(x) で重み付け（正解サンプルは重み1）、クラスバランスサンプリングと θ1 からの L2 正則化を加えて較正用データ上で最終層を再学習する。理論面では、2次リスクがELBOの上界になること、および再重み付き経験リスクに対するPAC-Bayes型の最悪グループリスク上界を示している。

**どうやって有効だと検証した？**

Waterbirds、CelebA、MultiNLI、CivilComments、CheXpert、Colored MNIST の6データセットで、ResNet-50 と BERT を用いて評価し、最悪グループ精度（WGA）を主指標とした。Colored MNIST では少数グループ精度が ERM の3.74%から84.58%に向上した。実データではグループ注釈なしの手法の中で最良のWGAを達成し（Waterbirds 92.2%、CelebA 84.4%、MultiNLI 74.5%、CivilComments 80.2%）、CheXpert でもWGA 73.6%・平均精度79.9%で比較手法を上回った。一方、CelebA では CnC が最良、CivilComments では DFR のWGA（81.8%）が上回っており、全てで首位というわけではない。

**議論はある？**

較正用データには検証セットの半分を使い、モデル選択にも残り半分を用いるため、完全に追加データ不要とは言えない点に留意が必要である。また最適なアニーリング step η などのハイパーパラメータはデータセット依存であり、CelebA ではCnCやDFRに及ばないなど、データによって性能差がある。なお、本文の一部（結論・付録など）は提供された範囲では省略されており、そこに書かれている限界や今後の展望は確認できていない。

**次に読むべき論文は？**

- Evidential Deep Learning to Quantify Classification Uncertainty：本手法の第1段階の土台となる、ディリクレ分布によるエビデンス学習と不確実性推定の原典であるため。
- Last Layer Re-Training is Sufficient for Robustness to Spurious Correlations：最終層のみの再学習でグループ頑健性を高める DFR であり、本手法の主要な比較対象かつ設計上の基礎であるため。
- Bias Amplification Enhances Minority Group Performance：注釈なしで誤分類サンプルを重み付けする直近の手法 BAM で、決定論的な補助モデルに依存する点が本手法との対比になるため。

:::


### 2. 多数の弱い実験にまたがる判断ルールの評価 {#paper-2}

🏆 Best Paper（ADS トラック） ・ Winston Chou, Colin Gray, Nathan Kallus, Aurélien Bibaut ほか ・ [論文を読む ↗](https://arxiv.org/abs/2502.08763)

<small>原題: Evaluating Decision Rules Across Many Weak Experiments</small>

何千もの A/B テストを行う企業では、結果からどの施策を採用するかの「判断ルール」が事業成果を左右します。判断ルールを事業の主要指標への累積的な効果で評価する方法を提案し、厳密な指針が乏しかった領域に枠組みを与えました。

::: info 📝 落合フォーマット

**どんなもの？**

A/Bテストの「決定ルール」（実験結果から本番展開する処置アームを選ぶ標準手順）を、過去の多数の実験における北極星指標への累積リターンで評価・選択する枠組みを提案した研究。個々の実験はS/N比が低い（弱い実験）ため推定が難しく、その推定手法として交差検証（CV）推定量を開発した。Netflixの過去123件のA/Bテストで新ルールを評価し、実際の採用につなげた。

**先行研究と比べてどこがすごい？**

単純なプラグイン推定量は勝者の呪い（winner's curse）で偏り、そのバイアスは実験数Nを増やしても消えず、実験あたりユニット数Mが有限である限り残る。本研究はExperiment splittingに基づくCV推定量で、勝者の選択に使うデータと報酬評価に使うデータを分離してこの偏りを除去する。プロキシ指標、p値閾値、ガードレール等を決定ルールという一般的な枠組みで統一的に評価でき、実験数Nを増やす漸近設定での一致性保証を与えた点も新しい。

**技術や手法のキモはどこ？**

各実験のユニットをP個のfoldに分割し、残りのfoldで決定ルールを適用して勝者アームを選び、保持したfoldでその勝者の報酬を推定して、全fold・全実験で（重み付き）平均する。CV推定量には、ルールが全データでなく一部データに適用されることによる小さな負のバイアスが残るが、fold数Pを増やすことで軽減できる。実験のユニット数M_iがポアソン分布に従う場合、leave-ℓ-out CVはスケーリング付きで不偏となること（定理3.1）を示し、leave-one-outで有限個の候補ルールから最良ルールを選べること（定理3.2、収束率O_p(√(log|D|/(N M_0)))）を示した。

**どうやって有効だと検証した？**

ガウス分布を仮定した閉形式解析とシミュレーション（N=100、M=1,000,000、P=10、1万回試行）により、ナイーブ推定量は単位レベルのノイズ共分散に影響され、ノイズ相関が強い「悪い」プロキシを選びうること、一方CV推定量は真の処置効果の共分散のみに依存して正しく順位付けできることを示した。Netflixの123件の実験ではナイーブ推定が累積リターンを系統的に過大評価し、CV推定はfold数を増やしても安定した。新しいプロキシ指標に基づくルール3は、北極星指標の累積リターンを33%超増加させると推定された（p値0.07〜0.09）。この結果が新ルールの採用に直結した。

**議論はある？**

実験間で処置効果が独立であること（他実験の起動判断に依存しない）と、過去に最適なルールが将来も有効であるという定常性を仮定しており、これらが崩れる場合には推定が妥当でなくなる可能性がある。実験間の依存をCVに組み込む拡張、p値閾値の評価やコストの組み込み、事前定義の集合からではなくルールそのものを学習する方向（最適性と解釈可能性のトレードオフ）が今後の課題として挙げられている。また、Netflixでの改善はごく少数の高インパクト実験に由来し、統計的有意性も限界的（p値0.07〜0.09）であった点にも留意が必要である。

**次に読むべき論文は？**

- Learning the Covariance of Treatment Effects Across Many Weak Experiments：本論文が実応用で使ったプロキシ指標の構築手法で、真の処置効果の共分散を推定する前提となる研究である。
- Improving Treatment Effect Estimators through Experiment Splitting：本論文のCV推定量の基礎となるexperiment splittingによる勝者の呪い対策の元論文である。
- Optimizing Returns from Experimentation Programs：p値閾値など決定ルールの最適設計を理論面から扱っており、本論文の経験的評価と補完関係にある。

:::


### 3. ヘテロフィリーが異種性と出会うとき:課題と新たな大規模グラフベンチマーク {#paper-3}

🏆 Best Paper（データセット・ベンチマーク） ・ Junhong Lin, Xiaojie Guo, Shuaicheng Zhang, Yada Zhu ほか ・ [論文を読む ↗](https://arxiv.org/abs/2407.10916)

<small>原題: When Heterophily Meets Heterogeneity: Challenges and a New Large-Scale Graph Benchmark</small>

異種グラフかつヘテロフィリーという両方の性質を併せ持つ大規模グラフ向けに、初のノード分類ベンチマーク H2GB を提案した研究です。5分野9データセットと28のベースライン、統一的なライブラリを公開し、クラス不均衡を補正する新指標 H2 index や新モデル H2G-former も示しています。H2G-former は平均順位1.1で最良となり、同種ヘテロフィリックGNNが異種ホモフィリックGNNに劣る傾向や、小規模向け手法が大規模ではスケールしにくいことも明らかにした点が注目されます。

::: info 📝 落合フォーマット

**どんなもの？**

異種グラフ（複数のノード・エッジタイプ）かつヘテロフィリー（隣接ノードのラベル・属性が異なる）という両性質を併せ持つ大規模グラフ向けのノード分類ベンチマーク H2GB を提案した研究。5分野9データセット、28のベースラインモデル、統一的なデータローダ・評価器・モデリングフレームワークを含むライブラリを公開している。さらに、標準ワークフローに沿って開発した新モデル H2G-former も示している。

**先行研究と比べてどこがすごい？**

従来のベンチマークは「ヘテロフィリックな同種グラフ」か「ホモフィリックな異種グラフ」のどちらかに偏っており、両方を同時に扱うものがなかった。H2GB はこのギャップを埋める初の大規模ベンチマークで、数百万ノード・数千万エッジ規模のデータを含む。また、メタパスに基づく部分グラフ上でクラス不均衡を補正した新しいヘテロフィリー指標 H2 index を導入し、従来の MLH が不均衡データで見かけ上低い値（ホモフィリー側）になってしまう問題を改善している。

**技術や手法のキモはどこ？**

データは PyG の HeteroData 形式に統一し、多くのデータで時系列分割を採用している。H2 index は、メタパス誘導部分グラフごとに調整済みヘテロフィリー（ランダムグラフ構成モデルでの期待値で補正）を計算し、長さ2のメタパスで平均を取る。モデル面では UnifiedGT によりサンプリング・エンコーディング・注意機構・FFN などをモジュール化し、HGT を基に 1-hop マスクを k-hop マスクへ置換、マスクドラベル埋め込みと型別FFNを追加して H2G-former を構築した。全モデルでミニバッチ学習とサンプリング戦略を揃えて公平に比較している。

**どうやって有効だと検証した？**

9データセット（ogbn-mag、mag-year、oag-cs/eng/chem、RCDD、IEEE-CIS-G、H-Pokec、PDNS）で、精度またはF1（クラス不均衡の大きいもの）を指標に、5シードの平均と標準偏差で28モデルを比較した。H2G-former は平均順位 1.1 で最良となり、oag-cs では精度 28.47%（最良ベースライン R-GCN の 23.10% に対し +5.37 ポイント）を達成した。また、同種ヘテロフィリックGNNは異種ホモフィリックGNNに劣る傾向があり、HINormer は全データでOOM、FAGCN や ACM-GCN など小規模向け手法は大規模ではスケールしにくいことが示された。

**議論はある？**

現状の評価はノード分類に限られており、今後はリンク予測やノード回帰などの他タスク、さらなるデータセットへの拡張が課題とされている。H2 index は計算を長さ2のメタパスと平均集約に限定しており、より長いメタパスや他の集約での妥当性は本文では十分に検討されていない。また、全モデルで同一のサンプリング戦略を用いているため、モデルごとに最適な手法を使った場合の性能差は反映されていない。

**次に読むべき論文は？**

- Large Scale Learning on Non-Homophilous Graphs: New Benchmarks and Strong Simple Methods：大規模ヘテロフィリックグラフのベンチマークと LINKX の元論文であり、H2GB が拡張した先行研究として位置づけを理解できる。
- Homophily-Oriented Heterogeneous Graph Rewiring：異種グラフでメタパス部分グラフのホモフィリーが性能に影響することを示しており、H2 index の動機を理解する助けになる。
- Heterogeneous Graph Transformer：H2G-former のベースとなった HGT の仕組みを把握できる。

:::


### 4. ロバスト性と個人公平性のモニタリング {#paper-4}

🏆 Runner-up（研究トラック） ・ Ashutosh Gupta, Thomas A. Henzinger, Konstantin Kueffner, Kaushik Mallik ほか ・ [論文を読む ↗](https://arxiv.org/abs/2506.00496)

<small>原題: Monitoring Robustness and Individual Fairness</small>

デプロイ済みのブラックボックス分類器に対し、過去の類似入力が非類似な出力を生んだ時点で警告し、該当する過去入力の集合（witness set）も示す、実行時の入出力ロバスト性モニタリングを提案した研究です。敵対的ロバスト性・意味的ロバスト性・個人公平性を同じ枠組みで扱い、問題を固定半径最近傍（FRNN）探索のオンライン版に帰着させ、ツール Clemont として公開しています。10万次元超の入力や3.5億パラメータ超のモデルでも1決定あたり数分の1秒〜数秒で検出でき、最先端のオフラインのロバスト化を施したモデルでも実行時の違反が残ると示した点が注目されます。

::: info 📝 落合フォーマット

**どんなもの？**

デプロイ済みのブラックボックスAI分類器について、過去の類似入力が非類似な出力を生んだ時点で警告を出す「実行時の入出力ロバスト性（runtime i.o.r.）」のモニタリングを提案した研究。敵対的ロバスト性、意味的ロバスト性、個人公平性を同じ枠組みで扱い、違反時には該当する過去の入力の集合（witness set）も提示する。実装はツール Clemont として公開されている。

**先行研究と比べてどこがすごい？**

従来のロバスト性評価は、確率的または最悪ケースのオフライン検証が中心で、分布シフトや大規模モデルでは現実的でなかった。本研究は実際に観測された1本の実行列だけを対象にする実行時変種を定義し、グローバルなi.o.r.より弱い性質であることを示した。また、このモニタリングを固定半径最近傍（FRNN）探索のオンライン版に帰着させた。個人公平性の既存モニタはブルートフォース程度で、多くのベンチマークで不十分とされる。

**技術や手法のキモはどこ？**

問題を FRNN に帰着させ、2種類の解法を示した。(1) 静的FRNN（k-d木、SNN）を周期的に再索引する方式で、長期記憶には索引を使い、直近τ件の短期記憶はブルートフォースで探索する。τは償却計算量を最小化するように選ぶ。(2) L∞距離向けの新アルゴリズムで、実数次元を幅εの区間に離散化して過去入力をBDDに格納し、同一ラベルまたは隣接ラベルを高速に絞り込んだうえで、候補だけをブルートフォースで厳密に確認する。さらにL∞では、次元を分割して部分問題を並列に解き、結果を合成する並列化ラッパーも提案している。

**どうやって有効だと検証した？**

敵対的・意味的ロバスト性と個人公平性の標準ベンチマークで、Clemont内の各モニタ（ブルートフォース〔Faiss〕、k-d木、SNN、BDD、並列版）を比較した。本文によれば、違反を実行時に正しく検出でき、10万次元超の入力や3.5億パラメータ超のモデルでも、1決定あたり数分の1秒〜数秒で検出できたとされる。また、オフラインのロバスト化で実行時違反は大きく減るが、最先端手法で作ったモデルでも違反は残った。具体的な各モニタの数値比較は、提供された本文では省略されており確認できない。

**議論はある？**

BDD方式と並列化はL∞距離に限定され、SNNもL∞に対応しない。BDD方式では実数次元に有界な範囲が必要になる。runtime i.o.r.が成り立っても、モデルがグローバルにロバストだとは結論できない。増分更新が可能な厳密動的FRNN（Blelloch & Dobson ら）の組込みは今後の課題とされている。

**次に読むべき論文は？**

- Fast and exact fixed-radius neighbor search based on sorting：本研究が静的FRNNのバックエンドとして採用したSNNアルゴリズムの原論文で、索引方式の仕組みと制約を理解できる。
- Fairness-aware programming：個人公平性の実行時モニタリングを扱う数少ない先行研究で、本研究が比較対象とするブルートフォース型モニタの出発点になる。
- Parallel Nearest Neighbors in Low Dimensions with Batch Updates：厳密な動的FRNNを実現する数少ない先行研究で、本研究が今後組み込む予定とした増分索引の手法を学べる。

:::


### 5. 大規模言語モデルに対する間接プロンプトインジェクション攻撃のベンチマークと防御 {#paper-5}

📈 被引用数上位（Paper Digest の集計で同年1位） ・ Jingwei Yi, Yueqi Xie, Bin Zhu, Emre Kiciman ほか ・ [論文を読む ↗](https://arxiv.org/abs/2312.14197)

<small>原題: Benchmarking and Defending Against Indirect Prompt Injection Attacks on Large Language Models</small>

外部コンテンツに埋め込まれた悪意ある指示でLLMの出力を操作する間接プロンプトインジェクションについて、初の体系的ベンチマークBIPIA（5つのアプリシナリオ、250の攻撃目標）を構築し、評価した25のLLMがすべて脆弱であることを示した研究です。攻撃成功の原因を「文脈と指示の区別ができないこと」と「外部コンテンツ内の指示を実行しないという認識の欠如」に整理し、境界認識と明示的リマインダという2つの防御を提案しました。ホワイトボックス防御ではVicuna-7B/13BのASRをほぼ0まで下げられた一方、構成によってはMT-Benchの低下も見られ、被引用数でも同年1位（Paper Digest集計）と注目されています。

::: info 📝 落合フォーマット

**どんなもの？**

外部コンテンツに埋め込まれた悪意ある指示でLLMの出力を操作する間接プロンプトインジェクション攻撃について、初のベンチマークBIPIAを構築し、25のLLMの脆弱性を評価した研究。さらに、境界認識(boundary awareness)と明示的リマインダ(explicit reminder)という2つの防御機構を、ブラックボックス・ホワイトボックス両設定で提案した。

**先行研究と比べてどこがすごい？**

間接プロンプトインジェクションを体系的に評価する初のベンチマーク（5つのアプリシナリオ、250の攻撃目標）を提示した点が新しい。また、攻撃成功の原因を「情報としての文脈と実行すべき指示の区別ができないこと」と「外部コンテンツ内の指示を実行しないという認識の欠如」の2点と整理し、それに対応する防御を設計した点に独自性がある。ホワイトボックス防御では特殊トークンと敵対的学習を組み合わせている。

**技術や手法のキモはどこ？**

BIPIAはメールQA、Web QA、表QA、要約、コードQAの5タスクに、テキスト攻撃30種・コード攻撃20種（各5指示）を先頭・中間・末尾に挿入して構成し、訓練用626,250件・テスト用86,250件のプロンプトを持つ。ブラックボックス防御では、明示的リマインダをプロンプトに加えた上で、境界認識として外部コンテンツと指示を別ターンに分けるマルチターン対話、またはインコンテキスト学習を用いる。ホワイトボックス防御では、&lt;data>と&lt;/data>の特殊トークンを語彙に追加して外部コンテンツを囲み、リマインダを含むプロンプトでBIPIA訓練セットの攻撃入力に対する無害な応答を教師データとしてファインチューニングする。無害な応答はBIPIAのラベル、元LLMの応答、GPT-4の応答の3通りで構築した。

**どうやって有効だと検証した？**

25のLLMを評価した結果、すべてが脆弱であり、GPT-4の全体ASRは0.3103、GPT-3.5-turboは0.2616で、平均の0.1179より高かった。テキストタスクではArena Eloとの間に正の相関（Pearson係数0.6635）があった。ブラックボックス防御ではASRが大きく低下した（例: GPT-4でマルチターン対話により0.3103→0.2056、Vicuna-7Bで0.1237→0.0617）。ホワイトボックス防御ではVicuna-7B/13BのASRがほぼ0（GPT-4応答を使った場合0.0053/0.0047）まで下がり、ROUGE-1とMT-Benchの低下も小さかった。ただし、GPT-4応答以外の構成ではMT-Benchの低下が見られ、特にBIPIAラベルを使ったVicuna-13Bでは5.2062→1.6625と大きく低下した。

**議論はある？**

ブラックボックス防御はASRを下げるものの、LLMを攻撃に対して頑健にするには至らない。ホワイトボックス防御は一般タスクの性能に影響しうる。著者らは、特定のエンドツーエンドのアプリケーションでの十分なテストとレッドチーミングなしに、これらの防御に過度に依存しないよう注意を促している。また、本文の条件では、防御の評価対象は主にVicunaやGPT系モデルに限られる。

**次に読むべき論文は？**

- More than you've asked for: A Comprehensive Analysis of Novel Prompt Injection Threats to Application-Integrated Large Language Models：間接プロンプトインジェクションを最初に体系化した論文であり、本研究の問題設定の背景を理解できる。
- The instruction hierarchy: Training LLMs to prioritize privileged instructions：指示の優先順位を学習させる防御であり、本研究のホワイトボックス防御と比較しながら読める。
- Judging LLM-as-a-judge with MT-Bench and Chatbot Arena：本研究が一般性能の評価（MT-Bench）と能力指標（Arena Elo）に使っているため、評価方法を理解する助けになる。

:::
