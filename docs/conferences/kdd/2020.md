# KDD 2020

🔎 データマイニング・Web ・ [KDD の年ごとの流れ](./) ・ [公式サイト ↗](https://kdd.org/)

::: info この回のまとめ
サンディエゴで予定されていた KDD 2020 は、2020年8月23〜27日にオンラインで開催されました。研究トラックは投稿1,279本・採択216本（16.9%）で、応用データサイエンス（ADS）トラックを含めると投稿は2,000本超、採択は338本でした。研究トラックの最優秀論文は、推薦システムの評価で計算を省くために使われる「サンプリングした評価指標」が、本来の指標と食い違う順位を出しうることを示した研究（Google）です。ADS トラックでは、時間と文脈を考慮したリアルタイム推薦（Amazon）が選ばれました。
:::

- **日程**: 2020年8月23日〜27日
- **開催地**: オンライン開催（当初予定は米国・サンディエゴ）
- **規模**: 投稿 1,279 本 ／ 採択 216 本 ／ 採択率 16.9%（研究トラックの数値。ADS トラックを含む全体では投稿2,000本超・採択338本）

**📝 注目論文（1 本）**

1. [アイテム推薦におけるサンプリングした評価指標について](#paper-1)

## 🔭 この回の主なテーマ

- 推薦システムの評価: サンプリングした指標は正確な指標と矛盾しうる
- 実運用の推薦: 時間と文脈に応じて手動調整なしで動くリアルタイム推薦
- プライバシー: 中間表現を匿名化して未知のタスクにも使えるデータ収集（最優秀学生論文）

::: tip 💡 技術動向への示唆
- 推薦システムのオフライン評価の方法そのものが結論を左右することが示され、実務の A/B テストやオフライン評価の設計を見直すきっかけになった
- 研究トラックと ADS トラックの両輪で、企業の実データに基づく成果が学術的にも評価される KDD の特徴がはっきりした
:::

## 📝 注目論文

### 1. アイテム推薦におけるサンプリングした評価指標について {#paper-1}

🏆 Best Paper（研究トラック） ・ Walid Krichene, Steffen Rendle

<small>原題: On Sampled Metrics for Item Recommendation</small>

推薦の評価では、全アイテムではなく少数の候補をサンプリングして順位を測ることが広く行われていました。この方法が本来の指標と矛盾する結論を導きうることを示し、補正方法を提案しました。
