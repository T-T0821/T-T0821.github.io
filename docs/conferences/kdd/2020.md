### 1. アイテム推薦におけるサンプリングした評価指標について {#paper-1}

🏆 Best Paper（研究トラック） ・ Walid Krichene, Steffen Rendle

<small>原題: On Sampled Metrics for Item Recommendation</small>

推薦の評価では、全アイテムではなく少数の候補をサンプリングして順位を測ることが広く行われていました。この方法が本来の指標と矛盾する結論を導きうることを示し、補正方法を提案しました。

### 2. TIPRDC：匿名化した中間表現を用いるディープラーニングのための、タスク非依存・プライバシー尊重型データクラウドソーシング枠組み {#paper-2}

🏆 Best Student Paper ・ Ang Li, Yixiao Duan, Huanrui Yang, Yiran Chen ほか ・ [論文を読む ↗](https://arxiv.org/abs/2005.11480)

<small>原題: TIPRDC: Task-Independent Privacy-Respecting Data Crowdsourcing Framework for Deep Learning with Anonymized Intermediate Representations</small>

下流の学習タスクをデータ収集者が事前に知らなくても使える、プライバシー保護型のデータクラウドソーシング枠組みを提案した研究です。ユーザー側で中間表現を抽出し、性別・年齢などの指定した秘匿属性を隠しつつ元データの情報をできるだけ残すよう学習する点が特徴で、主タスクの知識を必要としない初の枠組みだと主張しています。CelebA、LFW、DIALでの実験では多くの設定で最良の効用とプライバシーのトレードオフを示し（常に全ベースラインを上回るわけではありません）、KDD 2020 の Best Student Paper に選ばれました。

::: info 📝 落合フォーマット

**どんなもの？**

データ収集者が下流の学習タスクを事前に知らなくても使える、プライバシー保護型のデータクラウドソーシング枠組み TIPRDC を提案した研究。ユーザー側で生の入力から中間表現（特徴）を抽出し、性別・年齢などの指定した秘匿属性を隠しつつ、元データの情報を最大限残す特徴抽出器を学習する。

**先行研究と比べてどこがすごい？**

従来の敵対的学習によるプライバシー保護手法は、主タスクが既知であることを前提としていた。TIPRDC は主タスクの知識を必要としない最初のプライバシー配慮型データクラウドソーシング枠組みだと主張している。画像だけでなくテキストにも適用でき、秘匿属性の除去と元情報の保持を相互情報量の観点で定式化している。

**技術や手法のキモはどこ？**

特徴抽出器・敵対的分類器・相互情報量推定器の3モジュールを End-to-End で学習するハイブリッド手法である。PAT（Privacy Adversarial Training）では、敵対的分類器が特徴から秘匿属性 u を推定し、特徴抽出器はその交差エントロピー損失を最大化して I(z;u) の上界を下げる。MaxMI では Jensen-Shannon 型の相互情報量推定器で I(x; z,u) の下界を最大化し、元情報を保持する。両者は効用とプライバシーのバジェット λ∈[0,1] で重み付けし、バッチごとに交互に更新する。

**どうやって有効だと検証した？**

CelebA、LFW（画像）と DIAL（ツイート、テキスト）を用い、Noisy、DP、Encoder、Hybrid（PCA＋ノイズ）の4つのベースラインと比較した。多くの設定で最良の効用・プライバシーのトレードオフを示し、たとえば LFW で λ=0.9 のとき、秘匿属性 'Asian' の精度は55.31%、タスク 'eyeglass' の精度は86.88%だった。λ=0.9 では敵対者の分類器の構造を変えても性別の精度は59〜61%程度にとどまった。また CelebA と LFW の間のクロスデータセット評価で転移性も確認した。ただし常に全ベースラインを上回るわけではない。

**議論はある？**

λ を小さくすると効用は上がるがプライバシー保護は弱まるため、λ の選択が必要で、本文では λ=0.9 が最適としているが実験設定に依存する。秘匿属性を増やすと、相関する特徴まで隠れて効用がわずかに低下する。保護対象は事前に指定した属性に限られ、相互情報量は上界・下界による近似であり、差分プライバシーのような形式的な保証は与えない。評価は敵対者として特定の分類器を学習させる経験的なものにとどまる。

**次に読むべき論文は？**

- Learning controllable fair representations：I(z;u) の上界と敵対的学習による定式化の根拠となっており、理論的背景を理解できる。
- Learning deep representations by mutual information estimation and maximization：MaxMI で用いる Jensen-Shannon 型の相互情報量推定器の元になった手法である。
- Privacy Adversarial Network: Representation Learning for Mobile Data Privacy：主タスクが既知の場合の敵対的特徴学習の代表的な先行研究で、TIPRDC との違いを比較できる。

:::


### 3. GCC: グラフニューラルネットワーク事前学習のためのGraph Contrastive Coding {#paper-3}

📈 被引用数上位（Paper Digest の集計で同年1位） ・ Jiezhong Qiu, Qibin Chen, Yuxiao Dong, Jing Zhang ほか ・ [論文を読む ↗](https://arxiv.org/abs/2006.09963)

<small>原題: GCC: Graph Contrastive Coding for Graph Neural Network Pre-Training</small>

ラベルや属性を使わない自己教師ありのGNN事前学習フレームワークGCCを提案し、部分グラフのインスタンス識別という汎用的なタスクで、属性なしの社会・情報ネットワークから転移可能な構造パターンを学習する研究です。事前学習済みモデルを未見のグラフやタスクにファインチューニング、または凍結したまま適用でき、H-indexではGCC(MoCo, full)が80.6、GraphWaveの70.3を上回り、COLLABでもGINを上回りました。KDD 2020でPaper Digestの集計により同年被引用数1位となった点も注目されます。

::: info 📝 落合フォーマット

**どんなもの？**

複数のグラフから普遍的で転移可能な構造パターンを捉えるため、ラベルや属性を使わない自己教師ありのGNN事前学習フレームワーク Graph Contrastive Coding (GCC) を提案した研究。事前学習済みモデルを未見のグラフ・タスクにファインチューニング、あるいは凍結したまま適用できることを示した。

**先行研究と比べてどこがすごい？**

従来のネットワーク埋め込み（DeepWalk等）は学習したグラフに紐づき、未見グラフへ転移できなかった。既存のGNN事前学習は属性付きグラフ（分子グラフ等）や人手で定義したタスクに依存していたが、GCCは属性なしの一般的な社会・情報ネットワークを対象に、部分グラフのインスタンス識別という汎用的な事前学習タスクを設計した点が新しい。

**技術や手法のキモはどこ？**

各頂点のr-egoネットワークを1つのインスタンスとみなし、同じegoネットワークから再始動付きランダムウォーク（RWR）で2回サンプリングし、誘導部分グラフ化と匿名化を行ったものを正例ペア、別のegoネットワーク由来を負例とする。エンコーダにはGINを用い、頂点特徴は正規化グラフラプラシアンの上位固有ベクトル（一般化位置埋め込み）、次数のone-hot、ego頂点の指示子で初期化する。損失はInfoNCEで、辞書の維持にはE2EとMoCo（モーメンタム更新）の2方式を比較した。

**どうやって有効だと検証した？**

学術・SNSの6グラフで事前学習し、ノード分類（US-Airport, H-index）、グラフ分類（IMDB-B/M, COLLAB, REDDIT-B/M）、類似度検索（co-authorグラフ）の3タスク・10データセットで評価した。例えばH-indexではGCC(MoCo, full)が80.6、GCC(MoCo, freeze)が75.2でGraphWave(70.3)を上回り、Struc2vecは1日以内に完了しなかった。グラフ分類ではGINと同等水準で、COLLABでは81.1とGIN(80.2)を上回った。ランダム初期化(rand)との比較から、IMDB-Bを除き事前学習が有効と示された。

**議論はある？**

IMDB-Bでは事前学習データとのドメインシフトのためか事前学習の利点が見られず、MoCoの辞書サイズ拡大の効果もコンピュータビジョンほど大きくない（K=16384対1024で精度差は1.0程度）。事前学習データ数を増やすと精度が上がる傾向はあるが、US-Airportでは統計的に有意でない（p=0.231）。対象は属性なしの構造表現に限られる。

**次に読むべき論文は？**

- Momentum Contrast for Unsupervised Visual Representation Learning：GCCが辞書維持に採用したMoCoの仕組みと、モーメンタム更新・辞書サイズの役割を理解するため。
- How Powerful are Graph Neural Networks?：GCCのエンコーダであるGINの表現力と、グラフ分類での比較対象としての性能を確認するため。
- Pre-training graph neural networks：属性付き分子グラフを対象とした既存のGNN事前学習手法で、GCCとの違いを把握するため。

:::


### 4. 点をつなぐ：グラフニューラルネットワークによる多変量時系列予測 {#paper-4}

📈 被引用数上位（Paper Digest の集計で同年2位） ・ Zonghan Wu, Shirui Pan, Guodong Long, Jing Jiang ほか ・ [論文を読む ↗](https://arxiv.org/abs/2005.11650)

<small>原題: Connecting the Dots: Multivariate Time Series Forecasting with Graph Neural Networks</small>

変数間の依存関係（グラフ構造）をデータから自動で学習し、空間依存と時間依存をGNNで同時に捉える汎用フレームワーク MTGNN を提案した研究です。従来の時空間GNNが外部の事前定義グラフに依存していたのに対し、一方向（非対称）な関係を学習するグラフ学習層によりグラフ学習とGNN学習をエンドツーエンドで行え、著者らは多変量時系列を一般にグラフ視点からGNNで扱う初の研究だと主張しています。Traffic などの単一ステップ予測で最良級の結果を示し、METR-LA と PEMS-BAY では事前定義グラフ無しで DCRNN や Graph WaveNet などと同等の性能を達成しており、KDD 2020 の被引用数上位（Paper Digest 集計で同年2位）に選ばれています。

::: info 📝 落合フォーマット

**どんなもの？**

多変量時系列予測のために、変数間の依存関係（グラフ構造）をデータから自動で学習し、グラフニューラルネットワーク（GNN）で空間依存と時間依存を同時に捉える汎用フレームワーク MTGNN を提案した研究。事前定義のグラフが無い一般的な多変量時系列にも、あるデータにも適用できる。

**先行研究と比べてどこがすごい？**

従来の時空間GNNは外部の事前定義グラフに依存していたが、本手法は変数間の一方向（非対称）な関係を学習するグラフ学習層を備え、グラフ学習とGNN学習をエンドツーエンドで同時に行える。著者らは、多変量時系列を一般にグラフ視点からGNNで扱う初の研究と主張している。さらに過平滑化を抑えるmix-hop伝播層と、複数周期を捉えるdilated inception層を新たに導入している。

**技術や手法のキモはどこ？**

グラフ学習層はノード埋め込みから M1M2^T − M2M1^T に tanh・ReLU を適用して非対称な隣接行列を作り、各ノードの上位k個の近傍だけを残して疎にする。mix-hop伝播層は元の状態を比率βで保持しながら伝播し（過平滑化の回避）、各ホップの出力を重み行列で選択して和を取る。時間畳み込みはカーネル長 1×2, 1×3, 1×6, 1×7 のinceptionと指数的に増えるdilationを組み合わせ、グラフ畳み込みと交互に積む。学習ではノードをランダムに分割して部分グラフで学習しメモリ・計算量を削減し、予測長を段階的に伸ばすカリキュラム学習で良い局所最適を目指す。

**どうやって有効だと検証した？**

単一ステップ予測では Traffic、Solar-Energy、Electricity、Exchange-Rate の4データセットで RSE・CORR により比較し、Traffic、Solar-Energy、Electricity でほぼ全ホライズンにおいて最良級の結果を示した。例えば Traffic の RSE はホライズン3, 12, 24でそれぞれ7.24%、3.88%、4.83%低減した。複数ステップ予測では METR-LA と PEMS-BAY で、事前定義グラフを使う DCRNN、STGCN、Graph WaveNet、MRA-BGCN、GMAN などと同等の性能を、事前定義グラフ無しで達成した。METR-LA での アブレーションでは、グラフ畳み込み、mix-hop、inception、カリキュラム学習の各要素が有効であると示された。ノード分割による学習（MTGNN+sampling）でも性能低下は小さい。

**議論はある？**

Exchange-Rate では改善が得られず、著者らはグラフが小さく学習サンプルが少ないことが原因ではないかと推測している。学習するグラフは学習期間にわたって静的であり、動的な空間依存を扱わない設計である（動的にすると収束が難しくなるため）。なお、inceptionの効果はMAEでは僅少でRMSEで顕著といった差もあり、各要素の寄与の解釈には注意が必要である。本文には今後の展望の明示的な記述は確認できない。

**次に読むべき論文は？**

- Graph WaveNet for Deep Spatial-Temporal Graph Modeling：自己適応的な隣接行列を導入した時空間GNNで、本論文のグラフ学習層やdilated畳み込みの直接の先行手法として比較対象になっている。
- Modeling Long- and Short-Term Temporal Patterns with Deep Neural Networks (LSTNet)：多変量時系列予測の代表的な深層学習ベースラインであり、単一ステップ予測のデータセット・評価設定の出典でもある。
- Predict then Propagate: Graph Neural Networks meet Personalized PageRank：mix-hop伝播層で元の状態を保持して過平滑化を避ける発想の元になった研究である。

:::


### 5. クラウドソースされた呼吸音データからのCOVID-19自動診断の探究 {#paper-5}

📈 被引用数上位（Paper Digest の集計で同年3位） ・ Chloë Brown, Jagmohan Chauhan, Andreas Grammenos, Jing Han ほか ・ [論文を読む ↗](https://arxiv.org/abs/2006.05919)

<small>原題: Exploring Automatic Diagnosis of COVID-19 from Crowdsourced Respiratory Sound Data</small>

スマートフォンアプリで集めた約7000ユーザー(陽性申告200人超)の咳・呼吸音という、統制されていない大規模データを用い、COVID-19の音声による事前スクリーニングの可能性を探った研究です。小規模データでの過学習を避けるため、手作り特徴とVGGish転移学習特徴を組み合わせた浅い分類器を採用し、3つの二値分類タスクでROC-AUC 0.80以上を示しました。被引用数が同年3位(Paper Digest集計)と高く、関心の大きさがうかがえます。

::: info 📝 落合フォーマット

**どんなもの？**

スマートフォンアプリ（Web/Android）でクラウドソースした咳・呼吸音のデータセットを用い、COVID-19の音声ベースの事前スクリーニングが可能かを探索した研究。COVID陽性者と健常者、咳のある健常者、咳のある喘息患者を区別する3つの二値分類タスクを構築し、機械学習で識別可能性を示した。

**先行研究と比べてどこがすごい？**

約7000ユーザー（陽性申告200人超）という、統制されていないクラウドソースの大規模COVID-19音データを扱い、咳・呼吸・声など多様な音を2日ごとに繰り返し収集できる点が特徴。先行研究（Imranら）は統制環境の約100サンプルでend-to-end深層学習を用いたが、本研究は小規模データでの過学習を避けるため、手作り特徴とVGGish転移学習特徴を組み合わせた浅い分類器を採用した。

**技術や手法のキモはどこ？**

音声を22kHzにリサンプルしてlibrosaで477次元の手作り特徴（継続時間、onset、tempo、period、RMS、スペクトル重心、MFCCとそのΔ・Δ²の統計量など）を抽出し、VGGishで256次元の埋め込みを得て、これらを連結しPCAで次元削減した。分類器にはロジスティック回帰とRBFカーネルSVMを使い、ユーザー単位で訓練/テストを分離したネスト型交差検証（外側10分割、内側5分割）で評価した。小規模なTask 2・3では、陰性クラスに増幅・白色ノイズ・ピッチ/速度変更のデータ拡張を訓練時のみ適用した。

**どうやって有効だと検証した？**

陽性141サンプル（62人）対非COVID 298サンプルなどの部分集合で評価し、ROC-AUCはTask 1（咳+呼吸）で0.80、Task 2（咳のあるCOVID対咳のある健常者）で0.82、Task 3（咳のあるCOVID対咳のある喘息）で0.80と、全タスクで80%以上となった。データ拡張によりTask 2・3でAUCが約0.87〜0.88、再現率が0.8〜0.9台に向上した。年齢・性別を加えても結果はほぼ変わらず（AUC ±2未満）、手作り特徴とVGGishの併用が単独より良好だった。

**議論はある？**

サンプル数が少なく標準偏差が大きいため結果は予備的であり、単独のスクリーニングツールとするには不十分と著者自身が述べている。ラベルは自己申告で、健常者は「COVIDが流行していない国の無症状者」と仮定しているため正解の信頼性に限界がある。今後は検査結果を正解とする統制データの収集、声の音の活用、他の呼吸器疾患との比較、経時データによる病状進行の解析、より高度な機械学習が挙げられている。

**次に読むべき論文は？**

- AI4COVID-19: AI enabled preliminary diagnosis for COVID-19 from cough samples via an App：本研究が最も近い先行研究と位置づけ、咳からのCOVID-19診断を統制データと深層学習で行っており、手法の違いを比較できる。
- Coswara – A database of breathing, cough, and voice sounds for COVID-19 diagnosis：同様のクラウドソース型COVID-19音データセットであり、データ収集設計の比較に役立つ。
- CNN architectures for large-scale audio classification：本研究が転移学習の特徴抽出器として使うVGGishの元論文で、特徴量の性質を理解できる。
