# KDD

🔎 [データマイニング・Web](../#dm) ・ ACM SIGKDD Conference on Knowledge Discovery and Data Mining ・ 毎年8月 ・ [公式サイト ↗](https://kdd.org/)

::: info 2020年からの流れ
KDD は ACM SIGKDD が主催するデータマイニングの最高峰会議で、研究トラックと応用データサイエンス（ADS）トラックの2本立てが特徴です。最優秀論文は、推薦の評価指標の落とし穴（2020年）、高速なテンソル分解と移動データによる COVID-19 対策（2021年）、ハイパーグラフ上の因果推論（2022年）、グラフのプロンプト学習（2023年）、解釈可能な概念モデルと LinkedIn の GNN（2024年）、見せかけの相関への頑健性と A/B テストの判断ルール（2025年）、ベクトル検索の索引構築とマルチキャリブレーション（2026年）でした。2024年に初めて欧州（バルセロナ）で開催され、2027年はサンノゼで開催予定です。
:::

## 📅 各回のまとめ

- **KDD 2027** — 開催前です<br><small>2027年8月1日〜5日 ・ 米国・サンノゼ</small>
- **[KDD 2026](./2026)** — 済州島開催。行列演算で超高速に近傍探索の索引を作る PiPNN と、Web 規模のマルチキャリブレーション MCGrad が最優秀論文に<br><small>2026年8月9日〜13日 ・ 韓国・済州島</small>
- **[KDD 2025](./2025)** — トロント開催。グループ情報なしで「見せかけの相関」への依存を減らす研究と、多数の A/B テストの判断基準の評価が最優秀論文に<br><small>2025年8月3日〜7日 ・ カナダ・トロント</small>
- **[KDD 2024](./2024)** — バルセロナで初の欧州開催。概念にもとづく解釈可能なモデル CAT と LinkedIn の GNN 基盤が最優秀論文に<br><small>2024年8月25日〜29日 ・ スペイン・バルセロナ</small>
- **[KDD 2023](./2023)** — ロングビーチ開催。グラフニューラルネットにプロンプト学習を持ち込んだ「All in One」が最優秀論文に<br><small>2023年8月6日〜10日 ・ 米国・ロングビーチ</small>
- **[KDD 2022](./2022)** — ワシントン D.C. で3年ぶりの現地開催。ハイパーグラフ上の因果効果推定が研究トラックの最優秀論文に<br><small>2022年8月 ・ 米国・ワシントン D.C.</small>
- **[KDD 2021](./2021)** — 2年連続のオンライン開催。人の移動データで COVID-19 対策を支援するモデルが ADS トラックの最優秀論文に<br><small>2021年8月14日〜18日 ・ オンライン開催</small>
- **[KDD 2020](./2020)** — サンディエゴ開催予定からオンラインへ。推薦の評価で使う「サンプリングした指標」の落とし穴を示した研究が最優秀論文に<br><small>2020年8月23日〜27日 ・ オンライン開催（当初予定は米国・サンディエゴ）</small>

## 🔭 年ごとのテーマの移り変わり

- 2020: 推薦の評価指標の見直し、オンライン開催
- 2021: テンソル分解の効率化、移動データによる感染症対策
- 2022: ハイパーグラフ上の因果推論、連合グラフ学習
- 2023: グラフのプロンプト学習、推薦モデルの学習安定化
- 2024: 解釈可能な概念モデル、実運用の GNN、初の欧州開催
- 2025: 見せかけの相関への頑健性、A/B テストの判断ルール、データセット・ベンチマークトラック新設
- 2026: ベクトル検索の索引構築、マルチキャリブレーション、RAG ベンチマーク

::: tip 💡 技術動向への示唆
- ADS トラックでは Google・LinkedIn など企業の実運用の知見が毎年最高賞を得ており、大規模サービスの機械学習運用のベストプラクティスを知るのに向いている
- 因果推論・解釈性・公平性・較正など「予測を信頼して意思決定に使う」ための研究が増えており、データ分析の成果を業務判断につなげる方法論が整いつつある
:::
