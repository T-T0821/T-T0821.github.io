# ICML 2026

🤖 AI・機械学習全般 ・ [ICML の年ごとの流れ](./) ・ [公式サイト ↗](https://icml.cc/)

::: info この回のまとめ
ソウル（COEX）で開催され、投稿は約2.4万本（前年の約2倍）、採択は6,352本（約26.6%）と過去最大でした。最優秀論文は、拡散言語モデルが任意の順序で生成できる柔軟性がかえって数学・コードの推論を妨げうることを示した「The Flexibility Trap」と、拡散モデルと対数凹分布の高精度サンプリングの理論の2本。佳作には LLM がどれだけ記憶できるかの定量化、グロッキング（学習後半で突然汎化する現象）の証明、RLVR で誠実さがどこで生まれるかを探る研究などが並びました。ポジション論文部門では「アラインメント研究が意図せず検閲の道具箱を作っている」という主張が受賞しています。Test of Time 賞は非同期強化学習の A3C です。
:::

## 🔭 この回の主なテーマ

- 拡散言語モデルと推論: 生成順序の自由度と強化学習の関係を再検討（The Flexibility Trap）
- 生成モデルの理論: 拡散モデルの高精度サンプリング、ランダム行列による一貫性の分析
- LLM の記憶と汎化: 言語モデルの記憶容量の測定、グロッキングの理論的証明
- 安全性の副作用と誠実さ: アラインメント技術の検閲転用リスク、RLVR と欺瞞の検出

::: tip 💡 技術動向への示唆
- 拡散 LLM は「柔軟だから強い」とは限らないことが示され、推論用途では自己回帰的な制約を残す設計が見直されている
- 投稿数が1年で倍増し、AI 研究の量的拡大が止まらない一方、理論研究が最高賞を得ており「なぜ動くか」への関心も強い
- 安全性のための技術が別の目的に転用されうるという指摘は、AI ガバナンスの議論に技術者が関わる必要性を示している
:::

## 📝 注目論文

### 1. 柔軟性の罠：拡散言語モデルにおける任意順序生成の価値を再考する {#paper-1}

🏆 Outstanding Paper ・ Zanlin Ni, Shenzhi Wang, Yang Yue, ほか ・ [論文を読む ↗](https://arxiv.org/abs/2601.15165)

<small>原題: The Flexibility Trap: Rethinking the Value of Arbitrary Order in Diffusion Language Models</small>

拡散 LLM は好きな順序でトークンを生成できるため推論に有利と考えられてきましたが、実際には不確実で重要なトークンを後回しにして探索を早々に打ち切ってしまうことを示し、強化学習の設計を単純化する道を示しました。

::: info 📝 落合フォーマット

**どんなもの？**

拡散言語モデル(dLLM)の任意順序生成は、数学・コーディングなど一般的な推論タスクでは、かえって推論ポテンシャル(Pass@k で測る解空間のカバレッジ)を狭めうることを示した研究。この知見に基づき、RL 学習時に任意順序を放棄して dLLM を自己回帰(AR)ポリシーとして扱い、標準の GRPO をそのまま適用する手法 JustGRPO を提案した。

**先行研究と比べてどこがすごい？**

従来の dLLM 向け RL は、任意順序の柔軟性を保つために、組合せ的なデノイジング軌跡や扱いにくい尤度の近似(ELBO 等)に取り組んできた。本研究は柔軟性そのものが探索を損なうと指摘し、その前提を覆して拡散特有の RL 適応を不要にした。また、任意順序が論理的分岐トークン(Therefore, Since など)を後回しにして分岐点のエントロピーが下がる「entropy degradation」を、解空間縮小の機構として示した。

**技術や手法のキモはどこ？**

dLLM の過去トークンを観測、未来を [MASK] とした入力 x̃_k を作り、位置 k のロジットの Softmax を AR ポリシー π_AR と定義する。これにより系列尤度が各トークン条件付き確率の積として厳密に計算でき、重要度比も定義できるため、標準 GRPO を修正なしで適用できる。AR 制約は RL 学習時の「足場」にとどまり、因果マスクは課さないため双方向注意と並列デコードは保たれる。さらに JustGRPO-Fast は、エントロピー上位25%の位置でのみ確率比を計算して学習を高速化する。

**どうやって有効だと検証した？**

LLaDA-Instruct、Dream-Instruct、LLaDA 1.5 を GSM8K、MATH-500、HumanEval、MBPP で評価し、AR 順序は k=1 では任意順序と同程度でも、k が大きいほど Pass@k が高いことを確認した。ブロックサイズ B を大きくする(任意性が増す)ほど Pass@k が単調に低下し、HumanEval では AR のみが解ける問題が21.3%、任意順序のみが0.6%だった。JustGRPO は系列長256で GSM8K 89.1%、MATH-500 45.1%、HumanEval 49.4%、MBPP 52.4% を達成し、設定を揃えた再現実験でも d1、ESPO、SPG を上回った。EB-Sampler による並列デコードでも精度が保たれ、MBPP では元モデルとの差が1トークン/ステップの+10.6%から約5トークン/ステップの+25.5%に拡大した。

**議論はある？**

主張の対象は数学・コーディングなどの一般推論タスクに限られ、sudoku など任意順序が有利とされるタスクには当てはまらない可能性がある。また、ベースライン比較は設定が不均一で、HumanEval では LLaDOU が高い数値を報告している。さらに、厳密な尤度計算には位置ごとの評価で反復あたりの追加コストがかかり、JustGRPO-Fast で軽減しているものの完全には解消されていない。

**次に読むべき論文は？**

- d1: Scaling reasoning in diffusion large language models via reinforcement learning：dLLM 向け RL の代表的ベースラインであり、本論文が不要とみなした拡散特有の近似との違いを理解できる。
- Principled RL for diffusion LLMs emerges from a sequence-level perspective (ESPO)：系列レベルの ELBO 近似に基づく有力な比較手法で、JustGRPO の厳密尤度アプローチと対比できる。
- Beyond the 80/20 rule: High-entropy minority tokens drive effective reinforcement learning for LLM reasoning：高エントロピーの分岐トークンが探索を駆動するという、本論文の機構説明と JustGRPO-Fast の根拠となる知見を扱っている。

:::
