# ICML

🤖 [AI・機械学習全般](../#ml) ・ International Conference on Machine Learning ・ 毎年7月 ・ [公式サイト ↗](https://icml.cc/)

::: info 2020年からの流れ
ICML は理論と手法の両面に強い会議で、2020〜2022年は対称性・メタ学習・公平性やプライバシーなど「信頼できる ML」の研究が最高賞を多く占めました。ChatGPT 後の2023年からは LLM の透かし（2023年）、世界モデル Genie と商用 LLM への攻撃（2024年）、拡散言語モデルと協働型 LLM（2025年）、拡散 LM の生成順序の罠（2026年）と生成 AI 関連が中心になり、2024年からはポジション論文も表彰対象です。投稿は2026年に約2.4万本と前年の約2倍に急増しました。
:::

## 📅 各回のまとめ

- **ICML 2027** — 開催前です<br><small>2027年7月31日〜8月6日 ・ ブラジル・リオデジャネイロ</small>
- **[ICML 2026](./2026)** — 投稿約2.4万本・ソウル開催。拡散 LM の「自由な生成順序」の罠と、拡散モデルの高精度サンプリング理論が受賞した回<br><small>2026年7月6日〜11日 ・ 韓国・ソウル</small>
- **[ICML 2025](./2025)** — 投稿1.2万本（バンクーバー）。マスク型拡散 LM、受け身でない協働型 LLM、次トークン予測の創造性の限界が受賞した回<br><small>2025年7月13日〜19日 ・ カナダ・バンクーバー</small>
- **[ICML 2024](./2024)** — ウィーン開催。Genie・VideoPoet・SD3 など生成 AI と、本番 LLM の一部を盗み出す攻撃が最優秀論文に並んだ回<br><small>2024年7月21日〜27日 ・ オーストリア・ウィーン</small>
- **[ICML 2023](./2023)** — ChatGPT 後最初の ICML（ホノルル）。LLM の電子透かしと、学習率調整が不要な最適化が最優秀論文になった回<br><small>2023年7月23日〜29日 ・ 米国・ホノルル</small>
- **[ICML 2022](./2022)** — 現地開催の再開（ボルチモア）。公平性・プライバシー・データの難しさなど「信頼できる ML」が最優秀論文の多くを占めた回<br><small>2022年7月17日〜23日 ・ 米国・ボルチモア</small>
- **[ICML 2021](./2021)** — 2年連続オンライン開催。学習の最適化手法そのものを学習する「メタ最適化」や自己教師あり学習の理論が評価された回<br><small>2021年7月18日〜24日 ・ オンライン開催</small>
- **[ICML 2020](./2020)** — ウィーン開催予定から初のオンライン開催へ。集合データの対称性や画像版 GPT など「構造」と「事前学習」が並んだ回<br><small>2020年7月 ・ オンライン開催（当初予定はウィーン）</small>

## 🔭 年ごとのテーマの移り変わり

- 2020: 集合・対称性の学習、画像の生成的事前学習（Image GPT）
- 2021: 展開された計算グラフの勾配推定（PES）、自己教師あり学習の理論
- 2022: 公平性・プライバシー・データの難しさ・共形予測
- 2023: LLM の電子透かし、学習率不要の最適化
- 2024: 世界モデル（Genie）、動画・画像生成、LLM への攻撃、ポジション論文
- 2025: マスク型拡散 LM、次トークン予測の創造性の限界、協働型 LLM
- 2026: 拡散 LM の柔軟性の罠、拡散モデルのサンプリング理論、LLM の記憶容量

::: tip 💡 技術動向への示唆
- 拡散言語モデルが2年連続で最高賞の対象になっており、自己回帰に代わる、または補完するテキスト生成方式として本格的に研究が進んでいる
- ポジション論文の表彰は、査読危機や AI と雇用など、技術の外側の論点も研究コミュニティの重要課題になったことを示す
:::
