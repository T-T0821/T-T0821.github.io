# ICML 2024

🤖 AI・機械学習全般 ・ [ICML の年ごとの流れ](./) ・ [公式サイト ↗](https://icml.cc/)

::: info この回のまとめ
ウィーンで開催され、投稿は約9,500本、採択は約2,600〜2,900本（出典により差あり）と急拡大しました。最優秀論文は10本で、動画から操作可能な2D世界を生成する Genie、LLM で動画を生成する VideoPoet、Stable Diffusion 3 の基礎となった Rectified Flow Transformer、離散データの拡散モデル（SEDD）など生成モデルが半数近くを占めました。一方で、API 経由で商用 LLM の最終層の重みの一部を復元する攻撃や、より説得力のある LLM 同士に議論させると真実に近づくという研究、データセットの多様性を主張するなら測定せよという「ポジション論文」も受賞し、安全性と研究のあり方への関心も示されました。Test of Time 賞は DeCAF（深層特徴の転移学習）です。
:::

## 🔭 この回の主なテーマ

- 世界モデル・動画生成: Genie（操作できる環境の生成）、VideoPoet（LLM による動画生成）
- 拡散・フローの新展開: Rectified Flow Transformer（SD3）、離散拡散（SEDD）
- LLM のセキュリティ: 本番 LLM の埋め込み射影層を API から復元する攻撃
- スケーラブルな監督: LLM 同士の議論（Debate）で人間が正解を見抜きやすくなる
- ポジション論文の導入: 研究の進め方への提言が論文として採択・受賞されるように

::: tip 💡 技術動向への示唆
- 生成 AI が「画像・動画を作る」から「操作可能な環境（世界モデル）を作る」へ広がり、ロボットやゲーム開発への応用が視野に入った
- 商用 LLM も API 経由の攻撃で内部情報が漏れうることが示され、モデル提供側の防御が実務課題になった
- 人間を超える AI をどう監督するかという「スケーラブルな監督」が、実験で検証できる研究テーマになった
:::

### 1. Genie：操作できる環境を生成するモデル {#paper-1}

🏆 Best Paper ・ Jake Bruce, Michael Dennis, Ashley Edwards, ほか ・ [論文を読む ↗](https://arxiv.org/abs/2402.15391)

<small>原題: Genie: Generative Interactive Environments</small>

ラベルのないインターネット上のゲーム動画だけから学習し、画像1枚やテキストから「プレイヤーが操作できる」2D世界を生成します。行動のラベルなしに潜在的な行動を学ぶ点が新しく、世界モデル研究の流れを作りました。

::: info 📝 落合フォーマット

**どんなもの？**

ラベルなしのインターネット動画のみから教師なしで学習した、初の生成的インタラクティブ環境「Genie」を提案した研究。テキスト・合成画像・写真・スケッチなどのプロンプトから、フレーム単位で操作可能な仮想世界を生成できる。11Bパラメータの基盤世界モデルとして位置づけられる。

**先行研究と比べてどこがすごい？**

従来の世界モデルは行動ラベル付きデータを必要とし、動画モデルは動画単位のテキスト制御に留まっていたが、Genieは動画のみを学習データとしてフレーム単位の制御を実現した。潜在行動空間を教師なしで学習することで、大規模なインターネット動画の活用と、未見の画像プロンプトからの環境生成を可能にした。また、ST-transformerに基づくトークナイザ（ST-ViViT）はC-ViViTより計算効率が良く、品質も高い。

**技術や手法のキモはどこ？**

モデルは、動画を離散トークン化するビデオトークナイザ（VQ-VAE+ST-transformer）、連続フレーム間の潜在行動を推定する潜在行動モデル（LAM、VQ-VAE目的、語彙数|A|=8）、次フレームのトークンをMaskGITで自己回帰的に予測するダイナミクスモデルの3要素からなる。全コンポーネントに空間・時間注意を交互に重ねるST-transformerを採用し、計算量がフレーム数に対し線形に増える。潜在行動は加算埋め込みとして与えて制御性を高めている。推論時はLAMを捨て、ユーザーが選んだ離散行動で1フレームずつ生成する。

**どうやって有効だと検証した？**

約3万時間（フィルタ後）の2Dプラットフォーマーゲーム動画で学習し、モデルサイズ40M〜2.7B、バッチサイズを変えたスケーリング実験で、規模拡大に伴い学習損失が一貫して低下することを示した。ロボット動画（RT1等）で学習した2.5BモデルはFVD 82.7を達成し、ラベルなしで一貫した潜在行動を獲得した。CoinRunでは、潜在行動を使った模倣学習が、わずか200個程度の専門家サンプルでオラクルBCと同等のスコアを達成した。アブレーションでは、LAMへの入力はピクセルがトークンよりΔtPSNRで優れ（Platformers: 1.91対1.33）、トークナイザはST-ViViTがFVD 81.4、ΔtPSNR 1.66でViT・C-ViViTを上回った。

**議論はある？**

自己回帰トランスフォーマー特有の非現実的な未来の幻覚、16フレームの記憶長による長期的な一貫性の欠如、約1FPSという低い推論速度がインタラクションの課題として挙げられている。今後は、より大規模なインターネット動画での学習や、汎用エージェント訓練用の多様な環境生成への応用が期待される。なお、モデルの重みやデータセットは非公開とされている。

**次に読むべき論文は？**

- Phenaki: Variable Length Video Generation From Open Domain Textual Description：時間方向を考慮したトークナイザC-ViViTを提案しており、Genieの ST-ViViTと比較される直接の先行研究であるため。
- MaskGIT: Masked Generative Image Transformer：Genieのダイナミクスモデルが採用する、マスクトークン予測による反復生成の基礎手法であるため。
- Playable Video Generation：動画から潜在行動を学習して操作可能な生成を行う、Genieが一般化した直接の先行課題であるため。

:::


### 2. 本番運用中の言語モデルの一部を盗む {#paper-2}

🏆 Best Paper ・ Nicholas Carlini, Daniel Paleka, Krishnamurthy Dj Dvijotham, ほか ・ [論文を読む ↗](https://arxiv.org/abs/2403.06634)

<small>原題: Stealing Part of a Production Language Model</small>

通常の API 問い合わせだけで、OpenAI の商用モデルの隠れ層の次元数と最終射影層の重みを（対称性を除いて）復元できることを示しました。公開前に提供元へ報告され、API 側で対策が取られています。

::: info 📝 落合フォーマット

**どんなもの？**

OpenAIのChatGPT系やGoogleのPaLM-2のようなブラックボックスの商用LLMに対し、通常のAPIアクセスだけでTransformerの最終層である埋め込み射影層（対称性を除く）を復元するモデル窃取攻撃を提案した研究。隠れ次元の特定と、射影行列全体の抽出ができる。OpenAIのada・babbageでは20ドル未満で射影行列全体を抽出し、隠れ次元が1024と2048であることを確認した。gpt-3.5-turboでは正確な隠れ次元を復元している。

**先行研究と比べてどこがすごい？**

従来の高忠実度の窃取攻撃は小規模なReLUネットワークが対象で、入力層から積み上げる方式だったため、Attentionや正規化層を持つ商用LLMには適用できなかった。本研究は最終層から攻める「トップダウン」の方針をとり、商用の大規模Transformerから精密で自明でない情報を取り出すことに初めて成功した。

**技術や手法のキモはどこ？**

最終層は隠れ次元hからより大きな語彙次元lへの射影なので、出力ロジットはh次元の部分空間に収まる。多数のランダムなプロンプトでロジットベクトルを集めて行列Qを作り、特異値分解（SVD）をかける。特異値の乗法的ギャップが最大となる位置からhを推定し、U·Σから射影行列をh×hの線形変換G（W·G）を除いて復元する。実際のAPIは上位K個のlogprobしか返さないため、logit biasで対象トークンをtop-5に押し上げて基準トークンとの差から全ロジットを再構成する。さらに、複数トークンを強制出力させて1クエリあたりの復元量を増やす改良版を用いる。logprobが得られないAPIでも、二分探索などによりコストは高いが抽出できる。

**どうやって有効だと検証した？**

GPT-2、Pythia、LLaMAの6つのオープンモデルでは、隠れ次元を誤差0〜2程度で推定し、射影行列のRMS誤差は3×10^-5〜6×10^-4だった。ランダム初期化モデルとのRMS誤差は2×10^-2で、これと比べて100〜500倍小さい。OpenAIのada・babbage・babbage-002では隠れ次元（1024・2048・1536）がOpenAIにより正しいと確認され、ada・babbageの行列全体の抽出コストは約4ドルと約12ドルだった。gpt-3.5-turbo系では隠れ次元の抽出に200〜800ドルを要したが、行列全体の抽出は重みの安全のため実施せず、2,000〜8,000ドルと推定している。ロジット推定の精度は、4-logprob攻撃が23.0ビット・1ロジットあたり0.25クエリで最良だった。

**議論はある？**

復元できるのは最終層の1層のみで、h×hの変換の曖昧さが残る。非線形性のため他の層へ拡張する明確な方法もない。防御としては、logit biasの削除やlogit biasとlogprobsの併用禁止、ノイズ付加、ブロックリスト化、最終層のアーキテクチャ変更などが挙げられるが、いずれも機能や性能とのトレードオフがある。責任ある開示の結果、OpenAIとGoogleはすでに緩和策を導入済みである。今後の課題として、量子化重みによる対称性の解消や、temperatureやtop-kなど他のAPIパラメータを使った攻撃などが挙げられている。

**次に読むべき論文は？**

- Stealing Machine Learning Models via Prediction APIs：モデル窃取という研究分野の出発点となる論文で、本研究の問題設定の背景を押さえられる。
- High Accuracy and High Fidelity Extraction of Neural Networks：精度（accuracy）と忠実度（fidelity）という窃取の目的の区別や、従来の高忠実度攻撃の限界を理解できる。
- Logits of API-Protected LLMs Leak Proprietary Information：同時期にAPI経由でLLMのロジット情報が漏れる問題を扱った関連研究で、本攻撃との比較に役立つ。

:::


### 3. VideoPoet: ゼロショット動画生成のための大規模言語モデル {#paper-3}

🏆 Best Paper ・ Dan Kondratyuk, Lijun Yu, Xiuye Gu, José Lezama ほか ・ [論文を読む ↗](https://arxiv.org/abs/2312.14125)

<small>原題: VideoPoet: A Large Language Model for Zero-Shot Video Generation</small>

テキスト・画像・動画・音声など多様な入力から音声付きも含む動画を生成する、デコーダのみの大規模言語モデルを、LLMと同様の事前学習とタスク適応の二段階で学習し、T2V、I2V、動画編集、スタイライゼーションを単一モデルで扱えることを示した研究です。拡散モデルが主流の動画生成において、LLM方式でも最先端水準の品質、特に大きく高忠実な動きを実現し、タスクの連鎖による未学習タスクのゼロショット実行や最大10秒の長尺生成も可能にした点が注目されます。約250プロンプトの人間評価では、動きの面白さと現実性で比較手法を大きく上回り、映像品質ではLumiereのみが上回りました。

::: info 📝 落合フォーマット

**どんなもの？**

VideoPoet は、テキスト・画像・動画・音声など多様な入力条件から、音声付きも含む高品質な動画を生成するデコーダのみの大規模言語モデル（LLM）である。LLM と同様の「事前学習＋タスク適応」の二段階で学習し、1つのモデルでT2V、I2V、動画編集、スタイライゼーションなどを実行できる。拡散モデルが主流の動画生成に対し、LLM 方式でも最先端水準の品質、特に大きく高忠実な動きの生成が可能であることを示した。

**先行研究と比べてどこがすごい？**

動画生成の主流である拡散モデル（画像モデルにアダプタ等で機能を追加する方式）に対し、LLM のインフラと学習レシピをそのまま使い、多様なタスクを単一モデル・統一語彙で扱う点が新しい。テキスト付き動画だけでなく、テキストなし動画も複数の自己教師ありタスクに再利用して学習できる。さらに、タスクの連鎖（I2V→スタイライゼーションなど）による未学習タスクのゼロショット実行や、最後の1秒を条件にした自己回帰的な最大10秒の長尺生成も可能にした。

**技術や手法のキモはどこ？**

MAGVIT-v2 で画像・動画を、SoundStream で音声を離散トークン化して統一語彙にし、テキストは凍結した T5 XL の埋め込みとして入力する。プレフィックス付きデコーダのみのトランスフォーマで、&lt;task> トークンと入出力の組合せによりT2V、I2V、将来フレーム予測、インペイント/アウトペイント、音声⇄動画、スタイライゼーション（テキスト＋オプティカルフロー＋深度）などを学習する。系列長ごとにタスクをまとめる Alternating Gradient Descent でパディングをほぼ0%にし、前半25%は画像90%、以降は動画90%とする2段階サンプリングを行う。さらに、窓付き局所注意を用いた非自己回帰の超解像トランスフォーマをトークン空間で2段（各2倍）カスケードし、224×128 から 896×512 を得る。

**どうやって有効だと検証した？**

MSR-VTT、UCF-101（T2V）、Kinetics-600（フレーム予測）、SSv2（インペイント/アウトペイント）でゼロショット評価した。300M モデルのタスク比較では全タスク併用が全体として最良で、8B モデルでは MSR-VTT の FVD が 355、UCF-101 の FVD が 687 などの結果を示した。T2V の比較では、事前学習モデルで MSR-VTT の FVD 213、UCF-101 の FVD 355、IS 38.44 を得て、微調整後は MSR-VTT の CLIPSIM 0.3123 を達成した。約250プロンプトの人間評価では、Show-1、VideoCrafter、Phenaki、Pika、Gen2、WALT、Lumiere と比較し、動きの面白さと現実性で大きく優位で、映像品質では Lumiere のみが上回った。

**議論はある？**

限界として、トークナイザの再構成が視覚的忠実度の上限になること、学習データの方針（LAION など著作権のある画像を除外）により静止シーンの美的品質が最良のベースラインに及ばないこと、動きを伴う小さな物体や細部が難しいことが挙げられている。また300Mモデルではマルチタスク学習がやや劣る場合があり、各タスクの学習不足の可能性が指摘されている。悪用（ディープフェイクなど）への懸念があり、電子透かしなどの対策が述べられている。

**次に読むべき論文は？**

- Language Model Beats Diffusion -- Tokenizer is Key to Visual Generation (MAGVIT-v2)：VideoPoet の視覚トークナイザであり、生成品質の上限を決める設計を理解するため。
- MAGVIT: Masked Generative Video Transformer (COMMIT)：インペイント/アウトペイント等のマルチタスク動画生成と、超解像で用いる非自己回帰トランスフォーマの基礎を押さえるため。
- Lumiere: A Space-Time Diffusion Model for Video Generation：人間評価で映像品質のみ VideoPoet を上回った拡散ベースの比較対象で、両方式の違いを理解するため。

:::


### 4. 高解像度画像合成に向けた Rectified Flow Transformer のスケーリング {#paper-4}

🏆 Best Paper ・ Patrick Esser, Sumith Kulal, Andreas Blattmann, Rahim Entezari ほか ・ [論文を読む ↗](https://arxiv.org/abs/2403.03206)

<small>原題: Scaling Rectified Flow Transformers for High-Resolution Image Synthesis</small>

高解像度のテキスト画像生成に向けて、Rectified Flow のタイムステップサンプリングを改良し、テキストと画像で別々の重みを持ちトークンを双方向に混合する Transformer「MM-DiT」を提案した研究です。これまで小〜中規模での検証が中心だった Rectified Flow を、61種類の定式化の系統的な比較と最大8Bパラメータまでのスケーリングで検証し、検証損失が予測可能に低下して自動評価・人手評価の向上と相関することを示した点が注目されます。最大の8Bモデルは SDXL や DALL-E 3 などを、プロンプト理解の定量評価と人手選好評価で上回ったと報告されており、ICML 2024 の Best Paper に選ばれました。

::: info 📝 落合フォーマット

**どんなもの？**

高解像度テキスト画像生成に向けて、Rectified Flow の学習時ノイズ（タイムステップ）サンプリングを改良し、テキストと画像で別々の重みを持つ新しい Transformer アーキテクチャ MM-DiT を提案した研究。最大8Bパラメータまでスケールさせ、検証損失が予測可能にスケールすることと、それが自動評価・人手評価の向上と相関することを示した。

**先行研究と比べてどこがすごい？**

Rectified Flow は理論的には優れるが、これまでは小〜中規模でクラス条件付きモデル中心の検証に留まっていた。本研究は大規模・系統的な比較により、中間タイムステップを重視するサンプラー（logit-normal 等）で従来の拡散定式化を上回ることを示した。また、固定のテキスト表現をクロスアテンションで入れる従来方式と異なり、画像・テキストのトークンを双方向に混合する構造を採用した。

**技術や手法のキモはどこ？**

RF の損失をタイムステップ密度 π(t) による重み付き損失として扱い、速度予測が難しい中間の t を多く引くために logit-normal、heavy-tail の mode sampling、CosMap などのサンプラーを導入した。MM-DiT は、画像とテキストで独立した重みを持つ2系統のTransformerを使い、アテンション時のみ系列を連結して相互参照させる構造である。さらに、学習安定化のためのQ・KへのRMSNorm（QK正規化）、解像度に応じたタイムステップのシフト（式23、1024²ではα=3.0）、可変アスペクト比のための位置エンコーディング、16チャネルのオートエンコーダ、CogVLMによる合成キャプションと元キャプションの50/50混合を組み合わせている。

**どうやって有効だと検証した？**

ImageNetとCC12Mで61種類の定式化を、CLIPスコアとFID、複数のサンプラー設定について非支配ソートで順位付けした。rf/lognorm(0.00, 1.00) は一貫して上位で、一様サンプリングのRFやLDM-Linear（eps/linear）を上回り、サンプリングステップを減らしたときの劣化もRFは小さかった。MM-DiTはDiT、CrossDiT、UViTより良好で、GenEvalの総合スコアは合成キャプション混合により43.27から49.78に向上した。スケーリング研究では検証損失がモデルサイズと学習ステップに対して滑らかに低下し、GenEval、人手評価、T2I-CompBenchと強く相関した。最大の8BモデルはSDXL、SDXL-Turbo、Pixart-α、DALL-E 3などを、プロンプト理解の定量評価と人手選好評価で上回ったと報告されている。

**議論はある？**

解像度シフト値の決定は「全画素が一定」という非現実的な仮定に基づく導出に、人手評価で補った経験的なものであり、QK正規化も万能な処方箋ではなく学習設定に応じた調整が必要だと著者自身が述べている。また、評価した定式化はCLIPとFIDで得意・不得意が分かれ、サンプリングステップ数によって最良の設定が変わるなど、条件依存性が残る。提供された本文は途中で省略されているため、動画モデルでの検証や付録の詳細（DPOによるアライメントなど）は本稿の情報だけでは評価できない。

**次に読むべき論文は？**

- Scalable Diffusion Models with Transformers：MM-DiTのベースとなるDiTアーキテクチャと、モジュレーションによる条件付けの仕組みを理解するため。
- Flow Matching for Generative Modeling：本論文の学習目的である条件付きフロー・マッチングと確率パスの理論的基礎を押さえるため。
- Elucidating the Design Space of Diffusion-Based Generative Models：本論文が比較対象とするEDMの定式化と、ノイズスケジュール設計の考え方を理解するため。

:::


### 5. Vision Mamba: 双方向状態空間モデルによる効率的な視覚表現学習 {#paper-5}

📈 被引用数上位（Paper Digest の集計で同年2位） ・ Lianghui Zhu, Bencheng Liao, Qian Zhang, Xinlong Wang ほか ・ [論文を読む ↗](https://arxiv.org/abs/2401.09417)

<small>原題: Vision Mamba: Efficient Visual Representation Learning with Bidirectional State Space Model</small>

Mamba（選択的状態空間モデル）を画像向けに拡張し、self-attentionを使わずSSMのみで構成した汎用ビジョンバックボーン「Vision Mamba（Vim）」を提案した研究です。ImageNet分類・COCO検出・ADE20Kセグメンテーションで同規模のDeiTを上回り、1248×1248の画像のバッチ推論ではDeiTより2.8倍高速でGPUメモリを86.8%削減しており、高解像度での効率の高さが注目されます。密予測タスクを扱えた最初の純SSMモデルだと主張されており、被引用数でもICML 2024の上位（Paper Digest集計で同年2位）に入っています。

::: info 📝 落合フォーマット

**どんなもの？**

Mamba（選択的状態空間モデル）を画像向けに拡張し、self-attentionを使わずSSMのみで構成した汎用ビジョンバックボーン「Vision Mamba（Vim）」を提案した研究。ImageNet分類、COCO検出、ADE20Kセグメンテーションで、高解像度時の計算・メモリ効率に優れつつDeiTを上回る性能を示した。

**先行研究と比べてどこがすごい？**

従来の視覚向けSSMはタスク特化型か、CNNやattentionとのハイブリッドが中心だった。Vimは画像をパッチ列として扱う純粋なSSMバックボーンであり、密予測タスクを扱えた最初の純SSMモデルだと主張している。2次元の帰納バイアスを入れず、ViTと同様の系列的・モダリティ非依存の表現学習を保っている。

**技術や手法のキモはどこ？**

画像をパッチに分割して線形射影し、位置埋め込みとクラストークンを加えた系列をVimブロックに通す。Vimブロックは、前向きと後ろ向きの両方向にそれぞれConv1dと選択的SSMを適用し、zでゲートして足し合わせる双方向構造をとる。MambaのハードウェアアウェアなSRAM内計算と再計算によりIOとメモリを削減し、計算量は系列長に対して線形になる。分類トークンは系列の中央に置く設計が最良だった。

**どうやって有効だと検証した？**

ImageNet-1KでVim-Tiが76.1%、Vim-Sが80.3%、Vim-Bが81.9%を達成し、DeiT-Ti/S/Bをそれぞれ3.9/0.5/0.1ポイント上回った。長系列ファインチューニング後はVim-S†が81.4%でDeiT-B級の精度になった。ADE20KではVim-Tiが41.0 mIoUでDeiT-Tiより1.8高く、Vim-Sは44.9 mIoUでDeiT-Sより0.9高かった。COCOではVim-TiがDeiT-Tiより box AP で1.3、mask AP で1.1高かった。1248×1248の画像でのバッチ推論では、DeiTより2.8倍高速で、GPUメモリを86.8%削減した。

**議論はある？**

本文中の実験は教師あり分類での事前学習に限られ、マスク画像モデリングなどの大規模な教師なし事前学習やCLIP型のマルチモーダル学習は今後の課題とされている。また、効率の優位は高解像度で顕著になる一方、512×512ではDeiTと同程度のFPS・メモリである。医用画像、リモートセンシング、長尺動画など超高解像度・長系列への応用が展望として挙げられている。

**次に読むべき論文は？**

- Mamba: Linear-time sequence modeling with selective state spaces：Vimの基盤となる選択的SSMとハードウェアアウェアなアルゴリズムの詳細を理解するため。
- VMamba: Visual state space model：多方向スキャンと階層構造を使う同時期の視覚向けMambaで、Vimとの設計の違いを比較できるため。
- Efficiently modeling long sequences with structured state spaces：S4はMambaやVimにつながるSSMの原点であり、連続系から離散化・畳み込み表現までの基礎が学べるため。

:::
