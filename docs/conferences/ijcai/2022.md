# IJCAI 2022

🏛️ AI全般（老舗・総合） ・ [IJCAI の年ごとの流れ](./) ・ [公式サイト ↗](https://www.ijcai.org/)

::: info この回のまとめ
欧州の AI 会議 ECAI と合同の IJCAI-ECAI 2022 として、ウィーンで現地開催されました。投稿4,535本・採択679本（約14.9%）です。最優秀論文は3本で、有権者の好みを距離で表したとき最適な「歪み」を達成するシンプルな投票ルール Plurality Veto、量化ブール式の SAT ソルバーの学習戦略の比較、化合物の合成経路を逆向きに探す逆合成への証明数探索の応用でした。研究功績賞は Stuart Russell 氏、Computers and Thought 賞は機械学習の信頼性・安全性の Bo Li 氏です。
:::

### 1. Plurality Veto：最適な距離歪みを達成するシンプルな投票ルール {#paper-1}

🏆 Distinguished Paper ・ Fatih Erdem Kizilkaya, David Kempe ・ [論文を読む ↗](https://arxiv.org/abs/2206.07098)

<small>原題: Plurality Veto: A Simple Voting Rule Achieving Optimal Metric Distortion</small>

有権者と候補者の好みを「距離」として捉えたとき、選ばれた候補が最適な候補に比べてどれだけ悪くなりうるか（歪み）を最小にする投票ルールは複雑なものしか知られていませんでしたが、各候補の得票数から順に拒否票を引いていくだけの単純なルールで最適値3を達成できることを示しました。

::: info 📝 落合フォーマット

**どんなもの？**

有権者と候補者が計量空間に埋め込まれ、有権者は近い候補者ほど上位に順位付けするというメトリック・ディストーションの枠組みで、歪み（distortion）3を達成する非常に単純な投票ルール PluralityVeto を提案した研究。さらに、これを k ラウンドだけ実行して残りスコアに比例して当選者を選ぶランダム化ルール（k-Round PluralityVeto）に一般化し、期待ディストーションが任意の k で高々3であることを示した。

**先行研究と比べてどこがすごい？**

決定論的ルールの下限3を達成する先行結果（Gkatzelis らの PluralityMatching）は、二部グラフの完全マッチングに基づく非構成的な存在証明と複雑な探索に依存していた。本研究は、各候補者の初期スコアを第1位票数とし、有権者が順に残存候補の最下位を拒否するだけという極めて単純な構成で同じ最適値3を達成し、証明も1段落で済む。また各有権者への問い合わせは2回程度で通信量が小さく（有権者あたり O(log m) ビット）、多勝者ルールで多項式時間かつ歪み3という Caragiannis らの未解決問題にも解答を与えた。

**技術や手法のキモはどこ？**

各候補者のスコアを plurality スコア（第1位票数）で初期化し、n人の有権者を任意の順に処理して、各有権者が残存候補のうち自分の最下位の候補のスコアを1減らし、0になった候補は脱落させる。スコアの総和は n なので最終的に全員が脱落し、最後に残った候補が当選する。証明は、ドミネーション・グラフ G(c) が完全マッチングを持てば c の歪みが高々3という補題を利用し、拒否の過程から該当マッチングを構成する形で行われる。ランダム化版は k ラウンドで止め、残りスコアに比例した確率で当選者を選ぶ。k=0 で Random Dictatorship、k=n-1 で PluralityVeto に一致する。さらに整数でなく分数的に減らす FractionalVeto により Ranking-Matching Lemma の構成的証明も与える。

**どうやって有効だと検証した？**

実験ではなく理論的な証明による検証である。PluralityVeto は歪み3を達成し、第1位票が過半数の候補は処理順に関わらず当選することが示された。k-Round PluralityVeto は任意の k で期待歪みが高々3であり、k=0 の Random Dictatorship は既知の 3-2/n に対応する。また、第1位票を持つ候補しか選べないルールの歪みは 3-o(1) 以上という既存の下限により、この上界はほぼ最適とされる。

**議論はある？**

ランダム化ルールでも歪み3を超える改善（3-Ω(1) など）が可能かは未解決であり、k は出力の分散を制御するが歪みの上界自体は改善しない。また実装には有権者を逐次的に問い合わせる n ラウンドの手続きが必要で、並列性や戦略的操作への耐性は本文からは明確でなく、実データでの評価も示されていない。

**次に読むべき論文は？**

- Resolving the Optimal Metric Distortion Conjecture：歪み3を初めて達成した PluralityMatching と Ranking-Matching Lemma の原典で、本研究が簡略化した対象である。
- An Analysis Framework for Metric Voting Based on LP Duality：ドミネーション・グラフとフローを用いた上界証明の枠組みを与えており、本論文の証明の土台になっている。
- The Metric Distortion of Multiwinner Voting：本研究が未解決問題を解決した多勝者ルールの歪みの設定と還元手法を理解できる。

:::


### 2. 機械学習におけるシャープレイ値 {#paper-2}

📈 被引用数上位（Paper Digest の集計で同年1位） ・ Benedek Rozemberczki, Lauren Watson, Péter Bayer, Hao-Tsung Yang ほか ・ [論文を読む ↗](https://arxiv.org/abs/2202.05594)

<small>原題: The Shapley Value in Machine Learning</small>

協力ゲーム理論の解概念であるシャープレイ値について、基礎概念と公理的性質を整理し、特徴選択・説明可能性・マルチエージェント強化学習・アンサンブル剪定・データ評価・連合学習への応用をサーベイした論文です。分野ごとに扱われてきた重要度・貢献度の問題を、転移可能効用（TU）協力ゲームという統一的な枠組みで捉え、応用ごとのゲーム定式化、近似手法、計算時間を比較しています。近似下では公理が成り立たない問題を最大の未解決課題として示している点や、Paper Digestの集計で同年の被引用数1位だった点でも注目されます。

::: info 📝 落合フォーマット

**どんなもの？**

協力ゲーム理論の解概念であるシャープレイ値が機械学習で幅広く使われていることを踏まえ、基礎概念と公理的性質を整理し、特徴選択・説明可能性・マルチエージェント強化学習・アンサンブル剪定（モデル評価）・データ評価・連合学習への応用をサーベイした論文。あわせてシャープレイ値の限界と今後の研究方向を示している。

**先行研究と比べてどこがすごい？**

個別の分野ごとに扱われてきた重要度・貢献度の問題を、プレイヤー集合と特性関数を定義する転移可能効用（TU）協力ゲームという統一的な枠組みで整理した点が特徴である。応用ごとにゲームの定式化（プレイヤー、ペイオフ）、近似手法、計算時間を表（Table 2）で比較している。また、近似下では公理が成り立たない問題を最大の未解決課題として明示している。

**技術や手法のキモはどこ？**

シャープレイ値を、全順列にわたるプレイヤーの限界貢献の平均として定義し、ヌルプレイヤー・効率性・対称性・線形性の4公理で特徴づけられることを示す。計算量が指数的になるため、モンテカルロ順列サンプリング（層化抽出や対称サンプリングなどの分散削減を含む）、多重線形拡張、重み付き最小二乗による線形回帰近似（SHAP）といった近似法を整理している。各応用については、特徴・データ点・データサイロ・ニューロン・エッジ・エージェント・モデルなどをプレイヤーとする個別のゲームを定義している。

**どうやって有効だと検証した？**

本論文はサーベイであり、独自の実験は行っていない。3人ゲームの例で全6順列の限界貢献を手計算し、シャープレイ値が32/6、50/6、68/6になることを示している。応用については、既存研究のペイオフ定義、近似手法、計算時間の比較表で整理している。

**議論はある？**

限界として、計算時間（厳密計算は階乗時間）、解釈の難しさ（値の大小を実務上の行動に結びつけにくい）、近似下で公理が保証されない点を挙げ、最後の点を最大の未解決課題としている。今後の方向としては、オーウェン値やウィンター値などの階層的な提携構造、重複提携を扱う配置ゲーム、コアや核仁など他の解概念の活用を挙げている。

**次に読むべき論文は？**

- A Unified Approach to Interpreting Model Predictions：シャープレイ値に基づく説明手法SHAPの原典で、線形回帰近似の仕組みを理解できる。
- Data Shapley: Equitable Valuation of Data for Machine Learning：データ評価へのシャープレイ値適用の代表的研究で、データ評価ゲームの具体的な定式化と近似を学べる。
- Problems with Shapley-Value-Based Explanations as Feature Importance Measures：本論文が指摘する解釈性の限界を、批判的な視点から詳しく検討している。

:::


### 3. クロスモダリティ画像生成と位置合わせによる、位置ずれのある赤外線・可視画像の教師なし融合 {#paper-3}

📈 被引用数上位（Paper Digest の集計で同年2位） ・ Di Wang, Jinyuan Liu, Xin Fan, Risheng Liu ・ [論文を読む ↗](https://arxiv.org/abs/2205.11876)

<small>原題: Unsupervised Misaligned Infrared and Visible Image Fusion via Cross-Modality Image Generation and Registration</small>

位置ずれ（シフト・変形）のある赤外線画像と可視画像を、事前の手動位置合わせなしで融合し、ゴーストを抑える教師なしフレームワークを提案した研究です。可視画像から疑似赤外画像を生成して単一モダリティの位置合わせに帰着させる生成-位置合わせパラダイム（CGRP）を赤外・可視融合に適用し、特徴を適応的に選択する相互作用融合モジュール（IFM）も備えています。TNOとRoadSceneでの評価では、FlowNet+STNやVoxelMorphが改善に乏しいなか、CGRPはMIで改善を示し、融合ではCC・VIF・SSIMの全指標で最良となり、IJCAI 2022で被引用数上位（Paper Digestの集計で同年2位）に入った点でも注目されます。

::: info 📝 落合フォーマット

**どんなもの？**

位置ずれ（シフト・変形）のある赤外線画像と可視画像を、事前の手動位置合わせなしで融合し、ゴースト（二重像）を抑える教師なしフレームワークを提案した研究。可視画像から疑似赤外画像を生成し、歪んだ赤外画像との単一モダリティ位置合わせに帰着させたうえで融合する。

**先行研究と比べてどこがすごい？**

クロスモダリティ位置合わせを「画像生成→単一モダリティ位置合わせ」に置き換える生成-位置合わせパラダイム（CGRP）を赤外・可視融合に適用した点が新しい。赤外画像の「テクスチャよりも構造重視」という性質に合わせ、CycleGAN系の構造に知覚・スタイル損失とパス間のクロス正則化を加えて鋭い構造の疑似赤外画像を生成する。さらに特徴を適応的に選択する相互作用融合モジュール（IFM）で、連結や加重平均によるテクスチャの平滑化を避ける。

**技術や手法のキモはどこ？**

CPSTNは9個のResNetブロックを持つUNet型生成器で、可視画像から疑似赤外画像を作る。MRRNは共有多段特徴抽出器と粗から細への変形場推定を行い、STN類似のリサンプラで位置合わせ済み赤外画像を再構成する。DIFNは残差密結合ネットワークで特徴を抽出し、IFMで両モダリティの1×1畳み込み特徴の積にSigmoidをかけた注意マップで再較正して融合する。損失は知覚・スタイル損失、クロス正則化（内容・エッジ）、GAN損失、双方向類似度と平滑化の位置合わせ損失、MS-SSIM・結合勾配・顕著性の融合損失の和である。

**どうやって有効だと検証した？**

TNOとRoadSceneにアフィン・弾性変形を人工的に加えた画像で評価した。位置合わせではFlowNet+STNやVoxelMorphが改善に乏しく入力より悪化する場合もあったが、提案CGRPはMIでTNOに約0.10、RoadSceneに約0.23の改善を示した。融合では、FlowNet+STNまたはVoxelMorphと組み合わせた既存7手法を含む比較で、CC・VIF・SSIMの全指標で最良となり、VIFはGAN-FMに対しTNOで0.33、RoadSceneで0.46上回った。アブレーションでCPSTN・MRRN・IFMの有効性を確認し、CPSTNは既存手法に組み込んでも融合性能を改善した。

**議論はある？**

評価は既に位置合わせ済みのデータに人工的な変形を加えたものに限られ、実際のセンサ由来のずれでの検証は本文に示されていない。TNOはテスト専用で枚数も限られ、効率比較も登録と融合を合わせた提案手法と融合のみの他手法という条件の違いがある。今後は実環境の位置ずれデータでの検証や、他の融合手法・モダリティへの拡張が課題となる。

**次に読むべき論文は？**

- Unsupervised multi-modal image registration via geometry preserving image-to-image translation：画像変換でクロスモダリティ位置合わせを行う直接の先行研究で、本手法のCPSTNがこれを改良したものと位置づけられているため。
- Unpaired image-to-image translation using cycle-consistent adversarial networks：CPSTNの基盤であるCycleGANの循環一貫性学習を理解するため。
- An unsupervised learning model for deformable medical image registration：比較対象かつMRRNの変形場推定の背景となるVoxelMorphの基礎を押さえるため。

:::


### 4. 視覚言語事前学習モデルのサーベイ {#paper-4}

📈 被引用数上位（Paper Digest の集計で同年3位） ・ Yifan Du, Zikang Liu, Junyi Li, Wayne Xin Zhao ・ [論文を読む ↗](https://arxiv.org/abs/2202.10936)

<small>原題: A Survey of Vision-Language Pre-Trained Models</small>

画像とテキストを統合的に扱う視覚言語事前学習モデル（VL-PTM）について、画像・テキストの符号化、両モダリティの相互作用を扱うアーキテクチャ、事前学習タスク、下流タスクへの適用、今後の研究方向を体系的に整理したサーベイである。既存のサーベイが V-L タスクやデータセット中心、あるいは動画言語 PTM に限定されていたのに対し、画像を対象とした VL-PTM を包括的にレビューし、代表モデルを一覧化して一貫した枠組みで整理している。被引用数が上位（Paper Digest の集計で同年3位）であることも、この分野の入口として広く参照されていることを示している。

::: info 📝 落合フォーマット

**どんなもの？**

視覚と言語を統合的に扱う事前学習モデル（VL-PTM）の研究動向を整理したサーベイ論文。画像・テキストの符号化、両モダリティの相互作用を扱うアーキテクチャ、事前学習タスク、下流タスクへの適用、今後の研究方向を体系的にまとめている。

**先行研究と比べてどこがすごい？**

既存のサーベイは V-L タスク・データセット・従来手法が中心（Mogadala et al.）か、動画言語 PTM に限定（Ruan and Jin）されていた。本論文は画像を対象とした VL-PTM の包括的なレビューとして、代表モデルを表1で一覧化し、エンコーダ設計・事前学習タスク・下流適用を一貫した枠組みで整理している点が特徴である。

**技術や手法のキモはどこ？**

VL-PTM の構築を「画像・テキストの符号化」「モダリティ間相互作用のモデル化」「事前学習タスクの設計」の3段階で整理している。アーキテクチャは fusion encoder（single stream / dual stream）、dual encoder、両者の併用（FLAVA、VLMo の MoME）に分類。事前学習タスクは cross-modal MLM、MRP（MRC・MRFR）、ITM、CMCL に分け、数式と代表モデルの工夫（マスク戦略、モーメンタム蒸留など）を示している。

**どうやって有効だと検証した？**

サーベイのため独自の実験は行っていない。引用として、LXMERT が 9.18M の画像テキスト対で事前学習し VQA・NLVR2 で従来モデルを大きく上回ったこと、ALIGN が 675.4M パラメータ・18億画像テキスト対で、ほぼ全ての下流タスクで最高性能を達成したこと、WenLan が 6.5億対に拡張したことなどを報告している。また CLIP などの dual encoder は検索に強い一方、NLVR など難しい理解タスクには弱いという傾向を整理している。

**議論はある？**

今後の課題として、統一モデルアーキテクチャ（UNIMO や FLAVA は一部タスクでタスク特化ベースラインに劣る）、量子化・枝刈りなどモデル圧縮と推論高速化、敵対的学習や段階的事前学習などの高度な事前学習手法、より大規模で高品質なデータとパラメータによる性能の限界追求を挙げている。

**次に読むべき論文は？**

- Learning Transferable Visual Models From Natural Language Supervision (CLIP)：dual encoder と対照学習による大規模事前学習の代表例で、ゼロショット転移の基礎を理解できる。
- Align before Fuse: Vision and Language Representation Learning with Momentum Distillation (ALBEF)：ViT ベースの dual stream 構成とモーメンタム蒸留を用いた対照学習の具体的な設計を学べる。
- VLMo: Unified Vision-Language Pre-training with Mixture-of-Modality-Experts：fusion encoder と dual encoder を MoME で単一モデルに統合する、本サーベイが注目する手法である。
