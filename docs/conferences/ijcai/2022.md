# IJCAI 2022

🏛️ AI全般（老舗・総合） ・ [IJCAI の年ごとの流れ](./) ・ [公式サイト ↗](https://www.ijcai.org/)

::: info この回のまとめ
欧州の AI 会議 ECAI と合同の IJCAI-ECAI 2022 として、ウィーンで現地開催されました。投稿4,535本・採択679本（約14.9%）です。最優秀論文は3本で、有権者の好みを距離で表したとき最適な「歪み」を達成するシンプルな投票ルール Plurality Veto、量化ブール式の SAT ソルバーの学習戦略の比較、化合物の合成経路を逆向きに探す逆合成への証明数探索の応用でした。研究功績賞は Stuart Russell 氏、Computers and Thought 賞は機械学習の信頼性・安全性の Bo Li 氏です。
:::

- **日程**: 2022年7月
- **開催地**: オーストリア・ウィーン（ECAI と合同）
- **規模**: 投稿 4,535 本 ／ 採択 679 本 ／ 採択率 14.9%

## 📝 注目論文

### 1. Plurality Veto：最適な距離歪みを達成するシンプルな投票ルール {#paper-1}

🏆 Distinguished Paper ・ Fatih Erdem Kizilkaya, David Kempe ・ [論文を読む ↗](https://arxiv.org/abs/2206.07098)

<small>原題: Plurality Veto: A Simple Voting Rule Achieving Optimal Metric Distortion</small>

有権者と候補者の好みを「距離」として捉えたとき、選ばれた候補が最適な候補に比べてどれだけ悪くなりうるか（歪み）を最小にする投票ルールは複雑なものしか知られていませんでしたが、各候補の得票数から順に拒否票を引いていくだけの単純なルールで最適値3を達成できることを示しました。

::: info 📝 落合フォーマット

**どんなもの？**

有権者と候補者が計量空間に埋め込まれ、有権者は近い候補者ほど上位に順位付けするというメトリック・ディストーションの枠組みで、歪み（distortion）3を達成する非常に単純な投票ルール PluralityVeto を提案した研究。さらに、これを k ラウンドだけ実行して残りスコアに比例して当選者を選ぶランダム化ルール（k-Round PluralityVeto）に一般化し、期待ディストーションが任意の k で高々3であることを示した。

**先行研究と比べてどこがすごい？**

決定論的ルールの下限3を達成する先行結果（Gkatzelis らの PluralityMatching）は、二部グラフの完全マッチングに基づく非構成的な存在証明と複雑な探索に依存していた。本研究は、各候補者の初期スコアを第1位票数とし、有権者が順に残存候補の最下位を拒否するだけという極めて単純な構成で同じ最適値3を達成し、証明も1段落で済む。また各有権者への問い合わせは2回程度で通信量が小さく（有権者あたり O(log m) ビット）、多勝者ルールで多項式時間かつ歪み3という Caragiannis らの未解決問題にも解答を与えた。

**技術や手法のキモはどこ？**

各候補者のスコアを plurality スコア（第1位票数）で初期化し、n人の有権者を任意の順に処理して、各有権者が残存候補のうち自分の最下位の候補のスコアを1減らし、0になった候補は脱落させる。スコアの総和は n なので最終的に全員が脱落し、最後に残った候補が当選する。証明は、ドミネーション・グラフ G(c) が完全マッチングを持てば c の歪みが高々3という補題を利用し、拒否の過程から該当マッチングを構成する形で行われる。ランダム化版は k ラウンドで止め、残りスコアに比例した確率で当選者を選ぶ。k=0 で Random Dictatorship、k=n-1 で PluralityVeto に一致する。さらに整数でなく分数的に減らす FractionalVeto により Ranking-Matching Lemma の構成的証明も与える。

**どうやって有効だと検証した？**

実験ではなく理論的な証明による検証である。PluralityVeto は歪み3を達成し、第1位票が過半数の候補は処理順に関わらず当選することが示された。k-Round PluralityVeto は任意の k で期待歪みが高々3であり、k=0 の Random Dictatorship は既知の 3-2/n に対応する。また、第1位票を持つ候補しか選べないルールの歪みは 3-o(1) 以上という既存の下限により、この上界はほぼ最適とされる。

**議論はある？**

ランダム化ルールでも歪み3を超える改善（3-Ω(1) など）が可能かは未解決であり、k は出力の分散を制御するが歪みの上界自体は改善しない。また実装には有権者を逐次的に問い合わせる n ラウンドの手続きが必要で、並列性や戦略的操作への耐性は本文からは明確でなく、実データでの評価も示されていない。

**次に読むべき論文は？**

- Resolving the Optimal Metric Distortion Conjecture：歪み3を初めて達成した PluralityMatching と Ranking-Matching Lemma の原典で、本研究が簡略化した対象である。
- An Analysis Framework for Metric Voting Based on LP Duality：ドミネーション・グラフとフローを用いた上界証明の枠組みを与えており、本論文の証明の土台になっている。
- The Metric Distortion of Multiwinner Voting：本研究が未解決問題を解決した多勝者ルールの歪みの設定と還元手法を理解できる。

:::
