# IJCAI 2020

🏛️ AI全般（老舗・総合） ・ [IJCAI の年ごとの流れ](./) ・ [公式サイト ↗](https://www.ijcai.org/)

::: info この回のまとめ
環太平洋の AI 会議 PRICAI との合同で横浜開催が予定されていましたが、COVID-19 のため半年延期され、2021年1月に完全オンラインで開催されました。投稿4,717本・採択592本（約12.6%）と、主要会議の中でも特に狭き門です。研究功績賞（Award for Research Excellence）は制約充足の Eugene Freuder 氏、若手向けの Computers and Thought 賞は計算社会選択の Piotr Skowron 氏でした。JAIR 最優秀論文賞には、低レベルの技能から計画用の記号表現を学ぶ研究が選ばれ、学習と記号推論の橋渡しが評価されました。
:::

- **日程**: 2021年1月
- **開催地**: オンライン開催（当初予定は横浜。2021年1月に延期）
- **規模**: 投稿 4,717 本 ／ 採択 592 本 ／ 採択率 12.6%

**📝 注目論文（3 本）**

1. [言語上のソフトな推論器としてのTransformer](#paper-1)
2. [LogiQA: 論理推論を伴う機械読解のためのチャレンジデータセット](#paper-2)

## 🔭 この回の主なテーマ

- 学習と記号推論の統合: 技能から計画用の記号表現を学ぶ研究が JAIR 最優秀論文賞
- マルチエージェント経路計画: 衝突ベース探索（CBS）が AIJ Prominent Paper 賞
- 計算社会選択・制約充足: 受賞者の顔ぶれに古典的 AI の強さが表れた

::: tip 💡 技術動向への示唆
- 倉庫ロボットや AGV の経路計画に使われるマルチエージェント経路探索が表彰されており、物流・製造の自動化に直結する AI 研究が IJCAI の柱の一つであることがわかる
- 学習した知覚と記号的な計画をつなぐ研究は、現在の LLM エージェントの計画能力の議論にも通じる
:::

### 1. 言語上のソフトな推論器としてのTransformer {#paper-1}

📈 被引用数上位（Paper Digest の集計で同年1位） ・ Peter Clark, Oyvind Tafjord, Kyle Richardson ・ [論文を読む ↗](https://arxiv.org/abs/2002.05867)

<small>原題: Transformers as Soft Reasoners over Language</small>

事実とルールを形式表現ではなく自然言語の文で与え、RoBERTaを用いた「RuleTaker」が演繹的な質問応答を解けるかを調べた研究です。同分布テストで99%、学習時より深い深さ5の問題でも97.6%を記録し、人手作成のルールベースでもゼロショットで6変種中5つが90%以上でした。構造を課さず言語のまま推論させる、Transformerの「ソフト定理証明器」という新しい役割を示した点が注目され、IJCAI 2020でPaper Digest集計の被引用数が同年1位となっています。

::: info 📝 落合フォーマット

**どんなもの？**

事実とルールを形式表現ではなく自然言語の文として与え、Transformer（RoBERTa）が与えられた文の真偽を推論（または推論の入出力挙動をエミュレート）できるかを調べた研究。合成データで学習した「RuleTaker」モデルが、ルールベースの演繹的な質問応答を高精度で解けることを示した。Transformerを言語上の限定的な「ソフト定理証明器」として使う新しい役割を提案している。

**先行研究と比べてどこがすごい？**

bAbIやHotpotQAのように推論規則が暗黙で例から帰納する課題と異なり、例ごとに異なる明示的ルール集合に対する推論を体系的に学習できるかを初めて実証した。意味解析で形式表現に変換する手法や、推論過程に構造を課すニューラル定理証明とも異なり、構造を課さず言語のまま直接推論させる点が特徴。

**技術や手法のキモはどこ？**

ロジックプログラム（否定は失敗による否定、層化済み）として小さな理論（事実1〜16個、ルール1〜9個、変数は最大1つの連言含意）をランダム生成し、前向き推論で全帰結を求めて真の質問を選び、閉世界仮説で未証明の事実を偽の質問とする。これをテンプレートで英語化し、推論深さ D=0〜3、5の5データセット（各10万例）を作る。RACEで追加微調整したRoBERTa-largeに [CLS] context [SEP] statement [SEP] を入力し、真偽の2値分類として学習する。

**どうやって有効だと検証した？**

同分布テストで99%の精度を達成し、D≤3で学習したモデルは学習時より深い深さ5の問題でも97.6%を記録した。人手作成の2つのルールベース（Birds、Electricity）ではゼロショットで6変種中5つで90%以上、クラウドソーシングで言い換えたParaRulesでは学習に加えると98.8%、ゼロショットでは66.6%だった。また、証明に不可欠な文を除くと予測が真から偽に変わる割合は81%で、不可欠な文の特定はF1=92.4（70%超の問題で完全一致）、BERTは95%、ESIMは約80%だった。

**議論はある？**

理論の規模（20事実未満、10ルール未満）、ルール言語（変数1つ、多変数ルールや選言などは未対応）、合成言語への依存が限界であり、生成データの偏りがElectricity4のような盲点を生む可能性がある。著者らはTransformerが実際に「推論」しているかは未解決とし、証明に不可欠な文の特定の精度も形式証明器の100%には及ばない。今後は、より豊かなルール言語、より自然な言語、敵対的なデータ生成、説明性・訂正可能性・反実仮想推論への展開が挙げられている。

**次に読むべき論文は？**

- CLUTRR: A Diagnostic Benchmark for Inductive Reasoning from Text：本論文が対比している、例から規則を帰納する課題とパラフレーズ収集の手法を理解できる。
- Probing Natural Language Inference Models through Semantic Fragments：単一ルールの適用を測る合成プローブで、本論文の複数ステップ推論の位置づけを把握できる。
- Towards AI-Complete Question Answering: A Set of Prerequisite Toy Tasks：暗黙のルールを学習するbAbIと、明示ルールを使う本研究との違いを確認できる。

:::


### 2. LogiQA: 論理推論を伴う機械読解のためのチャレンジデータセット {#paper-2}

📈 被引用数上位（Paper Digest の集計で同年2位） ・ Jian Liu, Leyang Cui, Hanmeng Liu, Dandan Huang ほか ・ [論文を読む ↗](https://arxiv.org/abs/2007.08124)

<small>原題: LogiQA: A Challenge Dataset for Machine Reading Comprehension with Logical Reasoning</small>

中国の国家公務員試験の論理問題を元に、専門家作成の8,678件の4択問題からなる機械読解データセット LogiQA を構築した研究です。人間の正答率86.00%に対し最良の RoBERTa でも35.31%にとどまり、既存モデルの論理推論能力の不足を示しました。論理推論に特化した大規模ベンチマークとして位置づけられ、被引用数が同年2位と高い点でも注目されます。

::: info 📝 落合フォーマット

**どんなもの？**

中国の国家公務員試験の論理問題を元に、論理推論を要する機械読解データセット LogiQA（8,678件の段落・質問ペア、各4択）を構築した研究。カテゴリ的・条件的・選言的・連言的などの演繹推論を網羅し、中国語版も公開している。既存の機械読解モデルの論理推論能力を測るベンチマークとして位置づけられる。

**先行研究と比べてどこがすごい？**

従来の読解データセットは事実抽出、マルチホップ推論、常識知識が中心で、論理推論を主眼とした大規模データは少なかった。LogiQAはクラウドソーシングではなく専門家が作成した試験問題に基づくため品質が高く、答えが段落中のスパンではなく、語彙的一致だけでは解けない点が特徴である。Hurleyによる5種類の演繹推論タイプで分類している点も新しい。

**技術や手法のキモはどこ？**

公開された国家公務員試験の13,918件から、選択肢が4つでない問題、図表を含む問題、「下線」「文の並べ替え」を含む問題、重複を除去して8,678件にした。原文は中国語で、5名の英語専門家が翻訳し3名の校正者が検査した。テストセットはカテゴリ的・十分条件・必要条件・選言・連言の5タイプに手作業で分類している。評価には、ルールベース（単語一致、スライディングウィンドウ）、深層学習（Stanford Attentive Reader、Gated-Attention Reader、Co-Matching Network）、事前学習モデル（BERT、RoBERTa）を用いた。

**どうやって有効だと検証した？**

データを訓練80%・開発10%・テスト10%に分割して評価した。人間の正答率は86.00%、天井性能は95.00%に対し、最良のRoBERTaでも35.31%にとどまり、ルールベースは22.51〜28.37%でランダム（25%）並みだった。段落や質問を除くアブライション、RACE・COSMOSからの転移学習、入力長別、語彙オーバーラップ、推論タイプ別の分析も行い、データセットのバイアスが弱いこと、既存データとは異なる課題であることを示した。推論タイプ別ではRoBERTaはカテゴリ的推論で55.00%だったが、条件・選言・連言では17〜23%程度と低かった。

**議論はある？**

事前学習モデルの論理推論知識は弱く、attentionベースのテキストマッチングでは論理規則を学習しにくいことが示された。ケーススタディでは、RoBERTaが否定（not）を無視したり、複数の場合を列挙する推論ができなかったりした。深層学習型の読解モデルに強い推論能力をどう持たせるかは未解決で、論文はシンボリック手法との統合も含めた今後の研究課題としている。

**次に読むべき論文は？**

- RoBERTa: A Robustly Optimized BERT Pretraining Approach：LogiQAで最高性能を示したベースラインモデルであり、その仕組みを理解するため。
- Cosmos QA: Machine Reading Comprehension with Contextual Commonsense Reasoning：LogiQAとの比較や転移学習実験、アブライション分析の対象となった、常識推論型の読解データセットである。
- RACE: Large-scale ReAding Comprehension Dataset From Examinations：試験問題から構築された大規模読解データセットで、LogiQAの転移学習実験でも使われているため。

:::


### 3. コミュニティ検出のための深層学習：進展、課題、そして機会 {#paper-3}

📈 被引用数上位（Paper Digest の集計で同年3位） ・ Fanzhen Liu, Shan Xue, Jia Wu, Chuan Zhou ほか ・ [論文を読む ↗](https://arxiv.org/abs/2005.08225)

<small>原題: Deep Learning for Community Detection: Progress, Challenges and Opportunities</small>

コミュニティ検出に対する深層学習手法を、深層ニューラルネットワーク・深層グラフ埋め込み・グラフニューラルネットワークの3系統に整理した、著者らの知る限り初の包括的なサーベイです。コミュニティ数が未知、階層型・異種・動的・大規模ネットワークなど7つの未解決課題と、それぞれの研究機会を体系的に示しています。IJCAI 2020 の論文で、Paper Digest の集計では同年の被引用数3位に入っており、この分野の入口として広く参照されていることがうかがえます。

::: info 📝 落合フォーマット

**どんなもの？**

コミュニティ検出に対する深層学習手法を網羅的にレビューしたサーベイ論文。手法を「深層ニューラルネットワーク」「深層グラフ埋め込み」「グラフニューラルネットワーク」の3系統に整理し、未解決の課題と今後の研究機会を提示している。

**先行研究と比べてどこがすごい？**

著者らの知る限り、コミュニティ検出における深層学習を包括的にレビューした初の研究である。手法を技術観点で分類したうえで、7つの未解決課題（コミュニティ数が未知、階層型ネットワーク、異種ネットワーク、符号付きエッジ、コミュニティ埋め込み、動的ネットワーク、大規模ネットワーク）とそれぞれの研究機会を体系的に示した点が特徴。

**技術や手法のキモはどこ？**

NIPS、ICLR、AAAI、IJCAI、KDD、ICDM、CIKM、ICDE、WWWなどの主要会議や査読付き論文誌の文献を対象に調査・分類している。深層NNはCNN・オートエンコーダ・GAN、深層グラフ埋め込みは深層NMF・深層スパースフィルタリング・コミュニティ埋め込み、GNNはGCNや非後退演算子などに整理し、各系統の代表的モデルの貢献を要約する。その上で課題ごとに既存の対処法と限界を論じ、今後の方向性を提案している。

**どうやって有効だと検証した？**

サーベイ論文のため、独自の実験や数値による検証は行っていない。代表的な既存手法（CommunityGAN、深層スパースフィルタリング、GCNとMarkov random fieldの組み合わせなど）の貢献を文献ベースで紹介し、課題ごとの既存手法の限界（例：符号付きネットワークの疎な埋め込みが小規模実ネットワークでスペクトル法のベースラインに及ばない場合がある）を指摘している。

**議論はある？**

コミュニティ数が未知の問題は完全には解決されておらず、階層型・異種・符号付き・動的ネットワークに対する深層学習手法もまだ十分に発展していない。大規模ネットワークでは低ランク近似などの次元削減や分散計算も計算コストが高く、精度と速度の両面で現状を大きく超える新しいフレームワークが求められると論じている。

**次に読むべき論文は？**

- Overlapping community detection with graph neural networks：GCNとBernoulli–Poissonモデルを組み合わせた重複コミュニティ検出の代表的手法で、GNN系アプローチの具体像を把握できるため。
- CommunityGAN: Community detection with generative adversarial nets：GANによる重複コミュニティ検出とノードのメンバーシップ強度の表現を同時に扱う手法の詳細を理解できるため。
- Learning community embedding with community detection and node embedding on graphs：課題Vで取り上げられたコミュニティ埋め込みの基礎となる研究であるため。

:::
