# IJCAI 2023

🏛️ AI全般（老舗・総合） ・ [IJCAI の年ごとの流れ](./) ・ [公式サイト ↗](https://www.ijcai.org/)

::: info この回のまとめ
マカオで開催され、投稿4,566本・採択643本（約14.1%）でした。最優秀論文は3本で、圧縮の分野で使われる文脈モデルを探索の方策に取り入れた Levin Tree Search、記述論理の概念を SAT ソルバーで PAC 学習する手法、確率論理の「シールド」で強化学習エージェントの危険な行動を防ぐ手法が選ばれました。研究功績賞はマルチエージェントシステムの Sarit Kraus 氏、Computers and Thought 賞は AI の敵対的頑健性の Pin-Yu Chen 氏です。
:::

:::

## 📝 注目論文

### 1. 確率論理シールドによる安全な強化学習 {#paper-1}

🏆 Distinguished Paper ・ Wen-Chi Yang, Giuseppe Marra, Gavin Rens, Luc De Raedt ・ [論文を読む ↗](https://arxiv.org/abs/2303.03226)

<small>原題: Safe Reinforcement Learning via Probabilistic Logic Shields</small>

強化学習エージェントの行動を、確率論理プログラムで書いた安全規則に照らして危険な行動の確率を下げる「シールド」を、方策勾配法に微分可能な形で組み込みました。安全性を保ちながら学習の性能も落としにくい点が評価されました。

::: info 📝 落合フォーマット

**どんなもの？**

安全制約を論理で記述し、確率論理プログラミング(ProbLog)で微分可能な「確率的論理シールド(PLS)」として実装することで、行動を棄却するのではなくポリシー全体をより安全な分布に変換する手法を提案した。これを任意の方策勾配法に組み込む Probabilistic Logic Policy Gradient (PLPG) により、ノイズのあるセンサ下でも安全かつ高報酬な方策学習を目指す。

**先行研究と比べてどこがすごい？**

従来のシールドは行動が安全か危険かを決定論的に判定し棄却するため、センサのノイズを扱えず、棄却される行動を学習側が知らないことで最適方策への収束が保証されなかった。本手法は安全性を確率として扱い、シールド済み方策 π+ をベース方策の再正規化として定義するため微分可能で、完全な安全情報があれば標準の方策勾配と同形になり収束が保証される。また MDP 全体のモデルは不要で、安全に関する抽象モデルのみで済む。

**技術や手法のキモはどこ？**

ProbLog プログラムを、方策を表す注釈付き選言(行動確率)、状態の安全関連抽象(センサ由来の確率的事実)、安全仕様(節)の3要素で構成し、ニューラルネットの出力確率を入力する(ニューラル述語)。シールド済み方策は π+(a|s)=P(safe|s,a)π(a|s)/P_π(safe|s) で得られ、方策勾配の対象を π+ に置き換える(shielded policy gradient)。さらにセマンティックロス -log P_π+(safe|s) に基づく安全勾配を係数 α で加え、両者を合わせて PLPG とする。回路へコンパイルすることで推論と勾配計算を効率化する。

**どうやって有効だと検証した？**

Stars、Pacman、Car Racing の3環境(各2設定)で、PPO、VSRL(決定論的棄却型シールド)、ε-VSRL と比較し、600kステップ、5シードで平均正規化リターンと累積違反数を評価した。ノイズセンサ下で PLPG の違反数は PPO より51.3%、VSRL より24.5%、ε-VSRL より13.5%少なく、リターンも同等かやや高かった(PPO比+4.5%、VSRL比+6.5%)。アブレーションでは両勾配の併用が片方のみより違反が少なく、最適な α は概ね0.1〜1であった。

**議論はある？**

現状の確率論理言語は離散行動に限られ、連続行動や連続方策を持つ RL アルゴリズムへの拡張が今後の課題である。多段先読みでは安全ホライズンを延ばすと回路サイズと推論時間が指数的に増大し(4ステップで回路サイズ373676、評価27.39秒)、スケーラビリティに制約がある。また Car Racing のようにセンサが慣性等を捉えきれない領域では安全センサだけでは不十分で、安全勾配の重要度が環境で変わる点も論点である。

**次に読むべき論文は？**

- Verifiably Safe Exploration for End-to-End Reinforcement Learning：本論文の主要比較対象である VSRL の原典で、決定論的な棄却型シールドの仕組みと限界を理解できる。
- A Semantic Loss Function for Deep Learning with Symbolic Knowledge：PLPG の安全勾配の基礎となるセマンティックロスの定義と考え方を学べる。
- Safe Reinforcement Learning using Probabilistic Shields：確率的シールドの形式的な枠組みを示した先行研究で、本手法との違いを把握するのに役立つ。

:::
