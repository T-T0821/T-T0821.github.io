# EMNLP 2022

💬 自然言語処理 ・ [EMNLP の年ごとの流れ](./) ・ [公式サイト ↗](https://aclanthology.org/venues/emnlp/)

::: info この回のまとめ
2022年12月7〜11日にアラブ首長国連邦のアブダビでハイブリッド開催されました。投稿は4,190本（ARR からのコミット275本を含む）で、本会議に829本（20%）、Findings に549本（13%）が採択されています。「言語モデルとその分析」や「リソースと評価」が200本超の主要トラックになりました。最優秀論文は、タングラムの図形に人々が付けた多様な説明を大規模に集め、人間と機械の抽象的な視覚推論を比べるデータセット KiloGram（コーネル大学ほか）です。基調講演には Gary Marcus 氏らが登壇しました。
:::

- 主要トラック: リソースと評価、NLP 応用、機械学習、対話、言語モデルの分析、マルチモーダル、情報抽出

:::

### 1. タングラム図形による抽象的な視覚推論 {#paper-1}

🏆 Best Paper ・ Anya Ji, Noriyuki Kojima, Noah Rush, Alane Suhr ほか ・ [論文を読む ↗](https://arxiv.org/abs/2211.16492)

<small>原題: Abstract Visual Reasoning with Tangram Shapes</small>

1,000種類以上のタングラム図形に、人々が「何に見えるか」「どの部品が何か」を付けた大規模データ KiloGram を作りました。CLIP などのモデルは抽象的な図形の理解で人間に及ばず、部品の情報や色付けで改善することを示しました。

::: info 📝 落合フォーマット

**どんなもの？**

人間と機械の抽象的視覚推論を調べるための資源 KiloGram を提案した研究。1,016個のタングラム図形をベクタ画像化し、全体形状の説明、パーツ分割、パーツ名を含む13,404件のアノテーションを収集した。これを使い、事前学習済みマルチモーダルモデル（CLIP、ViLT）の抽象視覚推論能力を参照ゲームで評価している。

**先行研究と比べてどこがすごい？**

従来のタングラム研究は10〜20個、最大でも60個程度の小規模な刺激セットに限られていたが、本研究は約2桁大きい1,016個を提供する。画像は元のパズルピースから構成したベクタ図形で、全体の説明だけでなくセグメンテーションとパーツ名まで含むため、全体-部分の推論を扱える。1図形あたり複数の注釈（最低10件、一部は50件以上）を集め、注釈の分布そのものを表現している点も特徴である。

**技術や手法のキモはどこ？**

MTurkで2段階の注釈を行った。まず全体形状の説明（「This shape, as a whole, looks like ___」）を書き、次にピースを選んでパーツ名を付ける。注釈の分散は、形状命名の乖離（SND）、パーツ命名の乖離（PND）、パーツ分割の一致度（PSA）の3指標で測る。評価では、テキストと10枚の画像から正しい画像を選ぶ参照ゲームを用いる。入力条件は、テキストが全体のみかパーツ名付きか、画像が単色（black）かパーツ別の色分け（color）かの組合せで、事前学習済み重みと対照学習によるファインチューニング、およびパーツ部分集合によるデータ拡張（aug）を比較した。

**どうやって有効だと検証した？**

事前学習済みモデルはランダム（10%）をわずかに上回る程度で、テスト精度はCLIPが17〜18%台、ViLTが11〜13%台だった。ファインチューニングで大きく改善し、テストのparts + colorではViLTが77.3%、CLIPが46.5%となり、人間（開発セットで63.0%）を上回った。人間も、パーツ名と色分けの両方があるときに最も成績が高かった。ViLTは、両方の情報を同時に符号化できることでパーツ情報を活用できたと考えられる。データ分析では、SNDの平均が0.91と高く、命名が多様であることが示された。

**議論はある？**

説明が孤立した画像に対して集められており、文脈に応じた語用論的な詳細さを欠くため、参照ゲームには解けない曖昧さが含まれ、精度の上限は100%を下回ると考えられる。人間評価は予備的で、参加者が高成績群と低成績群に分かれたため、人間とモデルの比較には慎重さが必要である。分析は英語に限られており、今後は対話型の参照ゲームや他言語・他文化への拡張が課題とされている。

**次に読むべき論文は？**

- ViLT: Vision-and-Language Transformer Without Convolution or Region Supervision：本研究で joint encoding の代表として評価され、パーツ情報の活用で高性能を示したモデルの詳細を理解できる。
- Learning Transferable Visual Models From Natural Language Supervision (CLIP)：separate encoding の代表として評価され、対照学習による事前学習とファインチューニングの基礎となる手法である。
- Referring as a collaborative process：タングラムを用いた参照ゲームの認知科学的な原点であり、本研究の動機と課題設定の背景が分かる。

:::


### 2. デモンストレーションの役割を再考する：in-context learning はなぜ機能するのか {#paper-2}

📈 被引用数上位（Paper Digest の集計で同年1位） ・ Sewon Min, Xinxi Lyu, Ari Holtzman, Mikel Artetxe ほか ・ [論文を読む ↗](https://arxiv.org/abs/2202.12837)

<small>原題: Rethinking the Role of Demonstrations: What Makes In-Context Learning Work?</small>

in-context learning（ICL）でデモンストレーションのどの要素が性能向上に効いているかを、入力-ラベル対応・入力分布・ラベル空間・フォーマットに分解して実証的に分析した研究です。GPT-3を含む12モデルと26データセットの評価で、正解ラベルをランダムに置換しても性能低下は多くの場合0〜5%にとどまり、ラベル空間・入力分布・フォーマットが主な要因であることを示しました。ICLがゼロショットを上回る理由を調べた初の分析と位置づけられ、同年のEMNLPで被引用数1位（Paper Digest集計）という点でも注目されています。

::: info 📝 落合フォーマット

**どんなもの？**

in-context learning（ICL）において、デモンストレーション中のどの要素が性能向上に寄与するかを実証的に分析した研究。正解の入力-ラベル対応はほとんど不要で、ラベル空間・入力テキストの分布・フォーマットが主な要因であることを示した。

**先行研究と比べてどこがすごい？**

ICLがゼロショットを上回る理由を実証的に調べた初めての分析と位置づけられる。デモの要素を入力-ラベル対応、入力分布、ラベル空間、フォーマットに分解し、それぞれの寄与を個別に切り分けた点が新しい。また、メタ訓練（MetaICL）がこれらの傾向をさらに強めることも示した。

**技術や手法のキモはどこ？**

デモ中のラベルを正解から一様ランダムなラベルに置換する比較を基本とする。さらに、正解ラベルの割合の変更、外部コーパスの文を入力に使うOOD入力、ランダムな英単語をラベルに使う設定、ラベルのみ・入力のみ（ペア形式を除去）といった変種を作り、各要素の影響を単離した。direct法とchannel法の両方で、k=16、最小テンプレートを基本として評価した。

**どうやって有効だと検証した？**

GPT-3を含む12モデル（774Mから175B）で、26個の分類・多肢選択データセットを評価した。ランダムラベルへの置換による性能低下は多くのモデルで絶対値0〜5%にとどまり、分類で平均2.6%、多肢選択で平均1.7%、MetaICLでは0.1〜0.9%だった。OOD入力では3〜16%低下し、direct法でランダム英単語ラベルに変えると5〜16%低下した。ペア形式を保てば、入力のみ・ラベルのみでも改善の最大95%を保持できた。

**議論はある？**

対象は分類・多肢選択タスクに限られ、生成タスクへの拡張は未検証である。データセットごとの差もあり、財務系データセットとGPT-Jの組み合わせでは最大約14%の差が出ている。後続研究（Kim et al., 2022）は、否定ラベルを使うと性能が大きく下がることを示しており、正解ラベルがどこまで必要かは議論の余地がある。

**次に読むべき論文は？**

- MetaICL: Learning to Learn In Context：本論文で分析対象となり、デモの単純な側面のみを利用する傾向を強めるメタ訓練モデルの詳細を理解できる。
- Ground-Truth Labels Matter: A Deeper Look into Input-Label Demonstrations：本論文の結論に対する後続の反証的分析で、否定ラベルでは性能が大きく下がることを示している。
- Noisy Channel Language Model Prompting for Few-Shot Text Classification：本論文で使うdirect法とchannel法の定義と違いを理解する助けになる。

:::


### 3. Super-NaturalInstructions: 1600以上のNLPタスクにおける宣言的指示を通じた汎化 {#paper-3}

📈 被引用数上位（Paper Digest の集計で同年2位） ・ Yizhong Wang, Swaroop Mishra, Pegah Alipoormolabashi, Yeganeh Kordi ほか ・ [論文を読む ↗](https://arxiv.org/abs/2204.07705)

<small>原題: Super-NaturalInstructions: Generalization via Declarative Instructions on 1600+ NLP Tasks</small>

1,616個のNLPタスク（76タスクタイプ、55言語）に専門家作成の指示文を付けたメタデータセットを構築し、指示に従って未見タスクを解くT5系モデルTk-Instructを学習・分析した研究です。学習データが非公開のInstructGPTと異なり公開データで再現・拡張でき、11BのTk-InstructはROUGE-Lで英語タスクにてInstructGPTを9.9ポイント、mTk-Instructは非英語タスクで13.3ポイント上回りました。訓練タスク数とモデルサイズに対する性能の対数線形な向上など、指示に基づく汎化の分析も示しており、被引用数が同年2位である点も注目に値します。

::: info 📝 落合フォーマット

**どんなもの？**

1,616個の多様なNLPタスクとその専門家作成の指示文を集めたメタデータセット Super-NaturalInstructions（76タスクタイプ、55言語）を構築した研究。あわせて、指示（タスク定義やk-shot例）に従って未見タスクを解くT5系モデル Tk-Instruct を学習し、指示に基づく未見タスクへの汎化を評価・分析した。

**先行研究と比べてどこがすごい？**

先行のNatInst（61タスク）の約26倍のタスク数と多様なタスクタイプ、非英語タスクを備え、指示付きの公開ベンチマークとして大規模である。InstructGPT等は学習データが非公開であるのに対し、本研究は公開データで再現・拡張が可能である。また、未見タスクの言語をまたぐ汎化（cross-lingual cross-task）を初めて調べた。

**技術や手法のキモはどこ？**

各タスクを「定義」「正例（説明付き）」「負例（説明付き）」という共通スキーマの指示で記述し、1タスク最大6.5Kインスタンスに制限した。タスクはGitHub上でコミュニティから募り、自動検査・1〜2名の査読・クラウドワーカーのフィードバックで品質管理した。Tk-Instructは、指示をテキスト化して入力の前に連結し、T5（多言語版はmT5）を訓練タスク群でマルチタスク学習する。既定の指示はタスク定義と正例2件である。

**どうやって有効だと検証した？**

12カテゴリ154タスクを評価用に分離し（英語119、他言語35、1タスク最大100件）、ROUGE-Lで評価した。英語では11BのTk-Instructが62.0で、InstructGPT（52.1）を9.9ポイント上回り、mTk-Instructは非英語でInstructGPTを13.3ポイント上回った（66.1対52.8）。人手評価では、77%のインスタンスで正解と同等以上と判定された。ROUGE-Lと人手評価のPearson相関は0.998であった。分析では、訓練タスク数とモデルサイズに対して性能が対数線形に向上し、タスクあたりのインスタンス数は64件程度で飽和した。

**議論はある？**

データは英語や短い出力のタスクに偏っており、長文出力などのロングテールの不足が課題である。ROUGE-Lは、入力コピーでも高得点になりうる書き換え・誤り訂正タスクには適さず、より良い評価指標が求められる。InstructGPTの学習データが非公開のため評価タスクとの重複は不明であり、教師あり学習との間にもなお大きな性能差（74.3、英語）が残る。

**次に読むべき論文は？**

- Cross-Task Generalization via Natural Language Crowdsourcing Instructions：本論文の前身であるNatInstで、指示スキーマと未見タスク汎化の設定の出発点を確認できる。
- Multitask Prompted Training Enables Zero-Shot Task Generalization：T0の手法で、プロンプト形式の違いによる汎化性能を本研究と比較して理解できる。
- Finetuned Language Models are Zero-Shot Learners：FLANによる指示チューニングの代表的な先行研究で、タスク数やモデル規模に関する知見と比較できる。

:::


### 4. 言語モデルを用いた言語モデルのレッドチーミング {#paper-4}

📈 被引用数上位（Paper Digest の集計で同年3位） ・ Ethan Perez, Saffron Huang, Francis Song, Trevor Cai ほか ・ [論文を読む ↗](https://arxiv.org/abs/2202.03286)

<small>原題: Red Teaming Language Models with Language Models</small>

別の言語モデル（赤チームLM）でテストケースを自動生成し、280BパラメータのDialogue-Prompted Gopherチャットボットの有害な振る舞いを大規模に発見する手法を提案した研究です。0.5Mのゼロショット質問から18,444件の攻撃的返答の失敗例を得たほか、電話番号やメールアドレスなど個人情報の生成や学習データ漏洩も検出し、RLで生成した質問は人手のBADデータセットと同程度の難しさと多様性を示しました。人手では見つからない失敗も補完的に発見できる点が評価され、EMNLP 2022の被引用数上位（Paper Digest集計で同年3位）となっています。

::: info 📝 落合フォーマット

**どんなもの？**

別の言語モデル（赤チームLM）を使ってテストケースを自動生成し、対象LM（280BパラメータのDialogue-Prompted Gopherチャットボット）の有害な振る舞いを大規模に発見する「LMによるレッドチーミング」を提案した研究。攻撃的な発言に加え、個人情報・連絡先の生成、学習データ漏洩、集団ごとの分布的バイアス、対話中の有害化といった多様な害を対象にしている。

**先行研究と比べてどこがすごい？**

従来は人手で書いたテストケースに依存し、数と多様性が限られていたが、本手法は人手の例に頼らず数万件規模の失敗例を自動で得られる。勾配探索による意味不明な敵対的入力とは異なり、自然で流暢な質問を生成でき、プロンプトで狙った失敗モードを制御できる点が優れる。生成した質問は人間の敵対者が書いたBADデータセットと同程度の難しさ・多様性を持ち、人手では見つからない失敗も補完的に発見できる。

**技術や手法のキモはどこ？**

「赤LMでテストケース生成→対象LMで返答生成→赤チーム分類器で有害判定」の3段階を採る。テストケース生成法として、ゼロショット、確率的少数ショット（失敗例を分類器スコアに比例して選びプロンプトに追加）、教師あり微調整、A2Cによる強化学習（SL初期化に加え、多様性崩壊を防ぐKLペナルティを併用し、αで難しさと多様性を調整）を比較する。分類器は1.4B版GopherをBADデータで微調整した攻撃性判定器で、デコードはnucleus sampling（p=0.95）を用いる。プロンプトを変えることで、連絡先、集団名とテンプレート、対話全体の生成にも拡張する。

**どうやって有効だと検証した？**

0.5Mのゼロショット質問のうち3.7%が攻撃的返答を引き出し、18,444件の失敗例を得た。RL（α=0.3）では40%超で攻撃的返答を引き出し、その78%が「invisible」を含む質問に収束した。RL（α=0.4）は人手のBADと同程度の難しさと多様性（Self-BLEUで評価）を示した。そのほか、13-gram一致で1709件の学習データ漏洩、100k件の質問中3206件で電話番号、1006件でSSN、11683件でメールアドレスを含む返答を検出した。また、BADに含まれない上位名詞句が37/100あった。

**議論はある？**

赤LMや分類器自体のバイアスにより、網羅性が損なわれたり偽陽性・偽陰性が生じるため、すべての見落としを見つける手段ではなく人手テストの補完と位置づけられる。生成された集団名には無意味・無関係なものも多く、バイアス候補の抽出に留め、人手で確認すべきと述べている。（なお本文は途中で省略されており、対話レッドチーミングの詳細結果は与えられた範囲では確認できないが、攻撃的返答が連鎖することが示唆されている。）

**次に読むべき論文は？**

- Bot-Adversarial Dialogue (BAD) dataset: Bot-Adversarial Dialogue for Safe Conversational Agents：本論文が比較対象かつ分類器の学習データとして使う人手レッドチーミングの基準データセットで、手法の位置づけを理解できる。
- Extracting Training Data from Large Language Models：学習データ漏洩を扱う第4章の背景で、抽出攻撃とレッドチーミングを組み合わせる発想の元になっている。
- Universal Adversarial Triggers for Attacking and Analyzing NLP：勾配ベースで不自然な敵対的入力を探す先行手法であり、本手法の自然で制御可能な生成との違いを把握できる。

:::
