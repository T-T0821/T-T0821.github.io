## 🔭 この回の主なテーマ

- 多文化・多言語: 画像の文化的な翻案、数千言語の音声表現
- LLM の解釈性: 勾配を語彙空間に射影して学習の中身を読む（Backward Lens）
- 学習データの透明性: 事前学習データの検出（著作権・評価汚染の確認）
- 特別テーマ: 量子化・データ量・モデルサイズなどの効率化
- LLM エージェント: 幻覚検出や開発ツールなど多様な応用

::: tip 💡 技術動向への示唆
- 事前学習データの検出が最高賞を得たことは、著作権やベンチマーク汚染の検証が LLM の信頼性の中心課題になったことを示す
- 画像や音声も含めた多文化・多言語対応が繰り返し表彰されており、グローバル展開では言語だけでなく文化への適応が求められる
:::

### 1. 一枚の絵は千の言葉を語るが、誰もが聞き取れるか? 文化に合わせた画像トランスクリエーション {#paper-1}

🏆 Best Paper ・ Simran Khanuja, Sathyanarayanan Ramamoorthy, Yueqi Song, Graham Neubig ・ [論文を読む ↗](https://arxiv.org/abs/2404.01247)

<small>原題: An image speaks a thousand words, but can everyone listen? On image transcreation for cultural relevance</small>

広告や教材の画像を別の文化圏の人に伝わるよう作り替える課題を新たに定義し、画像編集モデルや LLM を組み合わせた手法を評価しました。現状のモデルは文化的な適切さで大きく不足していることを示しました。

::: info 📝 落合フォーマット

**どんなもの？**

画像を文化的に適応させる「画像トランスクリエーション」を機械学習で扱う新タスクとして提案し、最先端の生成モデルで3つのパイプラインを構築した研究。あわせて評価用の2部構成データセットを作成し、人手評価で現状の能力を測った。

**先行研究と比べてどこがすごい？**

機械翻訳が音声・テキストに留まる中、画像を対象に文化的関連性と意味の保存を狙う試みは本論文が初めてだと主張している。concept（600枚）とapplication（100枚）という二段構成のデータセットと、文化的関連性・意味保存・レイアウト・自然さ・不快感などを問う多面的な人手評価の枠組みも新しい。

**技術や手法のキモはどこ？**

3つのパイプラインを比較した。e2e-instructはInstructPix2Pixに「この画像を対象国に文化的に関連させよ」と指示して一度に編集する。cap-editはInstructBLIPで画像をキャプション化し、GPT-3.5で文化的に書き換え、その文を指示としてPlugnPlayで元画像を編集する。cap-retrieveは書き換えたキャプションで、URLのcctldで国別に分けたLAIONのサブセットから自然画像を検索する。補足としてGPT-4o＋GPT-4＋DALLE-3による生成も試している。

**どうやって有効だと検証した？**

conceptは7か国（ブラジル、インド、日本、ナイジェリア、ポルトガル、トルコ、米国）の画像、applicationは教育用ワークシートと児童書の画像で、各国の母語話者が評価した。LLMやリトリーバを組み込むと改善し、cap-retrieveは文化的関連性が上がった画像の割合が最も高く、e2e-instructは最も低かった。ただし成功した変換は、conceptでは最良のパイプラインでもナイジェリアで約5%、日本で約30%に留まり、applicationではポルトガルなど一部の国で成功例がなかった。DiNO-ViTの画像類似度やCLIPの国関連度といった自動指標は、ステレオタイプ的な成果物を高く評価するなど不十分だった。

**議論はある？**

文化を国単位で捉えている点、対象が7か国で英語キャプションのみである点、完全な一対一の対応は存在しえない点が限界である。ステレオタイプ化（日本で桜や富士山を挿入するなど）と関連性向上のトレードオフ、原文化の要素を残したい場合への対応、画像版BLEUのような自動評価指標の整備が今後の課題として挙げられている。

**次に読むべき論文は？**

- InstructPix2Pix: Learning to Follow Image Editing Instructions：e2e-instructパイプラインの基盤で、現行の画像編集モデルが色・形・スタイルの変更に留まる理由を理解するのに役立つ。
- Visually grounded reasoning across languages and cultures (MaRVL)：本論文のconceptデータセットが採用した、現地の人が主導する文化的データ収集プロトコルの元になっている。
- Plug-and-play diffusion features for text-driven image-to-image translation：cap-editで画像編集に使われ、空間レイアウトを強く保持する性質が不自然な出力につながる点を理解するのに役立つ。

:::


### 2. Backward Lens: 言語モデルの勾配を語彙空間に射影する {#paper-2}

🏆 Best Paper ・ Shahar Katz, Yonatan Belinkov, Mor Geva, Lior Wolf ・ [論文を読む ↗](https://arxiv.org/abs/2402.12865)

<small>原題: Backward Lens: Projecting Language Model Gradients into the Vocabulary Space</small>

順伝播の解釈に使われてきた「語彙空間への射影」を逆伝播の勾配にも広げ、モデルが学習や知識編集の際にどの単語の情報を書き込んでいるかを読み取れるようにしました。

::: info 📝 落合フォーマット

**どんなもの？**

Transformer 言語モデルの逆伝播で得られる勾配行列を語彙空間へ射影し、解釈する手法を提案した研究。勾配が順伝播の入力と逆伝播の VJP の線形結合（低ランク行列）で表せることを証明し、MLP 層が新しい知識を保存する仕組みを「imprint and shift」として説明する。

**先行研究と比べてどこがすごい？**

Logit Lens など語彙空間への射影は従来、順伝播の重みや隠れ状態にのみ適用されており、勾配を語彙空間へ射影したのは本研究が（著者の知る限り）初めてである。勾配行列全体ではなく、プロンプト長 n 本の小さな生成集合（x_i または δ_i）として解釈できる点も新しい。また勾配が低ランクであることは既知だったが、系列入力でのランクを n 以下と予測・証明し、解釈に活用した点が先行研究との違いである。

**技術や手法のキモはどこ？**

勾配は ∂L/∂W = Σ x_i^T δ_i（x_i は層入力、δ_i は出力の VJP）と書けるため、FF1 は x_i、FF2 は δ_i を生成集合として Logit Lens で語彙へ射影する。最上位層の VJP はターゲットトークン埋め込みが負の係数で支配的になるため、FF2 では射影で最も確率の低いトークンに着目する。更新により FF1 には入力が加減算され（imprint）、FF2 にはターゲット埋め込みへの変化が加えられる（shift）。この知見から、1 回の順伝播で得た最終トークンの入力 x_n とターゲット埋め込み D^T[t] の外積で FF2 を更新する「forward pass shifting」編集法も提案した。

**どうやって有効だと検証した？**

GPT2 と Llama2-7B で CounterFact から 100 プロンプトをサンプルし、SGD で 1 回の逆伝播を行って勾配ランクを測定した。最終層を除き 98.5% 以上でランクがプロンプト長 n と一致し、最終層はランク 1 で予測と合致した。GPT2-xl で Logit Lens を用いると、多くの層で勾配が編集ターゲット（例: Paris）の埋め込みに対応することが示された。forward pass shifting は CounterFact 1000 サンプルの単一編集で Efficacy 99.4%（ROME 99.4%、MEMIT 79.4%、MEND 71.4%）と同等だが、Paraphrase は 41.6% で ROME の 71.9% に劣る。

**議論はある？**

初期層の勾配は Logit Lens では解釈しにくく、追加の学習済み変換が必要かは未解決である。解析は SGD・単一プロンプト・単一ステップ・固定埋め込み、MLP 層のみ、Dropout や LayerNorm を無視した簡略化、デコーダ型 LM に限られ、Adam 等の最適化手法や複数プロンプトでの微調整、注意層への一般化は今後の課題である。forward pass shifting は代替手法ではなくケーススタディであり、汎化性と特異性では ROME に劣る。

**次に読むべき論文は？**

- Transformer Feed-Forward Layers Are Key-Value Memories：MLP の FF1/FF2 をキーと値の記憶とみなす imprint and shift の基礎となる考え方が学べる。
- Locating and Editing Factual Associations in GPT：本論文が比較対象とする ROME の手法で、知識編集の標準的な基準を理解できる。
- Transformer Feed-Forward Layers Build Predictions by Promoting Concepts in the Vocabulary Space：FF 層のニューロンを語彙空間へ射影する手法の直接の先行研究で、本論文の射影の土台になる。

:::


### 3. 数千言語に対応する頑健な音声表現学習に向けて {#paper-3}

🏆 Best Paper ・ William Chen, Wangyou Zhang, Yifan Peng, Xinjian Li ほか ・ [論文を読む ↗](https://arxiv.org/abs/2407.00837)

<small>原題: Towards Robust Speech Representation Learning for Thousands of Languages</small>

4,057言語・100万時間超の音声で事前学習した多言語自己教師あり音声エンコーダ XEUS を提案した研究です。言語カバレッジをMMSの約4倍に広げ、残響音声からクリーンな疑似ラベルを予測する脱残響タスクを新たに導入し、データ・重み・コード・200以上の中間チェックポイントまで公開しています。ML-SUPERBで最高スコアを記録し、低資源言語の音声翻訳でもMMS 1Bに対し相対約35%の向上を示した点が注目されます。

::: info 📝 落合フォーマット

**どんなもの？**

4,057言語・100万時間超の音声で事前学習した多言語自己教師あり学習(SSL)音声エンコーダ XEUS を提案した研究。既存の公開コーパス約100万時間に、新規収集した7,413時間・4,057言語の未ラベル音声コーパスを加えて学習している。モデル・コード・データ・中間チェックポイントも公開する。

**先行研究と比べてどこがすごい？**

従来の多言語SSLは50〜150言語程度が中心で、1,000言語超のMMSもデータ・学習コードが非公開だった。XEUSは言語カバレッジをMMSの約4倍に拡大し、データ・重み・コード・ログ・200以上の中間チェックポイントまで公開している。また、WavLM式のノイズ付加に加えて、残響を付与した音声からクリーンな疑似ラベルを予測する新しい脱残響(dereverberation)の自己教師タスクを導入した。

**技術や手法のキモはどこ？**

HuBERT型のマスク予測を基本とし、WavLabLMの表現をk-means(k=2,048)でクラスタリングして疑似ラベルを作る。入力にはDNS Challengeのノイズまたは他発話を確率0.2で付加し、さらにRIRとの畳み込みで残響を確率0.3で付加する。このとき、ピーク位置から求めたシフト量で残響音声を元の発話に再整列し、エネルギーを揃える工程がラベルとのずれを防ぐ上で重要とされる。アーキテクチャはTransformerをE-Branchformer(19層、577Mパラメータ)に置き換え、損失もクロスエントロピーに変更した。64基のA100で約670Kステップ学習している。

**どうやって有効だと検証した？**

ML-SUPERBでSUPERBsスコア956(10分・1時間設定とも)で最高となり、MMS 1BやXLS-R、w2v-BERT 2.0 v2を上回った。FLEURSではCER 8.9で、w2v-BERT 2.0 v2(8.7)に近く、MMS 1B(9.2)やXLS-R 1B(9.6)より良好だった。事前学習データが10時間未満の低資源言語3言語を対象にした音声翻訳ではchrF 22.1で、MMS 1B(15.5)より相対約35%向上した。英語SUPERBでは4タスク(KS, SD, ER, ASR)でWavLM Largeを上回り、音声再合成(VCTK)でもWER 10.0など全指標でWavLM LargeとW2v-BERT 2.0 v2を上回った。

**議論はある？**

4,000言語超のうち多くは音声が1時間未満で、低資源言語での性能は高資源言語より低いと見込まれ、評価も一部の言語に限られる。また評価はSUPERBなど軽量なベンチマーク中心でハイパーパラメータ調整も限定的であり、SOTA設定の大規模ファインチューニングは行っていない。今後は下流利用のより大規模な展開が課題として挙げられている。

**次に読むべき論文は？**

- Scaling Speech Technology to 1,000+ Languages：XEUSが直接の比較対象とし、言語カバレッジ拡大の先行例であるMMSの手法とデータを理解するため。
- WavLM: Large-scale self-supervised pre-training for full stack speech processing：XEUSの脱残響タスクの基礎となるデノイジング付きマスク予測の原典であるため。
- ML-SUPERB: Multilingual Speech Universal PERformance Benchmark：XEUSの主要評価ベンチマークであり、多言語SSLの評価設計を把握できるため。

:::


### 4. 大規模言語モデルの事前学習データ検出：divergence に基づく補正手法 {#paper-4}

🏆 Best Paper ・ Weichao Zhang, Ruqing Zhang, Jiafeng Guo, Maarten de Rijke ほか ・ [論文を読む ↗](https://arxiv.org/abs/2409.14781)

<small>原題: Pretraining Data Detection for Large Language Models: A Divergence-based Calibration Method</small>

ブラックボックスなLLMに対し、テキストが事前学習データに含まれていたかを判定する新手法DC-PDDを提案した研究です。divergence-from-randomnessの考え方でトークン確率を補正することで、Min-K% Probが苦手とする一般的な単語の多い非学習テキストの誤判定に対処し、Small Refのような追加の参照モデルやMin-K%++のような語彙全体の確率分布も必要としません。また初の中国語ベンチマークPatentMIAを整備し、BookMIAではAUCで最良の既存手法を5.4%、PatentMIAではMin-K% Probに対しTPR@5%FPRで13.2%上回った点が注目され、EMNLP 2024でBest Paperを受賞しました。

::: info 📝 落合フォーマット

**どんなもの？**

ブラックボックスなLLMに対し、与えられたテキストが事前学習データに含まれていたかを判定する「事前学習データ検出」の新手法DC-PDDを提案した研究。あわせて、中国語テキスト向けの検出ベンチマークPatentMIA（Google Patents由来、10,000件）も構築した。

**先行研究と比べてどこがすごい？**

従来のMin-K% Probは、LLMが高確率を予測しやすい一般的な単語を多く含む非学習テキストを学習データと誤判定しやすい問題があった。DC-PDDはdivergence-from-randomnessの考え方でトークン確率を補正し、Small Refのような追加の参照モデルや、Min-K%++のような語彙全体の確率分布へのアクセスを必要としない。また、既存ベンチマークが英語のみだったのに対し、中国語のベンチマークを初めて整備した。

**技術や手法のキモはどこ？**

対象LLMが出力するトークン確率分布と、公開コーパス（英語はC4、中国語はChineseWebTextの約15GB）から推定したトークン頻度分布（ラプラス平滑化あり）との間で、α_i = -p(x_i;M)·log p(x_i;D') というクロスエントロピーをトークンごとに計算する。各α_iには上限aを設けて少数トークンへの支配を防ぎ、同一トークンの2回目以降の出現は繰り返しで確率が上がるため除外して、初出トークンのみの平均をスコアβとする。βが閾値τ以上なら学習データに含まれていたと判定する。

**どうやって有効だと検証した？**

WikiMIA（OPT、Pythia、Llama、GPT-NeoX）、BookMIA（GPT-3）、PatentMIA（Baichuan-13B、Qwen1.5-14B）で、AUCとTPR@5%FPRを用いてPPL、Zlib、Min-K% Prob、Min-K%++ Probなどと比較した。BookMIAではAUCで最良の既存手法を5.4%、TPR@5%FPRで9.6%上回り、PatentMIAではMin-K% Probに対しAUCで5.4%、TPR@5%FPRで13.2%上回った。アブレーションでは上限制限（LUP）と初出トークン選択（SFO）の寄与を確認し、モデルサイズや文長が大きいほど性能が向上すること、参照コーパスの選択には比較的鈍感であることも示した。

**議論はある？**

WikiMIAの一部モデル（Llama-13Bなど）ではMin-K%++ Probの方が高いAUCで、DC-PDDが常に最良とは限らない。限界として、参照コーパスの頻度分布が実際の事前学習コーパスとどの程度近いかが不明であること、ハイパーパラメータaの最適値がモデルやデータで異なり設定指針が未確立であること、トークン確率にアクセスできないモデルには適用できないこと、実験が20B以下のモデルとGPT-3に限られることが挙げられている。今後は、コーパス単位の検出や、トークン確率以外のより信頼できる検出シグナルの探索が課題とされる。

**次に読むべき論文は？**

- Detecting Pretraining Data from Large Language Models：ベースラインのMin-K% ProbとWikiMIA/BookMIAを提案した本研究の直接の前提となる論文である。
- Min-K%++: Improved Baseline for Detecting Pre-training Data from Large Language Models：語彙全体の確率分布で正規化する別系統の補正手法であり、DC-PDDと比較して読む価値がある。
- Probabilistic models of information retrieval based on measuring the divergence from randomness：DC-PDDの着想元であるdivergence-from-randomnessの理論的背景を理解できる。

:::


### 5. Video-LLaVA: 射影前アラインメントによる統一的な視覚表現の学習 {#paper-5}

📈 被引用数上位（Paper Digest の集計で同年1位） ・ Bin Lin, Yang Ye, Bin Zhu, Jiaxi Cui ほか ・ [論文を読む ↗](https://arxiv.org/abs/2311.10122)

<small>原題: Video-LLaVA: Learning United Visual Representation by Alignment Before Projection</small>

画像と動画を言語特徴空間に事前に揃えた統一的な視覚表現として扱い、1つの大規模言語モデルで両方を理解できるLVLMベースライン Video-LLaVA を提案した研究です。画像と動画の混合データで共同学習すると両者の性能が互いに高まることを示し、動画QAではゼロショットで Video-ChatGPT を MSRVTT・MSVD・TGIF・ActivityNet のすべてで上回り、画像でも InstructBLIP-7B を5つのQAベンチマーク全てで上回りました。EMNLP 2024 の論文のうち Paper Digest の集計で被引用数が同年1位であることも、注目度の高さを示しています。

::: info 📝 落合フォーマット

**どんなもの？**

画像と動画を言語特徴空間に事前に揃えた統一的な視覚表現として扱い、1つの大規模言語モデルで画像・動画の両方を理解できるLVLMベースライン「Video-LLaVA」を提案した研究。画像と動画の混合データで共同学習し、両者が互いの性能を高め合うことを示している。

**先行研究と比べてどこがすごい？**

従来のLVLMは画像と動画を別々の特徴空間に符号化して射影層に渡すため、射影前の不整合（misalignment before projection）により LLM が相互作用を学びにくかった。本研究は「射影前アラインメント」を掲げ、LanguageBind エンコーダで画像・動画を言語空間に事前整列させたうえで共有の射影層を使う点が新しい。事前整列と画像・動画の共同学習を両立させた点が、VideoChat や Video-LLaMA、ImageBind-LLM との違いである。

**技術や手法のキモはどこ？**

画像・動画エンコーダには、OpenCLIP 初期化の LanguageBind（動画は VIDAL-10M の300万動画テキスト対で言語空間に整列）を用い、共有の2層MLP（GeLU）射影層を介して Vicuna-7B v1.5 に入力する。学習は2段階で、第1段階は LAION-CC-SBU の558K画像テキスト対と WebVid 由来の702K動画テキスト対による理解学習（射影層のみ学習）、第2段階は LLaVA 1.5 の665K画像指示データと Video-ChatGPT の100K動画指示データによる指示チューニング（LLMも学習）である。バッチ内に画像と動画を混在させ、動画は一様に8フレームをサンプリングする。

**どうやって有効だと検証した？**

動画QA（MSVD/MSRVTT/TGIF/ActivityNet）のゼロショット評価で Video-ChatGPT を MSRVTT で5.8%、MSVD で9.9%、TGIF で18.6%、ActivityNet で10.1%上回った。画像では5つのQAベンチマークと4つのツールキットで評価し、InstructBLIP-7B を5つのQAベンチマーク全てで上回り、MMBench で IDEFICS-80B を6.4%上回った。アブレーションでは、MAE や CLIP との比較で統一表現の優位性を、動画のみ学習版との比較で共同学習による動画性能の向上（MSVD で+5.9など）を示し、LLaVA-1.5†比では9ベンチマーク中8つで改善した。

**議論はある？**

一様8フレームのサンプリングでは長い動画の詳細が失われ、ActivityNet-QA では Chat-UniVi に及ばない。学習にも8基のA100-80Gで3〜4日と計算コストがかかる。今後は長い動画向けにトークンを圧縮できる効率的な共有射影、深度・赤外線など他モダリティへの拡張、時間関係を扱うタイムスタンプ埋め込みの導入が挙げられている。

**次に読むべき論文は？**

- LanguageBind: Extending Video-Language Pretraining to N-modality by Language-based Semantic Alignment：Video-LLaVA の統一視覚表現の土台となるエンコーダであり、射影前アラインメントの仕組みを理解できる。
- Video-ChatGPT: Towards Detailed Video Understanding via Large Vision and Language Models：主要な比較対象であり、動画指示データと評価パイプラインの出典である。
- Improved Baselines with Visual Instruction Tuning：Video-LLaVA の画像側の学習設定と指示データ（LLaVA-1.5）の元になっており、公平比較の基準でもある。

:::
