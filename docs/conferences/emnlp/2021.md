# EMNLP 2021

💬 自然言語処理 ・ [EMNLP の年ごとの流れ](./) ・ [公式サイト ↗](https://aclanthology.org/venues/emnlp/)

::: info この回のまとめ
2021年11月7〜11日にドミニカ共和国のプンタカナとオンラインで、EMNLP として初めてハイブリッド開催されました。投稿は過去最多の3,717本で、本会議に840本（23.3%）、Findings に419本が採択されています。投稿が多かった分野は NLP 応用、機械学習、機械翻訳と多言語、情報抽出です。最優秀長論文は、英語圏に偏った画像・言語データセットの問題を指摘し、5言語の話者が自文化の概念を選んで作った視覚推論データセット MaRVL（ケンブリッジ大学・コペンハーゲン大学ほか）でした。
:::

- **日程**: 2021年11月7日〜11日
- **開催地**: ドミニカ共和国・プンタカナ（ハイブリッド）

- **招待講演**: Ido Dagan（バル＝イラン大学）、Steven Bird（チャールズ・ダーウィン大学）、Evelina Fedorenko（MIT）

## 📝 注目論文

### 1. 言語と文化をまたぐ視覚的な推論 {#paper-1}

🏆 Best Long Paper ・ Fangyu Liu, Emanuele Bugliarello, Edoardo Maria Ponti, Siva Reddy ほか ・ [論文を読む ↗](https://arxiv.org/abs/2109.13238)

<small>原題: Visually Grounded Reasoning across Languages and Cultures</small>

ImageNet などの概念や画像が北米・西欧に偏っていることを示し、インドネシア語・スワヒリ語・タミル語・トルコ語・中国語の話者が自文化の概念と画像を選んで作ったデータセット MaRVL を構築しました。既存モデルは英語のデータより大きく性能が落ちました。

::: info 📝 落合フォーマット

**どんなもの？**

ImageNet由来の概念・画像が北米・西欧に偏っている問題を踏まえ、より多様な言語・文化を代表するImageNet風の概念階層と画像を構築する新しいプロトコルを提案した研究。これを用いて、多言語・多文化の視覚言語推論データセットMaRVL（Multicultural Reasoning over Vision and Language）を作成した。タスクは、画像ペアに関する根拠付き記述文の真偽を判定すること。

**先行研究と比べてどこがすごい？**

概念と画像の選定を自動スクレイピングではなく、すべてネイティブスピーカーが主導する点が新しい。対象はインドネシア語、中国語（北京語）、スワヒリ語、タミル語、トルコ語という類型論的に多様な言語で、英語中心の語彙データベースや画像検索に由来するバイアスを避けている。

**技術や手法のキモはどこ？**

各言語のネイティブスピーカーが、その言語・文化に即した概念を選び、対応する画像も選定してImageNet風の階層を構築する。そのうえで、ネイティブのアノテーターが画像ペアについて記述文を作成し、その文が真か偽かを判定するタスクとしてMaRVLを構成する。

**どうやって有効だと検証した？**

最先端のモデルを用いたベースラインを複数構築し、英語での教師あり性能と、他言語へのゼロショット的な言語間転移性能を比較した。その結果、言語間転移の性能は英語の教師あり性能に比べて大幅に劣ることが示された。具体的な数値は、アブストラクトのみでは確認できない。

**議論はある？**

現在の最先端モデルは、英語・西洋中心の狭い領域を超えると頑健性と精度に課題があることが示唆される。真に多言語・多文化に対応するシステムの開発に向けた新たな課題が提示された。なお、本文が取得できていないため、限界や詳細な分析についてはアブストラクトからは判断できない。

:::
