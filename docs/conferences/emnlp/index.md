# EMNLP

💬 [自然言語処理](../#nlp) ・ Conference on Empirical Methods in Natural Language Processing ・ 毎年11〜12月 ・ [公式サイト ↗](https://aclanthology.org/venues/emnlp/)

::: info 2020年からの流れ
EMNLP は経験的手法（データと実験）による NLP の国際会議で、ACL と並ぶ最高峰です。2020年に完全オンラインで開催し、本会議外の論文を掲載する Findings を導入しました。最優秀論文は無発声音声の合成（2020年）、多文化の視覚推論データセット MaRVL（2021年）、タングラムによる抽象的な視覚推論（2022年）、文脈内学習の仕組みの解明（2023年）、画像の文化的な翻案や事前学習データの検出（2024年）、インターネット規模の n-gram 検索 Infini-gram mini（2025年）、人間と LLM の答え方の比較と線形アテンションの改良（2026年）です。採択は2020年の752本から2026年には本会議と Findings を合わせ5,252本に増えました。
:::

## 📅 各回のまとめ

- **[EMNLP 2026](./2026)** — ブダペスト開催・採択5,252本。人間と LLM の答え方の違いを比べる DiscoTrace と線形アテンションの改良が最優秀論文に<br><small>2026年10月24日〜29日 ・ ハンガリー・ブダペスト</small>
- **[EMNLP 2025](./2025)** — 蘇州開催・第30回。インターネット規模のテキストを n-gram で正確に検索できる Infini-gram mini が最優秀論文に<br><small>2025年11月4日〜9日 ・ 中国・蘇州</small>
- **[EMNLP 2024](./2024)** — マイアミ開催。画像の文化的な「翻案」や数千言語の音声表現学習など5本が最優秀論文に。テーマは効率化<br><small>2024年11月12日〜16日 ・ 米国・マイアミ</small>
- **[EMNLP 2023](./2023)** — シンガポール開催・投稿4,909本。文脈内学習の仕組みを「ラベル語が錨になる」と説明した研究が最優秀長論文に<br><small>2023年12月6日〜10日 ・ シンガポール（ハイブリッド）</small>
- **[EMNLP 2022](./2022)** — アブダビ開催・投稿4,190本。タングラム（図形パズル）で抽象的な視覚推論を調べる KiloGram が最優秀論文に<br><small>2022年12月7日〜11日 ・ アラブ首長国連邦・アブダビ（ハイブリッド）</small>
- **[EMNLP 2021](./2021)** — プンタカナとオンラインで初のハイブリッド開催。多言語・多文化の視覚推論データセット MaRVL が最優秀長論文に<br><small>2021年11月7日〜11日 ・ ドミニカ共和国・プンタカナ（ハイブリッド）</small>
- **[EMNLP 2020](./2020)** — 初のオンライン開催・投稿3,677本。声を出さない口の動きを電極で捉えて音声にする研究が最優秀論文に<br><small>2020年11月16日〜20日 ・ オンライン開催</small>

## 🔭 年ごとのテーマの移り変わり

- 2020: 初のオンライン開催、Findings の導入、無発声音声の合成
- 2021: 初のハイブリッド開催、多言語・多文化の視覚推論（MaRVL）
- 2022: 抽象的な視覚推論（KiloGram）、言語モデルの分析が主要トラックに
- 2023: 文脈内学習の解明、LLM と検索・論理推論器の組み合わせ
- 2024: 画像の文化的な翻案、勾配の解釈、事前学習データの検出、効率化テーマ
- 2025: 学習データの正確な検索とベンチマーク汚染、CoT の忠実性
- 2026: 人間と LLM の答え方の比較、線形アテンション、エージェントと評価の論文が急増

::: tip 💡 技術動向への示唆
- 学習データの検出・検索やベンチマーク汚染の研究が連続して最高賞を得ており、LLM の性能比較では「評価データを学習していないか」の確認が前提になった
- 多文化・多言語の研究が毎年のように表彰されており、EMNLP の受賞論文はグローバル展開する言語 AI の課題を知るのに向いている
:::
