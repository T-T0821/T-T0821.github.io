### DeepStress: 深層検索エージェントのストレステスト

[DeepStress: Stress-Testing Deep Search Agents](https://arxiv.org/abs/2607.13920) ・ Hugging Face Daily Papers ・ Ismael Rousseau, Geraldine Damnati, Frederic Bechet

検索エージェントに、信頼性・関連性・事実性を独立に制御した劣化証拠を与える動的なストレステスト枠組みを提案している。最終回答を5分類し、慎重な行動を評価する指標 RAS と CoPRAS も導入した。

**注目ポイント:** 検索・RAG 型エージェントが低品質な根拠にどう振る舞うかを再現可能に測れる点が実務に役立つ。

### ScrapeBench: AI エージェントのスクレイピング規約遵守評価

[ScrapeBench: Evaluating Legal Compliance of AI Agents in Website Scraping](https://arxiv.org/abs/2611.11306) ・ Hugging Face Daily Papers ・ Joseph Marvin Imperial, Daniel Slate, Noam Kolt

利用規約や robots.txt に対する AI エージェントの遵守度を評価する最初のエージェント型ベンチマークである。スクレイピングを禁止する1,626サイトで、多くのエージェントの遵守率は5%未満だった。

**注目ポイント:** Web 上で動くエージェントの法的・契約上のリスクを定量的に示している。

### LLM から効率的な System One モデルへ: 適応的計算

[From Large Language Models to Efficient System One Models via Adaptive Computation](https://arxiv.org/abs/2611.16321) ・ Hugging Face Daily Papers ・ Minh-Anh Nguyen

LLM を意思決定モデルに転用する際、判断情報は中間層に集中し、最終6層は性能を損なわず除去できると報告している。深さ方向で計算を共有するプレフィックス部分モデルを同時学習する手法を提案している。

**注目ポイント:** 判断用途で LLM の推論コストを下げる設計指針を示している。

### SteerDistill: 教師による閉ループ誘導で LLM エージェントを量子化

[SteerDistill: Quantizing LLM Agents via Closed-Loop Teacher Steering](https://arxiv.org/abs/2611.13410) ・ Hugging Face Daily Papers ・ Genming Cui, Xiangyu Li, Zixu Hao, Xin Ding ほか

低ビット量子化したエージェントは、タスク要件や環境条件を見落として失敗しやすいと分析している。フル精度の教師が失敗応答の修正を誘導し、生徒の実行結果で指示を改善する量子化対応蒸留を提案した。

**注目ポイント:** エージェントの推論コスト削減と成功率維持の両立に関わる。
