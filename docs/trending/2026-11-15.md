- **CLI と構成:** `@astryxdesign/cli` がコンポーネントのドキュメント参照、テンプレート、スキャフォールド、テーマ、codemod を提供します。パッケージは core / cli / build / themes に分かれています。chart 系（`@astryxdesign/vega`、`@astryxdesign/charts`）は `@canary` タグのみで、安定版はまだありません。

**使いどころ:** React 19 以上のプロジェクトで、アクセシビリティ対応済みのコンポーネント群をベースに、ブランドに合わせたテーマ適用や深いカスタマイズを行いたい場合に向きます。Claude Code などの AI コーディングエージェントと並走する開発でも、CLI 経由で同じドキュメントを参照できます。ただし現在は Beta である点に注意が必要です。

**始め方:**
```bash

npm install -D @astryxdesign/cli
```
その後、CSS の import とテーマプロバイダの設定が必要です。Next.js、Tailwind、Vite、CDN 向けの詳細は `packages/core/README.md` の Quick Start を参照してください。

Windows・Linux・macOS 向けの、Rust 製オープンソース（GPL-3.0）のダウンロードマネージャーで、IDM（Internet Download Manager）に近い操作感を目指したものです。

## 4. morluto/rea {#morluto-rea}

★ 459,814（今週 +16,095） ・ TypeScript ・ MIT ・ [GitHub ↗](https://github.com/morluto/rea) ・ [Website ↗](https://rea.tools)

::: tip 一言で
エージェント（Claude Code、Codex、Cursor など）から MCP 経由でネイティブバイナリ、JavaScript/Electron アプリ、.NET アセンブリ、Web サイトなどを解析できるようにする、リバースエンジニアリング用ツール群（CLI も同等機能を提供）。
:::

> Reverse engineer anything with agents, from app behavior down to native binaries.

::: v-pre

**解決する課題:** ソースコードのないアプリの機能がどう動くかを調べるには、逆アセンブラやデコンパイラ、パケット解析ツールなどを個別に使い分ける必要があります。REA はこれらを 1 つの MCP サーバーにまとめ、エージェントが調査・根拠の提示・実装の試作までを一貫して行えるようにします。解析結果には、各結論の根拠と限界が併せて返されると README に記載されています。

**技術的なポイント:**
- TypeScript 製の MCP サーバーで、npm パッケージ `rea-agents` として配布。Node.js 22.x / 24.x / 26.x と npm が必須。解析はローカルで実行される。
- ネイティブ解析は既存の Hopper、Ghidra、IDA、Kuna を利用し、擬似コード、アセンブリ、文字列、シンボル、参照関係を取得する。Hopper はセットアップ時に承認のうえインストールも可能。
- 対象が非常に幅広い。Go/Rust バイナリ、PE 証明書・インポート、GPU コードオブジェクト、GGUF/safetensors、IL2CPP メタデータ、Godot PCK、SQLite、WASM、EVM バイトコード、APK（JADX）、ADB 実機、ファームウェア（Binwalk/Unblob）、HAR/pcap などを扱える。多くは組み込みの静的解析で、外部ツール不要。一部は WABT、pwntools、TShark などの外部ツールが必要。
- JavaScript/Electron の静的解析は、ネイティブ解析エンジンなしで動作し、モジュール、インポート、ソースマップ、ルート、IPC、Electron の境界などを返す。
- MCP の入力スキーマはコンテキスト節約のためデフォルトでコンパクト。環境変数で full に切り替えられ、出力スキーマも compact/off に設定できる。
- セットアップは変更内容の確認と承認を経て、既存設定のバックアップを取りつつ MCP サーバー登録とワークフロー指示を追加する。Claude Code / Codex のプラグインや Cursor Marketplace のプラグインもある。
- 注意点: Linux では Ghidra、JADX、静的 JavaScript/Electron 解析などに procps 互換の `ps` が必要。README には公式配布元以外を信用しないよう注意書きがある。

**使いどころ:** 他社アプリの気になる機能の仕組みを、ソースなしで根拠付きに把握し、自分のプロジェクトへの実装の参考にしたい場合。また、マルウェアやファームウェア、Android アプリなど複数種類の成果物を、エージェントを使って横断的に調査したい場合。

**始め方:**
```bash
# エージェントへのセットアップ（確認・承認後、エージェントを再起動）
npx rea-agents setup

# 展開済みの JavaScript/Electron アプリを CLI で解析する例
npx -y rea-agents@latest analyze-javascript-application /absolute/path/to/app --json

# CLI を常用する場合
npm install --global rea-agents
rea --help
```

:::

## 5. huamidev/GestaltX {#huamidev-gestaltx}

★ 7,558（今週 +7,480） ・ Swift ・ GPL-3.0 ・ [GitHub ↗](https://github.com/huamidev/GestaltX)

::: tip 一言で
iOS / iPadOS 27.x 上で MobileGestalt（デバイスの機能フラグやモデル情報を保持するシステムキャッシュ）を直接読み書きできる、SwiftUI 製の編集アプリです。
:::

> An MobileGestalt editor for iOS 27.x, featuring region-code tweaks, device presets, backups, and support for 7 languages.

::: v-pre

**解決する課題:** MobileGestalt の値は Dynamic Island、Always-On Display、Camera Control、リージョンコードなどデバイスの機能表示に関わりますが、通常は手作業で plist を編集するしかありません。GestaltX はそれらをプリセットとして GUI から切り替え、`CacheExtra` の任意フィールドも編集できるようにします。書き込み前の自動バックアップと検証付き書き込みを備え、変更の取り消しもしやすくなっています。

**技術的なポイント:**
- Swift / SwiftUI 製で、オンデバイスの MobileGestalt アクセスには [worse_query](https://github.com/forcequitOS/worse_query) を利用しています。SystemGroup へのアクセスは iOS 27 が必要で、iOS 26.x ではオンデバイスアクセス非対応と明記されています。
- 機能は 2 系統あります。プリセット（Display、Device、iPad、Intelligence、Advanced）と、`CacheExtra` の汎用フィールドエディタです。後者は String / Integer / Real / Boolean / Data / Date / Array / Dictionary を扱え、plist のインポート／エクスポートにも対応します。
- 安全面の設計が手厚く、初回の自動バックアップ、書き込みごとのバックアップ、元の値と型の記録、書き込み後の検証、プリセット単位の復元があります。元々存在しなかったキーは復元時に削除されます。
- plist インポートは共有エクステンション経由（App Group で受け渡し）で行い、端末固有の識別子（2 つ以上）か GestaltX のエクスポートに含まれる端末紐付けの証明で本人性を検証し、検証できないファイルは拒否します。
- Apple Intelligence 関連は、ハードウェア情報（product / board / CPU）を偽装しない実験的フラグ設定です。過去の偽装で Face ID や音声入力が壊れた場合に備えた「Restore Hardware Identity」もありますが、現状 iPhone 11〜15/15 Plus（SE 第 2・第 3 世代を含む）のみ対応で、効果の保証はなく端末依存です。
